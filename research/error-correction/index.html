Chapter 5

5 Quantum error correction

Quantum codes, syndrome measurement, decoding, and fault-tolerant logical operations.

Scope and methods

An error-correcting code stores logical information in a subspace of several physical systems. Carefully chosen measurements reveal information about errors while avoiding a direct measurement of the protected logical state.

Fault tolerance extends this idea to imperfect operations, measurements, and recovery procedures. Code properties, connectivity, and decoding all contribute to the practical cost. Different code families make different tradeoffs.
