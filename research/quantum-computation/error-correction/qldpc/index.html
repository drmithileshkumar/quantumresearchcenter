Research topic

Quantum low-density parity-check codes

Quantum low-density parity-check codes, decoding algorithms, and implementation overhead.

Scope and methods

Quantum low-density parity-check codes use sparse sets of checks to constrain errors. Some constructions offer attractive encoding rates, but code parameters alone do not determine whether an implementation is practical.

Research combines mathematical code design with syndrome circuits, connectivity, decoding, and logical operations. Comparisons must use compatible noise models and account for the full implementation rather than only stored qubits.

Open problems

  • Which low-overhead constructions remain favorable after routing and syndrome extraction are included?
  • How can efficient decoding and a useful set of logical operations be realized together?

Selected references

  1. High-threshold and low-overhead fault-tolerant quantum memory

    Sergey Bravyi et al.. 2023. Research paper

    Studies a low-overhead memory protocol with explicit code, connectivity, decoding, and noise assumptions.

  2. Stabilizer Codes and Quantum Error Correction

    Daniel Gottesman. 1997. Doctoral thesis

    Develops the stabilizer framework used to describe many quantum error-correcting codes.

  3. Quantum error correction at ultra-low overhead

    Zhide Lu, Weikang Li, Dong-Ling Deng. 2026. Preprint / numerical study

    Proposes a high-rate code family with a hardware-oriented syndrome schedule; its reported performance depends on the simulated noise and architecture assumptions.
