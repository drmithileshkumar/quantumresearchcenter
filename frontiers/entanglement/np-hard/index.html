Deciding separability is NP-hard

Proved, with a source.

Gurvits proved hardness for states within an inverse exponential distance of the separable set. Gharibian extended it to an inverse polynomial distance. So no efficient general test is expected unless P = NP, which is consistent with the hierarchy above having no fixed cut-off level.
