How these tools are built

Each model is a small programme that runs in the page: no account, no server, and no tracking. Where a drawing depends on a physical parameter, the static page still shows a meaningful state, and the controls always have a keyboard path — sliders for continuous values, buttons for everything else.

They are companions to the courses and the research handbook. If a model contradicts your calculation, the calculation is the arbiter.
