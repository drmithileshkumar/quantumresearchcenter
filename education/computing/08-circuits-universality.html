Chapter 08

Quantum Circuits and Universality

The algorithms so far were described with whole operations: an oracle, a reflection, a Hadamard on every qubit. A real quantum computer applies a fixed set of elementary gates, each acting on one or two qubits. Before an algorithm’s advantage can be trusted, its operations must be built from such gates, and their cost counted.

We begin with circuit diagrams, which record which gate acts on which qubit and in what order, and with the difference between a coherent control and a control by a measured bit. We then build the gates the algorithms used: rotations, controlled gates, oracles, and reflections. This raises the question of universality. One-qubit gates alone can never entangle, but adding one entangling gate allows every operation to be built, and a finite set allows every operation to be approximated. Universality says nothing about cost, so we finish by counting resources: gates, depth, qubits, the connections between qubits, and the errors that accumulate in long circuits.

The next chapter uses these costs to ask when a quantum advantage is real.

What separates an operation we can describe mathematically from one we can construct with finite means?

Every quantum operation can be built from a few kinds of gate, but not every operation can be built cheaply.

Reading guide · preparation, aims, and assumptions

Translate abstract operations into circuits and account for the work hidden inside a gate box.

Before you begin

Use the query and search algorithms from Chapters 6 and 7.

What you should be able to do

  • Read circuit order and controlled operations.
  • Distinguish exact construction from approximation.
  • Count gates, depth, and workspace separately.

The example to follow

Decompose the controlled phase and reflections already used in search instead of treating them as free operations.

Scope and assumptions

A finite discrete gate set generally approximates arbitrary unitaries; universality does not imply every transformation has a short exact circuit.

8.1

Circuit Representation

The algorithms so far were written as products of operators. A circuit diagram shows the same products in a form that makes their structure visible: which operation acts on which qubit, and in what order. Read as circuits, Deutsch’s algorithm and search show how much is hidden inside a single box such as an oracle. A diagram must also show where measurements occur and how their results control later gates, which distinguishes two kinds of control.

8.1.1 Wires and gate ordering§

A circuit draws one wire for each qubit and a box for each operation, with time running left to right. A wire identifies a subsystem; it need not carry a definite zero or one. In an entangled computation, follow the joint state of all wires.

If \(U\) acts first and \(V\) second, the state becomes \(VU\ket\psi\). The drawing’s time order and the matrix product’s right-to-left action describe the same sequence.

Gates on disjoint wires commute: \((U\otimes I)(I\otimes V)=U\otimes V\). Gates sharing a wire generally do not. This lets us recognize possible parallel work in the diagram, while leaving physical scheduling to the hardware model.

Problems

  1. A circuit applies \(H\) to qubit 1, then \(X\) to qubit 2, then CNOT with qubit 1 as control and qubit 2 as target, starting from \(\ket{00}\). Write the state after each step.

    Show solutionHide solution

    \(H\): \((\ket{00}+\ket{10})/\sqrt2\). \(X\) on qubit 2: \((\ket{01}+\ket{11})/\sqrt2\). CNOT flips qubit 2 where qubit 1 is \(1\): \((\ket{01}+\ket{10})/\sqrt2\).

  2. Apply, to \(\ket{00}\), first \(H\) on qubit 1 and then CNOT, and in the other order. Do the two operations commute?

    Show solutionHide solution

    \(H\) then CNOT gives \((\ket{00}+\ket{11})/\sqrt2\). CNOT then \(H\) gives \((\ket{00}+\ket{10})/\sqrt2\), because CNOT leaves \(\ket{00}\) unchanged. They do not commute; the two gates share qubit 1.

  3. Prove that \((U\otimes I)(I\otimes V)=(I\otimes V)(U\otimes I)=U\otimes V\): gates on different wires commute.

    Show solutionHide solution

    On a product state \(\ket a\ket b\), both orders give \(U\ket a\otimes V\ket b\), which is also \((U\otimes V)\ket a\ket b\). The three matrices agree on every product basis state, and every state is a combination of these, so by linearity they are equal.

8.1.2 Circuits for query and search algorithms§

Read the algorithms we have met as circuits. In Deutsch’s circuit, the first pair of \(H\) gates prepares \(\ket+\ket-\), the oracle box puts the function into signs, and the last \(H\) exposes their relation. In search, a block consisting of the phase oracle and the reflection \(D\) is repeated.

Does a box labelled \(O_f\) tell us how to build \(O_f\)? No. Drawing an operation as a single box does not make it a single elementary gate; its cost is unknown until we say how it is implemented.

Problems

  1. In the four-item search circuit, how many oracle uses and how many Hadamard gates does one Grover iteration contain, and how many Hadamard gates prepare the start?

    Show solutionHide solution

    One iteration has one oracle use, the first controlled-\(Z\), and four Hadamard gates in the reflection, two before and two after the reflection about \(\ket{00}\). Two more Hadamard gates prepare \(\ket s\) from \(\ket{00}\).

  2. List the gates of Deutsch’s algorithm in time order, starting from \(\ket{00}\), with the qubits each acts on.

    Show solutionHide solution

    \(X\) on qubit 2; \(H\) on qubit 1 and \(H\) on qubit 2, which can act at the same time; \(U_f\) on qubits 1 and 2; \(H\) on qubit 1; measurement of qubit 1.

  3. An oracle box \(O_f\) on \(n\) qubits marks one fixed string. It is built from \(X\) gates and a phase flip controlled on all \(n\) qubits, which in turn uses Toffoli gates and \(n-2\) workspace qubits. Count the gates in such a construction.

    Show solutionHide solution

    Up to \(n\) \(X\) gates before and \(n\) after, on the positions where the string has \(0\). The phase flip computes the AND of \(n-1\) qubits into the workspace with \(n-2\) Toffoli gates, applies a controlled-\(Z\) between the last workspace qubit and the remaining qubit, and uncomputes with \(n-2\) more Toffoli gates. Altogether about \(2n\) \(X\) gates, \(2(n-2)\) Toffoli gates, and one controlled-\(Z\): one box hides a number of gates proportional to \(n\).

8.1.3 Measurement and classical control§

A measurement symbol produces a classical outcome. The qubit itself may remain available in its conditional post-measurement state; the symbol does not mean that the physical system ceases to exist. In these drawings, solid lines carry quantum systems and dashed lines carry classical records.

A classically controlled correction chooses a gate using a recorded bit. A coherent controlled gate instead acts on an unmeasured control and can preserve a superposition of branches.

Teleportation uses both kinds of control. Alice’s CNOT is coherent. Bob’s correction is selected after receiving her classical outcomes. Replacing the first by a measurement-controlled flip would change the protocol; replacing the second requires retaining and handling the outcomes coherently, rather than simply deleting the message.

Problems

  1. Bob receives a bit \(b\) and applies \(X\) only if \(b=1\). Write his operation for each value of \(b\).

    Show solutionHide solution

    \(b=0\): the identity \(I\). \(b=1\): \(X\). The bit is known when the gate is chosen, so this is a classical choice, not a quantum gate.

  2. For the input \((\alpha\ket0+\beta\ket1)\ket0\), compare (a) CNOT followed by measuring the control with (b) measuring the control first and then applying \(X\) to the target if the result is \(1\). Show that the outcomes and final states agree.

    Show solutionHide solution

    (a) CNOT gives \(\alpha\ket{00}+\beta\ket{11}\). Measuring the control gives \(0\) with probability \(|\alpha|^2\), leaving \(\ket{00}\), and \(1\) with probability \(|\beta|^2\), leaving \(\ket{11}\). (b) Measuring first gives the same probabilities, leaving \(\ket{00}\) or \(\ket{10}\), and the classical \(X\) turns \(\ket{10}\) into \(\ket{11}\). The results agree: a measurement of the control may be moved past a gate that it controls.

  3. Now the control is not measured at the end. Compare CNOT with “measure the control, then apply \(X\) if \(1\)” on the input \(\ket+\ket-\), by applying \(H\) to the control afterward and measuring it.

    Show solutionHide solution

    CNOT gives \(\ket-\ket-\), by phase kickback; \(H\) on the control gives \(\ket1\), so the result is \(1\) with certainty. Measuring first leaves the control in \(\ket0\) or \(\ket1\), with the target still \(\ket-\), up to sign; \(H\) then gives \(0\) or \(1\) with probability \(1/2\). A classically controlled gate is not a substitute for a coherent one when the control’s phase matters.

8.2

Gate Constructions

The algorithms used rotations of single qubits, controlled gates, phase oracles, and reflections. We now build each from standard gates: first single-qubit gates, then gates in which one qubit controls another, which are the gates that entangle. Combining these with the pattern of computing, applying a phase, and uncomputing gives the oracles and the reflection used in search.

8.2.1 Pauli, Hadamard, and rotation gates§

Which one-qubit gates do we need? We have met three:

\[X=\begin{pmatrix}0&1\\1&0\end{pmatrix},\quad Z=\begin{pmatrix}1&0\\0&-1\end{pmatrix},\quad H=\frac1{\sqrt2}\begin{pmatrix}1&1\\1&-1\end{pmatrix}.\]

A fourth, \(Y=\begin{pmatrix}0&-i\\i&0\end{pmatrix}\), completes the Pauli matrices \(I\), \(X\), \(Y\), and \(Z\).

Fixed gates turn a qubit by fixed amounts. A general operation, such as the half of a NOT met earlier, needs turns of any size. For a Pauli matrix \(P\), define the rotation gate

\[R_P(\theta)=\cos\tfrac\theta2\,I-i\sin\tfrac\theta2\,P.\]

Is it unitary? Since \(P^\dagger=P\) and \(P^2=I\), we get \(R_P(\theta)^\dagger R_P(\theta)=\cos^2\tfrac\theta2\,I+\sin^2\tfrac\theta2\,P^2=I\). It is.

Two fixed rotations will matter when gates must come from a finite set: the phase gates \(S=\operatorname{diag}(1,i)\) and \(T=\operatorname{diag}(1,e^{i\pi/4})\). Here \(S\) names the conventional phase gate, not the square root of NOT from Chapter 3. These gates change the relative phase of \(\ket1\) by \(\pi/2\) and by \(\pi/4\).

Predict first. Starting from \(\ket0\), compare applying \(H\) twice with applying \(H\), then \(Z\), then \(H\). Predict both final measurement distributions before trying the gates.

Experiment: a gate changes amplitudes

After trying it: compare your explanation

\(H\) followed by \(H\) returns \(\ket0\), so 0 is certain. \(H\), \(Z\), \(H\) produces \(\ket1\), so 1 is certain. \(Z\) changes a relative sign that the final \(H\) converts into a different outcome.

Problems

  1. Compute \(R_X(\pi)\) and \(R_Z(\pi)\), and compare them with \(X\) and \(Z\).

    Show solutionHide solution

    \(R_P(\pi)=\cos\tfrac\pi2I-i\sin\tfrac\pi2P=-iP\). So \(R_X(\pi)=-iX\) and \(R_Z(\pi)=-iZ\): the Pauli gates, up to the global phase \(-i\).

  2. Verify by multiplying matrices that \(HZH=X\), \(HXH=Z\), \(S^2=Z\), and \(T^2=S\).

    Show solutionHide solution

    \(HZ=\tfrac1{\sqrt2}\begin{pmatrix}1&-1\\1&1\end{pmatrix}\), and multiplying by \(H\) gives \(\begin{pmatrix}0&1\\1&0\end{pmatrix}=X\). Similarly, \(HXH=Z\). For the phase gates, \(S^2=\operatorname{diag}(1,i^2)=\operatorname{diag}(1,-1)=Z\) and \(T^2=\operatorname{diag}(1,e^{i\pi/2})=\operatorname{diag}(1,i)=S\).

  3. Show that \(R_Z(\theta)=\operatorname{diag}(e^{-i\theta/2},e^{i\theta/2})\), and that up to a global phase it is \(\operatorname{diag}(1,e^{i\theta})\). Which values of \(\theta\) give \(S\) and \(T\)?

    Show solutionHide solution

    \(\cos\tfrac\theta2I-i\sin\tfrac\theta2Z=\operatorname{diag}\bigl(\cos\tfrac\theta2-i\sin\tfrac\theta2,\;\cos\tfrac\theta2+i\sin\tfrac\theta2\bigr)=\operatorname{diag}(e^{-i\theta/2},e^{i\theta/2})\). Factoring out \(e^{-i\theta/2}\) leaves \(\operatorname{diag}(1,e^{i\theta})\). So \(S\) is \(R_Z(\pi/2)\) and \(T\) is \(R_Z(\pi/4)\), each up to a global phase.

8.2.2 Controlled and entangling gates§

How do we make a gate act on a target only when a control qubit is \(1\)? Use the projectors onto the two values of the control:

\[\text{controlled-}U=\ket0\bra0\otimes I+\ket1\bra1\otimes U.\]

It keeps the control and applies \(U\) to the target in the branch where the control is \(1\).

CNOT is controlled-\(X\). Controlled-\(Z\) multiplies only \(\ket{11}\) by \(-1\). Can one be made from the other? Since \(HXH=Z\), applying \(H\) to the target before and after a CNOT gives controlled-\(Z\).

Do controlled gates always entangle? Not on every input: CNOT leaves \(\ket0\ket0\) a product state. On \(\ket+\ket0\), however, it produces a Bell state.

Problems

  1. Apply controlled-\(Z\) to the four basis states. Show that exchanging the roles of control and target gives the same operation.

    Show solutionHide solution

    It fixes \(\ket{00}\), \(\ket{01}\), and \(\ket{10}\), and sends \(\ket{11}\) to \(-\ket{11}\): the matrix \(\operatorname{diag}(1,1,1,-1)\). The sign appears exactly when both qubits are \(1\), a condition symmetric in the two qubits.

  2. Verify that \((I\otimes H)\,\mathrm{CNOT}\,(I\otimes H)\) acts as controlled-\(Z\) on \(\ket{10}\) and \(\ket{11}\).

    Show solutionHide solution

    \(\ket{10}\to\ket1\ket+\to\ket1X\ket+=\ket1\ket+\to\ket{10}\). \(\ket{11}\to\ket1\ket-\to\ket1X\ket-=-\ket1\ket-\to-\ket{11}\). Only \(\ket{11}\) gains the sign, as for controlled-\(Z\).

  3. Let \(\ket v\) be an eigenvector of \(U\) with \(U\ket v=e^{i\phi}\ket v\). Show that controlled-\(U\) sends \(\ket+\ket v\) to \(\tfrac1{\sqrt2}(\ket0+e^{i\phi}\ket1)\otimes\ket v\). Is the result entangled?

    Show solutionHide solution

    Controlled-\(U\) leaves \(\ket0\ket v\) unchanged and sends \(\ket1\ket v\) to \(\ket1U\ket v=e^{i\phi}\ket1\ket v\). By linearity, \(\ket+\ket v\) becomes \(\tfrac1{\sqrt2}(\ket0+e^{i\phi}\ket1)\otimes\ket v\), a product state. The eigenvalue moves onto the control as a relative phase; phase kickback in Deutsch’s algorithm is the case \(U=X\), \(\ket v=\ket-\), \(\phi=\pi\).

8.2.3 Oracle and reflection circuits§

How is a phase oracle built? To mark one bit string, flip with \(X\) each of its positions that is \(0\), apply a phase flip controlled on all qubits being \(1\), and undo the flips. For a predicate computed by a circuit, use compute, phase, uncompute.

And the reflection \(D\)? Since \(H^{\otimes n}\) maps \(\ket{0^n}\) to \(\ket s\), we can reflect about \(\ket{0^n}\) between two layers of Hadamards:

\[D=H^{\otimes n}\bigl(2\ket{0^n}\bra{0^n}-I\bigr)H^{\otimes n}.\]

The two-qubit drawing implements the reflection about \(\ket{00}\) with \(X\) gates and a controlled-\(Z\), and so produces \(-D\). The sign is a global phase and changes nothing in an ordinary Grover iteration; it would matter if the iteration were itself controlled.

Problems

  1. Which gates mark the string \(01\) on two qubits, that is, multiply \(\ket{01}\) by \(-1\) and leave the other basis states alone?

    Show solutionHide solution

    \(X\) on qubit 1, controlled-\(Z\), then \(X\) on qubit 1. The first \(X\) turns \(\ket{01}\) into \(\ket{11}\), controlled-\(Z\) gives it the sign, and the second \(X\) restores the label. Every other basis state avoids \(\ket{11}\) and is unchanged.

  2. For two qubits, verify that \((H\otimes H)(2\ket{00}\bra{00}-I)(H\otimes H)\) and \(2\ket s\bra s-I\) agree on \(\ket{00}\).

    Show solutionHide solution

    Left side: \((H\otimes H)\ket{00}=\ket s\); the reflection gives \(2\ket{00}\braket{00}s-\ket s=\ket{00}-\ket s\), since \(\braket{00}s=\tfrac12\); and \(H\otimes H\) gives \(\ket s-\ket{00}\). Right side: \(2\ket s\braket s{00}-\ket{00}=\ket s-\ket{00}\). They agree.

  3. Show that \((X\otimes X)\,CZ\,(X\otimes X)=-(2\ket{00}\bra{00}-I)\). Why does this sign not matter in an ordinary Grover iteration, and when would it matter?

    Show solutionHide solution

    Conjugating by \(X\otimes X\) moves the sign of controlled-\(Z\) from \(\ket{11}\) to \(\ket{00}\), giving \(\operatorname{diag}(-1,1,1,1)=-\operatorname{diag}(1,-1,-1,-1)=-(2\ket{00}\bra{00}-I)\). In a Grover iteration the factor \(-1\) is a global phase and changes no probability. If the iteration were controlled by another qubit, the sign would apply only in the branch where the control is \(1\), becoming a relative phase that affects later interference.

8.3

Universal Gate Sets

Having built particular operations, we ask whether every operation can be built from a fixed collection of gates, and what such a collection requires. Entanglement sets the first requirement. Real hardware sets the second: it offers only finitely many gates, which forces us to say what building an operation means when exact construction is impossible.

8.3.1 Limits of local operations§

Can one-qubit gates alone produce every operation? A circuit of one-qubit gates acts as \(U_1\otimes\cdots\otimes U_n\). On a product state it gives another product state:

\[(U_1\otimes\cdots\otimes U_n)(\ket{\psi_1}\otimes\cdots\otimes\ket{\psi_n})=U_1\ket{\psi_1}\otimes\cdots\otimes U_n\ket{\psi_n}.\]

It can never prepare a Bell state from \(\ket{00}\), however many gates it uses. The argument settles the question without counting anything: a universal set needs a gate that lets qubits affect one another.

Problems

  1. Apply \(H\otimes H\) to \(\ket{00}\), and check that the result is a product state.

    Show solutionHide solution

    \((H\otimes H)\ket{00}=\ket+\ket+=(\ket{00}+\ket{01}+\ket{10}+\ket{11})/2\), a product of the two local states.

  2. A circuit applies \(H\) to qubit 1, then \(X\) to qubit 2, then \(H\) to qubit 1 again. Find the result on \(\ket{00}\), and explain why it had to be a product state.

    Show solutionHide solution

    The two \(H\) gates cancel on qubit 1, and \(X\) acts on qubit 2, so the result is \(\ket{01}\). Every gate acts on one qubit, so the circuit is \((HH)\otimes X\), which maps product states to product states.

  3. Show that one-qubit operations cannot turn an entangled two-qubit state into a product state.

    Show solutionHide solution

    Suppose \((A\otimes B)\ket\Phi=\ket u\otimes\ket v\) for unitaries \(A,B\). Applying \(A^\dagger\otimes B^\dagger\) gives \(\ket\Phi=A^\dagger\ket u\otimes B^\dagger\ket v\), a product state, contradicting the assumption that \(\ket\Phi\) is entangled. Local operations can neither create nor remove entanglement.

8.3.2 Entangling gates and universality§

CNOT together with arbitrary one-qubit unitaries can construct every finite-register unitary. This is a universality theorem about the whole set; possessing one entangling gate with no adequate local controls is not enough.

One proof first decomposes a unitary into transformations acting on pairs of basis states, then builds those transformations from controlled operations and one-qubit gates. We state the theorem here; its full synthesis proof is beyond the algorithms we need.

Universality settles possibility, not cost. A generic \(n\)-qubit unitary has exponentially many parameters and typically needs an exponentially long circuit. Useful algorithms work because their operations have additional structure. Our oracle and reflection constructions are examples of that structure made explicit.

Further detail: Barenco et al.: Elementary gates for quantum computation.

Problems

  1. Which of these gate sets can prepare a Bell state from \(\ket{00}\): \(\{H,X,Z\}\); \(\{H,\text{CNOT}\}\); \(\{\text{CNOT},X\}\)?

    Show solutionHide solution

    Only \(\{H,\text{CNOT}\}\). The first set has only one-qubit gates, which keep product states. The third has only permutations of basis states, which never create a superposition.

  2. Show that circuits of CNOT and \(X\) gates only permute computational basis states.

    Show solutionHide solution

    Each gate sends every basis state to a basis state and is one-to-one, so its matrix is a permutation matrix. A product of permutation matrices is a permutation matrix, so the whole circuit permutes the basis states, and from \(\ket{00}\) it reaches only another basis state.

  3. A reversible circuit on \(m\) wires uses \(g\) gates, each an \(X\), CNOT, or Toffoli on chosen wires. Show that there are at most \((3m^3)^g\) such circuits, and deduce that most Boolean functions of \(n\) bits need at least about \(2^n/\log_2(3m^3)\) gates.

    Show solutionHide solution

    Each gate is one of three types placed on at most \(m^3\) choices of wires, so there are at most \(3m^3\) choices per gate and \((3m^3)^g\) circuits of \(g\) gates. There are \(2^{2^n}\) Boolean functions of \(n\) bits, and a circuit computes one function on a chosen output wire, so computing all of them needs \((3m^3)^g\geq2^{2^n}\), that is, \(g\geq2^n/\log_2(3m^3)\). For \(n=20\) and \(m=30\), this is about \(64{,}000\) gates. Universality guarantees that every function can be built, not that it can be built cheaply.

8.3.3 Exact synthesis and approximation§

A finite gate alphabet produces only countably many finite circuits, while unitaries vary continuously. Exact synthesis of every unitary is therefore impossible. Approximation is the useful goal: a suitable set, such as Clifford+T, approximates arbitrary quantum operations up to a global phase.

Choose consistent phase representatives and ask for \(\|U-V\|\leq\epsilon\). This operator-norm bound guarantees that the two output vectors differ by at most \(\epsilon\) on every unit input. If the operation will itself be controlled, its relative phase must be specified; it cannot simply be discarded as a global phase of the larger circuit.

A circuit with \(L\) approximated gates has total operator-norm error at most \(\sum_i\epsilon_i\). To meet a budget \(\epsilon\), one simple allocation gives each gate tolerance \(\epsilon/L\). The triangle-inequality proof appears in the problems.

An approximation claim therefore has two parts: can we reach the requested tolerance, and how many gates does doing so require? Universality answers only the first.

Problems

  1. Each of \(1000\) gates is approximated within \(10^{-6}\). What error bound holds for the whole circuit?

    Show solutionHide solution

    Errors add at most, so the bound is \(1000\times10^{-6}=10^{-3}\).

  2. A circuit has \(10^6\) gates and its total error must be at most \(10^{-2}\). What accuracy must each gate have if the error is split equally?

    Show solutionHide solution

    \(10^{-2}/10^6=10^{-8}\) per gate.

  3. Prove that \(\|U_2U_1-V_2V_1\|\leq\|U_2-V_2\|+\|U_1-V_1\|\) for unitaries \(U_1,U_2,V_1,V_2\).

    Show solutionHide solution

    Write \(U_2U_1-V_2V_1=U_2(U_1-V_1)+(U_2-V_2)V_1\). For every unit vector \(v\), \(\|U_2(U_1-V_1)v\|=\|(U_1-V_1)v\|\leq\|U_1-V_1\|\), since \(U_2\) preserves length, and \(\|(U_2-V_2)V_1v\|\leq\|U_2-V_2\|\), since \(V_1v\) is a unit vector. The triangle inequality gives the result; repeating the argument covers \(L\) gates.

8.4

Implementation Resources

Universality says that an operation can be built, but not at what cost. An advantage is a statement about cost, so we measure circuits, first on paper and then on a device, where qubits interact only with some neighbours, data must be loaded, and gates make errors. An advantage counted in queries must survive all of these to be an advantage in practice.

8.4.1 Gate count, depth, and workspace§

What does a circuit cost? Three measures matter: the gate count, the total number of elementary gates; the depth, the number of layers of gates that must run one after another; and the width, the number of qubits, including extra workspace qubits called ancillas.

These trade off. More workspace can reduce depth, while recomputing an intermediate value instead of storing it can save qubits. Ancillas must start in a known state and are usually returned to it by uncomputation, so that they can be reused.

There is a subtler cost. An algorithm needs a circuit for every input length \(n\). A circuit family is uniform if a classical procedure produces the circuit for each \(n\), and the family counts as efficient only if that procedure is efficient too. Otherwise a short circuit could hide hard work in its design.

Problems

  1. A circuit on three qubits applies \(H\) to each qubit, then CNOT from qubit 1 to qubit 2, then CNOT from qubit 2 to qubit 3. Give its gate count, depth, and width.

    Show solutionHide solution

    Gate count \(5\). Depth \(3\): the three \(H\) gates form one layer, and the two CNOT gates must follow one another, since both use qubit 2. Width \(3\).

  2. Compute the AND of \(n=8\) bits with a chain of Toffoli gates: \(w_1=x_1x_2\), \(w_2=w_1x_3\), and so on, then the output, then uncompute the workspace. Give the gate count, depth, and width.

    Show solutionHide solution

    Computing uses \(n-1=7\) Toffoli gates (six into workspace bits, one into the output), and uncomputing uses \(6\) more: \(13\) gates. Each gate needs the previous result, so the depth is also \(13\). Width: \(8\) inputs, \(6\) workspace bits, and \(1\) output, \(15\) qubits.

  3. Compute the AND of the same \(8\) bits with a balanced tree instead: combine bits in pairs, then pairs of results, and so on. Compare gate count, depth, and workspace with the chain.

    Show solutionHide solution

    The tree uses \(4\) Toffoli gates on the input pairs, \(2\) on their results, and \(1\) into the output: \(7\) gates in \(3\) layers. Uncomputing the \(6\) workspace bits takes \(6\) gates in \(2\) layers. Total: \(13\) gates, depth \(5\), and \(6\) workspace bits. The chain has the same gate count and workspace but depth \(13\). For \(n\) bits, the tree’s depth grows like \(2\log_2n\) rather than \(2n\).

8.4.2 Connectivity and data preparation§

Can any two qubits interact? In a circuit diagram, yes; in a device, often only neighbouring qubits can. Gates between distant qubits then need SWAP gates to bring them together, which adds to the count and the depth.

Is loading data free? Preparing an arbitrary list of amplitudes can take work proportional to the length of the list, even though the register holding it is small. Likewise, the arithmetic that implements a predicate can cost far more than the number of oracle calls suggests.

A resource estimate must therefore state the gate set, the connectivity, how inputs are prepared, and how outputs are read, before an asymptotic advantage can become a claim about real machines.

Problems

  1. Three qubits sit on a line, \(1\)–\(2\)–\(3\), and only neighbours can interact. How many SWAP gates are needed to apply a CNOT between qubits 1 and 3 and restore the original placement?

    Show solutionHide solution

    Two: swap qubits 1 and 2, so that qubit 1’s state sits next to qubit 3; apply the CNOT; then swap back.

  2. A SWAP gate costs three CNOT gates. Count the CNOT gates in the construction above, and for a CNOT between the two ends of a line of \(n\) qubits.

    Show solutionHide solution

    For three qubits: \(2\times3+1=7\) CNOT gates instead of \(1\). For \(n\) qubits, moving one end next to the other takes \(n-2\) SWAP gates, and moving back takes \(n-2\) more: \(6(n-2)+1=6n-11\) CNOT gates.

  3. A data set of \(N=2^n\) numbers is loaded into amplitudes using one gate per number, and then searched with about \(\sqrt N\) queries. When does the quadratic query speedup survive in the total cost?

    Show solutionHide solution

    Loading costs about \(N\), more than the \(\sqrt N\) search, so a single search costs about \(N\), no better than scanning the data classically. The speedup survives only if the state is cheap to prepare, for example because it is produced by a short computation rather than loaded from data, or because one loaded state is used for many searches.

8.4.3 Error accumulation and reliability§

A gate can be synthesized accurately in mathematics and still be executed imperfectly. Approximation error concerns the chosen ideal circuit; physical noise concerns how the device actually realizes it. Both matter, but their models and remedies differ.

Quantum error correction encodes logical information across several physical qubits. Syndrome measurements reveal information about errors without revealing the encoded logical amplitudes. A syndrome need not identify a unique microscopic error; it must support a correction that preserves the logical state for the errors the code handles.

This does not clone the unknown input. The encoding creates a joint state, not independent copies available on separate wires. The no-cloning theorem remains intact.

We stop short of constructing a fault-tolerant computer. The foundation for that subject is now visible: joint states, subspaces, measurements, classical corrections, and a resource budget. Proving an ideal algorithm correct is necessary, but reliability is a further requirement.

Problems

  1. Each gate fails independently with probability \(10^{-3}\). What is the probability that a circuit of \(1000\) gates runs without any failure?

    Show solutionHide solution

    \((1-10^{-3})^{1000}\approx e^{-1}\approx0.37\).

  2. How small must the failure probability per gate be for a circuit of \(10^9\) gates to run without failure with probability at least \(0.9\)?

    Show solutionHide solution

    We need \((1-q)^{10^9}\geq0.9\). Since \((1-q)^N\approx e^{-qN}\), this requires \(q\lesssim-\ln0.9/10^9\approx1.05\times10^{-10}\), far below what physical gates achieve. Long computations need error correction.

  3. A repetition code stores a classical bit as three identical bits and decodes by majority. With independent flip probability \(0<q<1\), derive the failure probability and find when encoding helps. Now consider \(\alpha\ket{000}+\beta\ket{111}\): what does a phase flip \(Z\) on its first qubit do, and why does majority voting miss it?

    Show solutionHide solution

    Decoding fails after two or three flips: \(3q^2(1-q)+q^3=3q^2-2q^3\). This is smaller than \(q\) exactly for \(0<q<1/2\). But a phase flip gives \(\alpha\ket{000}-\beta\ket{111}\), which generally changes the encoded quantum state without changing any computational-basis bit pattern. Majority voting sees no error. Protecting quantum information therefore requires protection of relative phase as well as of bit values.

2. Worked problem §

Build the complete two-qubit Grover circuit for the marked item \(10\): the oracle from an \(X\) gate and a controlled-\(Z\), and the reflection from \(H\), \(X\), and controlled-\(Z\) gates. Verify that one iteration from \(\ket s\) gives \(10\).

Hint 1

The oracle flips the sign of \(\ket{10}\): apply \(X\) to the qubit that should be \(0\).

Hint 2

The reflection is \(H^{\otimes2}(X\otimes X)\,CZ\,(X\otimes X)H^{\otimes2}\).

Worked solution

Oracle: \(X\) on qubit 2, controlled-\(Z\), \(X\) on qubit 2. It sends \(\ket{10}\) to \(\ket{11}\), applies the sign, and restores \(\ket{10}\). Starting from \(\ket s=\tfrac12(1,1,1,1)\), the oracle gives \(\tfrac12(1,1,-1,1)\). The reflection circuit implements \(-D\), and \(D\) maps this state to \(\ket{10}\), so the result is \(-\ket{10}\): the outcome is \(10\) with certainty.

3. Extension §

A search over \(N=2^n\) items uses \((\pi/4)\sqrt N\) iterations. The oracle is compiled into \(20n\) gates and the reflection into \(10n\) gates. Give the total gate count as a function of \(n\), and evaluate it for \(n=30\).

Multiply the number of iterations by the gates per iteration.

Hint 2

\(\sqrt N=2^{n/2}\).

Worked solution

The total is about \((\pi/4)\,2^{n/2}\cdot30n\). For \(n=30\): \((\pi/4)\times32{,}768\times900\approx2.3\times10^7\) gates. The query count, about \(2.6\times10^4\), hides a factor of \(30n=900\) gates per query.
