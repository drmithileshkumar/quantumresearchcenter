Chapter 08

Quantum Circuits and Universality

What separates an operation we can describe mathematically from one we can construct with finite means?

An algorithm may name a transformation in a single line while leaving its construction unexplained. We open up those transformations into gates, wires, and intermediate steps, asking how a limited repertoire can generate a much wider range of operations. Controlled gates and universal gate sets lead to the distinction between exact construction and approximation. Counting the resulting resources returns us to a practical question: how much work was hidden inside the operation we first took for granted?

Reading guide · preparation, aims, and assumptions

Translate abstract operations into circuits and account for the work hidden inside a gate box.

Before you begin

Use the query and search algorithms from Chapters 6 and 7.

What you should be able to do

  • Read circuit order and controlled operations.
  • Distinguish exact construction from approximation.
  • Count gates, depth, and workspace separately.

The example to follow

Decompose the controlled phase and reflections already used in search instead of treating them as free operations.

Scope and assumptions

A finite discrete gate set generally approximates arbitrary unitaries; universality does not imply every transformation has a short exact circuit.

8.1

Circuit Representation

Circuit drawings record the order and subsystem support of operations.

8.1.1 Wires and gate ordering§

A circuit displays a sequence of operations with time increasing left to right. Each horizontal wire identifies a subsystem; a box denotes an operation. A wire does not carry a definite classical value when it belongs to a superposition or an entangled register. To interpret a circuit, track the joint vector between columns. If the first gate is \(U\) and the next is \(V\), the final state is \(VU\ket\psi\). Gates on disjoint wires act by tensor products and commute with one another, though a particular hardware schedule may impose additional constraints.

Problems

  1. In which direction does time run in the circuit drawings?

    Show solutionHide solution

    Time runs from left to right.

  2. A circuit applies \(H\) and then \(Z\). Write the matrix product acting on the input column vector in the correct order.

    Show solutionHide solution

    The product is \(ZH\): first \(H\) acts on the column vector, then \(Z\).

  3. Why can interchanging two adjacent gates change the result even when the set of gates is unchanged? Give a condition under which the interchange is safe and explain why wire labels matter.

    Show solutionHide solution

    In general \(BA\ket\psi\) differs from \(AB\ket\psi\). If \(A\) and \(B\) commute as full-register operators, swapping them is safe. Gates on disjoint wires commute, but gates with similarly named matrices on overlapping wires may not. Wire labels determine how each small matrix is embedded in the joint space.

8.1.2 Circuits for query and search algorithms§

The earlier algorithms now supply concrete reading exercises. In Deutsch’s circuit, the first \(H\) pair prepares the query state; the oracle encodes signs; the last \(H\) exposes their relation. In search, the repeated block consists of a phase oracle followed by reflection about the prepared state. Circuit notation records how to compose operations, but a box labelled \(O_f\) is still an abstract oracle until its implementation is specified. Drawing a box does not prove its cost is one elementary gate.

Problems

  1. What does an oracle box stand for in a query circuit?

    Show solutionHide solution

    One use of a specified reversible operation giving access to the function.

  2. A circuit uses three oracle boxes, each requiring ten gates when expanded. Count the gates contributed by those boxes.

    Show solutionHide solution

    \(3\times10=30\) gates are contributed by the oracle implementations.

  3. A circuit diagram can represent an entire oracle by one box. What must be specified before you can infer an implementation cost from that diagram? Which conclusions can still be drawn while the box remains abstract?

    Show solutionHide solution

    Specify the oracle’s gate decomposition, workspace, precision, and relevant hardware constraints before counting its implementation cost. While it remains abstract, one can still derive correctness under that oracle action and count how many times it is called. Those statements are conditional on the promised oracle access.

8.1.3 Measurement and classical control§

A measurement symbol terminates coherent evolution of that measured output within the diagram’s description and produces a classical result. Dashed lines here carry classical bits controlling later operations; solid lines carry quantum systems. A classical conditional correction means that the experimenter chooses a gate using a known outcome. It differs from a coherent controlled gate acting on an unmeasured superposition. Teleportation uses both: a coherent CNOT before measurement and classically controlled corrections afterward.

Problems

  1. What kind of information controls a classically conditioned correction?

    Show solutionHide solution

    A classical measurement outcome or another stored classical bit controls it.

  2. A measurement produces bit \(b\), and \(X\) is applied only if \(b=1\). Write the operation performed for each possible \(b\).

    Show solutionHide solution

    For \(b=0\), apply \(I\) and leave the target unchanged. For \(b=1\), apply \(X\).

  3. How does controlling an operation with a measured bit differ from controlling it coherently with a qubit? What happens to the possibility of interference between the control alternatives?

    Show solutionHide solution

    A measured control has a recorded classical outcome; each run follows that branch. A coherent controlled operation can retain amplitudes for both alternatives, possibly entangling control and target. Reading or ignoring a distinguishing measurement record generally removes the interference between alternatives that the coherent version could retain.

8.2

Gate Constructions

We construct the gates and phase operations already used in the algorithms.

8.2.1 Pauli, Hadamard, and rotation gates§

The basic matrices are \[X=\begin{pmatrix}0&1\\1&0\end{pmatrix},\quad Z=\begin{pmatrix}1&0\\0&-1\end{pmatrix},\quad H=\frac1{\sqrt2}\begin{pmatrix}1&1\\1&-1\end{pmatrix}.\] Also \(Y=\begin{pmatrix}0&-i\\i&0\end{pmatrix}\). For any Pauli matrix \(P\), define \(R_P(\theta)=\cos(\theta/2)I-i\sin(\theta/2)P\). Since \(P^2=I\), this is unitary. The phase gates \(S=\operatorname{diag}(1,i)\) and \(T=\operatorname{diag}(1,e^{i\pi/4})\) provide useful fixed relative phases. These formulas define the gates without requiring calculus or matrix exponentials.

Predict first. Starting from \(\ket0\), compare applying \(H\) twice with applying \(H\), then \(Z\), then \(H\). Predict both final measurement distributions before trying the gates.

Experiment: a gate changes amplitudes

Start in \(\ket{0}\). Apply \(H\) twice, then compare \(HZH\) with a single \(X\). Orange marks a negative amplitude; the bar length shows its squared magnitude.

State: \(1\ket0+0\ket1\)

Choose a gate to change the state.

This experiment uses real amplitudes. It illustrates X, Z, and H, not every possible qubit state.

After trying it: compare your explanation

\(H\) followed by \(H\) returns \(\ket0\), so 0 is certain. \(H\), \(Z\), \(H\) produces \(\ket1\), so 1 is certain. \(Z\) changes a relative sign that the final \(H\) converts into a different outcome.

Problems

  1. What does the \(X\) gate do to \(\ket0\) and \(\ket1\)?

    Show solutionHide solution

    \(X\) exchanges them: \(X\ket0=\ket1\) and \(X\ket1=\ket0\).

  2. Compare \(Z\ket0\) with \(Z\ket+\). Which input makes the relative-sign change apparent?

    Show solutionHide solution

    \(Z\ket0=\ket0\), whereas \(Z\ket+=(\ket0-\ket1)/\sqrt2=\ket-\). The \(\ket+\) input reveals the relative-sign change, which a subsequent \(H\) can convert to a basis outcome.

  3. Applying \(Z\) to \(\ket0\) changes nothing observable, but placing \(Z\) between two Hadamards changes the final outcome. Why is testing a gate on one input insufficient to establish that the gate has no effect?

    Show solutionHide solution

    A gate can act trivially on one state and nontrivially on another. \(Z\) fixes \(\ket0\) but changes \(\ket+\) to \(\ket-\). \(HZH\ket0=\ket1\) while \(HH\ket0=\ket0\). Testing just \(\ket0\) at the input to \(Z\) therefore misses its action on the other component and on superpositions.

8.2.2 Controlled and entangling gates§

A controlled-U is \(\ket0\bra0\otimes I+\ket1\bra1\otimes U\). It retains the control and conditionally transforms the target. CNOT is controlled-X; controlled-Z changes only the sign of \(\ket{11}\). Conjugating the target of CNOT by \(H\) gives controlled-Z because \(HXH=Z\). Not every controlled operation creates entanglement on every input, but CNOT can do so on \(\ket+\ket0\). Arbitrary local gates alone preserve product structure; an entangling operation is needed for general joint transformations.

Problems

  1. Which qubit changes in a CNOT operation?

    Show solutionHide solution

    The target flips when the control is one; the control basis label is preserved.

  2. Compare CNOT on \(\ket0\ket0\) with CNOT on \(\ket+\ket0\). Write both outputs and identify which is entangled.

    Show solutionHide solution

    CNOT leaves \(\ket{00}\) unchanged. On \(\ket+\ket0\) it gives \((\ket{00}+\ket{11})/\sqrt2\), an entangled Bell state.

  3. A controlled gate is capable of entangling some inputs but leaves others as product states. What features of the control and target preparations decide which happens? Test CNOT on a basis control and on a superposed control.

    Show solutionHide solution

    For product input \((a\ket0+b\ket1)\ket{t}\), the output is \(a\ket0\ket{t}+b\ket1X\ket{t}\). Entanglement requires both control components and target states \(\ket{t}\) and \(X\ket{t}\) that are not proportional. A basis control gives a product; a superposed control with target \(\ket0\) gives a Bell state. A target \(X\) eigenstate instead gives phase kickback without entangling these registers.

8.2.3 Oracle and reflection circuits§

A phase mark for a particular bit string can be built by flipping its zero positions, applying a phase flip controlled on all ones, and undoing those flips. A computed predicate can instead use compute–phase–uncompute. For uniform search, \(D=H^{\otimes n}(2\ket{0^n}\bra{0^n}-I)H^{\otimes n}\). The two-qubit drawing uses \(X\) gates and controlled-Z to realize the zero-state phase flip, producing \(-D\), which differs only by a harmless global phase in an uncontrolled Grover iteration. A controlled use would require tracking that phase explicitly.

Problems

  1. Why are temporary workspace wires included in an oracle circuit?

    Show solutionHide solution

    They hold intermediate values needed to implement the function reversibly.

  2. An implementation returns the correct answer but leaves a record \(g(x)\) in workspace. State the extra cleanup required before input branches can interfere without that record.

    Show solutionHide solution

    After preserving the required answer or phase, apply the inverse workspace computation so the workspace returns to the same clean state for every input branch.

  3. When replacing an oracle box by a circuit, why must you check the final workspace as well as the output bits? Could a circuit have the correct truth table on its output and still spoil the intended quantum algorithm?

    Show solutionHide solution

    Yes. Matching output bits on basis tests does not guarantee the same full quantum operation. A branch-dependent garbage record can entangle the input with workspace and obstruct later interference. One must check the complete coherent map, including phases and final workspace, not just the answer truth table.

8.3

Universal Gate Sets

A universal set must do more than independently rotate each qubit.

8.3.1 Limits of local operations§

A sequence made entirely of one-qubit gates has the form \(U_1\otimes\cdots\otimes U_n\). On a product input it produces another product state. It therefore cannot prepare a Bell state from \(\ket{00}\), regardless of how many local gates are used. This argument establishes a structural limitation without counting gates. Universal circuit construction needs a way for information in different subsystems to affect the joint state coherently.

Problems

  1. Can local unitary gates create entanglement from a product state?

    Show solutionHide solution

    No. Local unitary gates preserve the product form.

  2. Apply \(H\otimes I\) to \(\ket0\ket0\) and write the result as a product of two one-qubit states.

    Show solutionHide solution

    \((H\otimes I)\ket{00}=(H\ket0)\otimes(I\ket0)=\ket+\otimes\ket0\).

  3. Why can local unitary operations change the appearance of an entangled state without removing its entanglement? Use the inverse operations to test what would follow if they could turn it into a product state.

    Show solutionHide solution

    Suppose local unitaries \(A\otimes B\) turned an entangled pure state into a product \(\ket{u}\otimes\ket{v}\). Their local inverse would give \(A^\dagger\ket{u}\otimes B^\dagger\ket{v}\), also a product, contradicting the original entanglement. Local basis changes can alter coordinates and correlations seen in a chosen measurement, but not remove pure-state entanglement.

8.3.2 Entangling gates and universality§

Arbitrary single-qubit unitaries together with CNOT form a universal gate set for finite-qubit unitaries. One route to the theorem decomposes a matrix into two-level unitaries, each acting on a pair of basis vectors, and then implements those using controlled operations and local rotations. We state the synthesis theorem rather than prove every decomposition here. Its scope is expressibility, not efficiency: a generic operation on \(n\) qubits requires exponentially many parameters and generally many gates. Structured algorithmic operations are valuable because their descriptions permit economical constructions.

Further detail: Barenco et al.: Elementary gates for quantum computation.

Problems

  1. What does a universal gate set allow us to construct or approximate?

    Show solutionHide solution

    Arbitrary quantum unitaries on the specified registers, exactly or to any required accuracy according to the gate-set model.

  2. A collection contains only single-qubit gates. Starting from \(\ket{00}\), can it prepare a Bell state? Use the product-state form to explain.

    Show solutionHide solution

    No. A sequence of single-qubit gates sends \(\ket{00}\) to \(A\ket0\otimes B\ket0\), which remains a product. A Bell state is not a product.

  3. Why does the availability of an entangling gate need to be considered together with the allowed one-qubit gates? What is missing from the claim that any collection containing one entangling operation is automatically universal?

    Show solutionHide solution

    Universality concerns the operations generated by the whole set. An entangling operation alone, without sufficiently rich local controls, can generate only a restricted family. For example, powers of CNOT alone do not generate arbitrary one-qubit rotations. Arbitrary one-qubit unitaries together with CNOT provide the standard universal construction.

8.3.3 Exact synthesis and approximation§

A finite set such as Clifford+T generates a dense collection of unitaries, enabling approximation to any desired accuracy; it cannot express every continuously parameterized unitary exactly with a finite word. A useful target is operator-norm error \(\|U-V\|\leq\epsilon\), which bounds the output-vector error for every unit input. If a circuit contains \(L\) approximated gates, errors can be budgeted so their sum is at most the desired tolerance. Precision belongs in the resource analysis: a gate count without its accuracy requirement is incomplete.

Problems

  1. What distinguishes exact synthesis from approximate synthesis?

    Show solutionHide solution

    Exact synthesis reproduces the target operation; approximate synthesis produces an operation within a specified error tolerance.

  2. A circuit’s error is at most 0.01. Does this meet a requested tolerance of 0.1? Does it meet 0.001?

    Show solutionHide solution

    The guarantee 0.01 is sufficient for tolerance 0.1. It is not sufficient to certify tolerance 0.001: the actual error could be smaller, but the stated bound does not establish that.

  3. Why does approximating every desired operation arbitrarily closely differ from expressing every operation exactly with finitely many gates? What additional question about approximation cost matters to computation?

    Show solutionHide solution

    A finite gate alphabet yields countably many finite exact circuits, while unitaries vary continuously, so generic targets cannot all be represented exactly. Nevertheless those circuits may form a dense set and approximate every target. Computational usefulness also depends on how gate count and compilation effort grow as the requested error decreases.

8.4

Implementation Resources

Expressibility, efficient synthesis, and reliable execution are distinct requirements.

8.4.1 Gate count, depth, and workspace§

Gate count counts elementary operations, depth counts sequential layers that cannot be run in parallel, and width counts qubits, including ancillas. These resources can trade off: extra workspace may reduce depth, while repeated recomputation may save space. Clean ancillas must be initialized and usually restored for reuse. A uniform circuit family has a classical procedure generating the circuit for each input length; efficiency requires that construction to be efficient too. Otherwise a short circuit might conceal difficult work in its specification.

Problems

  1. What is the difference between gate count and circuit depth?

    Show solutionHide solution

    Gate count is the total number of gates. Depth is the number of sequential layers after compatible independent operations are scheduled in parallel.

  2. Four one-qubit gates act on four different qubits with no dependencies. Find their gate count and minimum depth, assuming parallel execution is available.

    Show solutionHide solution

    The gate count is four and the minimum depth is one.

  3. Two circuits use the same number of gates but have different dependencies. Why might their running times differ? What other resource could increase when you try to reduce their depth?

    Show solutionHide solution

    Dependencies force some gates to wait for earlier outputs, while independent gates can run together. Equal gate counts can therefore have different depths and running times. Reducing depth may require extra qubits, workspace, or duplicated computations, and hardware connectivity or gate duration can further constrain the schedule.

8.4.2 Connectivity and data preparation§

An abstract circuit may connect any pair of qubits, while a device permits only nearby interactions. Routing can add SWAP gates, count, and depth. Preparing an arbitrary list of amplitudes may itself require work proportional to the list size; it cannot be assumed free because the final register is small. Likewise, the arithmetic that implements a predicate may outweigh the number of oracle calls. A resource estimate should specify gate set, connectivity, input preparation, and output extraction before translating an asymptotic advantage into an implementation claim.

Problems

  1. What does hardware connectivity specify?

    Show solutionHide solution

    It specifies which physical qubits can participate directly in joint interactions.

  2. Three qubits lie in a line with interactions only between neighbors. Which pair cannot interact directly, and what kind of extra operation could bring its information together?

    Show solutionHide solution

    The two end sites cannot interact directly. A SWAP with the middle site can move one endpoint’s logical state next to the other; the placement can be restored afterwards if needed.

  3. A circuit assumes that two distant qubits can interact. How does restricted hardware connectivity change the operations actually required? Why should loading the input also be counted before claiming an end-to-end advantage?

    Show solutionHide solution

    Routing can add SWAPs, intermediate operations, and sequential layers absent from an abstract circuit. Loading classical input into the required quantum state can also be costly. An end-to-end comparison must count these costs, since a faster ideal query stage does not make them disappear.

8.4.3 Error accumulation and reliability§

Small coherent gate errors and stochastic noise can accumulate across a long circuit. Approximation error in ideal synthesis is different from physical noise, although both affect predictions. Reliable computation uses encoded logical information, syndrome extraction, and correction or fault-tolerant control. The no-cloning theorem does not forbid error correction: quantum codes encode one logical state into correlations, not independent readable copies. This book does not develop a noise model or threshold theorem. It identifies reliability as an additional resource requirement beyond proving an ideal algorithm correct.

Problems

  1. What does a per-gate error bound describe?

    Show solutionHide solution

    It bounds the discrepancy between one implemented operation and its ideal counterpart in a specified error measure.

  2. Using the bound that errors add, estimate the total error bound for 100 gates each with error at most 0.0001.

    Show solutionHide solution

    The sum bound is \(100\times0.0001=0.01\).

  3. Why can a small error in each gate become important in a long circuit? What assumptions would justify adding error bounds, and why should that worst-case bound not be mistaken for a prediction of the actual error in every run?

    Show solutionHide solution

    For unitary gate approximations in operator norm, expand the difference of the two circuit products into one term per gate. Submultiplicativity and unit norm of the other factors bound each term by that gate’s error; the triangle inequality gives the sum. Actual errors may cancel or affect a particular input less, so the worst-case bound need not be attained.

Check your understanding

Why is a circuit box not an implementation cost estimate?

Compare your explanation

A box may stand for a large subroutine, oracle, or state preparation. Its elementary gates, precision, routing, and workspace must be specified.

Questions and worked problems

Attempt each question before opening a hint. Explain your reasoning, then compare it with the solution.

1. Quick check §

Do \(H\) then \(Z\) and \(Z\) then \(H\) have the same action on \(\ket0\)?

Hint 1

Calculate the first step in each order.

Hint 2

\(Z\ket0=\ket0\), but \(Z\ket+=\ket-\).

Worked solution

No. \(H\) then \(Z\) gives \(\ket-\); \(Z\) then \(H\) gives \(\ket+\). Matrix multiplication order must match the circuit’s temporal order.

Revisit the relevant explanation

2. Worked problem §

Show that \(H\) on the target, CNOT, then \(H\) on the target implements controlled-\(Z\).

Hint 1

Separate the \(\text{control}=0\) and \(\text{control}=1\) cases.

Hint 2

Use \(H^2=I\) and \(HXH=Z\).

Worked solution

For control 0, the target undergoes \(H\cdot I\cdot H=I\). For control 1, it undergoes \(H\cdot X\cdot H=Z\). Only \(\ket{11}\) gains a minus sign, so the joint operation is controlled-\(Z\). Linearity extends the result to superpositions.

Revisit the relevant explanation

3. Extension §

A query algorithm uses \(q\) oracle calls. Each compiled oracle needs \(g\) elementary gates. What bound on total gates follows from \(q\) alone?

Hint 1

Account for the oracle implementations first.

Hint 2

Add state preparation, readout-related operations, and other processing.

Worked solution

No total gate bound follows from \(q\) alone. If each call costs \(g\) gates, the calls contribute \(qg\) gates, plus other operations. If \(g\) depends on input size or precision, it must remain in the analysis. Query savings alone do not establish a complete implementation advantage.
