How do we write one step?

Notation

\(\bra jS\ket i\) is the weight of the arrow from \(i\) to \(j\) under the step \(S\).

Read right to left: start at \(i\), apply \(S\), arrive at \(j\). For NOT: \(\bra1X\ket0=\bra0X\ket1=1\) and \(\bra0X\ket0=\bra1X\ket1=0\).

How do we see a whole run?

Copy the configurations once for each time and join the copies by the arrows of the rule.

A run is a path through the time-expanded diagram. From 0, NOT gives 0, 1, 0.

What if a configuration has several successors?

KEEP-OR-FLIP permits both successors from either bit: four two-step paths from 0.

A configuration is reachable if at least one permitted path ends there. This is possibility, not probability.

What does a probabilistic rule add?

COIN gives every arrow the probability \(P(j\mid i)=\tfrac12\).

Two exclusive histories end at 0, so \(P(c_2=0)=\tfrac14+\tfrac14=\tfrac12\).

3.2

Sum and Product Rules

Once arrows carry weights, how do we compute the weight of an endpoint?

Read the chapter9 / 24

What is one path worth?

  1. A path \(i\to j\to k\) needs every arrow along it.
  2. Its weight is the product \(\bra kT\ket j\,\bra jS\ket i\), with the first step on the right.
  3. Allowed arrow 1, missing arrow 0: the product is 1 exactly when the whole path is permitted.
  4. For COIN, each two-step path has weight \(\tfrac12\cdot\tfrac12=\tfrac14\).

Product rule: multiply along a path.

§3.2.1 in the book10 / 24

How do paths to one endpoint combine?

  1. \[\bra kTS\ket i=\sum_j\bra kT\ket j\,\bra jS\ket i\]
  2. Deterministic: one path. Nondeterministic: the sum counts paths. Probabilistic: the endpoint probability.
  3. COIN: \(\tfrac14+\tfrac14=\tfrac12\) at either endpoint.
  4. Every contribution is nonnegative, so adding a path can never lower a total.

Sum rule: add across paths. With nonnegative weights, nothing ever cancels.

§3.2.2 in the book11 / 24

How does a whole state change in one step?

  1. \[v^\prime_j=\sum_i\bra jS\ket i\,v_i\]
  2. Each configuration goes to its weighted successors: \(S\ket i=\sum_j\bra jS\ket i\,\ket j\).
  3. Example: \(\mathrm{COIN}\ket0=\tfrac12\ket0+\tfrac12\ket1\).
  4. A reversible rule only permutes configurations: \(\mathrm{CNOT}\ket{10}=\ket{11}\). RESET and COIN merge distinct states.

3.3

Signed Weights

What changes if a weight may be negative?

Read the chapter13 / 24

What does a negative arrow do to a path?

  1. The product rule is unchanged: \(\bra kS\ket j\,\bra jS\ket i\).
  2. An odd number of negative arrows makes the path weight negative.
  3. \((\tfrac12)(-\tfrac12)=-\tfrac14,\qquad(-\tfrac12)(-\tfrac12)=+\tfrac14\)
  4. A negative path weight is not a negative probability. It is a signed contribution to a later sum.
§3.3.1 in the book14 / 24

Can two paths add up to nothing?

Two routes contribute \(ca\) and \(db\), with \(a=b=c=\tfrac12\) and \(d=-\tfrac12\).

\(\tfrac14-\tfrac14=0\): cancellation. Adding a path can now lower a total.

§3.3.2 in the book15 / 24

Predict

Can a step spread a bit out and still undo itself?

Give three arrows the weight \(c\) and one arrow the weight \(-c\). Apply the step twice, starting from 0. What must \(c\) be to return to 0 with weight 1?

Count the two paths into 0 and the two paths into 1.

Answer

Into 0: \(c^2+c^2=2c^2\). Into 1: \(c^2-c^2=0\). So \(2c^2=1\) and \(c=1/\sqrt2\). This step is the Hadamard step \(H\).

§3.3.3 in the book16 / 24

The Hadamard step undoes itself

\(H\ket0=(\ket0+\ket1)/\sqrt2,\qquad H\ket1=(\ket0-\ket1)/\sqrt2\)

\(HH=I\). After one step the squared weights add to one, \(c^2+c^2=1\): a hint that squares will give probabilities.

3.4

Complex Amplitudes and Interference

A sign is a two-way choice. What does a continuously varying direction allow?

Read the chapter18 / 24

Predict

Is there a square root of NOT?

Find a step \(\sqrt X\), with stay-weight \(a\) and switch-weight \(b\), such that two steps of it give NOT.

Two steps: the return paths give \(a^2+b^2\); the switch paths give \(2ab\).

Answer

We need \(a^2+b^2=0\) and \(2ab=1\). No real numbers work. Complex numbers do: \(a=\tfrac{1+i}{2},\ b=\tfrac{1-i}{2}\).

§3.4.1 in the book19 / 24

Squares that cancel

In the plane, multiplying by \(i\) is a quarter turn, so \(i^2=-1\).

\(a^2=\tfrac i2\) and \(b^2=-\tfrac i2\): the return paths cancel, and \(2ab=1\) sends the bit across.

§3.4.1 in the book20 / 24

Which probability rule fits complex amplitudes?

  1. \(a^2=i/2\) cannot be a probability.
  2. Use the squared magnitude instead: \(p(j)=v_jv_j^*=|v_j|^2\).
  3. Normalization: \(\sum_j|v_j|^2=1\).
  4. Add amplitudes first, then square: \(|A+B|^2=|A|^2+|B|^2+AB^*+A^*B\).
  5. To keep total probability one, each step needs unit-length, mutually orthogonal columns.
§3.4.1 in the book21 / 24

How does a phase change an outcome?

  1. Start from \((\ket0+e^{i\phi}\ket1)/\sqrt2\): probabilities \(\tfrac12,\tfrac12\) for every \(\phi\).
  2. \[p(0)\text{ after }H=\left|\frac{1+e^{i\phi}}{2}\right|^2=\frac{1+\cos\phi}{2}\]
  3. \(\phi=0\): certainly 0. \(\phi=\pi\): certainly 1. \(\phi=\pi/2\): even odds.
  4. A common (global) phase changes nothing; a relative phase changes what happens next.

Interference: amplitudes add at a common endpoint before we square.

§3.4.2 in the book22 / 24

Does a record of the path matter?

Run \(H\), then CNOT onto a record bit, then \(H\) again.

Record kept

  • Final state \(\tfrac12(\ket{00}+\ket{01}+\ket{10}-\ket{11})\).
  • \(+\tfrac12\) and \(-\tfrac12\) land on 10 and 11.
  • They cannot cancel: \(p(\text{first}=1)=\tfrac12\).

Record undone

  • Apply CNOT again before the last H.
  • Both contributions now reach 10, and cancel.
  • The run returns to \(\ket{00}\) with certainty.

Anything that can tell the paths apart belongs in the configuration. Uncomputing the record restores interference.

§3.4.3 in the book23 / 24

What we found

  1. A state is a weight per configuration; a step is a weight per arrow.
  2. Multiply along paths, add across paths, for every kind of rule.
  3. Signed weights cancel, which lets the Hadamard step undo itself.
  4. Complex amplitudes give a square root of NOT; probabilities are squared magnitudes.
  5. Paths interfere only where they meet; a record of the path prevents it.
