Can a truth table become a formula?

  1. Work modulo two: \(1+1=0\), so \(+\) is XOR and \(\times\) is AND.
  2. A row detector, \(\delta_s(x)=\prod_{s_i=1}x_i\prod_{s_i=0}(1+x_i)\), equals 1 only on row \(s\).
  3. Add the detectors of the rows where \(f=1\).
  4. OR: \((1+x)y+x(1+y)+xy=x+y+xy\pmod2\).

Every Boolean function is a polynomial in its input bits.

Do we need more than one kind of gate?

\(\operatorname{NAND}(a,a)=\neg a\); NOT of NAND is AND; four NANDs make XOR.

NAND is universal. Classically, copying a bit to several gates (fan-out) is free.

Information Erasure

Does losing information have a physical price?

Read the chapter10 / 18

What does erasing a bit cost?

Landauer’s principle (quoted result)

Erasing one equally likely bit, without keeping its value elsewhere, releases at least \(k_{\mathrm B}T\ln2\) of heat on average.

A bit already known to be 0 can be left alone. A biased bit, or one with a record elsewhere, costs less, but the record must be counted too.

§2.3.1 in the book11 / 18

Is reversible the same as cool?

Logically reversible

  • A one-to-one map.
  • Avoids the cost that erasure forces.
  • A real device may still dissipate energy.

Run slowly

  • AND run slowly still merges inputs.
  • Reversibility is a property of the map, not its speed.

Keep apart two questions: can the map be inverted, and how much energy does the device use?

§2.3.2 in the book12 / 18

Can every function be computed without erasure?

  1. Keep the input: \(U_f:(x,t)\mapsto(x,\,t\oplus f(x))\).
  2. With \(t=0\), the target becomes \(f(x)\).
  3. Apply twice: \(t\oplus f(x)\oplus f(x)=t\). \(U_f\) is its own inverse.
  4. \(f\) still merges inputs; the larger map does not.

The extra bits are what make the transformation one-to-one.

Reversible Gates

Which gates carry out a reversible embedding?

Read the chapter14 / 18

How can one bit control another without loss?

  1. Keep the control; let it choose a reversible update of the target.
  2. CNOT: \((a,b)\mapsto(a,b\oplus a)\), so \(10\to11\) and \(11\to10\).
  3. Applying it twice restores both bits: the control tells us what was done.
  4. Discard the control and we cannot undo the flip.
§2.4.1 in the book15 / 18

Which reversible gates suffice?

\(\operatorname{Toffoli}(a,b,c)=(a,b,c\oplus ab)\)

With the target 1, Toffoli gives NAND; CNOT copies a bit onto 0. So Toffoli gates build every circuit reversibly.

§2.4.2 in the book16 / 18

What do we do with leftover workspace?

Compute, copy the answer, then run the computation backward.

Only the input and the answer remain. In quantum computing, leftover records would block interference.

§2.4.3 in the book17 / 18

What we found

  1. Encodings turn tasks into Boolean functions; every function is a polynomial over bits.
  2. Circuits evaluate any function, and NAND alone is enough.
  3. Erasing information has a minimum heat cost; merging inputs forces erasure.
  4. Keeping the input makes every function reversible: Toffoli gates do it.
  5. Uncomputation clears the workspace without erasing it.
