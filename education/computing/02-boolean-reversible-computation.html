Chapter 02

Boolean and Reversible Computation

A computation, we have seen, is a run of configurations produced by transition rules, and some questions cannot be settled by any such run. For the questions that can, we now ask how a single step is carried out. Every finite piece of data can be written in bits, so every step can be built from operations on bits. But the most familiar of these operations forget their inputs: an AND gate that outputs 0 cannot say which of three inputs it received, and the history of the computation is lost.

We therefore begin by describing what is to be computed, as a Boolean function, and show that every such function can be built from a few elementary gates arranged in a circuit. We then examine what is lost when a gate discards information, and why that loss has a physical price: erasing a bit releases heat. This motivates computing without discarding anything. We show that every function can be embedded in a reversible operation, build reversible gates that carry this out, and learn to clear the temporary workspace they leave behind by running the computation backward.

The next chapter takes reversible steps as its starting point and compares the kinds of transition a physical computer can make.

What must a computation remember in order to undo what it has done?

An AND gate that outputs 0 cannot say which of three inputs it received. Computing without such losses requires keeping more than the answer.

Reading guide · preparation, aims, and assumptions

Build computations from Boolean operations and learn how to preserve the information they would otherwise discard.

Before you begin

Recall that a computation transforms configurations step by step, and that one function can have different implementations.

What you should be able to do

  • Write a Boolean function as a truth table and as a polynomial modulo two.
  • Construct Boolean functions from NAND gates.
  • Verify a reversible function embedding.
  • Explain why temporary workspace is uncomputed rather than erased.

The example to follow

Follow a function value from a truth table to a reversible target update. The same update becomes the oracle in Chapter 6.

Scope and assumptions

Logical reversibility alone does not guarantee low physical dissipation. Landauer’s bound concerns erasure under stated thermodynamic conditions.

2.1

Boolean Functions

To build computations from operations on bits, we first need a precise description of what is to be computed, independent of how. Encodings reduce every task to a function on bit strings, and truth tables specify such functions completely. A specification is not yet a method, so we then ask how a truth table can be turned into a formula built from a few operations.

2.1.1 Binary encodings§

A computer acts on bit strings. An encoding tells us what those strings mean: \(00,01,10,11\) might represent the integers zero through three, while \(01000001\) can represent either the integer 65 or the character A in ASCII.

The choice matters because computational cost is measured against input length. An integer \(N\) needs about \(\log_2N\) binary digits, but \(N\) marks in unary. The same numerical task can therefore have very different size measures.

For a fixed length \(n\), a computation acts on \(2^n\) possible bit strings. An algorithm handles all permitted lengths by one systematic procedure; we do not get to hide a separately invented answer table for every size.

Problems

  1. Write \(13\) in binary with four bits, and decode \(1011\) as an unsigned binary integer.

    Show solutionHide solution

    \(13=8+4+1\), so it is \(1101\). The string \(1011\) is \(8+2+1=11\).

  2. An integer \(N\) is written in binary and, alternatively, in unary, as \(N\) marks. For \(N=1000\), compare the two input lengths. How does a procedure that takes \(N\) steps compare with each length?

    Show solutionHide solution

    Since \(2^9=512\leq1000\lt 1024=2^{10}\), binary needs \(10\) bits, while unary needs \(1000\) marks. A procedure taking \(N\) steps is linear in the unary length but exponential in the binary length, about \(2^{10}\) steps for \(10\) bits. The same procedure is “efficient” or not depending on the encoding.

  3. Show that any encoding of the integers \(0,1,\dots,M-1\) by bit strings of one fixed length \(n\) needs \(n\geq\log_2M\).

    Show solutionHide solution

    There are \(2^n\) bit strings of length \(n\). An encoding gives different integers different strings, so it needs at least \(M\) strings: \(2^n\geq M\). Taking logarithms, \(n\geq\log_2M\). Binary achieves this up to rounding up.

2.1.2 Boolean functions and truth tables§

What exactly do we want to compute? Take a yes/no question about an \(n\)-bit input. Its answer is a Boolean function \(f:\{0,1\}^n\to\{0,1\}\), which assigns \(0\) or \(1\) to every input. An answer of several bits is a list of such functions, one for each output bit.

The most direct way to specify \(f\) is to list every input together with its output. This list is the truth table of \(f\). For AND and OR on two bits:

Input \(xy\)ANDOR
\(00\)\(0\)\(0\)
\(01\)\(0\)\(1\)
\(10\)\(0\)\(1\)
\(11\)\(1\)\(1\)

Does a truth table tell us how to compute \(f\)? It tells us what the answer is, not how to obtain it. It also grows quickly: a function of \(n\) bits has \(2^n\) rows, so the table alone is exponentially large. We want a description built from a few simple operations.

Problems

  1. Write the truth table of the majority function on three bits, which outputs \(1\) when at least two of its inputs are \(1\).

    Show solutionHide solution

    \(000\to0\), \(001\to0\), \(010\to0\), \(011\to1\), \(100\to0\), \(101\to1\), \(110\to1\), and \(111\to1\).

  2. How many Boolean functions of two bits are there? List those that output \(1\) on exactly one input.

    Show solutionHide solution

    A truth table has four rows, each with output \(0\) or \(1\), so there are \(2^4=16\) functions. Those with a single \(1\): output \(1\) only on \(11\) (AND), only on \(10\) (\(x\) and not \(y\)), only on \(01\) (not \(x\) and \(y\)), and only on \(00\) (NOR).

  3. Show that there are \(2^{2^n}\) Boolean functions of \(n\) bits. For \(n=10\), show that fewer than one function in a thousand can be described by a string of fewer than \(1014\) bits.

    Show solutionHide solution

    The truth table has \(2^n\) rows, and each row’s output can be chosen independently, giving \(2^{2^n}\) functions. For \(n=10\) that is \(2^{1024}\). The number of bit strings shorter than \(1014\) bits is \(1+2+\dots+2^{1013}=2^{1014}-1\lt 2^{1014}\). Different functions need different descriptions, so at most \(2^{1014}\) functions have such a short description, a fraction below \(2^{1014}/2^{1024}=2^{-10}\lt 1/1000\). Almost every function has no description much shorter than its truth table.

2.1.3 Polynomial representation over the binary field§

Can a truth table be turned into a formula? Use arithmetic modulo two, in which \(1+1=0\). Addition modulo two is then XOR, and multiplication is AND.

The idea is to build, for each row \(s\) of the table, a detector that equals \(1\) on the input \(s\) and \(0\) on every other input. The factor \(x_i\) equals \(1\) exactly when \(x_i=1\), and the factor \(1+x_i\) equals \(1\) exactly when \(x_i=0\). Multiplying one such factor for each bit gives

\[\delta_s(x)=\prod_{i:\,s_i=1}x_i\prod_{i:\,s_i=0}(1+x_i).\]

For two bits \((x,y)\), the detector of the row \(01\) is \((1+x)y\).

Now add the detectors of the rows on which \(f\) equals \(1\):

\[f(x)=\sum_{s:\,f(s)=1}\delta_s(x)\pmod 2.\]

Why is this \(f\)? On any input \(x\), exactly one detector, \(\delta_x\), equals \(1\). If the row \(x\) is among those added, the sum is \(1\); otherwise it is \(0\).

For OR, the rows with output \(1\) are \(01\), \(10\), and \(11\):

\[(1+x)y+x(1+y)+xy=x+y+3xy=x+y+xy\pmod 2.\]

Check the row \(11\): \(1+1+1=1\) modulo two, as required, whereas ordinary addition would give \(3\). Expanding the detectors in this way writes every Boolean function as a polynomial in its input bits.

Problems

  1. Evaluate \((1+x)(1+y)\) modulo two for all four inputs. Which function is it?

    Show solutionHide solution

    It equals \(1\) only when both factors are \(1\), that is, when \(x=y=0\). For \(00,01,10,11\) the values are \(1,0,0,0\): this is NOR, the negation of OR.

  2. Build the polynomial of XOR from its truth table using detectors, and simplify it.

    Show solutionHide solution

    XOR is \(1\) on the rows \(01\) and \(10\). Their detectors are \((1+x)y\) and \(x(1+y)\), so XOR is \((1+x)y+x(1+y)=y+xy+x+xy=x+y\pmod2\), since \(xy+xy=0\).

  3. Show that the polynomial of the three-bit majority function is \(xy+yz+xz\) modulo two.

    Show solutionHide solution

    Majority is \(1\) on \(011\), \(101\), \(110\), and \(111\). The detectors add to \((1+x)yz+x(1+y)z+xy(1+z)+xyz=yz+xz+xy+4xyz\). Since \(4xyz=0\) modulo two, the polynomial is \(xy+yz+xz\). Check: on \(110\) it gives \(1+0+0=1\), and on \(111\) it gives \(1+1+1=1\).

2.2

Boolean Circuits

A polynomial names the operations to perform, but not their order or the values passed between them; a circuit supplies both. We show that circuits compute every Boolean function, reduce the kinds of gate needed to one, and then look at the gates themselves, asking what each one keeps of its inputs.

2.2.1 Polynomial evaluation by circuits§

How do we evaluate \(x+y+xy\) one operation at a time? Compute \(u=xy\) with an AND gate, compute \(x+y\) with an XOR gate, and combine the two results with a second XOR gate.

This arrangement is a circuit. Its gates are elementary operations, and its wires carry bits from one gate to the next; here a wire carries \(u\) from the AND gate to the last XOR gate. A wire may also carry a fixed bit, \(0\) or \(1\). No wire leads back to an earlier gate, so the gates can be evaluated in order.

The same method works for every polynomial: multiply factors with AND gates and add terms with XOR gates. So every Boolean function of a fixed number of bits has a circuit.

Does it have a small circuit? Not necessarily: the polynomial built from a truth table can have exponentially many terms. That every function can be built is one claim; that it can be built economically is another.

Problems

  1. Evaluate the circuit for \(x+y+xy\), built from one AND gate and two XOR gates, on the input \(10\), giving the bit on every wire.

    Show solutionHide solution

    The AND gate outputs \(u=1\cdot0=0\). The first XOR gate outputs \(x+y=1\). The second XOR gate combines these: \(1+0=1\). The output is \(1\), as OR requires.

  2. Build a circuit for majority, \(xy+yz+xz\), from AND and XOR gates. How many gates does it use?

    Show solutionHide solution

    Three AND gates compute \(xy\), \(yz\), and \(xz\), and two XOR gates add them: first \(xy+yz\), then that sum plus \(xz\). That is five gates in all.

  3. The parity function \(x_1+x_2+\dots+x_n\pmod2\) equals \(1\) on half of its inputs. How many detectors does the truth-table construction add, and how many XOR gates does the simplified polynomial need?

    Show solutionHide solution

    Parity is \(1\) on \(2^{n-1}\) of the \(2^n\) inputs, so the construction adds \(2^{n-1}\) detectors, each a product of \(n\) factors. After simplification the polynomial is just \(x_1+\dots+x_n\), which needs \(n-1\) XOR gates. The general construction proves that a circuit exists, but it can be exponentially wasteful.

2.2.2 NAND universality§

Do we need AND, XOR, and NOT as separate kinds of gate? One kind is enough. NAND outputs the negation of AND, \(\operatorname{NAND}(a,b)=\neg(a\land b)\); it is \(0\) only when \(a=b=1\).

Tying both inputs to the same bit gives NOT: \(\operatorname{NAND}(a,a)=\neg a\). Negating a NAND output gives AND. XOR takes four NAND gates:

\[t=\operatorname{NAND}(a,b),\quad u=\operatorname{NAND}(a,t),\quad v=\operatorname{NAND}(b,t),\quad a\oplus b=\operatorname{NAND}(u,v).\]

Checking the four input pairs confirms the last identity. Since NAND builds AND, XOR, and NOT, it can evaluate the polynomial of any Boolean function. A gate with this property is universal.

In this construction one bit often feeds several gates: \(a\) and \(b\) each feed two NAND gates, and so does \(t\). Copying a bit in this way, called fan-out, is free in classical circuits.

Problems

  1. Compute \(\operatorname{NAND}(a,b)\) for all four inputs. Use the table to check that \(\operatorname{NAND}\bigl(\operatorname{NAND}(a,b),\operatorname{NAND}(a,b)\bigr)=a\land b\).

    Show solutionHide solution

    \(\operatorname{NAND}\) gives \(1,1,1,0\) on \(00,01,10,11\). Feeding the same bit into both inputs of a NAND gate negates it, so the outer gate turns \(1,1,1,0\) into \(0,0,0,1\), which is AND.

  2. Build OR from NAND gates, and verify the construction on all four inputs.

    Show solutionHide solution

    \(a\lor b=\operatorname{NAND}(\neg a,\neg b)\) with \(\neg a=\operatorname{NAND}(a,a)\): three gates. For \(00\): \(\operatorname{NAND}(1,1)=0\). For \(01\): \(\operatorname{NAND}(1,0)=1\). For \(10\): \(\operatorname{NAND}(0,1)=1\). For \(11\): \(\operatorname{NAND}(0,0)=1\). These are the outputs of OR.

  3. Show that circuits of AND and XOR gates, with no constant inputs, cannot compute NOT, but that adding the constant \(1\) makes the set universal.

    Show solutionHide solution

    On the all-zero input, AND and XOR gates output \(0\) when both their inputs are \(0\). By induction along the circuit, every wire carries \(0\), so the output is \(0\); NOT must output \(1\) on input \(0\). With the constant \(1\), \(\neg x=x\oplus1\), and AND together with NOT builds NAND, which is universal.

2.2.3 Irreversible Boolean operations§

An AND output of one identifies its input: it must have been \(11\). An output of zero does not: \(00\), \(01\), and \(10\) all fit. Reversibility must work for every allowed input, so unrestricted AND has no inverse.

Always specify which registers are kept. A circuit can discard an intermediate copy while still retaining enough information elsewhere to recover its original input. Conversely, an output that looks reversible need not have been produced through reversible elementary steps.

For a quantum implementation, we need the stronger construction: a sequence of steps that each preserves distinctions in the full state. The next sections show how to obtain the same Boolean answer without using AND as a two-input, one-output erasure.

Problems

  1. For OR on two bits, list the inputs that share each output. Can the inputs be recovered from the output?

    Show solutionHide solution

    Output \(0\) comes only from \(00\); output \(1\) comes from \(01\), \(10\), and \(11\). After an output \(1\), the input cannot be recovered.

  2. A circuit computes \((x,y)\mapsto(x\land y,\;x\lor y)\). Is this map one-to-one? Which inputs collide?

    Show solutionHide solution

    The outputs are \(00\mapsto(0,0)\), \(01\mapsto(0,1)\), \(10\mapsto(0,1)\), and \(11\mapsto(1,1)\). The inputs \(01\) and \(10\) collide, so the map is not one-to-one, even though it produces two bits from two.

  3. The map \((x,y)\mapsto(x,\,x\oplus y)\) is computed by copying \(x\) and feeding \(x\) and \(y\) into an XOR gate, which on its own loses information. Show that the map is one-to-one, and explain where the information discarded by the XOR gate survives.

    Show solutionHide solution

    Given the output \((x,s)\) with \(s=x\oplus y\), we recover \(y=x\oplus s\). So different inputs give different outputs. The XOR gate alone cannot distinguish \(00\) from \(11\), but the copied \(x\) separates them. The information is kept by the fan-out copy, not by the gate.

2.3

Information Erasure

Logical information loss has a physical side, because every bit is held by a physical system. We find the minimum cost of erasing a bit, separate it from other sources of heat, and ask whether it can be avoided altogether. It can, by a construction that keeps the input beside the answer.

2.3.1 Landauer’s principle§

A reset sends either initial bit value to zero. In the standard isothermal setting, erasing one equally likely bit without retaining its value elsewhere releases at least

\[Q\geq k_{\mathrm B}T\ln2\]

of heat into the environment on average. This is Landauer’s principle; \(T\) is absolute temperature and \(k_{\mathrm B}\) is Boltzmann’s constant.

The bound is about an entropy reduction under stated physical conditions, not a fee charged whenever a gate runs. A bit already known to be zero can be left untouched. Bias or usable side information changes the uncertainty being removed; if that information lives in another physical memory, its eventual treatment matters too.

We will not need a thermodynamic derivation. The computational question is enough for now: can a useful calculation avoid merging distinct logical states? If it can, it avoids forcing erasure at those steps, though its physical implementation may still dissipate energy.

Further detail: Bennett: Landauer’s principle and reversible computation.

Problems

  1. Compute \(k_{\mathrm B}T\ln2\) at \(T=300\) K, with \(k_{\mathrm B}=1.38\times10^{-23}\) J/K.

    Show solutionHide solution

    \(1.38\times10^{-23}\times300\times0.693\approx2.9\times10^{-21}\) J.

  2. A processor erases \(10^{18}\) bits per second at \(300\) K. What minimum power does Landauer’s principle require? Compare it with a processor that uses \(50\) W.

    Show solutionHide solution

    \(10^{18}\times2.9\times10^{-21}\) J per second is about \(2.9\times10^{-3}\) W, roughly \(3\) mW. A \(50\) W processor dissipates more than ten thousand times this. Today’s heat comes mostly from other losses, not from the erasure limit.

  3. Erasing a bit that is \(0\) with probability \(p\) and \(1\) with probability \(1-p\) has the minimum cost \(H\,k_{\mathrm B}T\ln2\), where \(H=-p\log_2p-(1-p)\log_2(1-p)\). Compute \(H\) for \(p=0.9\), and compare the cost with that of an unbiased bit and a known bit.

    Show solutionHide solution

    \(H=-0.9\log_20.9-0.1\log_20.1\approx0.137+0.332=0.469\). The cost is about \(0.47\,k_{\mathrm B}T\ln2\), roughly half that of an unbiased bit, for which \(H=1\). For a known bit, \(p=1\) gives \(H=0\): nothing uncertain is erased, so no minimum cost applies.

2.3.2 Logical reversibility and dissipation§

If a computation never erases information, does it produce no heat? Not necessarily. A logically reversible map, one that is one-to-one on its allowed states, avoids the cost that erasure forces. A real device may still dissipate energy through resistance, friction, imperfect control, or the speed at which it runs.

Conversely, can a gate that loses information be made reversible by operating it slowly? No. Running AND slowly does not make its output reveal its input. Reversibility is a property of the map, not of how the map is carried out.

Two questions must therefore be kept apart: whether the mathematical map can be inverted, and how much energy its physical realization uses. For quantum computation the first question is decisive, because the operations of an isolated quantum system can always be inverted.

Problems

  1. Which of these are logically reversible: NOT; AND; \((x,y)\mapsto(x,x\oplus y)\); a reset to \(0\)?

    Show solutionHide solution

    NOT and \((x,y)\mapsto(x,x\oplus y)\) are one-to-one, hence reversible. AND and the reset merge different inputs, so they are not.

  2. A device implements NOT but dissipates \(10^{-18}\) J per operation, while the Landauer bound at \(300\) K is about \(2.9\times10^{-21}\) J. Does the dissipation contradict the reversibility of NOT? Does Landauer’s principle require any dissipation for NOT?

    Show solutionHide solution

    No contradiction: reversibility is a property of the map, and the device may lose energy for other reasons. Landauer’s principle requires no minimum for NOT, since NOT erases nothing. The bound applies only when information is erased.

  3. Show that a reversible map on \(n\)-bit strings is a permutation of the \(2^n\) strings. For \(n=2\), count the reversible maps and compare with the number of all maps from two bits to two bits.

    Show solutionHide solution

    A reversible map is one-to-one on the \(2^n\) strings, and a one-to-one map of a finite set to itself is onto, so it is a permutation. For \(n=2\) there are \(4!=24\) permutations of the four strings, while all maps number \(4^4=256\). Fewer than one map in ten is reversible.

2.3.3 Reversible function embeddings§

Can every function be computed without erasing information, even one such as AND that merges its inputs? It can, provided we keep the input.

Add a target bit \(t\) and replace \(f\) by the map

\[U_f:(x,t)\mapsto(x,\,t\oplus f(x)).\]

The input \(x\) is kept, and \(f(x)\) is added to the target modulo two. With \(t=0\), the target becomes the answer \(f(x)\).

Why is this map reversible? Apply it twice: \(t\oplus f(x)\oplus f(x)=t\), because adding the same bit twice modulo two gives zero. The map is its own inverse. For AND it is \((x,y,t)\mapsto(x,y,t\oplus xy)\):

\((x,y,t)\)\((x,y,t\oplus xy)\)\((x,y,t)\)\((x,y,t\oplus xy)\)
\(000\)\(000\)\(001\)\(001\)
\(010\)\(010\)\(011\)\(011\)
\(100\)\(100\)\(101\)\(101\)
\(110\)\(111\)\(111\)\(110\)

Has AND become invertible? No: \(f\) itself is unchanged and still merges its inputs. What is invertible is the larger map, whose output keeps \(x\). The extra bits are not mere bookkeeping; they are what makes the transformation one-to-one.

Problems

  1. Write the outputs of \(U_f:(x,y,t)\mapsto(x,y,t\oplus(x\lor y))\) for the four inputs with \(t=0\).

    Show solutionHide solution

    \(000\to000\), \(010\to011\), \(100\to101\), and \(110\to111\): the target receives the OR of the inputs.

  2. For OR, apply \(U_f\) to \((1,0,1)\), then apply it again. A programmer expected the target to contain \(f(1,0)=1\) after the first call. What assumption did they overlook?

    Show solutionHide solution

    The first call gives \((1,0,0)\), since \(1\oplus1=0\). The second gives \((1,0,1)\), restoring the input. The oracle adds the function value modulo two to the existing target; it does not overwrite that target. To read \(f(x)\) directly from the target, initialize it to \(0\).

  3. For a function \(f\) from \(n\)-bit strings to \(m\)-bit strings, define \(U_f(x,t)=(x,t\oplus f(x))\), where \(t\) has \(m\) bits and \(\oplus\) acts bit by bit. Prove that \(U_f\) is its own inverse for every \(f\).

    Show solutionHide solution

    \(U_f(U_f(x,t))=U_f(x,t\oplus f(x))=(x,t\oplus f(x)\oplus f(x))=(x,t)\), because each bit of \(f(x)\) added twice modulo two gives \(0\). So \(U_f\) undoes itself. In particular it is one-to-one, whatever \(f\) is.

2.4

Reversible Gates

A reversible embedding exists for every function, but we still need gates that carry it out. We look for the simplest gates that change a bit without losing anything, find which of them suffice for every Boolean function, and then deal with what a long reversible computation leaves behind.

2.4.1 Controlled reversible operations§

How can a gate act on one bit depending on another without losing anything? Keep the deciding bit unchanged, and let it choose a reversible update of the other bit. The kept bit is the control; the updated bit is the target.

The simplest example is controlled-NOT, or CNOT: \((a,b)\mapsto(a,b\oplus a)\). When the control \(a\) is \(0\), the target is unchanged; when \(a\) is \(1\), the target flips. So \(00\to00\), \(01\to01\), \(10\to11\), and \(11\to10\).

Applying CNOT twice restores both bits. Why does this work? The control survives the gate, so we know which update was applied, and each update, doing nothing or flipping, is its own inverse.

Would it be enough to make the target update reversible but discard the control? No: without the control we would not know whether to flip the target back.

Problems

  1. Apply CNOT with the second bit as control and the first as target to \(00\), \(01\), \(10\), and \(11\).

    Show solutionHide solution

    The map is \((a,b)\mapsto(a\oplus b,b)\): \(00\to00\), \(01\to11\), \(10\to10\), and \(11\to01\).

  2. Apply three CNOT gates in turn to \((a,b)\): control the first bit and target the second, then control the second and target the first, then control the first and target the second. Show that the result is \((b,a)\).

    Show solutionHide solution

    \((a,b)\to(a,\,a\oplus b)\to\bigl(a\oplus(a\oplus b),\,a\oplus b\bigr)=(b,\,a\oplus b)\to\bigl(b,\,b\oplus a\oplus b\bigr)=(b,a)\). Three CNOT gates swap two bits.

  3. A controlled operation keeps a control bit \(c\) and applies a map \(g_c\) to the target. Prove that it is reversible when \(g_0\) and \(g_1\) are both reversible, and give its inverse. Show by an example that it is not reversible if \(g_1\) is a reset.

    Show solutionHide solution

    The inverse keeps \(c\) and applies \(g_c^{-1}\) to the target: since \(c\) is unchanged, it knows which map to undo. If \(g_1\) resets the target to \(0\), the inputs \((1,0)\) and \((1,1)\) both go to \((1,0)\), so the controlled operation is not one-to-one.

2.4.2 CNOT, Toffoli, and Fredkin gates§

NOT and CNOT only produce XOR combinations of input bits, possibly with a constant added. They cannot produce the product \(ab\). To obtain a reversible AND, give the target two controls:

\[\operatorname{Toffoli}(a,b,c)=(a,b,c\oplus ab).\]

With \(c=0\), the target becomes \(ab\), while both inputs survive. Fixing one control to one gives CNOT; fixing both to one gives NOT. Together with clean workspace, these operations let us reversibly implement any Boolean circuit. This is a construction claim, not a promise that every circuit is small.

Fredkin uses a different operation: it swaps two targets when its control is one. On \((a,b,0)\), the last target becomes \(ab\); with targets \((0,1)\), its outputs include \(a\) and \(\neg a\). These constructions also provide universal Boolean computation with suitable constant bits and workspace.

In the drawings, a filled dot is a control on one, a circled plus is an XOR target, and a vertical connector makes them parts of the same gate. Toffoli and Fredkin are both their own inverses.

Problems

  1. Apply the Toffoli gate to all eight inputs \((a,b,c)\). Which inputs change?

    Show solutionHide solution

    Only those with \(a=b=1\): \(110\to111\) and \(111\to110\). The other six are unchanged.

  2. Using Toffoli gates and extra bits set to fixed values, compute \(a\land b\), \(\neg a\), and \(a\oplus b\). Specify the inputs of each gate.

    Show solutionHide solution

    \(a\land b\): Toffoli with controls \(a,b\) and a target set to \(0\). \(\neg a\): controls set to \(1,1\) and target \(a\), giving \(a\oplus1\). \(a\oplus b\): controls \(1\) and \(a\) with target \(b\), giving \(b\oplus a\).

  3. Prove that every output bit of a circuit of CNOT and NOT gates is a sum modulo two of input bits, possibly plus \(1\). Conclude that such circuits cannot compute \(a\land b\).

    Show solutionHide solution

    Each input bit has this form. NOT adds \(1\), and CNOT replaces the target by the sum of target and control; both keep the form, so by induction along the circuit every bit has it. If \(a\land b=c_0+c_1a+c_2b\) modulo two, the input \(00\) gives \(c_0=0\), the input \(10\) gives \(c_1=0\), and \(01\) gives \(c_2=0\), but then \(11\) gives \(0\neq1\).

2.4.3 Workspace and uncomputation§

Toffoli gates compute every function reversibly, but a longer computation produces intermediate results along the way. What becomes of them? Compute the AND of three bits \(x,y,z\) with Toffoli gates, using two extra bits that start at \(0\): a workspace bit \(w\) and an output bit \(t\). The first Toffoli gate writes \(w=xy\); the second, with controls \(w\) and \(z\), writes \(t=xyz\):

\[(x,y,z,0,0)\to(x,y,z,xy,0)\to(x,y,z,xy,xyz).\]

The answer is in \(t\), but \(w\) still holds \(xy\). What should we do with it? Resetting \(w\) to \(0\) erases it, with the cost of erasure. Leaving it means that the workspace keeps a record of the computation’s history, and every further computation adds more.

There is a third option: apply the first Toffoli gate again. It is its own inverse, so it returns \(w\) to \(xy\oplus xy=0\):

\[(x,y,z,xy,xyz)\to(x,y,z,0,xyz).\]

This is uncomputation. In general, a reversible computation of \(f\) produces its answer together with intermediate values \(g(x)\), often called garbage. Copy the answer into a fresh register with CNOT gates, then run the computation backward:

\[(x,0,0;0)\to(x,f(x),g(x);0)\to(x,f(x),g(x);f(x))\to(x,0,0;f(x)).\]

Only the input and the copied answer remain. Why go to this trouble? Classically, it avoids the cost of erasure. Quantum computation adds a stronger reason: leftover records of a computation’s history prevent the interference on which quantum algorithms depend.

Problems

  1. In the three-bit AND computation with workspace \(w\) and output \(t\), list the five bits \((x,y,z,w,t)\) after each of the three Toffoli gates for the input \((1,1,0)\).

    Show solutionHide solution

    \((1,1,0,0,0)\to(1,1,0,1,0)\to(1,1,0,1,0)\to(1,1,0,0,0)\). The second gate does nothing because \(z=0\), so \(t=0=1\land1\land0\), and the third gate resets \(w\).

  2. Compute the AND of four bits \(x,y,z,u\) with Toffoli gates, two workspace bits that start at \(0\), and one output bit, and return the workspace to \(0\). List the gates in order.

    Show solutionHide solution

    1. Controls \(x,y\), target \(w_1\): \(w_1=xy\). 2. Controls \(w_1,z\), target \(w_2\): \(w_2=xyz\). 3. Controls \(w_2,u\), target \(t\): \(t=xyzu\). 4. Repeat gate 2, resetting \(w_2\). 5. Repeat gate 1, resetting \(w_1\). The uncomputation runs in reverse order, because gate 2 needs \(w_1\) to still hold \(xy\).

  3. A reversible computation \(A\) maps \((x,0,0)\) to \((x,f(x),g(x))\). Show that applying \(A\), then copying the answer register into a fresh register with CNOT gates, then applying \(A^{-1}\), produces \((x,0,0;f(x))\) for every input \(x\).

    Show solutionHide solution

    \(A\) gives \((x,f(x),g(x);0)\). The CNOT gates add \(f(x)\) into the fresh register, giving \((x,f(x),g(x);f(x))\) and leaving the first three registers unchanged. \(A^{-1}\) acts only on those three; since \(A(x,0,0)=(x,f(x),g(x))\), it returns them to \((x,0,0)\). The result is \((x,0,0;f(x))\).

2. Worked problem §

Compute the three-bit majority function reversibly: using three Toffoli gates, turn \((x,y,z,t)\) into \((x,y,z,\,t\oplus\mathrm{maj}(x,y,z))\). Check the construction on the inputs \(110\) and \(100\) with \(t=0\).

Hint 1

Majority is \(xy+yz+xz\) modulo two.

Hint 2

Each Toffoli gate adds one product to the target.

Worked solution

Apply Toffoli gates with controls \((x,y)\), \((y,z)\), and \((x,z)\), each targeting \(t\). Together they add \(xy\oplus yz\oplus xz\), the polynomial of majority. On \(110\): \(1\oplus0\oplus0=1\). On \(100\): \(0\oplus0\oplus0=0\). The inputs are kept, so the map is reversible; it is its own inverse.

3. Extension §

Build the reversible embedding of OR, \((x,y,t)\mapsto(x,y,t\oplus(x\lor y))\), from CNOT and Toffoli gates, and show that the circuit is its own inverse.

Hint 1

\(x\lor y=x\oplus y\oplus xy\).

Hint 2

Each gate adds something to \(t\) and leaves \(x,y\) unchanged.

Worked solution

CNOT from \(x\) to \(t\), CNOT from \(y\) to \(t\), and Toffoli from \((x,y)\) to \(t\) add \(x\oplus y\oplus xy=x\lor y\) to \(t\). Since none of the gates changes \(x\) or \(y\), running the circuit twice adds \(x\lor y\) twice, which cancels. The circuit is its own inverse, and with \(t=0\) it leaves the answer in \(t\).
