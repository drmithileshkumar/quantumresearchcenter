Chapter 02

Boolean and Reversible Computation

What must a computation remember in order to undo what it has done?

An answer can conceal the history that produced it: several different inputs may leave the same output. We begin with Boolean functions and build circuits that calculate them, then examine what disappears when a logical operation discards information. Reversible gates offer another way to organize a calculation, carrying its history forward until it can be carefully uncomputed. Along the way, the distinction between logical information loss and physical dissipation becomes essential.

Reading guide · preparation, aims, and assumptions

Build computations from Boolean operations and learn how to preserve the information they would otherwise discard.

Before you begin

Use Chapter 1’s distinction between a function and an implementation.

What you should be able to do

  • Construct Boolean functions from elementary gates.
  • Verify a reversible function embedding.
  • Explain why temporary workspace must be uncomputed.

The example to follow

Follow a function value from a truth table to a reversible target update. The same update becomes the oracle in Chapter 6.

Scope and assumptions

Logical reversibility alone does not guarantee low physical dissipation. Landauer’s bound concerns erasure under stated thermodynamic conditions.

2.1

Boolean Functions

Begin with the answer we want before choosing gates to compute it.

2.1.1 Binary encodings§

A finite input can be represented by bits once an encoding is chosen. An integer may use binary digits; a string may encode characters; a graph may list edges. Encoding determines input length, which later affects resource counts. At a fixed length \(n\), there are \(2^n\) possible inputs. If outputs have a fixed bound, they too can be encoded, with padding if necessary. We first study a function on this finite domain. A procedure handling arbitrary lengths requires a systematic family of such functions, not a separate unrelated construction for every length.

Problems

  1. How many different strings can two bits represent?

    Show solutionHide solution

    Four strings: \(00\), \(01\), \(10\), and \(11\).

  2. Write the integers zero through three using two-bit binary strings.

    Show solutionHide solution

    \(0\to00\); \(1\to01\); \(2\to10\); \(3\to11\).

  3. The same bit string can represent an integer, a character, or an instruction. Which part of its meaning belongs to the bits, and which part belongs to the encoding convention? How could changing the encoding change the cost of a task?

    Show solutionHide solution

    The bits provide a distinguishable pattern; the encoding convention assigns its interpretation. For example, unary uses \(N\) marks for an integer \(N\), while binary uses order \(\log_2 N\) bits. An operation whose cost depends on representation length can therefore have very different costs under the two encodings.

2.1.2 Boolean functions and truth tables§

A Boolean function \(f:\{0,1\}^n\to\{0,1\}\) specifies a yes/no answer for each bit string. Its truth table lists all inputs and their outputs. For OR on two bits, the outputs for \(00,01,10,11\) are \(0,1,1,1\). A multi-bit answer is a collection of Boolean output functions. This description specifies what to compute but not how. It hides neither an algorithm nor an efficiency guarantee: writing the full table already takes exponentially many rows in \(n\). We need a way to turn the specification into operations.

Problems

  1. What values can a Boolean variable take?

    Show solutionHide solution

    Zero and one, also interpreted as false and true.

  2. List all input pairs for a two-input AND gate and give their outputs.

    Show solutionHide solution

    \(00\to0\), \(01\to0\), \(10\to0\), and \(11\to1\).

  3. A truth table specifies every output of a Boolean function. Why does possessing this complete description not necessarily give an efficient way to compute the function as the number of inputs grows?

    Show solutionHide solution

    An \(n\)-input truth table contains \(2^n\) rows. Storing or constructing the full table can already require exponential resources in \(n\). A table fixes the function but does not guarantee a compact circuit. Lookup can be inexpensive under a suitable memory model only after accounting for that memory and its access assumptions.

2.1.3 Polynomial representation over the binary field§

Work modulo two: addition is XOR, so \(1+1=0\), and multiplication is AND. For a row \(s\), define a detector \[\delta_s(x)=\prod_{i:s_i=1}x_i\prod_{i:s_i=0}(1+x_i).\] It equals one exactly when \(x=s\). Therefore \[f(x)=\bigoplus_{s:f(s)=1}\delta_s(x).\] On any input, at most one included detector is one, so XOR gives the required answer. Expanding produces a polynomial in the input bits. For OR, the expansion simplifies to \(x+y+xy\). Substituting \(x=y=1\) gives \(1\), as required; ordinary integer addition would give the wrong interpretation.

Problems

  1. What are \(1+1\) and \(1\times1\) in arithmetic modulo two?

    Show solutionHide solution

    \(1+1=0\) and \(1\times1=1\) modulo two.

  2. Evaluate \(x+y+xy\) modulo two for all four bit pairs. Which Boolean operation does it describe?

    Show solutionHide solution

    For \((x,y)=00,01,10,11\) the values are \(0,1,1,1\). For \(11\), the sum is \(1+1+1=1\) modulo two. This is OR.

  3. Why can \(x^2\) be replaced by \(x\) for Boolean inputs even though these are different polynomials over unrestricted numbers? What does this tell you about the role of the allowed input domain in an algebraic representation?

    Show solutionHide solution

    For \(x=0\) and \(x=1\), \(x^2=x\). Thus the two expressions agree on every allowed Boolean input even though they differ, for example, at \(x=2\) over the real numbers. Equality of represented functions depends on the domain and arithmetic, not just on whether the written expressions look different.

2.2

Boolean Circuits

The polynomial description gives a construction of a circuit, but says little about its size or reversibility.

2.2.1 Polynomial evaluation by circuits§

A circuit evaluates this polynomial by connecting operations: multiply factors with AND, add terms with XOR, and use fixed bits for constants. Wires carry intermediate bits; a gate’s outputs become later inputs. The circuit has no directed cycles, so its gates can be evaluated in order. This construction proves that every fixed-size Boolean function has a circuit. It may use exponentially many gates. Universality—being able to express every function—is a different claim from being able to express every function economically.

Problems

  1. What does a wire carry between Boolean gates?

    Show solutionHide solution

    It carries the bit produced by one gate to an input of another gate.

  2. For \(z=(a \text{ AND } b) \text{ XOR } c\), identify the intermediate value and draw the two operations in order.

    Show solutionHide solution

    First compute \(u=a \text{ AND } b\). Then compute \(z=u \text{ XOR } c\): \((a,b)\to\text{AND}\to u\), with \(u\) and \(c\) feeding \(\text{XOR}\to z\).

  3. Two algebraically equivalent expressions can produce circuits of different sizes. Where can sharing an intermediate result save gates, and what extra information about a computation does a circuit reveal beyond its truth table?

    Show solutionHide solution

    If several later gates need \(u=a \text{ AND } b\), a classical circuit can compute \(u\) once and fan it out rather than recomputing it. A circuit records dependencies, gate count, depth, and reuse of intermediates. A truth table records only the resulting input–output function.

2.2.2 NAND universality§

NAND returns \(\neg(a\land b)\). It can build the operations needed above: tying its inputs gives \(\neg a\), and negating a NAND output gives AND. XOR uses four NANDs: \[t=\operatorname{NAND}(a,b),\quad u=\operatorname{NAND}(a,t),\quad v=\operatorname{NAND}(b,t),\quad a\oplus b=\operatorname{NAND}(u,v).\] Checking the four input pairs verifies the last identity. Since NAND constructs AND, XOR, and negation, it evaluates the polynomial for any Boolean function. Classical fan-out is allowed here: the same bit may feed several gates. This is not yet a reversible construction.

Problems

  1. When does NAND output zero?

    Show solutionHide solution

    Exactly when both input bits are one.

  2. Use \(\mathrm{NAND}(x,x)\) to compute the output for \(x=0\) and \(x=1\). Which operation have you built?

    Show solutionHide solution

    \(\mathrm{NAND}(0,0)=1\) and \(\mathrm{NAND}(1,1)=0\). Tying the inputs together implements NOT.

  3. NAND can express every Boolean function. Does that make it the best gate for every implementation? Separate the claim that something can be built from the claim that it can be built economically.

    Show solutionHide solution

    No. Universality establishes that a function can be expressed with NAND gates; it does not establish the smallest, fastest, or least energy-consuming implementation. A different gate library can express a useful operation with fewer gates or suit the available hardware better.

2.2.3 Irreversible Boolean operations§

An AND output of zero could have come from \(00\), \(01\), or \(10\). If only the output remains, those inputs cannot be distinguished. The map is many-to-one and has no inverse. This is logical information loss, regardless of whether the gate was useful. A complicated circuit may implement a one-to-one overall input–output function while erasing internal records along the way. An overall reversible truth table does not by itself establish that each physical step is reversible or avoids dissipation.

Problems

  1. Can you always recover both AND inputs from its output?

    Show solutionHide solution

    No. Output zero has three possible input pairs.

  2. List the input pairs that give AND output zero. Use the list to explain the loss of information.

    Show solutionHide solution

    The pairs \(00\), \(01\), and \(10\) all produce zero. The output alone cannot distinguish which of these three inputs was supplied.

  3. An AND output of one identifies its input, while an output of zero does not. Why is the gate still classified as irreversible? Is reversibility a property of one observed run or of the whole allowed map?

    Show solutionHide solution

    Reversibility requires unique recovery for every allowed input, not just for a favorable output. Although output one identifies \(11\), the collision at zero makes the full AND map many-to-one. Restricting the allowed inputs could define a different map, but would not make unrestricted AND reversible.

2.3

Information Erasure

Erasing distinctions has a physical significance as well as a logical one.

2.3.1 Landauer’s principle§

A bit lives in a physical system. Resetting an unknown bit to zero merges two logical possibilities. Landauer’s principle assigns a minimum average heat cost \(k_{\mathrm B}T\ln2\) to erasing one unbiased bit in the usual thermal setting, without retaining a compensating record. Here \(T\) is temperature and \(k_{\mathrm B}\) is Boltzmann’s constant. The conditions matter: known bits, biased distributions, and available correlations change the information that must be erased. The principle is not a fixed energy charge on every logical gate. Its role here is to connect lost information to physical resources.

Further detail: Bennett: Landauer’s principle and reversible computation.

Problems

  1. Under the stated conditions, what happens to Landauer’s minimum erasure cost when temperature increases?

    Show solutionHide solution

    For an equally likely bit in the stated isothermal setting, the minimum \(k_BT\ln 2\) increases linearly with absolute temperature \(T\).

  2. Compare erasing two independent, equally likely bits with erasing one at the same temperature. How do their minimum costs compare?

    Show solutionHide solution

    One bit has minimum cost kBT ln 2. Two independent equally likely bits have twice the entropy to erase, giving 2kBT ln 2 under the same conditions.

  3. Erasing a known zero and erasing an unknown bit can leave the same final register value. What differs about the information being discarded? Why must a physical claim about erasure specify the initial situation?

    Show solutionHide solution

    A register already known to be zero can be left unchanged; an equally likely unknown bit requires removing a distinction between two possibilities. The standard bound concerns that entropy reduction under specified physical conditions. If knowledge is stored in another physical register, its use and eventual reset must also be included in a complete account.

2.3.2 Logical reversibility and dissipation§

A logically reversible map is one-to-one on its allowed states. It avoids the necessity of erasure at the level of that map, but a real implementation can still dissipate energy through resistance, friction, control, and imperfect operation. Conversely, an irreversible gate cannot be made logically invertible merely by operating it slowly. We must distinguish the mathematical map from its physical realization. Quantum unitary evolution will supply another reason for preserving information: it has an inverse. Measurement and interaction with an environment require a different description.

Problems

  1. Does logical reversibility alone guarantee that a physical device produces no heat?

    Show solutionHide solution

    No. Logical reversibility is a statement about information recovery, not a guarantee of zero heat.

  2. A gate’s truth table is reversible, but its implementation dissipates energy. Explain why these statements do not contradict each other.

    Show solutionHide solution

    The truth table can be one-to-one while the physical apparatus dissipates energy through its actual dynamics. Recovering the logical input and avoiding physical dissipation are distinct requirements.

  3. Could a logically reversible circuit still dissipate substantial energy in its physical implementation? What does knowing its truth table tell you, and what physical details does that table leave out?

    Show solutionHide solution

    Yes. A reversible truth table says that distinct inputs remain distinguishable. It does not specify switching speed, friction-like losses, coupling to the environment, or the thermodynamic protocol. Those physical details determine dissipation; logical reversibility alone does not determine it.

2.3.3 Reversible function embeddings§

Any Boolean function can be embedded in a reversible operation by retaining its input: \[U_f:(x,y)\mapsto(x,y\oplus f(x)).\] Applying it twice restores \(y\), because XOR with the same bit twice cancels. With \(y=0\), the second register becomes the answer. Reversibility does not require \(f\) itself to be injective: the retained \(x\) distinguishes the original inputs. Extra bits are therefore not incidental bookkeeping. They are part of the state needed to make the full transformation one-to-one.

Problems

  1. Which register is preserved in \((x,t)\to(x,t \text{ XOR } f(x))\)?

    Show solutionHide solution

    The input register \(x\) is preserved.

  2. Set \(f(0)=1\) and start with \((x,t)=(0,0)\). Apply the update twice. What returns to its original value?

    Show solutionHide solution

    \((0,0)\to(0,1)\to(0,0)\). The target flips twice and returns to zero; the input stays zero throughout.

  3. A reversible embedding retains the input while updating a target bit. Has it made the original many-to-one function invertible, or changed what counts as the full output? Explain why this distinction matters.

    Show solutionHide solution

    The original function \(f\) is unchanged and can remain many-to-one. The enlarged output retains \(x\), and XOR updating the target is invertible for each \(x\). Reversibility belongs to this full map on input and target, not to \(f\) viewed as a map that discards its input.

2.4

Reversible Gates

Retained controls and reversible target updates provide useful building blocks.

2.4.1 Controlled reversible operations§

A controlled operation retains a control value while reversibly updating a target. CNOT maps \((a,b)\) to \((a,b\oplus a)\). When \(a=0\), nothing changes; when \(a=1\), the target flips. In either case, the same operation undoes the change. Control is not synonymous with reversibility: the target operation must itself be reversible for every retained control value. This example introduces a useful design method—choose among invertible updates without discarding which update was chosen.

Problems

  1. In a controlled-NOT gate, which bit determines whether the target flips?

    Show solutionHide solution

    The control bit determines whether the target flips: it flips exactly when the control is one.

  2. Apply CNOT to \(00\), \(01\), \(10\), and \(11\), taking the first bit as control.

    Show solutionHide solution

    \(00\to00\), \(01\to01\), \(10\to11\), and \(11\to10\).

  3. A controlled gate uses one bit to determine what happens to another while preserving the control. Why is preserving the control helpful when reconstructing the past? Would merely knowing that a conditional instruction was executed be enough?

    Show solutionHide solution

    Keeping the control records which reversible target operation occurred, so the inverse can choose the corresponding inverse operation. Merely knowing that some conditional instruction ran does not identify its branch. For CNOT, the retained control tells whether to flip the target again.

2.4.2 CNOT, Toffoli, and Fredkin gates§

Toffoli maps \((a,b,c)\) to \((a,b,c\oplus ab)\). A zero target records AND while preserving its inputs. Fredkin retains a control and swaps two targets when that control is one. Both are their own inverses. Toffoli with initialized workspace can implement general reversible Boolean computations; CNOT alone cannot produce the nonlinear term \(ab\). In circuit drawings a filled dot denotes a control on one, and a circled plus denotes an XOR target. A vertical connector means these symbols belong to one joint gate.

Problems

  1. How many control bits does a Toffoli gate have?

    Show solutionHide solution

    Two control bits and one target bit.

  2. Apply Toffoli to \(110\) and \(100\), with the last bit as target. Explain why only one target flips.

    Show solutionHide solution

    \(110\to111\) because both controls are one. \(100\to100\) because the second control is zero.

  3. CNOT and Toffoli are both reversible, but Toffoli can write the AND of two inputs into a blank target. What additional dependence on the inputs does Toffoli introduce? Why does reversibility alone not determine a gate’s computational usefulness?

    Show solutionHide solution

    CNOT updates a target by XOR with one control; Toffoli updates it by XOR with the product of two controls. This introduces the nonlinear Boolean dependence xy needed to compute AND into a blank target. Many different one-to-one maps are reversible; they need not generate the same family of computations.

2.4.3 Workspace and uncomputation§

A reversible calculation often yields \((x,f(x),g(x))\), where \(g(x)\) is temporary “garbage.” Resetting it would erase information. Instead, compute, XOR the result into a clean output register, and run the computation backward: \[(x,0,0)\to(x,f(x),g(x))\to(x,f(x),g(x);f(x))\to(x,0,0;f(x)).\] The notation groups workspace schematically; only the copied answer remains in the fresh register. In a quantum computation this copies basis labels coherently, not an arbitrary unknown state. Uncomputation becomes essential when unwanted workspace records would obstruct interference.

Problems

  1. What is temporary workspace used for?

    Show solutionHide solution

    It holds intermediate values needed while carrying out the computation.

  2. Put these steps in order: reverse the computation, compute the result, copy the basis-state result into a clean output.

    Show solutionHide solution

    Compute the result, copy its basis-state value into a clean output, then reverse the original computation.

  3. If a computation retains every intermediate value, it can preserve its history but exhaust its workspace. How does computing, recording the result, and running backward avoid keeping that history forever? What information remains at the end?

    Show solutionHide solution

    The inverse reuses the information still present to undo intermediate steps and restore clean workspace. Because a separate output register holds the copied basis label, reversing the original registers does not erase that output. The input and output remain; the temporary history need not remain. This copying step concerns basis labels, not arbitrary unknown quantum states.

Check your understanding

Why does retaining x make an irreversible function usable in a reversible map?

Compare your explanation

The map keeps x and XORs f(x) into a target. The same operation undoes itself, even when distinct inputs have the same function value.

Questions and worked problems

Attempt each question before opening a hint. Explain your reasoning, then compare it with the solution.

1. Quick check §

Is AND reversible if only its one-bit output is retained?

Hint 1

List inputs with output zero.

Hint 2

\(00\), \(01\), and \(10\) have the same output.

Worked solution

No. The output does not uniquely identify the input. Keeping the inputs changes the full map and allows a reversible embedding.

2. Worked problem §

Apply \((x,y,t)\mapsto(x,y,t \text{ XOR } xy)\) to \(110\), \(111\), and \(010\). Then apply it again.

Hint 1

The target flips only when both controls are 1.

Hint 2

The controls never change.

Worked solution

\(110\to111\to110\); \(111\to110\to111\); \(010\to010\to010\). The gate is its own inverse on all three bits, even though AND alone is many-to-one.

Revisit the relevant explanation

3. Extension §

After computing an answer and temporary workspace, why not simply reset the workspace to zero? Describe a reversible alternative for classical basis inputs.

Hint 1

Resetting merges different workspace values.

Hint 2

Record the answer in a clean output, then reverse the computation.

Worked solution

Resetting erases the distinctions stored in the workspace. Compute the result, XOR it into a clean output register, then apply the inverse computation to the original registers. This restores the workspace while retaining the input and recorded output. Copying basis labels this way does not clone an arbitrary unknown quantum state.
