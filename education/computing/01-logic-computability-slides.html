What exactly is a proof?

Axioms are the chosen assumptions; rules of inference are the permitted steps.

A proof is a finite object that a procedure can check. Checking shows the conclusion follows, not that the axioms are right.

§1.1.1 in the book3 / 19

Can the rules themselves be trusted?

A system is consistent if it never proves both a statement and its opposite.

Hilbert’s plan: make the rules explicit, then prove with reasoning about finite objects that they never give a contradiction.

When does a proof search stop?

List every candidate proof by length and check each one. When does this search finish?

Answer

If a proof exists, eventually: it appears somewhere in the list. If none exists, never. No final candidate settles the matter.

Why is Euclid right, and why does it stop?

\((48,18)\to(18,12)\to(12,6)\to(6,0)\)

Correctness: the gcd never changes (an invariant). Termination: the second entry keeps falling and cannot fall forever.

What must we record to resume a computation?

A configuration is everything needed to continue; a run is a sequence of transitions between configurations.

Does the present determine the past?

In Euclid’s algorithm the next pair is determined. Is the previous one?

Answer

No. Both \((30,18)\) and \((48,18)\) lead to \((18,12)\). Knowing how to continue does not tell us how to go back.

What counts as an elementary step?

Break “divide” into steps that read a symbol, write one, move one cell, and change a finite state.

A rule table is finite data, so one universal machine can read any program and simulate it.

Computability and Its Limits

Is there a question that no procedure can settle?

Read the chapter12 / 19

Is the Turing machine the right model?

Equivalence of formal models is a theorem. That every effective method is a Turing machine is a thesis.

§1.3.1 in the book13 / 19

Can one program predict whether every program halts?

  1. Suppose \(H(P,x)\) always halts and says whether \(P\) halts on \(x\).
  2. Build \(D(p)\): if \(H(p,p)\) says “halts”, loop forever; otherwise stop.
  3. Run \(D\) on its own description \(d\).
  4. If \(H(d,d)\) says “halts”, \(D\) loops. If it says “does not halt”, \(D\) stops.
  5. Either answer is wrong, so no such \(H\) exists.

The halting problem is undecidable.

§1.3.2 in the book14 / 19

Two different limits

Undecidability concerns procedures; incompleteness concerns what fixed axioms can settle.

A consistent theory strong enough for arithmetic leaves some sentence undecided, and cannot prove its own consistency.

From Computability to Reversibility

For problems we can solve, what does the solution do to the information it is given?

Read the chapter16 / 19

Does knowing the next step tell us the last?

Deterministic means one successor. Reversible also needs one predecessor: the step must be one-to-one.

§1.4.1 in the book17 / 19

Must computing an answer lose the input?

No: keep \((x,f(x))\). Even a many-to-one \(f\) can be computed without losing \(x\).

§1.4.2 in the book18 / 19

What we found

  1. A proof is a finite object that a procedure can check.
  2. Search finds proofs that exist but cannot decide every question.
  3. Configurations and transitions make “procedure” precise; a universal machine runs them all.
  4. Some questions, such as halting, are undecidable; strong theories are incomplete.
  5. Reversibility asks whether a computation keeps the information it was given.
