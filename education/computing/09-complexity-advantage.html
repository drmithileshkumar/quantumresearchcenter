Chapter 09

Computational Complexity and Quantum Advantage

An advantage is meaningful only with a stated task, model, success condition, and resource. We distinguish algorithmic upper bounds, general lower bounds, and unresolved comparisons.

9.1

Resource Bounds

Fix the encoding and resource before interpreting a growth rate.

9.1.1 Input size and success criteria§

A comparison begins with the same task, encoding, input size, permitted access, and success criterion. For an integer \(N\), binary input length is of order \(\log N\), so a procedure taking \(N\) steps is exponential in that length. Distinguish worst-case, average-case, and expected costs; an expectation needs a stated distribution or algorithmic randomness. Query models also specify what one request returns. Changing the interface can change the problem, not merely the method used to solve it.

9.1.2 Asymptotic notation§

For eventually nonnegative functions, \(T(n)=O(g(n))\) means an eventual upper bound \(T(n)\leq Cg(n)\) for some constant \(C>0\). The notation \(\Omega(g(n))\) gives a corresponding lower bound; \(\Theta(g(n))\) gives both. For example, \(3n^2+7n+2=\Theta(n^2)\). These notations suppress constants, not the input encoding or the model. Polynomial bounds describe powers of input length; exponential bounds such as \(2^n\) grow much faster. A polynomial exponent can still make a method impractical at relevant sizes.

9.1.3 Query, gate, and space complexity§

Query complexity counts oracle uses, gate complexity counts elementary operations, and space complexity counts memory. A quantum query advantage may survive or disappear when translated into total gate and preparation cost. Physical runtime also depends on scheduling, error correction, and device constraints. State which level a bound concerns. For unstructured search, the quadratic query reduction is a precise theorem. It is not a theorem that searching any stored dataset on any quantum device is quadratically faster end to end.

9.2

Complexity Classes

Complexity classes organize tasks by the procedures and error guarantees allowed.

9.2.1 P, NP, and reductions§

P consists of decision problems solvable deterministically in polynomial time. NP consists of those whose yes instances have polynomial-size witnesses verifiable in polynomial time. Equivalently, a nondeterministic machine can guess a witness and verify it; this is not a claim that a physical random guess will probably find one. A polynomial-time reduction from A to B transforms instances so that a solver for B yields a solver for A with polynomial overhead. It compares difficulty without claiming equal runtimes. Whether P equals NP remains unresolved.

9.2.2 BPP and BQP§

BPP uses classical randomness and polynomial time, with error bounded by a constant below one half, conventionally one third. BQP uses uniformly generated polynomial-size quantum circuits with a comparable error bound. Repetition and suitable decision rules can reduce error when independent trials have a fixed gap above chance. Quantum circuits can implement classical randomized computation, giving \(\mathrm{BPP}\subseteq\mathrm{BQP}\). It is not known that BQP contains all of NP, or that every BQP problem lies outside efficient classical computation. These are classes of decision tasks; factoring is usually posed as a function task.

9.2.3 Factoring and search§

Quantum period-finding methods give polynomial-time factoring algorithms in the binary input length, although their derivation lies beyond this book. No polynomial-time classical factoring algorithm is known; this is not a classical lower bound proving exponential advantage. Grover search, in contrast, has a proved quadratic separation in a specified unstructured query setting. These examples illustrate two kinds of evidence: an algorithm compared with currently known competitors, and an optimality statement within a restricted model. Neither implies that quantum computers accelerate every task.

9.3

Query Lower Bounds

A limit on every possible method requires an argument stronger than an analysis of one method.

9.3.1 Upper and lower bounds§

An upper bound is established by an algorithm and a cost analysis. A lower bound must constrain every algorithm allowed by the model, including ones nobody has invented. Thus a slow known method does not establish a lower bound. Restricting to query access makes some general arguments possible: algorithms may perform arbitrary input-independent processing, but the hidden input influences them only through counted queries. A bound in this model can be strong and useful while saying nothing by itself about the cost of implementing a query.

9.3.2 Unstructured search optimality§

For finding a unique marked item among \(N\) candidates with constant success probability, quantum algorithms require \(\Omega(\sqrt N)\) queries. Grover’s \(O(\sqrt N)\) algorithm matches this, so the query complexity is \(\Theta(\sqrt N)\). Intuitively, a query can change the state substantially only through amplitude placed on the marked location; averaged over possible locations, that amplitude is limited. A hybrid argument makes this accumulation precise. We state the lower-bound theorem here; the geometric derivation of Grover alone proves its upper bound, not its optimality.

9.3.3 Acceptance polynomials and approximate degree (optional)§

An alternative method represents acceptance probability as a polynomial in Boolean oracle bits. After \(T\) standard queries, amplitudes have degree at most \(T\), and probabilities degree at most \(2T\). A bounded-error algorithm must therefore produce a low-degree polynomial approximating the desired Boolean function on every Boolean input. If the function’s approximate degree is \(d\), then \(T\geq d/2\). The approximate degree of OR on \(N\) bits is \(\Theta(\sqrt N)\), yielding a matching lower bound for detecting a marked item. Appendix E explains the representation; the approximation theorem is an additional mathematical result.

Further detail: Beals et al.: Quantum Lower Bounds by Polynomials.

9.4

Scope of Quantum Advantage

The book’s examples illustrate both the mechanism and the conditions of a defensible advantage.

9.4.1 Algorithmic mechanisms and assumptions§

The algorithms in this book use coherent transformations to make a requested property affect outcome probabilities. Deutsch’s algorithm turns equality of function values into relative phase and then a definite bit. Amplitude amplification rotates a prepared state toward a successful subspace. Their advantages require specified oracles, controllable inverse operations where used, and a suitable final measurement. Large state spaces provide room for these constructions, but size alone is not their explanation. Correctness is established by the evolution and readout calculation.

9.4.2 Computability and readout limitations§

Quantum computation does not remove the halting obstruction, permit arbitrary cloning, or expose all amplitudes through one measurement. It also does not eliminate the cost of encoding inputs, implementing operations, or protecting states from noise. These constraints are part of the model, not qualifications appended after the algorithm. A useful claim names the task, mechanism, success guarantee, and resources. The same discipline that distinguished a pattern from a proof at the start now distinguishes a plausible speedup from an established one.

9.4.3 Period finding and error correction: further topics§

Period finding develops a different use of interference: a Fourier transform converts periodic structure into measurable frequency information. Quantum error correction addresses the reliability of long computations through encoded subspaces and measured syndromes. Both build on the state, operator, measurement, and circuit language developed here, but require additional constructions and proofs. They are natural continuations rather than prerequisites to the present algorithms. The current foundation is complete enough to identify what those later chapters must explain: a mechanism, a correct readout, and an honest resource bound.
