Chapter 09

Computational Complexity and Quantum Advantage

We have seen quantum algorithms that use fewer queries than any classical method. Does that make quantum computers more powerful? A claim of this kind needs care. The same task, the same encoding of inputs, the same allowed error, and the same resources must be compared, and the comparison must hold against every possible method, not only the known ones.

We first fix how costs are measured: input size, asymptotic growth, and the resource being counted. Complexity classes then group problems by the resources needed to solve them, classically and quantum mechanically, and show what is known and what remains open. Lower bounds give the strongest evidence, a limit on every algorithm in a model; for unstructured search they show that Grover’s algorithm cannot be improved. Finally we take stock of what the algorithms in this book establish, what quantum computers cannot do, and where the subject continues.

What would justify saying that one form of computation is more powerful than another?

A faster algorithm shows what is possible; only a lower bound shows what is impossible. Establishing an advantage needs both.

Reading guide · preparation, aims, and assumptions

Evaluate a quantum advantage claim by fixing the task, model, error allowance, and counted resources.

Before you begin

Recall the query count of amplitude amplification and the gate costs of circuits.

What you should be able to do

  • Distinguish upper bounds from lower bounds.
  • Relate input length to numeric magnitude.
  • State the scope of the quantum search advantage.

The example to follow

Revisit four-item search as a member of a problem family, then count how queries scale with the number of items.

Scope and assumptions

Query lower bounds apply to the stated access model. An absence of known efficient classical algorithms is not a general classical lower bound.

9.1

Resource Bounds

A quantum algorithm that uses fewer queries than any classical one looks faster. Turning that impression into a claim requires fixing what is compared: the task and the size of its input, the rule for comparing costs as the input grows, and the resource being counted. Each choice can change the conclusion.

9.1.1 Input size and success criteria§

When can we say that one method is faster than another? Only when both solve the same task on the same terms: the same encoding of inputs, the same measure of input size, the same access to data, and the same standard of success.

Why does the encoding matter? Size is measured by the length of the input. An integer \(N\) written in binary has about \(\log_2N\) bits, so a procedure that takes \(N\) steps takes a number of steps exponential in the input length.

Which cost do we report? The worst case over all inputs, the average over a stated distribution of inputs, or the expected cost of an algorithm that uses randomness. Each is legitimate, but they must not be mixed.

In a query model, we must also say what one query returns. Changing the interface changes the problem, not merely the method used to solve it.

Problems

  1. How many bits does \(N=10^9\) have in binary? A procedure takes about \(\sqrt N\) steps. Is that polynomial in the input length?

    Show solutionHide solution

    \(2^{29}\lt10^9\lt2^{30}\), so \(N\) has \(30\) bits. With \(n\) bits, \(\sqrt N\approx2^{n/2}\), which is exponential in \(n\), not polynomial.

  2. An algorithm takes \(5\) steps on half of the \(n\)-bit inputs and \(2^n\) steps on the other half. Give its worst-case cost and its average cost over uniformly random inputs.

    Show solutionHide solution

    Worst case: \(2^n\). Average: \(\tfrac12\cdot5+\tfrac12\cdot2^n=(5+2^n)/2\), still exponential. A good average needs most inputs, weighted by their probability, to be cheap.

  3. Trial division finds a factor of \(N\) by testing the divisors \(2,3,\dots,\lfloor\sqrt N\rfloor\). Express its worst-case number of divisions in terms of the input length \(n=\log_2N\). Is it polynomial-time?

    Show solutionHide solution

    In the worst case, when \(N\) is prime or a product of two close primes, it tests about \(\sqrt N=2^{n/2}\) divisors. That is exponential in \(n\): trial division is not polynomial-time, although its cost is polynomial in the value \(N\).

9.1.2 Asymptotic notation§

To compare growth, write \(T(n)=O(g(n))\) when some constant \(C>0\) bounds \(T(n)\leq Cg(n)\) for all sufficiently large \(n\). Write \(\Omega\) for the corresponding lower bound and \(\Theta\) when both hold.

For \(n\geq1\),

\[3n^2\leq3n^2+7n+2\leq12n^2.\]

The cost is therefore \(\Theta(n^2)\). This describes the growth of that cost expression; it does not prove that every algorithm for the task needs quadratic time.

Asymptotic notation suppresses constant factors, lower-order detail, and finite-size crossover behavior. It does not supply the input encoding or computational model: those must be stated separately.

Every fixed polynomial eventually grows more slowly than an exponential with base greater than one. “Eventually” matters. A large exponent or constant can make a polynomial method impractical over the entire range of inputs we can use. Scaling and actual costs answer related but different questions.

Problems

  1. Is \(100n=O(n^2)\)? Is \(n^2=O(100n)\)? Give constants, or explain why none exist.

    Show solutionHide solution

    Yes: \(100n\leq100n^2\) for \(n\geq1\), so \(C=100\) works. No: \(n^2\leq C\cdot100n\) fails as soon as \(n\gt 100C\), whatever \(C\) is.

  2. Two algorithms take exactly \(1000n\) and \(n^2\) steps. Which is faster at \(n=100\), \(n=1000\), and \(n=10{,}000\)? Which scales better? Explain why these are different questions.

    Show solutionHide solution

    At \(n=100\), the costs are \(100{,}000\) and \(10{,}000\), so the quadratic algorithm wins. At \(n=1000\), both cost \(10^6\). At \(n=10{,}000\), the costs are \(10^7\) and \(10^8\), so the linear algorithm wins. Linear growth is eventually better, but the constant moves the crossover to \(1000\). A scaling claim needs the input size and actual costs before it becomes a practical recommendation.

  3. For which input lengths \(n\geq2\) is an algorithm costing \(n^{10}\) steps faster than one costing \(2^n\) steps? What does this show about asymptotic comparisons?

    Show solutionHide solution

    Comparing the two, \(n^{10}\gt 2^n\) for every \(n\) from \(2\) to \(58\), and \(n^{10}\lt2^n\) from \(n=59\) on. The polynomial algorithm wins only for inputs of at least \(59\) bits, where both costs exceed \(10^{17}\). Asymptotic statements describe eventual growth; at practical sizes, constants and exponents can decide the comparison.

9.1.3 Query, gate, and space complexity§

Which resource are we counting? Query complexity counts oracle uses, gate complexity counts elementary operations, and space complexity counts memory. Physical running time depends further on scheduling, error correction, and the device.

Does an advantage in one resource carry over to another? Not automatically. A quantum query advantage may survive, or disappear, once the cost of implementing each query and of preparing the input is counted.

For unstructured search, the quadratic reduction in queries is a theorem. It is not a theorem that searching any stored dataset on any quantum device is quadratically faster overall.

Problems

  1. A Grover search over \(N=10^6\) items uses about \((\pi/4)\sqrt N\) queries. If each query costs \(1000\) gates and each reflection \(50\) gates, estimate the total gate count.

    Show solutionHide solution

    \((\pi/4)\times1000\approx785\) iterations of \(1050\) gates each: about \(8.2\times10^5\) gates.

  2. A classical scan costs one operation per item. For \(N=10^6\), below which cost \(c\) per query does a Grover search, costing about \((\pi/4)\sqrt N\cdot c\) gates, beat the scan?

    Show solutionHide solution

    We need \(785c\lt10^6\), so \(c\lt1273\) gates per query. A more expensive oracle erases the quadratic advantage at this size.

  3. Algorithm A uses \(n^2\) queries and \(n^3\) other gates; algorithm B uses \(n\) queries and \(n^4\) other gates. If each query costs \(n^k\) gates, which algorithm has the smaller total gate count, depending on \(k\)?

    Show solutionHide solution

    A costs \(n^{2+k}+n^3\), and B costs \(n^{1+k}+n^4\). For \(k\lt2\), A grows like \(n^3\) and B like \(n^4\): A wins. For \(k=2\), both grow like \(n^4\). For \(k\gt 2\), A grows like \(n^{2+k}\) and B like \(n^{1+k}\): B wins. Fewer queries help only when queries dominate the cost.

9.2

Complexity Classes

The cost of one algorithm becomes a statement about a problem once we ask for the cheapest algorithm. Complexity classes collect the problems that can be solved within a given resource bound: in polynomial time deterministically, with a certificate that can be checked, with randomness and bounded error, or on a quantum computer. The relations between these classes are largely unproved, and this limits what can be claimed about factoring and search.

9.2.1 P, NP, and reductions§

Return to the distinction between finding an argument and checking one. P consists of decision problems solvable in polynomial time by a deterministic algorithm. NP consists of decision problems whose yes-instances have polynomial-size certificates checkable in polynomial time.

A proposed nontrivial factor of an integer illustrates the difference: division checks the candidate, but the checking procedure does not tell us how to find it. Equivalently, a nondeterministic machine can guess a certificate and accept if some branch verifies it. This says nothing about the probability that a random guess succeeds.

A polynomial-time reduction from \(A\) to \(B\) converts an instance of \(A\) into one of \(B\) while preserving the answer. An efficient solver for \(B\) would then give one for \(A\). Notice the direction: the solver for the target problem helps solve the source problem.

Whether every efficiently verifiable decision problem is efficiently solvable—whether P equals NP—remains open. We need these definitions to state computational claims precisely, not to suggest that quantum computation has already settled them.

Problems

  1. Which of these are decision problems: (a) is \(N\) prime? (b) find a factor of \(N\); (c) does a graph \(G\) contain a path from \(u\) to \(v\)?

    Show solutionHide solution

    (a) and (c): their answers are yes or no. (b) asks for a number; it can be turned into decision problems, such as “does \(N\) have a factor below \(k\)?”

  2. For the problem “does \(N\) have a factor \(d\) with \(1\lt d\lt k\)?”, give a witness for \(N=91\) and \(k=10\), and explain how a witness is checked in polynomial time.

    Show solutionHide solution

    \(d=7\): it satisfies \(1\lt7\lt10\), and \(91=7\times13\). Checking a proposed \(d\) means comparing it with \(1\) and \(k\) and dividing \(N\) by \(d\), which takes time polynomial in the number of digits. The problem is in NP.

  3. Prove that if \(A\) reduces to \(B\) in polynomial time and \(B\) is in P, then \(A\) is in P. Why must the reduction itself run in polynomial time?

    Show solutionHide solution

    Let the reduction run in time \(p(n)\) on inputs of length \(n\); its output then has length at most \(p(n)\). Solving that instance of \(B\) takes time \(q(p(n))\) for the polynomial \(q\) bounding \(B\)’s algorithm. The total, \(p(n)+q(p(n))\), is a polynomial in \(n\), so \(A\) is in P. If the reduction were slow, or produced an exponentially long instance, the composition would not be polynomial.

9.2.2 BPP and BQP§

What if an algorithm may use randomness and occasionally err? BPP is the class of decision problems solved in polynomial time by a randomized classical algorithm whose probability of error is at most \(1/3\) on every input. Why \(1/3\)? Any constant below \(1/2\) would do: repeating the algorithm and taking the majority answer drives the error down quickly.

BQP is the quantum counterpart: decision problems solved, with error at most \(1/3\), by a uniform family of polynomial-size quantum circuits.

How do the classes compare? A quantum circuit can simulate a randomized classical computation, so \(\mathrm{BPP}\subseteq\mathrm{BQP}\). Is BQP larger? This is not known, and neither is whether BQP contains NP. These are classes of decision problems; factoring is usually stated as a task whose answer is a number.

Problems

  1. An algorithm errs with probability at most \(1/3\). Run it three times independently and take the majority answer. What is the error probability?

    Show solutionHide solution

    The majority is wrong when at least two runs are wrong: \(3\cdot(1/3)^2\cdot(2/3)+(1/3)^3=6/27+1/27=7/27\approx0.26\), less than \(1/3\).

  2. How many independent runs, with a majority vote, bring the error below \(0.01\) when each run errs with probability \(1/3\)?

    Show solutionHide solution

    Summing the probability that at least half the runs are wrong, an odd number \(k\) of runs gives error below \(0.01\) first at \(k=47\), where it is about \(0.009\). The error falls exponentially in \(k\), so this kind of repetition is cheap.

  3. Show that an algorithm that ignores its input and answers by flipping a fair coin has error \(1/2\) on every input, and that majority voting over repeated runs never improves it. Why is the condition “error at most \(1/3\)” essential?

    Show solutionHide solution

    Each run is right with probability \(1/2\), whatever the input. With \(k\) independent fair coins, the majority is a fair coin by symmetry, so its error is still \(1/2\). Majority voting helps only when each run is right with probability bounded above \(1/2\); the gap, here at least \(1/3\) versus \(2/3\), is what repetition amplifies.

9.2.3 Factoring and search§

What evidence is there that quantum computers are more powerful? There are two kinds, of different strength.

Factoring: quantum period finding gives a factoring algorithm whose running time is polynomial in the number of digits; its derivation lies beyond this book. No polynomial-time classical algorithm is known. No one has proved that none exists, however, so this is an advantage over known methods, not a proven separation.

Search: Grover’s algorithm has a proved quadratic advantage, but only in the unstructured query model.

Neither kind of evidence suggests that quantum computers speed up every task.

Problems

  1. Trial division of a \(2048\)-bit number may test up to \(\sqrt N\approx2^{1024}\) divisors. Write this roughly as a power of ten.

    Show solutionHide solution

    \(2^{1024}=10^{1024\log_{10}2}\approx10^{308}\).

  2. A rough estimate for Shor’s factoring algorithm is \(n^3\) operations for an \(n\)-bit number. Compare \(n^3\) with \(2^{n/2}\) for \(n=2048\).

    Show solutionHide solution

    \(2048^3\approx8.6\times10^9\), against about \(10^{308}\). The polynomial is astronomically smaller, which is why factoring is the standard example of a possible exponential quantum advantage.

  3. The best known classical factoring method, the number field sieve, takes time roughly \(\exp\bigl(1.92(\ln N)^{1/3}(\ln\ln N)^{2/3}\bigr)\). Evaluate it for a \(2048\)-bit \(N\), and explain why this comparison does not prove that quantum computers are exponentially more powerful.

    Show solutionHide solution

    \(\ln N=2048\ln2\approx1420\), so \((\ln N)^{1/3}\approx11.2\) and \((\ln\ln N)^{2/3}\approx3.75\). The exponent is about \(81\), giving \(e^{81}\approx10^{35}\) steps: far better than trial division, still far worse than \(10^{10}\). The comparison is with the best known classical method. No one has proved that a faster classical algorithm cannot exist, so the gap is not a proven separation.

9.3

Query Lower Bounds

The strongest evidence of an advantage shows what no algorithm can do. Such statements are rarely provable for running time, but query models make them provable, and for unstructured search they show that Grover’s algorithm is the best possible. A second route turns query counts into the degrees of polynomials.

9.3.1 Upper and lower bounds§

An upper bound is constructive: exhibit one algorithm and bound its cost. A lower bound is universal: show that every algorithm allowed by the model needs at least a certain resource. An unsuccessful search for a faster method is neither proof nor evidence sufficient for a lower bound.

Query models isolate the obstacle. The hidden input can affect the computation only through oracle calls; the intervening operations must be independent of that hidden input except through what the calls make available.

This restriction can make a lower-bound proof possible even when gate-by-gate analysis of every imaginable algorithm would be hopeless. Its conclusion is strong within the model. It does not determine the physical cost of a query, or automatically apply when a different interface reveals more structure.

Problems

  1. Which of these establishes a lower bound on query complexity: (a) an algorithm using \(\sqrt N\) queries; (b) a proof that every algorithm needs at least \(\sqrt N\) queries; (c) many failed attempts to find an algorithm with fewer queries?

    Show solutionHide solution

    Only (b). An algorithm gives an upper bound, and failed attempts give no bound at all.

  2. Using the fact that \(k\) classical queries find a single marked item among \(N\) with probability at most \(k/N\), show that success probability \(1/2\) needs at least \(N/2\) queries.

    Show solutionHide solution

    \(k/N\geq1/2\) requires \(k\geq N/2\). So classical search needs \(\Omega(N)\) queries for constant success.

  3. In the query model, an algorithm may compute without limit between queries. Explain why a query lower bound still applies to algorithms with limited computation, but a query upper bound need not give a fast algorithm.

    Show solutionHide solution

    Algorithms with limited computation between queries are among those the model allows, so a bound that holds for every allowed algorithm holds for them. An upper bound is witnessed by one algorithm, which may perform huge computations between queries, or use queries that are expensive to implement; its query count says nothing about those costs.

9.3.2 Unstructured search optimality§

Can a quantum algorithm search faster than Grover’s? No. Finding a unique marked item among \(N\) with constant success probability requires \(\Omega(\sqrt N)\) queries. Grover’s algorithm uses \(O(\sqrt N)\), so the query complexity of the task is \(\Theta(\sqrt N)\).

Why can it not be faster? A single query can change the state substantially only through the amplitude on the marked label, and averaged over all possible positions of the mark, that amplitude is small. The hybrid argument makes this precise; we state its conclusion as a theorem. The geometry of the Grover iteration proves an upper bound, not optimality.

Problems

  1. For \(N=10^6\), compare Grover’s query count, about \((\pi/4)\sqrt N\), with the classical average \(N/2\).

    Show solutionHide solution

    About \(785\) queries against \(500{,}000\).

  2. If some quantum algorithm searched with only \(N^{1/3}\) queries, how many would it use for \(N=10^6\)? Which result rules this out?

    Show solutionHide solution

    \(N^{1/3}=100\). The lower bound of \(\Omega(\sqrt N)\) queries for unstructured search rules it out: no quantum algorithm searches an unstructured space substantially faster than Grover’s.

  3. Use the lower bound to show that no quantum algorithm finds a marked item among \(N=2^n\) with a number of queries polynomial in \(n\). What does this imply for solving NP problems by unstructured search?

    Show solutionHide solution

    Any algorithm needs \(\Omega(\sqrt N)=\Omega(2^{n/2})\) queries, which is exponential in \(n\). Treating an NP problem as a search over all \(2^n\) candidate witnesses, with a verifier as the oracle, therefore takes exponential time even on a quantum computer. An efficient quantum method would have to exploit the problem’s structure.

9.3.3 Acceptance polynomials and approximate degree (optional)§

Optional derivation · polynomial lower bounds

Is there another route to lower bounds? Write the hidden input of the oracle as bits \(z_1,\dots,z_N\). After \(T\) queries, every amplitude is a polynomial of degree at most \(T\) in these bits, and every acceptance probability is a polynomial of degree at most \(2T\).

An algorithm that is correct with probability at least \(2/3\) therefore yields a polynomial of degree at most \(2T\) that approximates the function it computes on every Boolean input. If every such approximating polynomial needs degree at least \(d\), the approximate degree, then \(2T\geq d\), so \(T\geq d/2\).

For OR on \(N\) bits, which detects whether any item is marked, the approximate degree is \(\Theta(\sqrt N)\). This gives a second proof of the \(\Omega(\sqrt N)\) lower bound. Appendix E explains why the degree grows by at most one per query; the approximate degree of OR is a separate theorem.

Further detail: Beals et al.: Quantum Lower Bounds by Polynomials.

Problems

  1. After \(T=3\) queries, what is the largest possible degree of an amplitude, and of an acceptance probability?

    Show solutionHide solution

    An amplitude has degree at most \(3\), and an acceptance probability, a sum of squared magnitudes, at most \(6\).

  2. The approximate degree of OR on \(N\) bits grows like \(\sqrt N\). For \(N=10^4\), what lower bound on queries does \(T\geq d/2\) give, up to a constant factor?

    Show solutionHide solution

    \(\sqrt N=100\), so \(T\) must be at least about \(50\) times a constant: of order \(\sqrt N\), matching Grover’s algorithm.

  3. Show that the exact degree of OR on \(N\) bits is \(N\), by writing \(\mathrm{OR}(z)=1-\prod_i(1-z_i)\). What does this imply for algorithms that must be correct with certainty?

    Show solutionHide solution

    \(\mathrm{OR}(z)=0\) exactly when every \(z_i=0\), which is when \(\prod_i(1-z_i)=1\). Expanding the product gives the term \((-1)^{N+1}z_1z_2\cdots z_N\) with a nonzero coefficient, and a multilinear polynomial representing a Boolean function is unique, so the degree is \(N\). An exact algorithm yields an acceptance probability of degree at most \(2T\) equal to OR, so \(2T\geq N\): it needs at least \(N/2\) queries.

9.4

Scope of Quantum Advantage

With these methods in place, we can take stock. The algorithms of the book share a mechanism, and their advantages rest on stated assumptions. Quantum computers do not escape the limits found for classical computation, and they add limits of their own. Two topics beyond this book, period finding and error correction, show where the same ideas lead.

9.4.1 Algorithmic mechanisms and assumptions§

What do the algorithms of this book have in common? Each uses coherent operations to make the property we want affect the probabilities of the final outcome. Deutsch’s algorithm turns the equality of two function values into a relative phase, and then into a definite bit. Amplitude amplification rotates a prepared state toward the successful outcomes.

What do their advantages depend on? Specified oracles, coherent access to inverses where they are used, and a measurement chosen to expose the answer. The large state space gives room for these constructions, but size alone explains nothing: correctness is established by calculating the evolution and the readout.

Problems

  1. For Deutsch’s algorithm and for Grover search, name the property that is encoded in phases, and the operation that turns it into probability.

    Show solutionHide solution

    Deutsch: whether \(f(0)=f(1)\), encoded as a relative sign by phase kickback and converted by the final \(H\). Grover: whether a label is marked, encoded as a sign by the oracle and converted by the reflection about the mean, repeated the right number of times.

  2. For each of the two algorithms, list costs that its query count does not include.

    Show solutionHide solution

    Both leave out preparing the initial state, the Hadamard gates, building the oracle from a description of \(f\), and measurement. Grover search also leaves out the reflections, choosing the number of iterations, and verifying the answer.

  3. An algorithm prepares the uniform superposition of \(n\) qubits, applies an oracle once, and measures immediately. Show that it does no better than one classical query, whether the oracle is a phase oracle or the reversible \(U_f\).

    Show solutionHide solution

    A phase oracle only changes signs, so every label is still measured with probability \(2^{-n}\): a uniformly random label, which a classical algorithm can produce without any query. With \(U_f\) and a clean target, the result is a uniformly random \(x\) together with \(f(x)\), exactly what one classical query of a random input gives. Without further operations that make amplitudes interfere, there is no advantage.

9.4.2 Computability and readout limitations§

Quantum computation changes some resource costs without removing all limits. In the standard effective circuit model, the gates and their required approximations have computable descriptions. A classical computer can simulate the resulting finite computations, generally at enormous cost; bounded-error decisions can be resolved by sufficiently accurate simulation. This does not furnish a general halting decider.

Other restrictions have different origins. Linearity prevents universal cloning. Measurement returns a sampled outcome rather than a readable list of all amplitudes. Input preparation, oracle construction, and protection from noise consume resources even when an ideal query count is small.

These are not reasons to dismiss an algorithm. They tell us what a convincing claim must contain: a specified task, an allowed access model, an observable answer with a success guarantee, and the costs of producing it.

Problems

  1. Can a quantum computer decide the halting problem? Why not?

    Show solutionHide solution

    No, in the usual effective model of quantum computation. Its gates and probabilities can be approximated by a classical algorithm. A bounded-error quantum decider can therefore be simulated to enough accuracy to distinguish its acceptance cases, however inefficiently. A halting decider in that model would give a classical halting decider, which is impossible. This assumes effectively specified operations, not a device supplied with an uncomputable real number as an oracle.

  2. A classical simulation of an \(n\)-qubit circuit stores all \(2^n\) amplitudes. How does its memory grow, and why does the simulation nevertheless show that quantum computers compute nothing beyond Turing machines?

    Show solutionHide solution

    The memory used by this direct simulation is proportional to \(2^n\) times the precision stored per amplitude. For any finite, effectively specified circuit, those amplitudes and its outcome probabilities can be approximated classically. With a promised acceptance gap, sufficient precision lets a classical algorithm make the same decision. The cost can be enormous; computability asks whether an algorithm exists at all, not whether it is practical.

  3. A source promises to prepare either \(\ket0\) on every run or \(\ket+\) on every run. After obtaining \(k\) copies, the alternatives are \(\ket0^{\otimes k}\) and \(\ket+^{\otimes k}\). Compute their overlap. Can any finite number of copies guarantee perfect discrimination? How does that differ from making the error very small?

    Show solutionHide solution

    Inner products multiply under tensor products, so the overlap is \((\braket0+)^k=2^{-k/2}\), which is nonzero for every finite \(k\). The nonorthogonal-state discrimination result therefore rules out a measurement that is always correct. Nevertheless, measuring every copy in the computational basis gives a simple approximate method: report \(\ket+\) if any result is \(1\), and \(\ket0\) otherwise. It never errs on \(\ket0\), and errs with probability \(2^{-k}\) on \(\ket+\). An arbitrarily small error is achievable; zero error with a fixed finite supply is not.

9.4.3 Period finding and error correction: further topics§

Two natural continuations now have a clear starting point. Period finding uses controlled operations, phase, and a quantum Fourier transform to make periodic structure observable. Error correction uses joint states, subspaces, and measurements to protect information while computations proceed.

Neither requires abandoning the rules developed here. Each requires new constructions and a proof that its measurements reveal the intended information without losing what is still needed.

When you meet such a construction, ask three questions: What property has been encoded in the state? Which operation makes it visible to measurement? What did preparing and protecting that process cost? If you can answer those, a large circuit becomes a chain of understandable claims.

Problems

  1. What is the period of \(f(x)=2^x\bmod15\)?

    Show solutionHide solution

    The values for \(x=0,1,2,3,4\) are \(1,2,4,8,1\), so the period is \(4\).

  2. Use the period \(r=4\) of \(2^x\bmod15\) to factor \(15\), by computing \(\gcd(2^{r/2}-1,15)\) and \(\gcd(2^{r/2}+1,15)\).

    Show solutionHide solution

    \(2^{r/2}=4\). \(\gcd(3,15)=3\) and \(\gcd(5,15)=5\), so \(15=3\times5\).

  3. Let \(a^x\bmod N\) have even period \(r\), with \(a^{r/2}\not\equiv-1\pmod N\). Show that \(\gcd(a^{r/2}-1,N)\) is a factor of \(N\) other than \(1\) and \(N\).

    Show solutionHide solution

    \(a^r\equiv1\), so \(N\) divides \(a^r-1=(a^{r/2}-1)(a^{r/2}+1)\). \(N\) does not divide \(a^{r/2}-1\), since that would make \(r/2\) a smaller period, and it does not divide \(a^{r/2}+1\), by assumption. So \(N\) shares a nontrivial factor with each of the two numbers, and the greatest common divisor finds it. Period finding is the step a quantum computer performs efficiently.

1. Quick check §

An algorithm uses \(O(N)\) steps on an integer \(N\) written in binary. Is that polynomial in the input length?

Hint 1

How many bits are needed to write \(N\)?

Hint 2

For \(n\) bits, \(N\) can be as large as \(2^n-1\).

Worked solution

Not in general. The input length is about \(\log_2N\), so \(N\) steps can be exponential in that length.

2. Worked problem §

One algorithm uses at most \(3n^2+7n+2\) operations, and at least \(n^2\). Give constants showing that its cost is \(\Theta(n^2)\). Does this prove that every algorithm for the task needs quadratic time?

Hint 1

For \(n\geq1\), compare each term with \(n^2\).

Hint 2

An upper bound for one algorithm is not a lower bound for the task.

Worked solution

For \(n\geq1\), \(n^2\leq3n^2+7n+2\leq3n^2+7n^2+2n^2=12n^2\), so the cost is \(\Theta(n^2)\) with constants \(1\) and \(12\). This describes one algorithm. A lower bound for the task would have to hold for every algorithm, which needs a separate argument.

3. Extension §

A quantum search uses \(\Theta(\sqrt N)\) queries, but each query requires \(\Theta(N)\) gates in a chosen implementation. What do the query and gate counts say about this implementation, and about the task?

Hint 1

Multiply the number of calls by the cost of each call.

Hint 2

Keep the implementation separate from the best possible gate count for the task.

Worked solution

The queries alone contribute \(\Theta(N^{3/2})\) gates, worse than a classical scan of \(N\) items. The quadratic query advantage is still a true statement about oracle access. It does not show that this implementation beats a classical method, and a cheaper oracle implementation could change the comparison.
