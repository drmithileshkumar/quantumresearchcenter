Chapter 06

Quantum Queries and Phase Kickback

Can we learn a relation among answers without learning the individual answers themselves?

A function is usually queried to obtain its value at a chosen input. We instead ask how a reversible query acts on a superposition, and what information survives when the final measurement yields only one outcome. Phase kickback lets a function leave its mark in relative phase. Deutsch’s algorithm shows how interference can turn that mark into knowledge of a global property, without making every function value available to read.

Reading guide · preparation, aims, and assumptions

Use a reversible query to encode a property in relative phase and read it through interference.

Before you begin

Use reversible target updates, the Hadamard transformation, and joint-state notation.

What you should be able to do

  • Derive phase kickback using \(\ket-\).
  • Calculate the output of Deutsch’s algorithm.
  • State exactly what a query advantage counts.

The example to follow

The reversible target update of a function becomes a phase mark, and two-path interference becomes the readout.

Scope and assumptions

Deutsch’s task here uses a one-bit Boolean function and an ideal reversible oracle. A single query does not reveal every function value.

6.1

Function Queries

Before comparing algorithms, fix the question and the way the function may be consulted.

6.1.1 Constant and balanced Boolean functions§

Here is a small question about a function \(f:\{0,1\}\to\{0,1\}\): is \(f(0)\) equal to \(f(1)\)? If they are equal, \(f\) is constant; if they differ, \(f\) is balanced. For a one-bit input, every function is one or the other.

What do we actually need to learn? One bit: equal or different. We do not need the values \(f(0)\) and \(f(1)\) themselves. Can an algorithm learn that one bit without learning both values? The gap between the answer we want and the full data is what the quantum algorithm will exploit.

For inputs of more bits, a function need not be constant or balanced. Restricting attention to those two cases is then a promise about the input.

Problems

  1. When is a one-bit Boolean function constant?

    Show solutionHide solution

    It is constant when \(f(0)=f(1)\).

  2. Classify the tables \((f(0),f(1))=(0,0)\), \((0,1)\), \((1,0)\), and \((1,1)\) as constant or balanced.

    Show solutionHide solution

    (0,0) and (1,1) are constant. (0,1) and (1,0) are balanced.

  3. For a one-bit function, the task asks whether two values agree, not what each value is. How can changing the requested answer change the information a successful algorithm must obtain?

    Show solutionHide solution

    The required output is one property of the table, not the whole table. Functions in the same class can lead to the same answer. This permits a quantum procedure to encode agreement versus disagreement in relative phase and read that property without returning both individual function values.

6.1.2 Classical query access§

Suppose the only access to \(f\) is a query: we choose \(x\) and receive \(f(x)\). How many queries does a classical algorithm need to answer with certainty?

After one query, say with the reply \(f(0)=0\), both possibilities remain: \(f(1)=0\) makes \(f\) constant, and \(f(1)=1\) makes it balanced. One query cannot settle the question; two clearly suffice.

This count belongs to the stated access model. If \(f\) were given in another form, for instance as a formula we could inspect, the comparison could change.

Problems

  1. How many values does one ordinary classical query reveal?

    Show solutionHide solution

    One value \(f(x)\) for the selected input \(x\).

  2. You queried \(f(0)\) and obtained 0. Write one constant and one balanced function consistent with that observation.

    Show solutionHide solution

    The constant table \((0,0)\) and the balanced table \((0,1)\) both agree with \(f(0)=0\).

  3. After one classical query, which two possible truth tables remain indistinguishable while belonging to different classes? Why does this pair obstruct an exact one-query decision procedure?

    Show solutionHide solution

    After observing \(f(0)=0\), the tables \((0,0)\) and \((0,1)\) give identical observations but require different answers. Similar pairs exist for either queried input and either reply. An exact method cannot correctly distinguish all these cases from that one classical reply.

6.1.3 Reversible quantum oracles§

How can a quantum computation query \(f\)? A query must be a valid operation, hence unitary, while \(f\) itself may merge its inputs. The reversible embedding of a function solves this: keep the input and add \(f(x)\) to a target bit.

\[U_f\ket{x,y}=\ket{x,\,y\oplus f(x)}.\]

On the four configurations, \(U_f\) is a rearrangement: it exchanges \((x,0)\) and \((x,1)\) when \(f(x)=1\) and leaves them alone otherwise. Its matrix is a permutation matrix, so it is unitary, and applying it twice restores every configuration.

What counts as one query? One use of \(U_f\), whatever state it is applied to, including a superposition. This is the black-box, or oracle, model: it counts the uses of \(U_f\) and ignores how \(U_f\) is built. The construction costs return when circuits are analysed in detail.

Problems

  1. What is the reversible oracle’s action on \(\ket{x}\ket{t}\)?

    Show solutionHide solution

    It maps \(\ket{x}\ket{t}\) to \(\ket{x}\ket{t \text{ XOR } f(x)}\).

  2. For \(f(0)=1\), find the oracle outputs on \(\ket0\ket0\) and \(\ket0\ket1\).

    Show solutionHide solution

    For \(f(0)=1\), \(\ket0\ket0\) maps to \(\ket0\ket1\) and \(\ket0\ket1\) maps to \(\ket0\ket0\).

  3. Why must the oracle specify what happens to its target register, not merely declare that it “returns \(f(x)\)”? How does retaining \(x\) permit a reversible operation even when \(f\) is many-to-one?

    Show solutionHide solution

    A quantum operation must specify its action on all allowed target states so that superpositions have a well-defined linear evolution. Retaining \(x\) separates different inputs, and XOR by the fixed bit \(f(x)\) is self-inverse. Overwriting the target with \(f(x)\) would generally discard its old value and fail to be reversible.

6.2

Coherent Function Evaluation

A query on a superposition produces a joint state; reading an answer from it is another matter.

6.2.1 Oracle action on superpositions§

What happens if we query \(f\) on both inputs at once? Prepare the input in \((\ket0+\ket1)/\sqrt2\) and the target in \(\ket0\). By linearity, \(U_f\) acts on each configuration separately:

\[U_f\left(\frac{\ket0+\ket1}{\sqrt2}\otimes\ket0\right)=\frac{\ket{0,f(0)}+\ket{1,f(1)}}{\sqrt2}.\]

Have we computed both values? Both appear in the state, but nothing has read them. Whether this helps depends on what we do next.

Problems

  1. Which rule lets us find an oracle’s action on a superposition from its action on basis states?

    Show solutionHide solution

    Linearity: apply the oracle to each basis component and retain its coefficient.

  2. For \(f(0)=0\) and \(f(1)=1\), apply the oracle to \(\ket+\ket0\) by expanding the input into two terms.

    Show solutionHide solution

    \(\ket+\ket0=(\ket{00}+\ket{10})/\sqrt2\). The oracle leaves \(\ket{00}\) fixed and sends \(\ket{10}\) to \(\ket{11}\), so the output is \((\ket{00}+\ket{11})/\sqrt2\).

  3. An oracle acts on every basis component of a superposition. Why is that not equivalent to receiving a readable list of all function values? Which subsequent step determines whether this action is useful?

    Show solutionHide solution

    The output is a joint quantum state, not a classical list that can be read entry by entry from one copy. Measurement samples an outcome. Useful processing arranges interference so that the desired property changes the measured distribution; merely applying the oracle in superposition does not guarantee that.

6.2.2 Register measurement§

Suppose we measure both registers now. The result is one random pair \((x,f(x))\): we learn one value, not both. Repeating the experiment gives more samples, but that is no better than classical queries.

To gain anything, the remaining steps must turn the property we want, equal or different, into states that a measurement can tell apart with certainty.

Problems

  1. Does one basis measurement return every amplitude of a register?

    Show solutionHide solution

    No. It returns one sampled basis label.

  2. For \((\ket{00}+\ket{11})/\sqrt2\), list the possible measured pairs and their probabilities.

    Show solutionHide solution

    The pairs \(00\) and \(11\) occur with probability \(1/2\) each. The pairs \(01\) and \(10\) have probability zero.

  3. If measuring the input register returns one sampled input, what becomes of the other function values encoded in the joint state? Why does the existence of those components not guarantee access to all of them in one run?

    Show solutionHide solution

    A projective input-register measurement selects a branch or subspace and removes the original coherence between different measured labels. The amplitudes of unobserved branches are not delivered as extra classical data. Repeated preparations provide samples, but one sample does not reveal the entire truth table or all amplitudes.

6.2.3 Workspace entanglement§

Could we apply \(H\) to the input and measure, as in the two-step experiment with \(H\)? Look at the target. If \(f(0)\neq f(1)\), the target holds different values in the two branches: it is a record of which input occurred.

Branches that end in different configurations cannot cancel. Applying \(H\) to the input alone then gives a random outcome, just as when a separate bit records the path between two applications of \(H\).

Is there a target state that the oracle leaves unchanged, so that no record forms, yet that still responds to \(f\)?

Problems

  1. What is a workspace record?

    Show solutionHide solution

    It is information stored in temporary registers that can distinguish branches of a computation.

  2. Compare \((\ket0\ket0+\ket1\ket0)/\sqrt2\) with \((\ket0\ket0+\ket1\ket1)/\sqrt2\). In which state does the second register distinguish the first-register alternatives?

    Show solutionHide solution

    The first state factors as \(\ket+\ket0\); the second register is identical in both branches. In the second state, its orthogonal values 0 and 1 perfectly distinguish the first-register alternatives.

  3. Two input branches leave different workspace records. Why can that obstruct the interference you wanted between them? What would have to be true of the final workspace for it to stop distinguishing the branches?

    Show solutionHide solution

    The interference cross term includes the overlap of the workspace states. Orthogonal records make that overlap zero when the workspace is ignored. Returning the workspace to the same state for every branch removes the record. Any remaining known branch phase must still be included in the input amplitudes; it is not a workspace distinction.

6.3

Phase Kickback

A carefully chosen target turns the function value into a sign.

6.3.1 Bit-flip eigenstates§

The oracle either flips the target or leaves it alone. Which target states does a flip leave unchanged, apart from a factor? The eigenvectors of \(X\):

\[X\ket+=\ket+,\qquad X\ket-=-\ket-,\]

since \(X(\ket0-\ket1)=\ket1-\ket0\).

A flip therefore multiplies \(\ket-\) by \(-1\), and no flip leaves it with the factor \(+1\): the target state stays the same while the factor records whether a flip occurred. The state \(\ket+\) is unchanged in both cases and cannot tell them apart. The target we want is \(\ket-\).

Problems

  1. What are the \(X\) eigenvalues of \(\ket+\) and \(\ket-\)?

    Show solutionHide solution

    The eigenvalues are \(+1\) for \(\ket+\) and \(-1\) for \(\ket-\).

  2. Apply \(X\) to \((\ket0-\ket1)/\sqrt2\) and factor out the sign.

    Show solutionHide solution

    \(X(\ket0-\ket1)/\sqrt2=(\ket1-\ket0)/\sqrt2=-\ket-\).

  3. Both \(\ket+\) and \(\ket-\) are eigenstates of the bit flip. Why does only one of them provide the sign change needed here? What property of the eigenvalue, rather than simply being an eigenstate, matters?

    Show solutionHide solution

    The eigenvalue must differ between applying the flip and doing nothing. On \(\ket+\) both choices act as \(+1\), so no function-dependent phase appears. On \(\ket-\) a flip contributes \(-1\) and no flip contributes \(+1\), producing the factors \((-1)^{f(x)}\) on the input components.

6.3.2 Phase-oracle construction§

Apply \(U_f\) to \(\ket x\ket-\). If \(f(x)=0\), nothing happens; if \(f(x)=1\), the target flips, which multiplies the state by \(-1\):

\[U_f\ket x\ket-=(-1)^{f(x)}\ket x\ket-.\]

With the input in \(\ket+\),

\[U_f\ket+\ket-=\frac{(-1)^{f(0)}\ket0+(-1)^{f(1)}\ket1}{\sqrt2}\otimes\ket-.\]

The target ends in \(\ket-\) whatever \(x\) is, so it holds no record of the input. The function value has moved into the sign of the input amplitude. This is phase kickback.

What do the signs mean? If \(f\) is constant, the two signs are equal and the input is \(\pm\ket+\); the common sign is a global phase. If \(f\) is balanced, the signs differ and the input is \(\pm\ket-\). The answer has become a relative phase.

Problems

  1. What phase factor is attached to input \(x\) by a phase oracle?

    Show solutionHide solution

    The factor is \((-1)^{f(x)}\): \(+1\) for \(f(x)=0\) and \(-1\) for \(f(x)=1\).

  2. For \(f(0)=0\) and \(f(1)=1\), apply the phase factors to \(\ket+\) and identify the new input state.

    Show solutionHide solution

    The \(\ket0\) term retains its sign and the \(\ket1\) term changes sign. The result is \((\ket0-\ket1)/\sqrt2=\ket-\).

  3. Complementing every value of a Boolean function changes every phase mark by a common minus sign. Which distinctions between functions are therefore unavailable from this phase action alone?

    Show solutionHide solution

    The phase oracles for \(f\) and \(1-f\) differ by an overall minus sign. Their direct action on an input state therefore yields identical measurement predictions. In particular, this action alone cannot distinguish the two constant tables from each other, or a balanced table from its complement. A separately supplied controlled version would be an additional access assumption.

6.3.3 Coherent uncomputation§

What if \(f\) is not given as an oracle but computed by a circuit \(A\) that uses workspace, \(A\ket{x,0,0}=\ket{x,f(x),g(x)}\)? Apply \(Z\) to the answer bit, which multiplies the state by \((-1)^{f(x)}\), then run \(A\) backward:

\[A^\dagger Z_{\mathrm{answer}}A\ket{x,0,0}=(-1)^{f(x)}\ket{x,0,0}.\]

The workspace returns to \(0\), and the sign remains. This is compute, phase, uncompute. It is not free: it uses \(A\) and its inverse, and an honest count of the cost must include both.

Problems

  1. What operation clears workspace by undoing its computation?

    Show solutionHide solution

    Apply the inverse of the reversible computation that produced the workspace.

  2. A reversible computation maps \(\ket{x}\ket{0}\) to \(\ket{x}\ket{g(x)}\). Write the action of its inverse on that output.

    Show solutionHide solution

    If \(U\) maps \(\ket{x}\ket{0}\) to \(\ket{x}\ket{g(x)}\), then \(U^\dagger\) maps \(\ket{x}\ket{g(x)}\) back to \(\ket{x}\ket{0}\).

  3. Why is erasing workspace by measurement generally different from uncomputing it coherently? What record or disturbance could remain after the first method that the second is designed to avoid?

    Show solutionHide solution

    Measurement can leave a branch record in an apparatus or environment and disturb the coherence of the input. Resetting the measured workspace does not automatically erase that external record. Uncomputation coherently restores the workspace by reversing its production, so it need not reveal which input branch was present.

6.4

Deutsch’s Algorithm

A final basis change turns the relative sign into the answer bit.

6.4.1 Interference and readout§

After the query, the input is \((s_0\ket0+s_1\ket1)/\sqrt2\), with \(s_x=(-1)^{f(x)}\). How do we read the relative sign? Apply \(H\), which sends \(\ket+\) to \(\ket0\) and \(\ket-\) to \(\ket1\):

\[H\,\frac{s_0\ket0+s_1\ket1}{\sqrt2}=\frac{s_0+s_1}2\ket0+\frac{s_0-s_1}2\ket1.\]

Equal signs give \(0\) with certainty; opposite signs give \(1\) with certainty. In terms of paths, the two contributions to the wrong answer cancel.

The outcome depends only on whether \(s_0\) and \(s_1\) agree, never on \(f(0)\) or \(f(1)\) separately. We learn the one bit we wanted, and nothing more.

Problems

  1. What role does the last Hadamard play in Deutsch’s algorithm?

    Show solutionHide solution

    It converts the relative-sign distinction into a computational-basis outcome.

  2. Calculate \(H\ket+\) and \(H\ket-\). Match the two results to constant and balanced functions.

    Show solutionHide solution

    \(H\ket+=\ket0\) and \(H\ket-=\ket1\). Constant functions give outcome 0 and balanced functions give outcome 1, up to irrelevant global phases.

  3. The oracle encodes the distinction in signs, but the final measurement reads a bit. What exactly does the last Hadamard do to bridge those descriptions? Why would measuring before it fail?

    Show solutionHide solution

    Before the final \(H\), both \(\ket+\) and \(\ket-\) give computational-basis probabilities \(1/2\) and \(1/2\). \(H\) combines their amplitudes so that one output cancels and the other adds. The relative sign selects which cancellation occurs, turning the encoded property into a certain bit.

6.4.2 Quantum and classical query counts§

Put the steps together. Prepare \(\ket0\ket1\) and apply \(H\) to each qubit, giving \(\ket+\ket-\). Query \(U_f\) once. Apply \(H\) to the input, and measure it. This is Deutsch’s algorithm.

It decides whether \(f\) is constant or balanced with one query and with certainty, where any classical method needs two. Is the comparison fair? Both use the same oracle and demand the same certainty. The other gates are real operations, but they are not queries. A query separation is a first example of quantum advantage, not a statement about total running time on real hardware.

Predict first. Compare a constant function with a balanced function. Before running the circuit, predict whether the final input bit is 0 or 1. Would complementing every function value change that bit?

Experiment: an oracle changes relative phase

Prepare the input in \(\ket{+}\) and the target in \(\ket{-}\). The oracle leaves the target unchanged and multiplies each input amplitude by \((-1)^{f(x)}\). A final Hadamard makes the relative sign observable.

Both input amplitudes have the same sign.

Choose a function, then apply its oracle.

A common sign changes no probabilities. Opposite signs change the result after the final Hadamard.

After trying it: compare your explanation

A constant function gives 0; a balanced function gives 1. Complementing the function multiplies the state after the phase oracle by a common minus sign, so it does not change the final measurement.

Problems

  1. How many oracle calls does the ideal Deutsch algorithm use?

    Show solutionHide solution

    One call to the ideal reversible oracle.

  2. Compare one quantum call with the two calls required by an exact classical method. Name one cost this count does not include.

    Show solutionHide solution

    The exact quantum procedure uses one call, compared with two for the worst-case exact classical procedure. This count excludes, for example, the elementary-gate cost of implementing the oracle.

  3. Deutsch’s algorithm uses one quantum query where exact classical computation needs two. Which access and success assumptions make that comparison meaningful? What extra information would be needed to compare total running times?

    Show solutionHide solution

    The comparison fixes the one-bit constant/balanced task, exact success, ordinary classical value queries, and coherent access to the specified reversible quantum oracle. Total running time also requires preparation, oracle implementation, intervening gates, measurement, and any error-control costs. Query advantage alone does not settle that comparison.

6.4.3 Preparation, oracle evaluation, and measurement§

What made the algorithm work? Four stages: prepare coherent alternatives; encode the property we want in their relative phases; recombine them; and measure in a basis that exposes the difference.

Each stage matters. Without the \(\ket-\) target, a record would block the interference; without the final \(H\), the signs would stay invisible. A short circuit can still fail if the final states for different answers cannot be told apart, so correctness requires following the state through all four stages, workspace included.

Searching for a marked input starts from the same kind of phase mark, but needs repeated recombination to turn the mark into a likely answer.

Problems

  1. Which target state is prepared for phase kickback?

    Show solutionHide solution

    The target is prepared in \(\ket-=(\ket0-\ket1)/\sqrt2\).

  2. Replace \(\ket-\) with \(\ket+\) and use \(X\ket+=\ket+\). Does the target flip now give the input a function-dependent sign?

    Show solutionHide solution

    No. Since \(X\ket+=\ket+\), flipping or not flipping has the same action on the target and contributes no distinguishing sign to the input.

  3. If the oracle is correct but the target is prepared in \(\ket+\) instead of \(\ket-\), where does the algorithm lose its ability to distinguish the functions? What does this reveal about treating preparation as part of correctness?

    Show solutionHide solution

    The distinction is lost at the oracle step: with a \(\ket+\) target, all function values act identically on the prepared joint state. The input remains \(\ket+\) and the final \(H\) gives 0 regardless of the function. Correct preparation is part of the algorithm’s proof, not an interchangeable preliminary step.

Check your understanding

Why does the target minus state help the oracle reveal equality of function values?

Compare your explanation

A flip multiplies it by minus one without leaving a distinct target record. The input gains relative signs that the final Hadamard converts into a readable distinction.

Questions and worked problems

Attempt each question before opening a hint. Explain your reasoning, then compare it with the solution.

1. Quick check §

Why use \(\ket-\) rather than \(\ket0\) as the target for phase kickback?

Hint 1

Apply \(X\) to both target states.

Hint 2

\(X\ket-=-\ket-\).

Worked solution

A flip changes \(\ket-\) only by a sign. The same target state remains, while the input amplitudes acquire function-dependent signs. A \(\ket0\) target instead records the function value and can become entangled with the input.

2. Worked problem §

Take \(f(0)=1\) and \(f(1)=0\). Starting with \(\ket+\ket-\), apply the oracle and then \(H\) to the input. What is measured on the input?

Hint 1

The input amplitudes gain signs \((-1)^{f(x)}\).

Hint 2

The input becomes \((-\ket0+\ket1)/\sqrt2\).

Worked solution

The oracle gives \(-\ket-\ket-\). The final \(H\) on the input gives \(-\ket1\ket-\). The overall minus sign changes no probabilities, so outcome 1 occurs with certainty: the function is balanced.

Replace \(f\) by its complement \(1-f\). Can Deutsch’s final measurement tell them apart?

Hint 1

Compare the two phase factors for every \(x\).

Hint 2

Complementing \(f\) multiplies every factor by \(-1\).

Worked solution

No. All input amplitudes gain the same extra minus sign, a global phase. The constant/balanced classification is unchanged. Deutsch’s measurement extracts that classification, not the individual truth table.
