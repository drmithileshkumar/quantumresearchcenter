A. Automata and Memory

A finite automaton stores one of finitely many control states while reading an input. Two states suffice for parity: reading one swaps “even” and “odd,” and reading zero leaves the state unchanged. Exact matching of arbitrarily many opening and closing symbols needs more memory. For the language \(\{a^nb^n:n\geq0\}\), two different long prefixes of a’s must reach the same state in any fixed finite automaton. Appending the number of b’s matching one prefix then forces the same decision on one valid and one invalid string. This state-collision argument proves the limitation.

A stack distinguishes arbitrarily many pending symbols. Push once for each a, then pop once for each b; accept when input and stack finish together in the correct order. A pushdown automaton formalizes this memory. A linear-bounded automaton has writable tape bounded by a constant multiple of input length. A Turing machine removes that fixed bound. More memory changes the configurations available, not the meaning of an individual step. These models explain different language classes; they are not successive hardware generations.

B. Grammars and Lambda Calculus

A grammar specifies a start symbol, terminal symbols, nonterminal symbols, and replacement rules. The rules \(S\to aSb\) and \(S\to\epsilon\) generate exactly matching a’s and b’s. Applying the first rule twice and then the second gives \(aabb\). Generation asks what can be produced; recognition asks whether a supplied string belongs to the generated set. Regular grammars correspond to finite automata, context-free grammars to pushdown automata, context-sensitive grammars to linearly bounded machines, and unrestricted grammars to Turing-recognizable languages, with the usual conventions about the empty string.

Lambda calculus describes computation by function application and substitution. The reduction \((\lambda x.t)u\to t[x:=u]\) replaces free occurrences of x in t by u, renaming bound variables when necessary to avoid capture. For example, \((\lambda x.x)u\to u\). A Church numeral n is a function that applies a supplied function n times to a supplied starting value. Thus three is \(\lambda f.\lambda x.f(f(f(x)))\). Functions alone can encode data and iteration. Agreement with Turing computability is a mathematical equivalence between formal models; it supports, rather than defines away, the broader Church–Turing thesis.

C. Linear Algebra Reference

For complex coordinates, use \(\braket uv=u^\dagger v\), where \(u^\dagger=(u^*)^T\). The norm is \(\sqrt{u^\dagger u}\). An orthonormal basis matrix B satisfies \(B^\dagger B=I\), and converts old coordinates to new by \(B^\dagger\). Matrix products act right to left on column vectors. The adjoint reverses their order: \((AB)^\dagger=B^\dagger A^\dagger\). A unitary preserves overlaps; a Hermitian operator equals its adjoint; an orthogonal projector satisfies \(P^2=P=P^\dagger\). These are different properties.

Tensor products obey \((A\otimes B)(u\otimes v)=Au\otimes Bv\) and \(\braket{u\otimes v}{x\otimes y}=\braket ux\braket vy\). In the binary ordering used in this book, the leftmost qubit is the most significant label. Operator norm is \(\|A\|=\max_{\|v\|=1}\|Av\|\). It is useful for uniform error bounds because \(\|(U-V)v\|\leq\|U-V\|\) for every unit vector. These identities provide reference material; their operational meanings are introduced where used in the chapters.

D. Mixed States and General Measurements

A density matrix records a preparation that need not be pure. An ensemble preparing \(\ket{\psi_r}\) with probability \(q_r\) has \(\rho=\sum_r q_r\ket{\psi_r}\bra{\psi_r}\). It is positive semidefinite and has trace one. A pure state has \(\rho=\ket\psi\bra\psi\); different ensembles can yield the same density matrix and therefore the same measurement predictions. The Born rule is \(p(j)=\operatorname{tr}(P_j\rho)\), and unitary evolution gives \(U\rho U^\dagger\).

For a joint system, the reduced state is \(\rho_A=\operatorname{tr}_B\rho_{AB}\): sum the B diagonal blocks in a product basis. Tracing one half of the Bell state gives \(I/2\). A trace-preserving local operation on B, with operators \(M_r\) satisfying \(\sum_rM_r^\dagger M_r=I\), leaves A’s reduced state unchanged when outcomes are ignored. This follows by inserting the sum into the partial trace. Conditioning on r changes the description only for someone who knows r.

A general measurement has positive effects \(E_j\) summing to identity and probabilities \(\operatorname{tr}(E_j\rho)\). Effects specify probabilities but not the complete state update; measurement operators provide that additional information. For example, to distinguish either \(\ket0\) or \(\ket+\), choose \(E_0=c\ket-\bra-\), \(E_+=c\ket1\bra1\), and \(E_?=I-E_0-E_+\), with \(c=1/(1+1/\sqrt2)\). The first outcome is impossible for \(\ket+\), the second for \(\ket0\), and the remaining outcome is inconclusive. Positivity of \(E_?\) follows because the largest eigenvalue of \(\ket-\bra-+\ket1\bra1\) is \(1+1/\sqrt2\). Certainty when conclusive is purchased by sometimes declining an answer.

E. Polynomial Lower Bounds

In the Boolean query model, the hidden input is a string \(z\in\{0,1\}^N\). A query transforms \(\ket{i,b}\) to \(\ket{i,b\oplus z_i}\). Each output amplitude is a combination of previous amplitudes multiplied by \(z_i\) or \(1-z_i\). Starting from input-independent amplitudes, induction shows that T queries produce amplitudes of polynomial degree at most T in the input bits. Input-independent unitaries form linear combinations and do not increase this degree.

An acceptance probability sums squared magnitudes of accepting amplitudes, so its degree is at most 2T. Restricting to Boolean inputs allows powers \(z_i^k\) with positive k to be replaced by \(z_i\). The approximate degree of a Boolean function is the least degree of a real polynomial approximating it to a chosen constant error below one half on every Boolean input. Hence query complexity is at least half that degree. Proving OR has approximate degree of order \(\sqrt N\) requires an approximation-theoretic argument beyond this short derivation. The polynomial representation and that theorem together yield the search-decision lower bound; neither follows from observing that known algorithms are slow.
