Chapter 07

Quantum Search and Amplitude Amplification

Deutsch’s algorithm answered a question about a function with a single interference step. Many tasks instead ask for a particular input: an item that passes a test we can check but cannot invert. Classically, finding one marked item among \(N\) requires checking a number of candidates proportional to \(N\). Can interference concentrate probability on the marked item faster?

We start with four items, where every amplitude can be followed by hand: a phase oracle marks the answer with a sign, and a reflection about the mean turns the sign into certainty. For larger searches we group the marked and unmarked items, which reduces the whole evolution to a rotation in a plane. The rotation explains both the speedup, about \(\sqrt N\) iterations instead of \(N\) queries, and its danger: rotating too far undoes the gain, so knowing when to stop is part of the algorithm. Finally we extend the method from a uniform start to any preparation and any test of success.

So far, oracles and reflections have been treated as single operations. The next chapter asks how such operations are built from elementary gates.

How can a process concentrate our chances of finding an answer that it can recognize but does not yet know?

Marking an answer with a sign does not change its probability. Repeated reflection turns the sign into a rotation toward the answer.

Reading guide · preparation, aims, and assumptions

Turn a phase mark into increased success probability and determine when to stop iterating.

Before you begin

Use phase oracles, reflections, and normalized state vectors.

What you should be able to do

  • Calculate the four-item search.
  • Interpret two reflections as a rotation.
  • Include preparation and oracle costs in amplification.

The example to follow

Start with four equal amplitudes; carry the same reflection picture into the good/bad two-dimensional plane.

Scope and assumptions

The standard iteration formula assumes ideal reflections and a fixed marked subspace. The best iteration count depends on the initial success probability.

7.1

Four-Item Search

Before the general case, we follow a quantum search with four candidates and one marked label, small enough that every amplitude can be written down. Two operations are needed: one that marks the answer, and one that turns the mark into probability.

7.1.1 Search predicates and classical queries§

Among \(N\) labels, some are marked, and a predicate \(f\) tells us whether a label \(x\) is marked: \(f(x)=1\) if it is, and \(0\) otherwise. We want to find a marked label. How many queries does a classical search need?

With one marked label in an unknown position, each query tests one candidate. Checking labels one by one may take \(N-1\) queries in the worst case, and about \(N/2\) on average. To succeed with a fixed probability, a classical search needs a number of queries proportional to \(N\).

We start with \(N=4\) and mark the label \(11\). As before, we count queries to \(f\) and keep the other operations in view. The task is to output a marked label, not to estimate how many there are.

Problems

  1. A predicate on three-bit labels marks the labels whose bits add to \(2\). How many labels are marked, and what is the probability that a uniformly random label is marked?

    Show solutionHide solution

    The marked labels are \(011\), \(101\), and \(110\): three of the eight. A random label is marked with probability \(3/8\).

  2. One label among \(N=8\) is marked. A classical search queries labels in a uniformly random order, without repetition, until it finds the marked one. What is the expected number of queries?

    Show solutionHide solution

    The marked label is equally likely to be in any of the \(8\) positions of the order, so the expected number of queries is \((1+2+\dots+8)/8=(N+1)/2=4.5\).

  3. One label among \(N\) is marked, in a uniformly random position. Show that any classical algorithm making \(k\) queries finds it with probability at most \(k/N\).

    Show solutionHide solution

    Consider first a deterministic algorithm. Until it finds the label, every answer is \(0\), so its sequence of queries before success is fixed in advance: some \(k\) labels. It succeeds exactly when the marked label is among them, with probability at most \(k/N\). A randomized algorithm is an average of deterministic ones, so it too succeeds with probability at most \(k/N\). Constant success therefore needs a number of queries proportional to \(N\).

7.1.2 State preparation and phase marking§

Can a quantum search do better than testing candidates one at a time? It can begin with all candidates at once. Two Hadamards prepare the uniform superposition

\[\ket s=\frac{\ket{00}+\ket{01}+\ket{10}+\ket{11}}2.\]

How should a query act? Phase kickback turns a query into a sign:

\[O_f\ket x=(-1)^{f(x)}\ket x.\]

With \(11\) marked, the amplitudes become \((1,1,1,-1)/2\).

Has this helped? Not yet. Every probability is still \(1/4\), and measuring now finds \(11\) with probability \(1/4\), as a guess would. The query has created a relative sign, and a further operation must turn that sign into probability.

The phase oracle \(O_f\) may be supplied directly, or built by phase kickback or by compute, phase, uncompute. Its cost in queries must be stated accordingly.

Problems

  1. For \(N=4\) with the label \(01\) marked, write the amplitudes after preparing the uniform superposition and applying the phase oracle.

    Show solutionHide solution

    \(\tfrac12(1,-1,1,1)\), in the order \(00,01,10,11\).

  2. For \(N=8\) with one marked label, what are the amplitudes after preparation and marking, and what is the probability of measuring the marked label?

    Show solutionHide solution

    Every amplitude is \(1/\sqrt8\), except the marked one, which is \(-1/\sqrt8\). The marked label is measured with probability \(1/8\), the same as before marking.

  3. Show that applying the phase oracle any number of times, with nothing in between, never changes any measurement probability.

    Show solutionHide solution

    \(O_f\) multiplies each amplitude by \(\pm1\), so it leaves every magnitude unchanged. Moreover \(O_f^2=I\), so any number of applications equals \(I\) or \(O_f\). The probabilities never change; an operation that mixes amplitudes is needed.

7.1.3 Reflection and final amplitudes§

Which operation turns a negative sign into a larger amplitude? Look at the amplitudes \((1/2,1/2,1/2,-1/2)\). Their mean is \(\mu=1/4\). The marked amplitude lies far below the mean, and the others slightly above it. Reflect every amplitude about the mean, \(a_x\mapsto2\mu-a_x\):

\[\tfrac12\mapsto2\cdot\tfrac14-\tfrac12=0,\qquad-\tfrac12\mapsto2\cdot\tfrac14+\tfrac12=1.\]

One marking and one reflection find \(11\) with certainty.

Is reflection about the mean a valid quantum operation? It is the matrix

\[D=2\ket s\bra s-I.\]

Indeed, \(\braket s a=\sum_xa_x/\sqrt N\), and every entry of \(\ket s\) is \(1/\sqrt N\), so the entries of \(2\ket s\braket sa\) are \(2\mu\), and \(D\ket a\) has entries \(2\mu-a_x\). Since \(D^2=4\ket s\bra s-4\ket s\bra s+I=I\) and \(D^\dagger=D\), it is unitary. It does not estimate the mean from samples; it acts on the amplitudes directly.

Problems

  1. Reflect the amplitudes \(\tfrac12(1,-1,1,1)\) about their mean.

    Show solutionHide solution

    The mean is \(\tfrac14\). The entries \(\tfrac12\) become \(2\cdot\tfrac14-\tfrac12=0\), and \(-\tfrac12\) becomes \(\tfrac12+\tfrac12=1\). The result is \((0,1,0,0)\): the marked label \(01\) with certainty.

  2. For \(N=8\) with one marked label, compute the amplitudes after one marking and one reflection about the mean, and the success probability.

    Show solutionHide solution

    Write \(a=1/\sqrt8\). After marking, seven amplitudes are \(a\) and one is \(-a\), so the mean is \(6a/8=3a/4\). The unmarked amplitudes become \(3a/2-a=a/2\), and the marked one becomes \(3a/2+a=5a/2\). The success probability is \((5a/2)^2=25/32\approx0.78\), up from \(1/8\). The seven unmarked probabilities, \(1/32\) each, account for the remaining \(7/32\).

  3. Show directly from \(a_x\mapsto2\mu-a_x\) that reflection about the mean preserves the sum of squared amplitudes, for real amplitudes.

    Show solutionHide solution

    \(\sum_x(2\mu-a_x)^2=\sum_x\bigl(4\mu^2-4\mu a_x+a_x^2\bigr)=4N\mu^2-4\mu\cdot N\mu+\sum_xa_x^2=\sum_xa_x^2\), using \(\sum_xa_x=N\mu\).

7.2

Search Geometry

Four candidates allowed us to follow every amplitude. A search over \(N\) candidates needs a description whose size does not grow with \(N\). The symmetry of the problem provides one: the whole evolution takes place in a plane, where the starting state lies at a small angle from the unmarked direction, and each step of the search turns it by a fixed angle.

7.2.1 Good and bad subspaces§

With \(N\) labels and \(M\) of them marked, \(0\lt M\lt N\), what stays simple as \(N\) grows? In the uniform start, and after every marking and reflection, all marked labels have equal amplitudes, and so do all unmarked ones.

So group them. Let \(\ket G\) be the normalized equal superposition of the marked labels, and \(\ket B\) that of the unmarked labels. They are orthogonal, because no label belongs to both. The uniform state lies in their plane:

\[\ket s=\sqrt{M/N}\,\ket G+\sqrt{1-M/N}\,\ket B.\]

We never need to construct \(\ket G\) or \(\ket B\) explicitly. They describe the state, and they let us prove what the operations do.

Problems

  1. For \(N=8\) with the marked labels \(011\) and \(101\), write \(\ket G\) and \(\ket B\).

    Show solutionHide solution

    \(\ket G=(\ket{011}+\ket{101})/\sqrt2\), and \(\ket B\) is the equal superposition of the other six labels, each with amplitude \(1/\sqrt6\).

  2. For \(N=8\) and \(M=2\), write \(\ket s\) as a combination of \(\ket G\) and \(\ket B\).

    Show solutionHide solution

    \(\ket s=\sqrt{2/8}\,\ket G+\sqrt{6/8}\,\ket B=\tfrac12\ket G+\tfrac{\sqrt3}2\ket B\).

  3. Show that the oracle \(O_f\) and the reflection \(D=2\ket s\bra s-I\) both map the plane of \(\ket G\) and \(\ket B\) into itself, by computing their action on \(\ket G\) and \(\ket B\).

    Show solutionHide solution

    \(O_f\ket G=-\ket G\) and \(O_f\ket B=\ket B\). With \(\ket s=\sin\theta\ket G+\cos\theta\ket B\), we have \(\braket sG=\sin\theta\) and \(\braket sB=\cos\theta\), so \(D\ket G=2\sin\theta\ket s-\ket G\) and \(D\ket B=2\cos\theta\ket s-\ket B\). Both are combinations of \(\ket G\) and \(\ket B\), so the state never leaves their plane.

7.2.2 Initial success amplitude§

Where does \(\ket s\) lie in this plane? Write \(\sin\theta=\sqrt{M/N}\), with \(0\lt\theta\lt\pi/2\). Then

\[\ket s=\sin\theta\,\ket G+\cos\theta\,\ket B:\]

the state makes the angle \(\theta\) with the bad direction, and its success probability is \(\sin^2\theta=M/N\). For \(N=4\) and \(M=1\), \(\sin\theta=1/2\), so \(\theta=\pi/6\), or \(30^\circ\).

Why is one angle enough, however many labels the register has? Both the oracle and the reflection map the plane to itself, so the state never leaves it.

Problems

  1. Find the angle \(\theta\) for \(N=16\) with \(M=1\), and for \(N=8\) with \(M=2\).

    Show solutionHide solution

    For \(N=16\), \(M=1\): \(\sin\theta=1/4\), so \(\theta\approx14.5^\circ\). For \(N=8\), \(M=2\): \(\sin\theta=1/2\), so \(\theta=30^\circ\).

  2. For \(N=8\) and \(M=2\), how many iterations give success with certainty?

    Show solutionHide solution

    \(\theta=30^\circ\), as for \(N=4\), \(M=1\). One iteration turns the state to \(3\theta=90^\circ\), the good direction, so one iteration succeeds with certainty.

  3. Show that, for \(0\lt M\lt N\), exactly one Grover iteration gives certain success precisely when \(M/N=1/4\).

    Show solutionHide solution

    After one iteration the success probability is \(\sin^2(3\theta)\), which equals \(1\) when \(3\theta=\pi/2+j\pi\). For \(0\lt\theta\lt\pi/2\) this gives \(\theta=\pi/6\) only, since the next solution, \(\theta=\pi/2\), would mean \(M=N\). And \(\sin^2(\pi/6)=1/4=M/N\).

7.2.3 Reflections and rotations§

What does the oracle do in this plane? It negates \(\ket G\) and keeps \(\ket B\): a reflection across the bad axis. The operation \(D\) is a reflection across \(\ket s\).

Two reflections in a plane make a rotation, by twice the angle between their axes. Here the axes are the bad direction and \(\ket s\), at the angle \(\theta\), so each Grover iteration \(DO_f\) rotates the state by \(2\theta\) toward the good direction.

For \(N=4\), the state starts at \(30^\circ\). The oracle reflects it to \(-30^\circ\), and the reflection across \(\ket s\) sends it to \(90^\circ\), the good direction: the certain success found above.

The picture also predicts what happens if we continue. The rotation does not stop at the good direction; it carries the state past it.

Problems

  1. For \(N=16\) and \(M=1\), by how many degrees does each Grover iteration rotate the state?

    Show solutionHide solution

    By \(2\theta\approx29^\circ\), where \(\sin\theta=1/4\).

  2. For \(N=16\) and \(M=1\), give the angle of the state and the success probability after \(1\), \(2\), \(3\), and \(4\) iterations.

    Show solutionHide solution

    The angle after \(k\) iterations is \((2k+1)\theta\), with \(\theta\approx14.48^\circ\): about \(43.4^\circ\), \(72.4^\circ\), \(101.3^\circ\), and \(130.3^\circ\). The success probabilities \(\sin^2\) of these angles are about \(0.47\), \(0.91\), \(0.96\), and \(0.58\). The best is three iterations; the fourth overshoots.

  3. In the plane with the bad direction as the first axis and the good direction as the second, reflection across the line at angle \(\alpha\) is \(\begin{pmatrix}\cos2\alpha&\sin2\alpha\\\sin2\alpha&-\cos2\alpha\end{pmatrix}\). Verify that reflecting across the bad axis and then across \(\ket s\) is a rotation by \(2\theta\).

    Show solutionHide solution

    The first reflection, across \(\alpha=0\), is \(\operatorname{diag}(1,-1)\). The second, across \(\alpha=\theta\), multiplies it on the left: \(\begin{pmatrix}\cos2\theta&\sin2\theta\\\sin2\theta&-\cos2\theta\end{pmatrix}\begin{pmatrix}1&0\\0&-1\end{pmatrix}=\begin{pmatrix}\cos2\theta&-\sin2\theta\\\sin2\theta&\cos2\theta\end{pmatrix}\), the rotation by \(2\theta\).

7.3

Grover Iteration

Since the rotation carries the state past the good direction, running the algorithm requires a stopping rule. The right number of iterations follows from the angle, which depends on how many labels are marked. When that number is unknown, randomized stopping points, together with a check of each candidate, keep the quadratic speedup.

7.3.1 Amplitude evolution§

Where is the state after \(k\) iterations, and how likely is success? It starts at the angle \(\theta\) and turns by \(2\theta\) each time, so it reaches \((2k+1)\theta\):

\[\ket{\psi_k}=\sin\bigl((2k+1)\theta\bigr)\ket G+\cos\bigl((2k+1)\theta\bigr)\ket B,\qquad p_k=\sin^2\bigl((2k+1)\theta\bigr).\]

Which marked label do we find? All marked labels share the amplitude of \(\ket G\), so given success, the result is uniform over the marked set. The success probability depends on the marked fraction \(M/N\), not on which labels are marked.

Problems

  1. For \(N=16\) and \(M=1\), compute \(p_k=\sin^2\bigl((2k+1)\theta\bigr)\) for \(k=0\) and \(k=3\).

    Show solutionHide solution

    With \(\sin\theta=1/4\): \(p_0=1/16\), and \(p_3=\sin^2(7\theta)\approx\sin^2(101.3^\circ)\approx0.96\).

  2. For \(N=64\) and \(M=1\), which number of iterations maximizes the success probability, and what is that probability?

    Show solutionHide solution

    \(\sin\theta=1/8\), so \(\theta\approx7.18^\circ\), and \(\pi/(4\theta)-1/2\approx5.8\). Comparing neighbours: \(k=5\) gives \(\sin^2(79^\circ)\approx0.96\), and \(k=6\) gives \(\sin^2(93.4^\circ)\approx0.997\). The best is \(k=6\), with success probability about \(0.997\).

  3. Show that, given success, the measured label is uniformly distributed over the \(M\) marked labels, and that, given failure, it is uniform over the unmarked labels.

    Show solutionHide solution

    The state is always \(\sin\bigl((2k+1)\theta\bigr)\ket G+\cos\bigl((2k+1)\theta\bigr)\ket B\), and \(\ket G\) gives every marked label the same amplitude \(1/\sqrt M\). So all marked labels have equal probability \(\sin^2\bigl((2k+1)\theta\bigr)/M\), and given success each has probability \(1/M\). The same argument with \(\ket B\) applies to failure.

7.3.2 Iteration count and overshooting§

How many iterations should we perform? Success is greatest when \((2k+1)\theta\) is close to \(\pi/2\), that is, for \(k\) close to \(\pi/(4\theta)-1/2\). For a small marked fraction \(\theta\approx\sqrt{M/N}\), so the number of iterations is about \(\tfrac\pi4\sqrt{N/M}\): of order \(\sqrt{N/M}\), where a classical search needs of order \(N/M\) queries.

Since \(k\) must be an integer, success is usually close to \(1\) but not exactly \(1\); \(N=4\) with \(M=1\) is a special case in which it is exact.

Does iterating longer help? No. For \(N=4\) and \(M=1\), the success probabilities for \(k=0,1,2\) are \(1/4\), \(1\), and \(1/4\): the second iteration rotates the state past the good direction. The stopping rule is part of the algorithm.

Predict first. Set Search space to 4 and reset. There is one marked item; start from equal amplitudes. Predict the success probability after one iteration and after a second. Does another iteration always help?

Experiment: rotate toward the marked item

There is one marked item. A full Grover iteration rotates the state by \(2\theta\), where \(\sin\theta=1/\sqrt N\). Keep stepping after the first peak to see why overshooting matters.

Probability of finding the marked item: 6.25%.

The initial state spreads probability uniformly over all items.

After trying it: compare your explanation

One iteration gives success probability 1. A second gives \(1/4\): continued rotation can move the state away from the marked direction. Compare this with the initial probability \(1/4\).

Problems

  1. For \(N=4\) and \(M=1\), compute the success probability after three iterations.

    Show solutionHide solution

    \(\theta=30^\circ\), so the angle is \(7\theta=210^\circ\), and \(\sin^2210^\circ=1/4\): no better than guessing.

  2. For \(N=2^{20}\approx10^6\) and \(M=1\), estimate the number of Grover iterations, and compare it with the expected number of classical queries.

    Show solutionHide solution

    About \(\tfrac\pi4\sqrt N=\tfrac\pi4\cdot1024\approx804\) iterations, each with one query. A classical search needs about \(N/2\approx524{,}000\) queries on average.

  3. Show that the sequence of success probabilities \(p_0,p_1,p_2,\dots\) is periodic when \(\theta\) is a rational multiple of \(\pi\), and find the period for \(N=4\), \(M=1\).

    Show solutionHide solution

    \(p_k=\sin^2\bigl((2k+1)\theta\bigr)\), and \(\sin^2\) repeats when its argument changes by \(\pi\). Each iteration adds \(2\theta\), so \(p_{k+j}=p_k\) whenever \(2j\theta\) is a multiple of \(\pi\). For \(\theta=\pi/6\), \(2j\theta=j\pi/3\), first a multiple of \(\pi\) at \(j=3\). The sequence is \(\tfrac14,1,\tfrac14,\tfrac14,1,\tfrac14,\dots\), with period \(3\).

7.3.3 Unknown marked fraction and verification§

What if we do not know \(M\), and so cannot compute the stopping point? A fixed guess may overshoot. A standard approach chooses a random number of iterations from a range that grows gradually, measures, and checks the candidate with one query to \(f\). When \(M\gt 0\), such schedules still need an expected number of queries of order \(\sqrt{N/M}\).

What if nothing is marked? Then no check ever succeeds, and an unbounded search never ends; it cannot prove that nothing is marked. A bounded version stops after a fixed budget and reports failure, with a stated probability of being wrong when marked labels do exist. That is a statistical guarantee, not a proof of absence.

If every label is marked, the very first measurement succeeds.

Further detail: Boyer, Brassard, Høyer, and Tapp: Tight bounds on quantum searching.

Problems

  1. An algorithm succeeds with probability \(p\) per attempt and checks its candidate with one query. How many attempts does it need on average to find a marked label?

    Show solutionHide solution

    The attempts are independent, so the number needed is geometric with mean \(1/p\). Because each candidate is checked, the algorithm never reports a wrong label.

  2. For \(N=1024\), the iteration count tuned for \(M=1\) is \(k=25\). What is the success probability if in fact \(M=4\)?

    Show solutionHide solution

    For \(M=4\), \(\sin\theta=\sqrt{4/1024}=1/16\), and \(51\theta\approx51\times3.58^\circ\approx182.7^\circ\), so the success probability is \(\sin^2(182.7^\circ)\approx0.002\). Tuned for \(M=1\) it would be about \(0.999\). Guessing \(M\) wrong can make the search almost certain to fail.

  3. Each verified attempt succeeds with probability at least \(1/4\), independently. Show that \(t\) attempts all fail with probability at most \((3/4)^t\), and find the smallest \(t\) for which this is below \(10^{-6}\).

    Show solutionHide solution

    Each attempt fails with probability at most \(3/4\), and independent failures multiply, so all \(t\) fail with probability at most \((3/4)^t\). We need \(t\ln(3/4)\lt\ln10^{-6}\), that is, \(t\gt\ln10^{-6}/\ln(3/4)\approx48.0\), so \(t=49\).

7.4

General Amplitude Amplification

The geometry of search did not depend on the uniform start or on the particular oracle. Any preparation that succeeds with some probability splits into a good part and a bad part, and the same pair of reflections rotates it toward the good part. Reflecting about a state we cannot write down requires only the preparation and its inverse. The result is a general method that reduces the number of repetitions from about \(1/p\) to about \(1/\sqrt p\).

7.4.1 Arbitrary state preparation§

Was the uniform start essential? Suppose a unitary \(A\) prepares \(A\ket0=\ket\psi\), and \(P_G\) projects onto the outcomes we count as successes, with success probability \(p=\|P_G\ket\psi\|^2\), where \(0\lt p\lt 1\). Normalizing the good and bad parts writes

\[\ket\psi=\sqrt p\,\ket G+\sqrt{1-p}\,\ket B.\]

This is the same plane as before, with \(\sin^2\theta=p\).

Where might \(A\) come from? A classical randomized procedure can sometimes be made coherent and serve as \(A\), but only through an explicit reversible implementation, including its random bits and its workspace. Access to a routine that produces samples is not enough.

Problems

  1. A preparation succeeds with probability \(p=1/9\). Find \(\theta\) and the amplitudes of \(\ket G\) and \(\ket B\).

    Show solutionHide solution

    \(\sin\theta=\sqrt p=1/3\), so \(\theta\approx19.5^\circ\). The amplitudes are \(\sqrt p=1/3\) and \(\sqrt{1-p}=2\sqrt2/3\).

  2. For \(p=1/9\), how many amplification iterations maximize success, and what is the success probability?

    Show solutionHide solution

    The angle after \(k\) iterations is \((2k+1)\theta\): about \(58.4^\circ\) for \(k=1\) and \(97.4^\circ\) for \(k=2\). The success probabilities are about \(0.73\) and \(0.98\), so \(k=2\) is best.

  3. A one-qubit preparation \(A\) gives \(A\ket0=\tfrac{\sqrt3}2\ket0+\tfrac12\ket1\), and success means outcome \(1\). Show that one amplification iteration succeeds with certainty, even though this preparation is not uniform.

    Show solutionHide solution

    \(p=1/4\), so \(\theta=30^\circ\), and one iteration turns the state to \(90^\circ\), the good direction. Directly: \(I-2P_G=Z\) gives \(\ket v=\tfrac{\sqrt3}2\ket0-\tfrac12\ket1\). Then \(R_\psi\ket v=2\ket\psi\braket\psi v-\ket v\) with \(\braket\psi v=\tfrac34-\tfrac14=\tfrac12\), giving \(\ket\psi-\ket v=\ket1\).

7.4.2 Reflection using preparation and its inverse§

The search reflected about \(\ket s\). How do we reflect about \(\ket\psi\) without knowing it? Reflection about \(\ket0\), \(2\ket0\bra0-I\), is easy: it negates every configuration except \(0\). Bring \(\ket\psi\) to \(\ket0\) with \(A^\dagger\), reflect there, and return with \(A\):

\[R_\psi=2\ket\psi\bra\psi-I=A\bigl(2\ket0\bra0-I\bigr)A^\dagger.\]

Applied to a state, the rightmost factor \(A^\dagger\) acts first. Together with \(I-2P_G\), which negates the successful part, \(R_\psi\) rotates the state toward the good direction exactly as in search.

What does this require? Coherent access to \(A\), to its inverse, and to the success test. Measuring whether a sample succeeded is no substitute: it destroys the superposition instead of reflecting it.

Problems

  1. For \(A=H\) on one qubit, write \(R_\psi=A(2\ket0\bra0-I)A^\dagger\) as a matrix.

    Show solutionHide solution

    Here \(\ket\psi=\ket+\), and \(R_\psi=2\ket+\bra+-I=\begin{pmatrix}1&1\\1&1\end{pmatrix}-I=\begin{pmatrix}0&1\\1&0\end{pmatrix}=X\).

  2. Show that \(A(2\ket0\bra0-I)A^\dagger=2\ket\psi\bra\psi-I\) when \(A\ket0=\ket\psi\), and that it is unitary.

    Show solutionHide solution

    \(A\ket0\bra0A^\dagger=(A\ket0)(A\ket0)^\dagger=\ket\psi\bra\psi\), and \(AIA^\dagger=AA^\dagger=I\), so the product is \(2\ket\psi\bra\psi-I\). It is a product of three unitaries, since \(2\ket0\bra0-I=\operatorname{diag}(1,-1,\dots,-1)\) is unitary, and so it is unitary.

  3. Why can the reflection \(R_\psi\) not be replaced by measuring whether the prepared state succeeded? Show that measuring after each oracle step makes the success probability stay at \(p\).

    Show solutionHide solution

    Measuring the prepared state \(\sqrt p\ket G+\sqrt{1-p}\ket B\) gives success with probability \(p\) and leaves a single outcome. Repeating preparation and measurement just gives independent trials, each with success \(p\). The reflection instead rotates the whole state toward \(\ket G\); measurement destroys the superposition that the rotation acts on.

7.4.3 Success probability and resource cost§

What do we gain? With independent trials, each succeeding with probability \(p\), we need about \(1/p\) preparations for a fixed chance of success. Amplitude amplification needs about \(1/\sqrt p\) iterations, each using \(A\), \(A^\dagger\), and the success test once.

If \(A\) costs \(C_A\) and the test costs \(C_G\), the total is of order \((C_A+C_G)/\sqrt p\), plus the cost of verifying the answer and of choosing the number of iterations. The improvement is quadratic in the number of uses of these resources. If preparing the state or building the oracle is itself expensive, that cost can dominate the total.

Problems

  1. For \(p=0.01\), compare the number of independent trials needed for a reasonable chance of success with the number of amplification iterations.

    Show solutionHide solution

    Trials: about \(1/p=100\). Amplification: about \(\tfrac\pi4/\sqrt p\approx8\) iterations, each using \(A\), \(A^\dagger\), and the success test.

  2. Preparing \(A\) costs \(100\) gates and the success test \(20\) gates. For \(p=10^{-4}\), compare the total cost of about \(1/p\) independent trials, each a preparation and a test, with about \(\tfrac\pi4/\sqrt p\) amplification iterations, each using \(A\), \(A^\dagger\), and the test.

    Show solutionHide solution

    Trials: \(10^4\times120=1.2\times10^6\) gates. Amplification: \(\tfrac\pi4\times100\approx79\) iterations of \(100+100+20=220\) gates, about \(1.7\times10^4\) gates, roughly \(70\) times fewer.

  3. Preparing an arbitrary list of \(N\) amplitudes costs about \(N\) gates. For a search among \(N\) items with one marked item, so that \(p=1/N\), compare the cost of amplitude amplification with a classical scan of the list.

    Show solutionHide solution

    Amplification needs about \(\sqrt N\) iterations, and each uses the preparation, costing about \(N\), so the total is about \(N\sqrt N\). A classical scan of the list costs about \(N\). If the data must be loaded this way, amplification is slower: the advantage depends on the preparation being cheap.
