Chapter 03

Probability Amplitudes and Interference

So far, we have treated computation as a logical procedure that moves between configurations. A machine, however, must carry out those transitions through physical processes. This led us to reversibility: discarding logical information has a thermodynamic cost, whereas a reversible computation keeps enough information to undo each step. We saw how to make such computations possible in principle.

We now turn to quantum computation. Its evolution between measurements is reversible, but a measurement need not give a predictable result. What should replace our description of a computation as a single path through configurations? We will compare deterministic, nondeterministic, and probabilistic transitions, then ask what must change to describe interference.

This chapter develops that picture through paths and their weights. The next expresses the same rules in the language of vectors, matrices, and measurement.

How can two steps that each look random combine into a certain result?

A quantum step can look as random as a coin flip, yet two such steps in a row can give a certain result. Explaining how leads to the central ideas of quantum mechanics.

Reading guide · preparation, aims, and assumptions

Understand why probabilities alone do not describe interference, and learn to calculate with amplitudes.

Before you begin

Recall that a computation is a run of configurations, and that a reversible gate can be undone.

What you should be able to do

  • Draw a transition rule as a state diagram, and list its runs as paths in a time-expanded diagram.
  • Apply the product rule along a path and the sum rule across paths.
  • Show why the same two-state probabilistic rule cannot reproduce two Hadamard steps.
  • Use the Born rule, and derive the constraints that preserve total probability.
  • Construct a complex square root of NOT.
  • Explain how a leftover record destroys interference and how uncomputation restores it.

The example to follow

The same bit, updated twice, runs through the whole chapter. Its quantum version, two Hadamard steps, returns in Deutsch’s algorithm.

Scope and assumptions

The Born rule and unitary evolution are physical postulates. The examples motivate them; they do not derive quantum mechanics from classical probability. The next chapter explains the state after measurement.

3.1

Three Kinds of Transition

A transition rule describes the possible future of a computation given its present configuration. We begin with a unique future: each configuration has exactly one successor, so the entire run is determined by its starting point. This is deterministic computation. We then relax that uniqueness and allow several possible successors. The resulting nondeterministic model specifies which futures are permitted, but does not assign probabilities to them. Assigning those probabilities gives the probabilistic model. The distinction between the three models therefore lies in what the present tells us about the future: what must follow, what may follow, and how likely each possibility is.

3.1.1 Deterministic transitions§

A deterministic rule gives each configuration a unique successor. Once the initial configuration is specified, every later configuration follows from it. For a single bit, NOT and RESET both satisfy this requirement: NOT changes the bit, while RESET writes zero regardless of its previous value.

Starting from zero, two applications give \(0\to1\to0\) under NOT and \(0\to0\to0\) under RESET. Both futures are determined, but only NOT preserves the past. After RESET gives zero, the earlier value could have been either zero or one. Determinism concerns the uniqueness of the future; reversibility also requires a unique past.

A state diagram represents each configuration by a node and each transition by an arrow. Exactly one arrow leaves each node for either rule. For NOT, exactly one also enters each node. For RESET, both arrows enter zero.

To follow a run, we draw separate copies of the configurations at times \(0,1,2\). A path through this time-expanded diagram records the successive configurations. From a specified start there is only one permitted path. We give each permitted arrow weight one and each missing arrow weight zero; these weights record which transitions occur with certainty.

Problems

  1. On two bits, the rule SWAP exchanges the bits: \(01\to10\) and \(10\to01\), while \(00\) and \(11\) stay as they are. Write the two-step run from \(01\). Is SWAP deterministic? Is it reversible?

    Show solutionHide solution

    The run is \(01,10,01\). Exactly one arrow leaves each configuration, so SWAP is deterministic. Exactly one arrow also enters each configuration: \(00\) from \(00\), \(01\) from \(10\), \(10\) from \(01\), and \(11\) from \(11\). So SWAP is reversible; in fact, applying it twice restores every configuration, so it is its own inverse.

  2. On the configurations \(0,1,2,3\), the rule INC adds \(1\) modulo \(4\), and the rule HALVE replaces \(n\) by \(\lfloor n/2\rfloor\), the integer part of \(n/2\). Draw both state diagrams, write the two-step runs from \(3\), and decide which rule is reversible.

    Show solutionHide solution

    INC has the arrows \(0\to1\to2\to3\to0\), so the run from \(3\) is \(3,0,1\). HALVE has the arrows \(0\to0\), \(1\to0\), \(2\to1\), and \(3\to1\), so the run from \(3\) is \(3,1,0\). Both are deterministic. INC is reversible: each configuration has exactly one incoming arrow, and subtracting \(1\) undoes it. HALVE is not: two arrows enter \(0\) and two enter \(1\), while none enters \(2\) or \(3\). From the end \(0\) of a run we cannot tell whether it started at \(0\), \(1\), \(2\), or \(3\).

  3. Prove that a deterministic rule on finitely many configurations is reversible exactly when every configuration has at least one incoming arrow. Then show that the statement fails for the rule \(n\mapsto\lfloor n/2\rfloor\) on all nonnegative integers.

    Show solutionHide solution

    Suppose there are \(N\) configurations. A deterministic rule has exactly one outgoing arrow at each, so \(N\) arrows in total, and these \(N\) arrows enter the \(N\) configurations. If every configuration receives at least one, none can receive two, since that would require more than \(N\) arrows. So each receives exactly one, and the rule is reversible. Conversely, a reversible rule gives every configuration exactly one incoming arrow, hence at least one. For \(n\mapsto\lfloor n/2\rfloor\) on all nonnegative integers, every \(n\) has an incoming arrow, from \(2n\); yet \(2n\) and \(2n+1\) both go to \(n\), so the rule is not reversible. The counting argument needs finitely many configurations.

3.1.2 Nondeterministic transitions§

Nondeterminism relaxes the requirement of a unique successor. A configuration may have several permitted successors, so specifying the present no longer specifies a unique future. The rule describes a set of possible runs rather than a single run.

For a bit, consider KEEP-OR-FLIP: from either configuration, both \(0\) and \(1\) are permitted. Its state diagram has all four arrows. Starting from \(0\), two steps admit four paths:

\[0\to0\to0,\qquad0\to1\to0,\qquad0\to0\to1,\qquad0\to1\to1.\]

A path is possible when every transition along it is permitted. A configuration is reachable when at least one possible path ends there. Both zero and one are therefore reachable after two steps. In a nondeterministic model of computation, acceptance is defined in the same way: an input is accepted if at least one permitted run accepts it.

This is a statement about possibility, not a mechanism for choosing among paths. Even if more paths reached one endpoint than another, the rule would not make that endpoint more likely. Counting possibilities and assigning probabilities are different tasks. To predict how often a future occurs, we need more information on the arrows.

Problems

  1. A rule on \(\{0,1\}\) allows \(0\to1\), \(1\to0\), and \(1\to1\), and forbids \(0\to0\). List the possible two-step runs from \(0\), and the configurations reachable at time \(2\).

    Show solutionHide solution

    From \(0\) the only allowed arrow is \(0\to1\); from \(1\), both \(1\to0\) and \(1\to1\) are allowed. The possible runs are \(0\to1\to0\) and \(0\to1\to1\). Both \(0\) and \(1\) are reachable at time \(2\), each by one path.

  2. For the same rule, list the possible three-step runs from \(0\). Which configurations are reachable at time \(3\), and by how many paths?

    Show solutionHide solution

    Extend each two-step run by an allowed arrow. From \(0\to1\to0\), only \(0\to1\) is allowed, giving \(0\to1\to0\to1\). From \(0\to1\to1\), both arrows are allowed, giving \(0\to1\to1\to0\) and \(0\to1\to1\to1\). So \(1\) is reachable by two paths and \(0\) by one. The counts differ, but neither configuration is “more possible”: both are simply reachable.

  3. On the configurations \(0,1,\dots,k\), a rule allows \(i\to i\) and \(i\to i+1\) for \(i\lt k\), and only \(k\to k\) at \(k\). Show that \(k\) is reachable from \(0\) at time \(t\) exactly when \(t\geq k\), and that the number of paths from \(0\) to \(k\) at time \(t\) is \(\binom tk\).

    Show solutionHide solution

    Each step either stays or advances by one, so reaching \(k\) needs \(k\) advances, and \(k\) is reachable at time \(t\) exactly when \(t\geq k\). Once at \(k\), every later step must stay. A path from \(0\) to \(k\) at time \(t\) is therefore fixed by choosing which \(k\) of the \(t\) steps advance: the last advance may fall anywhere, and the forced stays afterward are consistent with the choice. Every choice of \(k\) steps out of \(t\) gives exactly one allowed path, so there are \(\binom tk\) of them. The number of paths grows quickly with \(t\), but it measures only how many ways there are to reach \(k\), not how likely \(k\) is.

3.1.3 Probabilistic transitions§

A probabilistic rule supplies the information that nondeterminism leaves unspecified: the probability of each next configuration, given the present one. We write the probability on an arrow \(i\to j\) as \(P(j\mid i)\), read “the probability of \(j\) given \(i\).” Since some next configuration must occur, the probabilities leaving each configuration add to one.

The current configuration is assumed to contain all the information needed for this prediction. If earlier history matters, that history must be included in the configuration. With this assumption, the process is called Markov.

Consider COIN: whatever the bit currently holds, replace it by the result of a fresh fair coin flip. Its permitted arrows are the same as those of KEEP-OR-FLIP, but each now carries probability \(1/2\).

For the path \(0\to1\to0\), the first step has probability \(1/2\), and the second has conditional probability \(1/2\) given the intermediate configuration. The path probability is therefore \(1/4\). The other path to zero, \(0\to0\to0\), also has probability \(1/4\). These are mutually exclusive histories, so their probabilities add:

\[P(c_2=0)=\tfrac14+\tfrac14=\tfrac12,\]

where \(c_2\) is the configuration after two steps. The probability of ending at one is also \(1/2\). Unlike the deterministic rule, COIN does not fix the outcome of a single run. Unlike the nondeterministic rule, it predicts the distribution of outcomes over independently repeated runs.

Problems

  1. A step keeps the bit with probability \(2/3\) and flips it with probability \(1/3\). Starting from \(0\), compute \(P(c_2=0)\) by listing the paths that end at \(0\).

    Show solutionHide solution

    Two paths end at \(0\). The path \(0\to0\to0\) has probability \((2/3)(2/3)=4/9\), and \(0\to1\to0\) has probability \((1/3)(1/3)=1/9\). They cannot both happen, so \(P(c_2=0)=4/9+1/9=5/9\).

  2. For the same rule, compute \(P(c_3=0)\) from \(0\). Check your answer against the formula \(P(c_t=0)=\tfrac12+\tfrac12\left(\tfrac13\right)^t\).

    Show solutionHide solution

    After two steps the probabilities are \(5/9\) for \(0\) and \(4/9\) for \(1\). A third step reaches \(0\) by keeping \(0\) or by flipping \(1\): \(P(c_3=0)=(5/9)(2/3)+(4/9)(1/3)=10/27+4/27=14/27\). The formula gives \(\tfrac12+\tfrac12\cdot\tfrac1{27}=14/27\). They agree.

  3. Prove the formula \(P(c_t=0)=\tfrac12+\tfrac12\left(\tfrac13\right)^t\) for the rule above, and describe what happens to the run’s memory of its starting configuration as \(t\) grows.

    Show solutionHide solution

    Write \(p_t=P(c_t=0)\). The run is at \(0\) at time \(t+1\) if it was at \(0\) and kept, or at \(1\) and flipped: \(p_{t+1}=\tfrac23p_t+\tfrac13(1-p_t)=\tfrac13p_t+\tfrac13\). Subtracting \(\tfrac12\) from both sides gives \(p_{t+1}-\tfrac12=\tfrac13\bigl(p_t-\tfrac12\bigr)\). Since \(p_0-\tfrac12=\tfrac12\), induction gives \(p_t-\tfrac12=\tfrac12\left(\tfrac13\right)^t\). As \(t\) grows, \(p_t\) approaches \(\tfrac12\), whatever the start: each step shrinks the difference between the two starting points by a factor of three, so the run gradually forgets where it began.

3.2

Sum and Product Rules

The three models differ in what they say about the future, but a run has the same structure in each: a sequence of transitions between configurations. This lets us separate two questions. What does a particular path contribute, and how do the paths to the same endpoint combine? We first assign weights to individual transitions, then use products along paths and sums across paths. The meaning of the weights will depend on the model; the calculation will have a common form.

3.2.1 The product rule along a path§

A path specifies every intermediate configuration, so following it requires every transition along it. Assign a weight \(w(i\to j)\) to each arrow. The weight of a two-step path is the product

\[w(i\to j\to k)=w(j\to k)\,w(i\to j).\]

For deterministic and nondeterministic rules, let an allowed arrow have weight one and a missing arrow weight zero. The product is one precisely when the whole path is permitted: a single missing transition makes it zero.

For a probabilistic rule, use the transition probabilities as weights. Multiplication then gives the probability of that particular history. The factors are conditional probabilities for successive steps; they need not describe independent events. Their dependence on the past is already accounted for by the current configuration.

For COIN, each two-step path has weight \((1/2)(1/2)=1/4\). A path of \(t\) steps has weight \(2^{-t}\). This determines the contribution of one history. An endpoint may be reached through several histories, whose contributions must still be combined.

Problems

  1. Under the rule that keeps the bit with probability \(2/3\) and flips it with probability \(1/3\), what is the weight of the path \(0\to0\to1\to1\)?

    Show solutionHide solution

    By the product rule, it is \(w(0\to0)\,w(0\to1)\,w(1\to1)=(2/3)(1/3)(2/3)=4/27\).

  2. A nondeterministic rule on \(\{0,1\}\) allows \(0\to0\), \(0\to1\), and \(1\to1\), and forbids \(1\to0\). Using the product rule with weights \(1\) and \(0\), decide which of the eight three-step paths from \(0\) are possible.

    Show solutionHide solution

    A path has weight \(1\) exactly when none of its arrows is \(1\to0\), that is, once the path reaches \(1\) it stays there. From \(0\), the possible paths are \(0\to0\to0\to0\), \(0\to0\to0\to1\), \(0\to0\to1\to1\), and \(0\to1\to1\to1\). The other four contain the arrow \(1\to0\) and have weight \(0\).

  3. The product rule for probabilities assumes the Markov property. Find a two-step random process on \(\{0,1\}\) in which the probability of the path \(0\to1\to0\), given the start \(0\), differs from \(P(c_1=1\mid c_0=0)\,P(c_2=0\mid c_1=1)\).

    Show solutionHide solution

    Let \(c_0\) be a fair coin, let \(c_1\) be an independent fair coin, and let \(c_2=c_0\), so the second step copies the starting value. Given \(c_0=0\), the path \(0\to1\to0\) has probability \(1/2\): \(c_1=1\) with probability \(1/2\), and then \(c_2=0\) for certain. But \(P(c_2=0\mid c_1=1)=1/2\), because \(c_1\) says nothing about \(c_0\). The product is \((1/2)(1/2)=1/4\neq1/2\). The second step depends on \(c_0\), not only on the current configuration \(c_1\), so the process is not Markov and the product rule fails.

3.2.2 The sum rule across paths§

An endpoint specifies where the run finishes without specifying how it got there. To calculate its weight, we therefore sum the contributions of all paths that reach it. For two steps from \(i\) to \(k\), the paths differ only in the intermediate configuration \(j\):

\[w(i\Rightarrow k)=\sum_j w(j\to k)\,w(i\to j).\]

The arrow \(\Rightarrow\) here denotes the complete two-step transition. Each term accounts for one route; the sum accounts for all routes to the chosen endpoint.

For a deterministic rule, only one path from the start is permitted. The sum is one at its endpoint and zero elsewhere. For a nondeterministic rule, the sum counts permitted paths. A positive count establishes reachability, but is not a probability.

For a probabilistic rule, the histories are mutually exclusive, so the sum is the endpoint probability. Distinguishing the two-step probability \(P_2\) from the one-step probabilities \(P\), we have

\[P_2(k\mid i)=\sum_jP(k\mid j)P(j\mid i).\]

For COIN, this is \(1/4+1/4=1/2\) at either endpoint. In all three models, every contribution is nonnegative. Adding a permitted path can therefore increase an endpoint’s total weight or leave it unchanged, but cannot reduce it. This restriction will matter when we encounter quantum transitions.

Problems

  1. Under KEEP-OR-FLIP, how many possible paths lead from \(0\) to \(1\) in three steps, and what does the count tell us?

    Show solutionHide solution

    The first two steps are free and the third must end at \(1\), so there are \(2\cdot2=4\) paths. The positive count shows that \(1\) is reachable at time \(3\); it says nothing about how likely \(1\) is.

  2. A rule has \(P(0\mid0)=2/3\), \(P(1\mid0)=1/3\), \(P(0\mid1)=1/4\), and \(P(1\mid1)=3/4\). Use the sum rule to compute the four two-step weights \(w(i\Rightarrow k)\), and check that the weights from each start add to \(1\).

    Show solutionHide solution

    From \(0\): \(w(0\Rightarrow0)=\tfrac23\cdot\tfrac23+\tfrac13\cdot\tfrac14=\tfrac{19}{36}\) and \(w(0\Rightarrow1)=\tfrac23\cdot\tfrac13+\tfrac13\cdot\tfrac34=\tfrac{17}{36}\). From \(1\): \(w(1\Rightarrow0)=\tfrac14\cdot\tfrac23+\tfrac34\cdot\tfrac14=\tfrac{17}{48}\) and \(w(1\Rightarrow1)=\tfrac14\cdot\tfrac13+\tfrac34\cdot\tfrac34=\tfrac{31}{48}\). Indeed \(\tfrac{19}{36}+\tfrac{17}{36}=1\) and \(\tfrac{17}{48}+\tfrac{31}{48}=1\).

  3. Prove that, for any probabilistic rule, the two-step weights \(w(i\Rightarrow k)\) given by the sum and product rules add to \(1\) over \(k\). What does this show about composing two probabilistic steps?

    Show solutionHide solution

    By the sum and product rules, \(\sum_kw(i\Rightarrow k)=\sum_k\sum_jP(k\mid j)P(j\mid i)=\sum_jP(j\mid i)\sum_kP(k\mid j)\). The inner sum is \(1\), because the probabilities leaving \(j\) add to \(1\), and the remaining sum \(\sum_jP(j\mid i)\) is \(1\) for the same reason. The two-step weights are nonnegative and add to \(1\) from every start, so two probabilistic steps together form another probabilistic rule.

3.2.3 States and steps§

The same rules apply when the initial configuration is uncertain. Instead of choosing one starting node, assign a weight \(v_i\) to every configuration \(i\). This collection is the state used in the calculation. A definite start has weight one at one configuration and zero elsewhere; a probabilistic preparation has nonnegative weights adding to one.

During a step, the contribution from \(i\) to \(j\) is \(w(i\to j)v_i\). Summing over all starting configurations gives the new weight at \(j\):

\[v^\prime_j=\sum_i w(i\to j)\,v_i.\]

The state thus collects the information needed to predict the next step, without retaining a separate list of all earlier paths. For COIN, \(v^\prime_0=v^\prime_1=(v_0+v_1)/2=1/2\). Every initial probability distribution becomes the same fair distribution.

Whether a step can be undone depends on what this update preserves. A reversible deterministic rule permutes the configurations; reversing its arrows restores every initial state. CNOT is an example on two bits, with arrows \(00\to00\), \(01\to01\), \(10\to11\), and \(11\to10\).

RESET and COIN instead send distinct initial states to the same final state. No rule acting only on that final state can recover which preparation was used. To undo such a process, we would need additional information outside this description.

Problems

  1. Apply one step of COIN, and separately one step of NOT, to the state with weights \(0.9\) on \(0\) and \(0.1\) on \(1\).

    Show solutionHide solution

    COIN sends every distribution to weights \(1/2\) and \(1/2\): \(v^\prime_0=\tfrac12(0.9)+\tfrac12(0.1)=0.5\), and likewise \(v^\prime_1=0.5\). NOT moves each weight along its single arrow, giving \(0.1\) on \(0\) and \(0.9\) on \(1\).

  2. For the rule with \(P(0\mid0)=2/3\), \(P(1\mid0)=1/3\), \(P(0\mid1)=1/4\), and \(P(1\mid1)=3/4\), find the distribution that one step leaves unchanged.

    Show solutionHide solution

    We need \(v_0=\tfrac23v_0+\tfrac14v_1\) with \(v_0+v_1=1\). The first equation gives \(\tfrac13v_0=\tfrac14v_1\), so \(v_1=\tfrac43v_0\), and then \(v_0+\tfrac43v_0=1\) gives \(v_0=3/7\) and \(v_1=4/7\). Check: \(v^\prime_0=\tfrac23\cdot\tfrac37+\tfrac14\cdot\tfrac47=\tfrac27+\tfrac17=\tfrac37\).

  3. Prove that a probabilistic rule on finitely many configurations can be undone by another probabilistic rule only if it is deterministic and reversible.

    Show solutionHide solution

    Let \(T\) be undone by \(S\). From the definite configuration \(i\), \(T\) produces a distribution \(p_i\), and \(S\) must return it to \(e_i\): \(\sum_jp_i(j)\,S(e_j)=e_i\). Each \(S(e_j)\) is a distribution, and a weighted average of distributions with positive weights equals the definite configuration \(i\) only if every distribution in it is \(e_i\). So \(S(e_j)=e_i\) for every \(j\) with \(p_i(j)\gt 0\). A configuration \(j\) therefore cannot be reached from two different starts \(i\) and \(i^\prime\), since \(S(e_j)\) cannot equal both \(e_i\) and \(e_{i^\prime}\). The \(N\) starts thus reach disjoint, nonempty sets of configurations among only \(N\) configurations, so each set has exactly one element. Each start goes to a single configuration, so \(T\) is deterministic, and different starts go to different configurations, so \(T\) is reversible.

3.3

Signed Weights

For a probabilistic computation, the distribution over configurations contains everything needed to predict the next step. Once two preparations give the same distribution, the rule can no longer distinguish them. A qubit challenges this description: two preparations can give the same probabilities when measured now, yet different outcomes after a further operation. To describe its future, we must retain something beyond those probabilities. Signed amplitudes provide a first example of how this can work.

3.3.1 An operation that probability cannot describe§

Consider a physical system with two distinguishable measurement outcomes, labelled \(0\) and \(1\), such as a suitable pair of atomic energy levels. Such a quantum system is a qubit. We can prepare either basis state and apply an operation \(H\). Its ideal behavior is as follows:

  1. Apply \(H\) once to either basis preparation and measure: zero and one are equally likely.
  2. Apply \(H\) twice without an intervening measurement: the original basis outcome returns with certainty.
  3. Measure between the two applications: the final outcomes are again equally likely.

The first observation gives the same outcome probabilities as COIN. If those probabilities completely described the intermediate state, both starting preparations would have become the same state. The second application could then have no basis for returning one preparation to zero and the other to one. Observation 2 therefore tells us that the intermediate probabilities are incomplete: the distinction between the preparations has survived in a form they do not express.

We retain the path calculation but reconsider its weights. After two steps from zero, two paths contribute to the final outcome one. Both must have nonzero weights if the first-step possibilities are to remain represented. Yet their combined contribution must vanish. Nonnegative weights cannot do this; weights of opposite sign can.

This suggests extending the description from probabilities to signed quantities. It does not establish the full quantum rules, or exclude classical descriptions with extra hidden memory. It identifies the failure of the two-configuration probabilistic model and the kind of information its replacement must retain. We still need a rule connecting signed weights to probabilities, and an account of why an intervening measurement removes the cancellation.

Problems

It fails observation 2: two unobserved COIN steps from \(0\) give \(0\) with probability \(1/2\), not with certainty.

  2. Suppose a probabilistic rule satisfies observation 1. Show that it must be COIN, and compute the probability that two steps from \(0\) end at \(1\).

    Show solutionHide solution

    Observation 1 says that from either start each outcome has probability \(1/2\), so \(P(j\mid i)=1/2\) for all \(i\) and \(j\): the rule is COIN. Two steps from \(0\) end at \(1\) along \(0\to0\to1\) and \(0\to1\to1\), each with probability \(1/4\), so the probability is \(1/2\). Observation 2 requires \(0\).

  3. Suppose only runs starting at \(0\) are tested: one step is fair, but two unmeasured steps return \(0\) with certainty. Can the same probabilistic rule on two configurations reproduce even these observations? Let \(r\) be its probability of going from \(1\) to \(1\).

    Show solutionHide solution

    The first observation fixes \(P(0\mid0)=P(1\mid0)=1/2\). After two steps the probability of \(1\) is \((1/2)(1/2)+(1/2)r=1/4+r/2\), at least \(1/4\). It cannot be zero. Using a fair coin first and RESET second would change the rule between steps. Allowing extra hidden configurations would change the model as well. The contradiction concerns the same rule acting on a complete two-configuration description.

3.3.2 From weights to probabilities§

Once a weight may be negative, it can no longer be a probability. The two must be distinguished. Quantum mechanics calls these weights amplitudes and, for real amplitudes \(v_0,v_1\), assigns outcome probabilities \(v_0^2,v_1^2\). The probabilities add to one, so

\[\ket\psi=v_0\ket0+v_1\ket1,\qquad v_0^2+v_1^2=1.\]

Here \(\ket0\) and \(\ket1\) name the basis states, and their coefficients specify the amplitudes. A combination with both coefficients nonzero is a superposition in this basis. Squaring removes the signs from the immediate probabilities, but the state retains them for subsequent transitions. This probability rule is a physical postulate, not a consequence of the coin comparison alone.

A transition must now preserve the sum of squared amplitudes for every input state. Starting from a definite basis state \(i\) gives the first condition:

\[\sum_j w(i\to j)^2=1.\]

That is necessary, but not sufficient. A superposition combines the outgoing contributions from different starting configurations. For input \((\ket i+\ket k)/\sqrt2\), with \(i\ne k\), the total squared amplitude after the step is

\[\frac12\sum_j\bigl(w(i\to j)+w(k\to j)\bigr)^2=1+\sum_jw(i\to j)w(k\to j).\]

To keep this equal to one, the cross sum must vanish. Thus each outgoing list of weights has unit squared length, and different lists have zero cross sum. Together these conditions preserve normalization for every real superposition. In matrix language, the lists are orthonormal columns; reversing the arrows gives the inverse transformation on this finite state space.

NOT meets both conditions. RESET meets the first but fails the second, because both starting configurations feed the same output. Applied to \((\ket0-\ket1)/\sqrt2\), its contributions cancel into the zero vector, which cannot represent a normalized state. RESET is therefore not a possible closed-system evolution of the qubit. A physical reset requires an account of what happens outside it.

Problems

  1. Which of the following are possible qubit states under the measurement rule: \(\tfrac12\ket0+\tfrac12\ket1\); \(\tfrac35\ket0-\tfrac45\ket1\); \(\ket0-\ket1\)?

  3. Derive the condition \(\sum_jw(i\to j)\,w(k\to j)=0\) for \(i\neq k\) from the requirement that every operation leaves the total squared weight unchanged.

    Show solutionHide solution

    Apply the operation to the state with weight \(1/\sqrt2\) on \(i\) and on \(k\). By the sum and product rules, the new weight of \(j\) is \(\bigl(w(i\to j)+w(k\to j)\bigr)/\sqrt2\). Its total squared weight is \(\tfrac12\sum_j\bigl(w(i\to j)^2+w(k\to j)^2\bigr)+\sum_jw(i\to j)\,w(k\to j)=1+\sum_jw(i\to j)\,w(k\to j)\), using the first condition. Since the total must remain \(1\), the sum vanishes.

3.3.3 The Hadamard step§

The probability rule fixes the magnitudes needed for \(H\): an outcome probability of \(1/2\) requires an amplitude of magnitude \(1/\sqrt2\). The remaining choice is the signs. They must preserve normalization for every input and produce the return observed after two steps. One choice satisfying both requirements is

\[H\ket0=\frac{\ket0+\ket1}{\sqrt2},\qquad H\ket1=\frac{\ket0-\ket1}{\sqrt2}.\]

Each outgoing list has squared entries adding to one. Their cross sum is \(1/2-1/2=0\), so the operation satisfies the conditions just obtained. This is the Hadamard operation.

The two intermediate states give identical probabilities when measured, but differ in the sign of the amplitude at one. A second application of \(H\) acts on that difference:

\[H^2\ket0=\frac{(\ket0+\ket1)+(\ket0-\ket1)}2=\ket0.\]

The two paths to zero contribute \(+1/2,+1/2\), while those to one contribute \(+1/2,-1/2\). Their sums are one and zero, giving a certain return to zero. Starting from one similarly gives \(H^2\ket1=\ket1\).

The distinction between the initial preparations was never lost. It was carried by a sign that the intermediate outcome probabilities could not reveal. These signs are a consistent convention for the stated behavior, rather than a unique assignment inferred from the observations. Removing the minus sign, however, would violate the zero-cross-sum condition and destroy the required cancellation.

3.4

Complex Amplitudes and Interference

The signs of real amplitudes retain a distinction that probabilities discard. Complex amplitudes extend that distinction from a choice of sign to a continuously varying phase. We examine what this extension permits by constructing a square root of NOT, then ask how phase affects an observable outcome. Finally, we consider a further condition on interference: whether another part of the system keeps a record that distinguishes the contributing paths.

3.4.1 Complex weights§

The Hadamard operation returns a bit to its starting state after two steps. We can ask for a different composition: two identical steps whose combined action is NOT. Writing NOT as \(X\), we seek \(S\) such that \(S^2=X\). No reversible deterministic rule on one bit does this: both the identity and NOT square to the identity.

To construct such a step with amplitudes, let its stay-weight be \(a\) and its switch-weight be \(b\), the same from either configuration. Two steps return to the start by staying twice or switching twice, and reach the opposite configuration by staying then switching or switching then staying. The required path sums are therefore

\[a^2+b^2=0,\qquad2ab=1.\]

For real \(a,b\), the first equation forces both to vanish, contradicting the second. Complex numbers permit cancellation between the squares themselves. With \(i^2=-1\), choose

\[a=\frac{1+i}{2},\qquad b=\frac{1-i}{2}.\]

Then \(a^2=i/2\), \(b^2=-i/2\), and \(2ab=1\). The two-step transformation is exactly NOT. This construction shows what the larger number system permits; it is not a derivation of the quantum postulates.

The probability rule must also extend to complex amplitudes. For \(z=u+iv\), define its conjugate \(z^*=u-iv\) and its squared magnitude \(|z|^2=z^*z=u^2+v^2\). Quantum probabilities are squared magnitudes, which are real and nonnegative, rather than complex squares.

Our proposed step has \(|a|^2+|b|^2=1\) and \(a^*b+b^*a=0\). These are the complex versions of the normalization and cross-sum conditions. They ensure that the step preserves total probability for every input state. Its inverse is obtained by reversing the arrows and conjugating their weights.

A nonzero complex amplitude can also be written \(z=re^{i\phi}\), with magnitude \(r\) and phase \(\phi\). Positive and negative real amplitudes have phases zero and \(\pi\); complex amplitudes allow the angles between them. Multiplication multiplies magnitudes and adds phases. We still multiply along paths and add across paths, but now take the squared magnitude of the total to obtain an outcome probability.

Problems

  1. A symmetric step has stay-weight \(a\) and switch-weight \(b\). Write the two-step weights for returning and switching. Why can real \(a,b\) not make two steps equal NOT?

  3. Find every operation with \(S(0\to0)=S(1\to1)=a\) and \(S(0\to1)=S(1\to0)=b\) whose two steps give NOT. Show in particular that \(a\) and \(b\) cannot both be real.

    Show solutionHide solution

    Two steps from \(0\) give weight \(a^2+b^2\) at \(0\) and \(2ab\) at \(1\), and from \(1\) the same by symmetry. We need \(a^2+b^2=0\) and \(2ab=1\). If \(a\) and \(b\) were real, the first equation would force \(a=b=0\), contradicting the second. Over the complex numbers, \(a^2=-b^2\) gives \(a=\pm ib\). With \(a=ib\), \(2ib^2=1\), so \(b^2=-i/2\) and \(b=\pm(1-i)/2\), \(a=\pm(1+i)/2\). With \(a=-ib\), \(b^2=i/2\), so \(b=\pm(1+i)/2\) and \(a=\pm(1-i)/2\). There are four solutions: \(S\), \(-S\), and the two operations obtained from them by conjugating every weight. Each is unitary.

3.4.2 Interference and phase§

The probability of an outcome depends on the total amplitude reaching it, not on separate probabilities assigned to its contributing paths. This is interference:

\[p(k)=\Bigl|\sum_{\text{paths to }k}\text{path amplitude}\Bigr|^2.\]

Contributions interfere constructively when their combination raises the probability above the sum of their individual squared magnitudes, and destructively when it lowers it. For two Hadamard steps from zero, the two contributions to one are \(+1/2\) and \(-1/2\). Adding first gives zero probability; squaring first would give \(1/4+1/4=1/2\), the incorrect COIN prediction.

In the unmeasured experiment, the intermediate configurations label terms in an amplitude calculation. They are not separately observed events to which we assign classical path probabilities. The alternatives are coherent: their amplitudes combine before the probability is calculated. Measuring the intermediate configuration changes the experiment, as observation 3 showed.

The effect of phase follows directly. Multiplying every amplitude by the same \(e^{i\theta}\) multiplies every later amplitude by that factor. Since its magnitude is one, all outcome probabilities remain unchanged. This is a global phase; vectors differing only by it describe the same physical state.

A relative phase changes one contribution with respect to another, so it can change their sum. Consider

\[\frac1{\sqrt2}\bigl(\ket0+e^{i\phi}\ket1\bigr).\]

A direct computational-basis measurement gives zero and one with probability \(1/2\), independently of \(\phi\). After \(H\), however, the contributions to zero are \(1/2\) and \(e^{i\phi}/2\). Consequently,

\[p(0)=\left|\frac{1+e^{i\phi}}2\right|^2=\frac{1+\cos\phi}{2}.\]

At \(\phi=0\), zero is certain; at \(\phi=\pi\), it is impossible. Intermediate phases give intermediate probabilities. The phase that the first measurement could not reveal therefore controls the result of a later one.

The operation \(Z\), with stay-weights \(Z(0\to0)=1\) and \(Z(1\to1)=-1\), changes this relative phase by \(\pi\). Inserting it between two Hadamard steps changes the output from \(\ket0\) to \(\ket1\). This is a mechanism a quantum algorithm can use: encode information in relative phases, then combine amplitudes so that the information affects measurable probabilities.

3.4.3 Path information and interference§

Interference requires the contributions to end at the same configuration. If another register distinguishes them, the configuration of the whole system is no longer the same, even when the qubit we intend to measure has the same value. This explains why a record can remove interference without anyone reading it.

Let a second bit start at zero and record the intermediate value of the first. Write the first qubit’s label before the record’s label. Insert CNOT between two applications of \(H\), using the first qubit as control and the record as target. Each \(H\) acts only on the first qubit:

\[\ket{00}\xrightarrow{H}\tfrac1{\sqrt2}\bigl(\ket{00}+\ket{10}\bigr)\xrightarrow{\text{CNOT}}\tfrac1{\sqrt2}\bigl(\ket{00}+\ket{11}\bigr)\xrightarrow{H}\tfrac12\bigl(\ket{00}+\ket{10}+\ket{01}-\ket{11}\bigr).\]

The amplitudes contributing to first-qubit outcome one are still \(+1/2\) and \(-1/2\). They now belong to different joint configurations, \(10\) and \(11\). They cannot cancel. Ignoring the record means adding the probabilities of these distinguishable joint outcomes, giving \(1/4+1/4=1/2\) for the first qubit.

The relevant change is the existence of a distinguishable record, not a reader’s knowledge of it. To restore the original interference, apply CNOT a second time before the final \(H\). This returns the record to zero on both alternatives. The state becomes \((\ket{00}+\ket{10})/\sqrt2\), and the final \(H\) gives \(\ket{00}\). Here uncomputation restores the common endpoint needed for cancellation.

Identical records preserve interference; perfectly distinguishable records remove it; partial distinguishability gives an intermediate result. For a quantum computation, tracking only the intended output is therefore insufficient. We must also track any workspace that distinguishes alternatives we want to interfere, and coherently return those records to a common state when needed. The next chapters provide the vector and composite-system descriptions needed to follow these dependencies systematically.

Problems

  1. In the record experiment, find the probability of each of the four final configurations, and the probability that the record shows \(1\).

    Show solutionHide solution

    The final state is \(\tfrac12(\ket{00}+\ket{10}+\ket{01}-\ket{11})\), so each configuration has probability \(1/4\). The record shows \(1\) in \(01\) and \(11\), with total probability \(1/2\): the record is a fair coin, and so is the qubit.

  2. Check the final state \(\tfrac12(\ket{00}+\ket{10}+\ket{01}-\ket{11})\) by applying \(H\) to the qubit in \(\ket{00}\) and in \(\ket{11}\) separately.

    Show solutionHide solution

In between, the interference is reduced in proportion to how well the records tell the paths apart.
