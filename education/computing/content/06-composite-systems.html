6.1

Registers and Operations

The composite-state postulate gives the states a register can hold. To compute with them, we need to label the configurations of many qubits, recognize when the qubits still behave independently, and count how many numbers a general state carries. Only then can we ask which gates act on one qubit and which couple two.

6.1.1 Registers and product bases§

A task with several input bits needs several qubits. What is the state of such a register? For two qubits we already know the answer. The composite-state postulate assigns one amplitude to each pair of labels, and two independently prepared qubits combine by the tensor product,

\[\begin{pmatrix}a\\b\end{pmatrix}\otimes\begin{pmatrix}c\\d\end{pmatrix}=\begin{pmatrix}ac\\ad\\bc\\bd\end{pmatrix}.\]

What changes with a third qubit? Nothing new: we apply the same rule again, and each two-bit label gains a third bit. For \(n\) qubits, the basis vectors are

\[\ket x=\ket{x_1}\otimes\ket{x_2}\otimes\cdots\otimes\ket{x_n},\]

one for each \(n\)-bit string \(x=x_1x_2\cdots x_n\). They form the product basis. We write the first qubit as the leftmost bit, so \(\ket{01}\) means that the first qubit is \(0\) and the second is \(1\), and we list amplitudes in the order \(00,01,10,11\), as binary numbers.

Besides the qubits that hold the input, a register may contain working qubits, called ancillas, which start in \(\ket0\). Preparing them, and everything later done to them, is part of the computation.

In a circuit, each qubit gets its own wire, with the first qubit at the top. A box on one wire acts on that qubit; a box spanning several wires is a joint operation. A slash across a wire marks several qubits drawn as one line. It still stands for all of them, not for one larger qubit.

6.1.2 Product states§

When does a register behave like separate qubits? Exactly when its state is a product, \(\ket\psi\otimes\ket\phi\). Then each joint amplitude is a product of local amplitudes, so each joint probability is a product of local probabilities. We called such a state a product state.

Can we recognize one from its joint amplitudes? A superposition of several configurations may still be a product. The state \((\ket{00}+\ket{10})/\sqrt2\) has two nonzero amplitudes, yet

\[\frac{\ket{00}+\ket{10}}{\sqrt2}=\frac{\ket0+\ket1}{\sqrt2}\otimes\ket0:\]

the first qubit is in an equal superposition, and the second is certainly \(0\). All four amplitudes can be nonzero, too:

\[\frac{\sqrt3\ket{00}+\sqrt3\ket{01}+\ket{10}+\ket{11}}{2\sqrt2}\]\[=\frac{\sqrt3\ket0+\ket1}{2}\otimes\frac{\ket0+\ket1}{\sqrt2}.\]

Here the first qubit gives \(0\) with probability \(3/4\), whatever happens to the second. So the number of terms decides nothing. The question is whether one list of amplitudes for each qubit reproduces every joint amplitude. When it does, the qubits are independent; when it does not, the state is entangled.

6.1.3 Counting amplitudes§

How many numbers does a register hold? By the composite-state postulate, every unit vector of the tensor-product space is an allowed state, not only the products. A general state of \(n\) qubits is therefore

\[\ket\Psi=\sum_xc_x\ket x,\qquad\sum_x|c_x|^2=1,\]

with one amplitude for each of the \(2^n\) bit strings. A product state needs only two amplitudes per qubit, \(2n\) numbers in all. Every added qubit doubles the first count and adds two to the second.

Does a measurement return \(2^n\) numbers? No. Measuring all \(n\) qubits returns one \(n\)-bit label \(x\), with probability \(|c_x|^2\).

Storing a general state on a classical computer takes up to \(2^n\) amplitudes; thirty qubits already need more than a billion. Does that alone make quantum computers powerful? No. An advantage needs a task, and a procedure that turns the amplitudes into a likely correct answer.

6.1.4 Local and controlled gates§

How does a gate on one qubit act on the register? It changes the first label and leaves the second alone. Each arrow of \(U\) from \(i\) to \(j\) becomes, for each value \(b\) of the second label, an arrow from \(ib\) to \(jb\) with the same weight: \(\bra{jb}U\otimes I\ket{ib}=\bra jU\ket i\). We write this operation \(U\otimes I\). On a product state,

\[(U\otimes I)(\ket\psi\otimes\ket\phi)=(U\ket\psi)\otimes\ket\phi.\]

Gates that each act on a single wire are local gates. Gates on different wires can share a time step when the hardware permits.

Can local gates correlate two qubits? The equation above says no. A product state stays a product, whatever local gates we apply, so the qubits stay independent. To correlate them we need a gate whose action on one qubit depends on the other.

The simplest such gate flips a target qubit exactly when a control qubit is \(1\). It is the controlled-NOT, or CNOT. With the first qubit as control,

\[\operatorname{CNOT}\ket a\ket b=\ket a\ket{b\oplus a},\qquad a,b\in\{0,1\},\]

where \(\oplus\) is exclusive OR, addition modulo two. The circuit symbol is a filled dot on the control wire joined by a vertical line to a circled plus on the target wire. The dot is not a measurement: the rule acts on each configuration of a superposition, and linearity does the rest.

In the order \(00,01,10,11\), CNOT exchanges the last two amplitudes:

\[\begin{pmatrix}c_{00}\\c_{01}\\c_{10}\\c_{11}\end{pmatrix}\longmapsto\begin{pmatrix}c_{00}\\c_{01}\\c_{11}\\c_{10}\end{pmatrix}.\]

No amplitude is lost, and exchanging twice restores the input, so CNOT is unitary and is its own inverse. More generally, a controlled \(U\) leaves the target alone on the configurations where the control is \(0\) and applies \(U\) where it is \(1\).

Let us run a circuit with both kinds of gate. Start with \(\ket{00}\), apply \(H\) to the first wire and \(X\) to the second:

\[(H\otimes X)\ket{00}=\frac{\ket{01}+\ket{11}}{\sqrt2}.\]

Measuring both wires now gives 01 or 11, each with probability one half. Apply CNOT before measuring instead: 01 stays 01, while 11 becomes 10, so the results are 01 and 10. A definite second bit has become a bit that is always opposite the first.

The whole unitary is \(U=\operatorname{CNOT}(H\otimes X)\), with the rightmost operation first. It uses two qubits and three gates. \(H\) and \(X\) act on different wires and can share a time step, so the circuit has two layers of gates before measurement. The number of successive layers is the circuit depth, assuming these gates are available directly. An arbitrary operation on the whole register does not count as one gate.

6.2

Entangled States

Local gates keep a product state a product, and CNOT does not. Can a circuit of these gates turn independent qubits into an entangled pair? And if it can, how would a measurement tell entanglement apart from correlation that a coin could produce?

6.2.1 Bell-state preparation§

Start from \(\ket{00}\), apply \(H\) to the first qubit, then CNOT with the first qubit as control. What happens?

\(H\) gives \((\ket{00}+\ket{10})/\sqrt2\), still a product state. CNOT acts on each configuration: it leaves \(00\) alone and sends \(10\) to \(11\):

\[\ket{00}\to\frac{\ket{00}+\ket{10}}{\sqrt2}\to\frac{\ket{00}+\ket{11}}{\sqrt2}.\]

The result is a Bell state, written \(\ket{\Phi^+}\).

Does the vertical line of CNOT mean that the first qubit is measured and the result used to decide whether to flip the second? No. CNOT acts on both configurations of the superposition at once, without any measurement. That is why the result is a superposition of \(00\) and \(11\), rather than one of them.

The final pure state is entangled: its joint amplitudes do not factor into two single-qubit states. Its probabilities alone would not distinguish it from a classical mixture.

6.2.2 Nonfactorization of amplitudes§

Is \(\ket{\Phi^+}\) a product state? We have already shown that \((\ket{00}+\ket{11})/\sqrt2\) cannot be factored: a product would need nonzero \(ac\) and \(bd\), which makes \(ad\) and \(bc\) nonzero too. So the circuit has made an entangled state from the product state \(\ket{00}\).

Which gate did it? \(H\) acts on one wire, so after it the state \((\ket0+\ket1)/\sqrt2\otimes\ket0\) is still a product. The joint gate, CNOT, created the entanglement.

We can still predict every measurement on either qubit from the joint amplitudes. What fails is giving each qubit its own state vector and multiplying the two to recover the pair.

Do perfectly correlated results prove entanglement? Compare a classical mixture: toss a fair coin and, according to the result, prepare \(\ket{00}\) or \(\ket{11}\). Each run holds one definite state, and we average probabilities, not amplitudes, over the coin. A computational-basis measurement of this mixture gives 00 or 11, half the time each, exactly as for \(\ket{\Phi^+}\). To tell them apart we need a different measurement.

6.2.3 Joint, marginal, and conditional probabilities§

Although neither qubit of \(\ket{\Phi^+}\) has an individual pure-state vector, each still has well-defined local measurement probabilities. How do we read probabilities from a joint state? With amplitudes \(c_{ab}\), the joint probability is \(p(a,b)=|c_{ab}|^2\). The probability that the first qubit gives \(a\), whatever the second gives, is the marginal \(p(a)=\sum_bp(a,b)\), and the conditional probability of \(b\) given \(a\) is \(p(b\mid a)=p(a,b)/p(a)\) when \(p(a)\gt 0\).

For \(\ket{\Phi^+}\), \(p(00)=p(11)=1/2\); each qubit alone gives \(0\) or \(1\) with probability \(1/2\); and once the first result is known, the second is certain.

If only the first qubit is measured and its outcome is \(a\), keep the terms with that first label and divide by \(\sqrt{p(a)}\). For example, measuring the first qubit of \((\ket{00}+\ket{01}+\ket{11})/\sqrt3\) gives 0 with probability \(2/3\); conditional on that outcome the state becomes \((\ket{00}+\ket{01})/\sqrt2\). Measuring part of a register uses the same rule as measuring one qubit: keep the component that agrees with the result, and rescale it.

To test coherence, measure each qubit in the X basis instead. Applying \(H\) and then measuring in the computational basis is exactly that measurement: \(H\) sends \(\ket+=(\ket0+\ket1)/\sqrt2\) to \(\ket0\) and \(\ket-=(\ket0-\ket1)/\sqrt2\) to \(\ket1\), so result \(0\) means \(+\) and result \(1\) means \(-\).

For the Bell state, the two contributions are

\[(H\otimes H)\ket{00}=\frac{\ket{00}+\ket{01}+\ket{10}+\ket{11}}2,\qquad (H\otimes H)\ket{11}=\frac{\ket{00}-\ket{01}-\ket{10}+\ket{11}}2.\]

Adding them with the initial factor \(1/\sqrt2\) cancels 01 and 10, leaving \(\ket{\Phi^+}\) again. The results still agree with certainty. For the classical mixture, each run starts in either 00 or 11, and either preparation gives all four results with probability \(1/4\) after the two Hadamards. We average those probabilities; there is no addition of amplitudes between different runs.

The output depends on both the joint state and the gates before readout. A single basis measurement misses the coherence that this second circuit exposes.

6.3

Quantum Information Constraints

An entangled pair carries correlations that no list of single-qubit states describes. What can we do with such states? Two tasks look natural: copying an unknown state, and using a shared pair to send a message faster than an ordinary one. We test each against the rules we have.

6.3.1 Basis-state copying§

Can a quantum state be copied? CNOT seems to copy. With a blank target, \(\ket0\ket0\to\ket0\ket0\) and \(\ket1\ket0\to\ket1\ket1\).

What does it do to a superposition? By linearity,

\[(\alpha\ket0+\beta\ket1)\ket0\to\alpha\ket{00}+\beta\ket{11}.\]

Two copies would instead be

\[(\alpha\ket0+\beta\ket1)\otimes(\alpha\ket0+\beta\ket1)=\alpha^2\ket{00}+\alpha\beta\ket{01}+\alpha\beta\ket{10}+\beta^2\ket{11}.\]

These differ whenever \(\alpha\) and \(\beta\) are both nonzero. CNOT copies the labels \(0\) and \(1\), not superpositions of them.

6.3.2 The no-cloning theorem§

Could some cleverer unitary copy every state? Suppose \(U\ket\psi\ket0=\ket\psi\ket\psi\) for every state \(\ket\psi\). Take two states \(\ket\psi\) and \(\ket\phi\). A unitary preserves inner products. What is the inner product of two product states? For \(\ket u\otimes\ket v\) and \(\ket x\otimes\ket y\), the joint amplitudes are products, so

\[\bigl(\bra u\otimes\bra v\bigr)\bigl(\ket x\otimes\ket y\bigr)=\sum_{i,j}\overline{u_iv_j}\,x_iy_j=\Bigl(\sum_i\overline{u_i}x_i\Bigr)\Bigl(\sum_j\overline{v_j}y_j\Bigr)=\braket ux\braket vy:\]

the inner product of the parts, multiplied. Comparing the inner products before and after copying,

\[\braket\phi\psi\braket00=\braket\phi\psi^2,\qquad\text{that is,}\qquad\braket\phi\psi=\braket\phi\psi^2.\]

The overlap must therefore be \(0\) or \(1\). For two different states that are not orthogonal, such as \(\ket0\) and \(\ket+\) with overlap \(1/\sqrt2\), this fails. No unitary copies every state. This is the no-cloning theorem.

What does the theorem not forbid? States known to belong to an orthogonal set, such as basis labels, can be copied, and a state that we know how to prepare can simply be prepared again. What is impossible is a single fixed operation that perfectly copies an arbitrary unknown state.

6.3.3 Local states and no-signalling§

Alice and Bob share \(\ket{\Phi^+}\). If Alice measures her qubit in the computational basis, her outcomes occur equally often. Given her outcome, Bob has the matching basis state. Without her message, his probability of 0 is still \(\tfrac12(1)+\tfrac12(0)=1/2\). Alice cannot choose which result she obtains.

Checking only this one measurement would leave a loophole: perhaps Bob could apply a gate before readout and detect her choice. We can close it using the same amplitude rules. Write any joint state as \(\sum_{a,b}c_{ab}\ket{ab}\), with Alice’s label first. For each fixed Bob label \(b\), his probability is the squared length of the amplitude list \((c_{0b},c_{1b})\). An Alice-only unitary multiplies this list by her unitary, preserving its squared length. Thus it leaves every Bob probability unchanged.

If Bob first applies any local gate \(V\), perform that step first in the calculation. Alice’s and Bob’s gates act on different labels, so their order does not matter. The same norm argument then proves that Alice cannot change his probabilities for this readout either.

An unreported computational-basis measurement by Alice also leaves those probabilities unchanged: it separates the two values of \(a\) into alternatives, and averaging their probabilities gives the same sum \(\sum_a|c_{ab}|^2\). A measurement in another basis is a local unitary followed by this measurement, so it cannot help her signal. Without a message, then, Bob’s counts are the same whatever Alice does. A message reporting her outcome lets him sort his runs into groups, one for each of her results, and within a group his conditional statistics can differ.

This is no-signalling for the local gates and projective measurements used here. Correlations become useful for communication only when supplemented by an ordinary message. The appendix on mixed states extends the argument to more general local operations.

6.4

Quantum Teleportation

No-cloning and no-signalling say what entanglement cannot do. Teleportation shows what it can: with a shared Bell pair and two classical bits, an unknown state moves from sender to receiver without the qubit that holds it travelling. We follow the joint state through the sender’s operations and measurement, find the corrections the receiver must apply, and check that neither limit is violated.

6.4.1 Entanglement resources§

Alice holds a qubit in an unknown state \(\ket\psi=\alpha\ket0+\beta\ket1\) and wants Bob to have it. She cannot copy it, and measuring it would reveal only one bit. What can she do if they share a Bell pair?

The three qubits start in \(\ket\psi\otimes\ket{\Phi^+}\); Alice holds the first two and Bob the third. Alice applies CNOT from her input qubit to her half of the Bell pair, then \(H\) to her input qubit. The Bell pair must already have been distributed; no qubit is sent during the subsequent protocol. In the order input, Alice’s half, Bob’s half, the initial expansion is \((\alpha\ket{000}+\alpha\ket{011}+\beta\ket{100}+\beta\ket{111})/\sqrt2\). CNOT changes it to \((\alpha\ket{000}+\alpha\ket{011}+\beta\ket{110}+\beta\ket{101})/\sqrt2\). Next Alice applies \(H\) to the first qubit, and we follow where its two labels go.

6.4.2 Measurement and conditional corrections§

What does Alice’s Hadamard leave on Bob’s side? Apply \(H\ket0=(\ket0+\ket1)/\sqrt2\) and \(H\ket1=(\ket0-\ket1)/\sqrt2\) to the first label of each term:

\[\tfrac12\bigl(\alpha\ket{000}+\alpha\ket{100}+\alpha\ket{011}+\alpha\ket{111}+\beta\ket{010}-\beta\ket{110}+\beta\ket{001}-\beta\ket{101}\bigr).\]

Now collect the terms by Alice’s two labels. With labels \(00\), Bob’s qubit carries \(\alpha\ket0+\beta\ket1=\ket\psi\). With \(01\) it carries \(\alpha\ket1+\beta\ket0=X\ket\psi\). With \(10\) it carries \(\alpha\ket0-\beta\ket1=Z\ket\psi\). With \(11\) it carries \(\alpha\ket1-\beta\ket0=XZ\ket\psi\). So

\[\frac12\bigl(\ket{00}\ket\psi+\ket{01}X\ket\psi+\ket{10}Z\ket\psi+\ket{11}XZ\ket\psi\bigr).\]

The first label records Alice’s input-wire measurement, and the second records her Bell-half measurement.

This identity is the protocol. Every branch has squared norm \(1/4\), regardless of \(\alpha,\beta\). Alice measures her two qubits, sends their values \((m,n)\), and Bob receives the conditional state \(X^nZ^m\ket\psi\).

6.4.3 State transfer and classical communication§

Before the classical bits arrive, Bob averages probabilities over the four equally likely states \(\ket\psi,X\ket\psi,Z\ket\psi,XZ\ket\psi\). His probability of 0 is \((|\alpha|^2+|\beta|^2+|\alpha|^2+|\beta|^2)/4=1/2\). In fact every normalized test state \(\ket v=c\ket0+d\ket1\) has probability \(1/2\): pairing the two opposite signs in these four branches cancels cross terms, leaving \((|c|^2+|d|^2)(|\alpha|^2+|\beta|^2)/2\). No choice of local readout reveals the input. His qubit is already present, but he cannot use it as the recovered input or learn the input’s amplitudes from it. The useful transfer waits for the message.

Nor is there a second copy left with Alice. Her measured qubits are basis states, and the shared Bell pair has been consumed. Conditioned on the communicated outcome and Bob’s correction, the unknown input is now at Bob.

Keep three descriptions separate: the full joint state, Bob’s state given Alice’s result, and Bob’s state when that result is unknown. Confusing them makes teleportation look like instantaneous communication or cloning. Tracking them turns it into an explicit calculation with the rules we already have.

6.5

Quantum Parallelism

A register of qubits carries an amplitude for every bit string, and a gate on one wire updates all of them together. A reversible evaluation of a function should then act on every input string of the register in one run. We follow that run, ask how much of its result a measurement can deliver, and look for a question it might answer instead of the full table of values.

6.5.1 Evaluation on every input§

Teleportation used a register to move a state. Can a register also compute? Reversible computation already gave us a way to evaluate any Boolean function \(f\) without discarding information: keep the input \(x\) and add \(f(x)\) to a target bit. On the basis states of a quantum register this is the gate

\[U_f\ket x\ket y=\ket x\ket{y\oplus f(x)}.\]

For each input it either leaves the target alone or flips it, so it only rearranges configurations. It is unitary, and it can be built from Toffoli and CNOT gates at about the cost of evaluating \(f\) once, provided any workspace is cleared by uncomputation.

What does \(U_f\) do when the input register is not a single string? Take two input qubits, both \(\ket0\), and apply \(H\) to each:

\[(H\otimes H)\ket{00}=\tfrac12\bigl(\ket{00}+\ket{01}+\ket{10}+\ket{11}\bigr).\]

Two gates spread equal amplitude over all four inputs. With \(n\) input qubits, \(n\) Hadamard gates give all \(2^n\) strings, each with amplitude \(2^{-n/2}\). The number of gates grows by one per qubit; the number of configurations doubles.

Now add a target qubit in \(\ket0\) and apply \(U_f\). The gate is defined by one arrow from each basis configuration, and each configuration carries its amplitude along its own arrow. So

\[U_f\Bigl(\tfrac12\sum_x\ket x\Bigr)\ket0=\tfrac12\sum_x\ket x\ket{f(x)}.\]

For a concrete case, let \(f\) be AND, so \(f(x)=1\) only for \(x=11\):

\[\tfrac12\bigl(\ket{00}\ket0+\ket{01}\ket0+\ket{10}\ket0+\ket{11}\ket1\bigr).\]

One application of \(U_f\) has produced a state in which every input appears beside its own value. This is quantum parallelism. Has the computer evaluated \(f\) four times for the price of once? The state holds four input–value pairs, but holding them is not the same as reading them.

6.5.2 What a measurement reveals§

Suppose we measure every qubit of the AND state. Each configuration \(\ket x\ket{f(x)}\) has amplitude \(1/2\), so each of the four pairs \((00,0)\), \((01,0)\), \((10,0)\), and \((11,1)\) appears with probability \(1/4\). A run returns one input, chosen at random, together with its value. Afterwards the register is in the observed configuration, and the other three pairs are gone.

To learn the whole table, we prepare and measure again. The inputs arrive at random, so four runs are the minimum and repeats make more runs likely. Evaluating \(f\) on the four inputs one at a time takes exactly four evaluations. With \(n\) inputs, the table has \(2^n\) entries, while a measurement of the \(n+1\) qubits yields \(n+1\) bits.

Could we copy the state before measuring it and measure each copy? A device that copied every such state would copy states that are not orthogonal, which the no-cloning theorem forbids. Two different functions can give overlapping parallel states: for AND and for the constant zero function, the states agree in three of their four terms.

What if we measure only the target? For AND it gives \(0\) with probability \(3/4\), leaving the inputs in \((\ket{00}+\ket{01}+\ket{10})/\sqrt3\), and \(1\) with probability \(1/4\), leaving \(\ket{11}\). The target alone tells us one value that \(f\) takes, and the inputs that remain are exactly the strings with that value.

That conditional state shows something else. Unless \(f\) is constant, the parallel state is entangled: it cannot be written as an input state times a target state, because the target is \(\ket0\) beside some inputs and \(\ket1\) beside others. The target keeps a record of which input occurred. Parallel evaluation alone produces a random sample of the table, not the table.

6.5.3 Global properties through interference§

If a run cannot deliver the table, what could it deliver? Many questions need much less than the table. Is \(f\) constant? Does it take the value \(1\) anywhere? Each answer is a single bit, but it depends on all the values together. Such an answer is a global property of \(f\).

Interference combines contributions from all the inputs, so it is the natural tool. After \(U_f\), apply \(H\) to each input qubit again and measure the inputs. Each input string \(x\) sends amplitude \(1/2\) to the readout \(00\), so the readout \(00\) collects contributions from all four branches.

For a constant function \(f(x)=c\), the parallel state is \(\tfrac12\sum_x\ket x\ket c\), a product of the uniform input state and \(\ket c\). Applying \(H\otimes H\) again returns the inputs to \(\ket{00}\). The readout is \(00\) with certainty.

For AND, the contributions to \(00\) do not all end at the same configuration. Three branches carry target \(0\) and contribute \(\tfrac12\cdot\tfrac12\) each to \(\ket{00}\ket0\); the branch \(x=11\) carries target \(1\) and contributes \(\tfrac12\cdot\tfrac12\) to \(\ket{00}\ket1\). Amplitudes add only at a common configuration, so

\[p(00)=\Bigl(\tfrac34\Bigr)^2+\Bigl(\tfrac14\Bigr)^2=\tfrac58.\]

The readout \(00\) no longer separates the two cases reliably. The cause is the record the target keeps: branches with different target values sit at different configurations, and their contributions cannot cancel or reinforce one another. This is the path-information effect of interference, now produced by the computation itself.

Quantum parallelism is therefore a resource only when a later interference step turns many values into one useful bit, and that step needs a target that keeps no record of the branch. Which global properties can be read out this way, and how must the target be prepared? Functions that can be consulted only through queries make these questions precise.
