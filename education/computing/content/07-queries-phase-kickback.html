7.1

Function Queries

To compare quantum and classical computation without hardware-dependent assumptions, we count a standardized resource: calls to a black-box function \(f\). In this section, we classify one-bit Boolean functions into constant and balanced families, establish why any classical procedure requires two queries to tell them apart, and formulate the unitary oracle \(U_f\) that grants a quantum circuit coherent query access.

7.1.1 Constant and balanced Boolean functions§

Consider the four possible Boolean functions on a single bit, \(f:\{0,1\}\to\{0,1\}\). Instead of asking for the full truth table, suppose we ask a single relational question: does \(f(0)\) equal \(f(1)\)? If \(f(0) = f(1)\)—satisfied by the constant-\(0\) function (\(f(x)=0\)) and the constant-\(1\) function (\(f(x)=1\))—we say that \(f\) is constant. If \(f(0)\ne f(1)\)—satisfied by the identity (\(f(x)=x\)) and negation (\(f(x)=1\oplus x\))—equal numbers of inputs map to \(0\) and \(1\), and we say that \(f\) is balanced.

This question asks strictly for the single parity bit \(f(0)\oplus f(1)\): it evaluates to \(0\) when \(f\) is constant and \(1\) when \(f\) is balanced. The individual values \(f(0)\) and \(f(1)\) are irrelevant; only their relationship matters. For one-bit functions, every function is either constant or balanced. For \(n\)-bit functions \(f:\{0,1\}^n\to\{0,1\}\), where most functions are neither, restricting the input domain to constant or balanced functions defines a promise problem.

7.1.2 Classical query access§

Suppose our sole access to \(f\) is a black-box query: we submit an input bit \(x\in\{0,1\}\), and the box returns the output bit \(f(x)\). How many queries must a classical algorithm make to decide whether \(f\) is constant or balanced?

A single query—say \(x=0\), returning \(f(0)=0\)—leaves the unqueried value \(f(1)\) completely unconstrained. If \(f(1)=0\), the function is constant; if \(f(1)=1\), it is balanced. Among the functions consistent with any single reply, exactly one is constant and one is balanced. Even a randomized algorithm guessing after one query errs with probability \(1/2\) on the worst-case function. Any classical algorithm achieving deterministic certainty must therefore make two queries, evaluating both \(f(0)\) and \(f(1)\) to compute their difference.

Query complexity measures how efficiently an algorithm extracts relational information from an oracle without inspecting its internal wiring.

7.1.3 Reversible quantum oracles§

To query a black-box function in a quantum computer, the operation must be unitary, preserving inner products even when \(f\) is a non-injective constant function. The standard reversible query gate \(U_f\) acts on an input wire \(\ket{x}\) and target wire \(\ket{y}\) by addition modulo \(2\):

\[U_f\ket{x}\ket{y} = \ket{x}\ket{y\oplus f(x)},\qquad x,y\in\{0,1\}.\]

On the computational basis \(\{\ket{00},\ket{01},\ket{10},\ket{11}\}\), \(U_f\) permutes basis states: if \(f(x)=0\), it acts as the identity \(I\) on the target; if \(f(x)=1\), it applies the bit flip \(X\). Because every permutation of orthonormal basis vectors is unitary and swapping twice restores the original configuration, \(U_f\) is both unitary and self-inverse (\(U_f^2 = I\)).

In the quantum black-box model, each execution of \(U_f\) counts as exactly one quantum query. When the input register holds a superposition, linearity evaluates \(f\) across all basis branches in a single query.

7.2

Coherent Function Evaluation

Linearity allows \(U_f\) to evaluate superpositions of inputs in a single query. In this section, we examine the quantum state produced when the target qubit is initialized in \(\ket{0}\), demonstrate why direct measurement yields zero computational speedup, and diagnose how entanglement between the input register and target workspace destroys interference.

7.2.1 Oracle action on superpositions§

Prepare the input wire in the uniform superposition \(\ket{+} = (\ket{0}+\ket{1})/\sqrt{2}\) and the target wire in \(\ket{0}\). Applying the oracle \(U_f\) once acts on both basis components simultaneously by linearity:

\[U_f\left(\frac{\ket{0}+\ket{1}}{\sqrt{2}}\otimes\ket{0}\right) = \frac{\ket{0}\ket{f(0)} + \ket{1}\ket{f(1)}}{\sqrt{2}}.\]

Both function values \(f(0)\) and \(f(1)\) now reside within the joint amplitudes of the register. For a constant function (\(f(0)=f(1)=c\)), the target factors out cleanly as \(\ket{+}\otimes\ket{c}\). For a balanced function (\(f(0)\ne f(1)\)), the two wires are entangled: \(f=(0,1)\) yields the Bell state \((\ket{00}+\ket{11})/\sqrt{2}\), while \(f=(1,0)\) yields \((\ket{01}+\ket{10})/\sqrt{2}\).

Although both values are encoded in the joint state, reading out the relational parity \(f(0)\oplus f(1)\) requires a measurement.

7.2.2 Register measurement§

Measuring both qubits of \(\bigl(\ket{0}\ket{f(0)}+\ket{1}\ket{f(1)}\bigr)/\sqrt{2}\) in the computational basis collapses the superposition: we observe \((0, f(0))\) with probability \(1/2\) or \((1, f(1))\) with probability \(1/2\). The unobserved branch vanishes, leaving only a single input–output pair.

This outcome is statistically indistinguishable from choosing \(x\in\{0,1\}\) with an ordinary coin toss and querying \(f(x)\) classically. Querying a superposition and measuring in the standard basis offers no advantage over classical sampling. Collecting both values through repeated runs requires \(3\) queries on average (the coupon collector problem for two items), performing strictly worse than two deterministic classical queries.

Extracting a relational property like \(f(0)\oplus f(1)\) requires making the two branches interfere before measurement.

7.2.3 Workspace entanglement§

Suppose we attempt to create interference by applying a Hadamard gate \(H\) to the input wire before measuring. When \(f\) is constant, the state factors as \(\ket{+}\otimes\ket{c}\), so \((H\otimes I)\) yields \(\ket{0}\otimes\ket{c}\), returning input outcome \(0\) with certainty. But when \(f\) is balanced, say \(f=(0,1)\), the state is the entangled Bell pair \((\ket{00}+\ket{11})/\sqrt{2}\). Applying \(H\) to the input produces

\[(H\otimes I)\frac{\ket{00}+\ket{11}}{\sqrt{2}} = \frac{1}{2}\bigl(\ket{00}+\ket{10}+\ket{01}-\ket{11}\bigr) = \frac{\ket{0}}{\sqrt{2}}\otimes\ket{+} + \frac{\ket{1}}{\sqrt{2}}\otimes\ket{-}.\]

The two paths arriving at input \(0\) land on mutually orthogonal target configurations (\(\ket{00}\) and \(\ket{01}\)), so their amplitudes add incoherently rather than interfering. Measuring the input wire yields \(0\) and \(1\) with equal probability \(1/2\).

This failure reflects a general physical principle: whenever \(f\) is balanced, the target qubit records which input branch was taken. The input qubit is left in a completely mixed statistical mixture, destroying all phase coherence. To allow the input branches to interfere, the target qubit must remain in the identical state vector regardless of whether \(f(x)=0\) or \(f(x)=1\), while still imprinting a distinguishing phase factor on the input wire.

7.3

Phase Kickback

To prevent target entanglement from destroying interference, we prepare the target qubit in an eigenstate of the bit-flip operator \(X\). The oracle leaves the target unentangled while transferring function values into the relative phases of the input register—a mechanism known as phase kickback. We also show how to uncompute temporary workspace registers when evaluating general multi-gate circuits.

7.3.1 Bit-flip eigenstates§

For each basis input \(\ket{x}\), the oracle \(U_f\) acts on the target qubit as \(X^{f(x)}\): the identity \(I\) when \(f(x)=0\), and the bit flip \(X\) when \(f(x)=1\). Which target states are mapped to scalar multiples of themselves under \(X\)? Testing the diagonal basis states \(\ket{\pm} = (\ket{0}\pm\ket{1})/\sqrt{2}\) yields

\[X\ket{+} = +\ket{+},\qquad X\ket{-} = -\ket{-}.\]

Thus \(\ket{+}\) and \(\ket{-}\) are the two orthonormal eigenstates of \(X\), with eigenvalues \(+1\) and \(-1\). Preparing the target in \(\ket{+}\) is uninformative because \(X^y\ket{+} = (+1)^y\ket{+} = \ket{+}\), which erases all dependence on \(y\). Preparing the target in \(\ket{-}\), however, gives

\[X^y\ket{-} = (-1)^y\ket{-},\qquad y\in\{0,1\}.\]

In both cases the target qubit remains in the identical state \(\ket{-}\), leaving no distinguishing path record, while the eigenvalue \((-1)^y\) cleanly flags whether a bit flip occurred.

7.3.2 Phase-oracle construction§

When the target wire is prepared in \(\ket{-} = H\ket{1}\), the action of \(U_f\) on any basis input \(\ket{x}\) factors as

\[U_f\ket{x}\ket{-} = \ket{x}\otimes X^{f(x)}\ket{-} = \ket{x}\otimes\bigl((-1)^{f(x)}\ket{-}\bigr) = (-1)^{f(x)}\ket{x}\ket{-}.\]

Because the scalar factor \((-1)^{f(x)}\) commutes across the tensor product, the target qubit factors out completely, while the eigenvalue attaches directly to the input amplitude. This transfer of an eigenvalue from the target to the input register is called phase kickback.

Now supply the uniform superposition \(\ket{+} = (\ket{0}+\ket{1})/\sqrt{2}\) to the input wire. By linearity,

\[U_f(\ket{+}\otimes\ket{-}) = \left(\frac{(-1)^{f(0)}\ket{0} + (-1)^{f(1)}\ket{1}}{\sqrt{2}}\right)\otimes\ket{-} = (-1)^{f(0)}\left(\frac{\ket{0} + (-1)^{f(0)\oplus f(1)}\ket{1}}{\sqrt{2}}\right)\otimes\ket{-}.\]

The target qubit remains strictly in \(\ket{-}\), completely unentangled from the input register. Meanwhile, the parity bit \(f(0)\oplus f(1)\) is encoded directly into the relative sign of the input superposition: constant functions produce \(\pm\ket{+}\), while balanced functions produce \(\pm\ket{-}\). Phase kickback maps the functional distinction into two orthogonal states of a single unentangled qubit.

7.3.3 Coherent uncomputation§

When \(f\) is evaluated by a multi-gate reversible circuit \(A\) using scratchpad ancillas, the forward pass produces intermediate records: \(\ket{x}\ket{0}\ket{0} \xrightarrow{A} \ket{x}\ket{f(x)}\ket{g(x)}\), where \(\ket{g(x)}\) represents workspace garbage. Left unchecked, these garbage bits entangle with the input register and destroy interference.

We generate the phase \((-1)^{f(x)}\) and erase all workspace records using the compute, phase, uncompute pattern: execute \(A\) to compute the function, apply a single-qubit phase flip \(Z\) to the answer wire to impart the sign \((-1)^{f(x)}\), and execute the inverse circuit \(A^\dagger\) to restore both the answer and workspace registers to \(\ket{0}\ket{0}\):

\[A^\dagger Z_{\mathrm{answer}} A\,\ket{x}\ket{0}\ket{0} = A^\dagger\bigl((-1)^{f(x)}\ket{x}\ket{f(x)}\ket{g(x)}\bigr) = (-1)^{f(x)}\ket{x}\ket{0}\ket{0}.\]

Because the phase factor is a scalar multiplier on the computational branch \(\ket{x}\), it persists unchanged while \(A^\dagger\) restores all workspace qubits to \(\ket{0}\), eliminating path information and preserving full quantum coherence.

7.4

Deutsch’s Algorithm

With phase kickback encoding the relational invariant into the relative sign of \(\ket{\pm}\), a final basis change makes that sign directly observable. In this section, we complete Deutsch's algorithm with a Hadamard readout gate, examine the resulting quantum-versus-classical query separation, and distill the universal four-stage architecture shared by quantum algorithms.

7.4.1 Interference and readout§

Following phase kickback, the input qubit occupies \((-1)^{f(0)}\bigl(\ket{0} + (-1)^{f(0)\oplus f(1)}\ket{1}\bigr)/\sqrt{2}\). Measuring immediately in the computational basis would yield \(0\) or \(1\) with probability \(1/2\) each, because standard basis measurements detect amplitude magnitudes, not relative phases.

To convert the relative sign into a deterministic bit, we apply a Hadamard gate \(H\) to the input wire, which maps \(\ket{+}\mapsto\ket{0}\) and \(\ket{-}\mapsto\ket{1}\):

\[H\left((-1)^{f(0)}\frac{\ket{0}+(-1)^{f(0)\oplus f(1)}\ket{1}}{\sqrt{2}}\right) = (-1)^{f(0)}\ket{f(0)\oplus f(1)}.\]

The overall sign \((-1)^{f(0)}\) is an unobservable global phase. A computational-basis measurement of the input qubit yields the parity bit \(f(0)\oplus f(1)\) with probability \(1\): outcome \(0\) certifies that \(f\) is constant, and outcome \(1\) certifies that \(f\) is balanced. Interference extracts the global relation between \(f(0)\) and \(f(1)\) with certainty without revealing the value of either output individually.

7.4.2 Quantum and classical query counts§

The complete circuit for Deutsch’s algorithm operates in four steps: initialize \(\ket{0}\ket{1}\), apply \(H\otimes H\) to prepare \(\ket{+}\ket{-}\), query the oracle \(U_f\) once, and apply \(H\) to the input wire before measuring.

In the query complexity model, Deutsch’s algorithm succeeds with probability \(1\) using exactly \(1\) quantum query to \(U_f\), whereas any classical algorithm requires \(2\) queries. This establishes the first provable query separation between quantum and classical computation: \(Q_E(f) = 1 < D(f) = 2\).

The advantage does not stem from "computing two values simultaneously," since measuring two values would require multiple runs. Rather, quantum mechanics allows a single query to evaluate an interference pattern that isolates a global relational invariant while remaining completely agnostic to the underlying function values.

7.4.3 Preparation, oracle evaluation, and measurement§

Deutsch's algorithm establishes the universal four-stage architecture shared by quantum algorithms:

  1. State preparation: Hadamard gates create an unbiased, equal superposition across all computational inputs (\(\ket{0}\mapsto\ket{+}\)), opening every path to coherent evolution.
  2. Oracle encoding: Phase kickback evaluates \(U_f\) into relative phases rather than workspace registers (\(\ket{x}\mapsto (-1)^{f(x)}\ket{x}\)), imprinting relational properties while leaving the target unentangled.
  3. Interference transformation: A basis change converts relative phases into amplitude interference, steering constructive reinforcement onto states that represent the solution and destructive cancellation onto states that do not.
  4. Readout: A standard computational-basis measurement samples the constructive peak with certainty or bounded error.

Altering any stage breaks the interference: omitting the input superposition queries only a single input, using a \(\ket{0}\) target entangles the registers and destroys coherence, using \(\ket{+}\) suppresses all phase kickback (\(X\ket{+}=\ket{+}\)), and omitting the final Hadamard leaves the relative phase unobservable in the computational basis. In Chapter 9, we generalize this exact four-stage blueprint to amplify target amplitudes in Grover's search algorithm.
