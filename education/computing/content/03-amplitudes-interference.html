3.1

Three Kinds of Transition

Deterministic, nondeterministic, and probabilistic computations look different. To compare them, we take a single example and ask the same question under each kind of rule: from a given start, where can a two-step run end? Each answer comes from a diagram of the rule and a list of its paths. Doing the calculation three times shows what the three kinds of rule have in common.

3.1.1 Deterministic transitions§

Let us begin with the smallest computation we can examine completely: a register holding one bit, updated step by step by a rule.

What must we record in order to continue such a computation? Only the value of the bit. The register therefore has two configurations, \(0\) and \(1\). A transition rule tells us, for each configuration, which configuration comes next. Consider two rules: NOT flips the bit, and RESET writes \(0\) whatever the bit holds.

ConfigurationNext under NOTNext under RESET
\(0\)\(1\)\(0\)
\(1\)\(0\)\(0\)

Start from \(0\) and apply NOT twice. The bit goes to \(1\), then back to \(0\). Such a sequence of configurations is a run, written \(c_0,c_1,c_2\), where \(c_t\) is the configuration after \(t\) steps. Under RESET, the run from \(0\) is \(0,0,0\), and the run from \(1\) is \(1,0,0\).

A rule is easier to study when we draw it. In a state diagram, each configuration is a circle, and each transition the rule allows is an arrow. We attach a number to each arrow, its weight. For NOT and RESET every weight is \(1\): the step certainly follows that arrow. Other kinds of rule will need other weights.

A state diagram shows what can happen in one step, but not how a run unfolds in time. For that, draw a copy of the configurations for each time \(t=0,1,2\), and connect \(i\) at time \(t\) to \(j\) at time \(t+1\) whenever the rule has the arrow \(i\to j\). This is the time-expanded diagram. A run is now a path through it, from time \(0\) to time \(2\).

How many paths leave the start? For NOT, only one, because a single arrow leaves each configuration. A rule with exactly one outgoing arrow at every configuration is deterministic.

Can we also run the computation backward? Knowing that NOT ended at \(0\), we know it was at \(1\) a step earlier, because only one arrow enters \(0\). Under RESET we cannot tell: arrows from \(0\) and from \(1\) both enter \(0\). A deterministic rule is reversible when, in addition, exactly one arrow enters each configuration.

3.1.2 Nondeterministic transitions§

What if a rule allows more than one next configuration? Consider KEEP-OR-FLIP: after either configuration, both \(0\) and \(1\) are allowed. Its state diagram has all four arrows, which we label “yes.” A rule of this kind is nondeterministic.

Starting from \(0\), how many runs are there? Two arrows leave the start, and two leave each configuration after that, so four paths reach time \(2\):

\[0\to0\to0,\qquad0\to1\to0,\qquad0\to0\to1,\qquad0\to1\to1.\]

The rule does not say which path is taken. What can we still ask? Whether a run is possible: it is when every arrow on its path is allowed. And whether a configuration is reachable: it is when some possible path ends there. Here both \(0\) and \(1\) are reachable after two steps.

Two paths reach \(0\). Does that make \(0\) twice as likely? No. The rule lists what is allowed and says nothing about likelihood. Nondeterminism is still a useful idea: a nondeterministic machine accepts an input if some possible run accepts it, and Chapter 9 defines the class NP in this way. To speak about how likely an outcome is, the arrows need numbers of another kind.

3.1.3 Probabilistic transitions§

A nondeterministic rule says which configurations may come next, but not how often each does. Suppose the rule chooses at random. Each arrow \(i\to j\) then carries a probability \(P(j\mid i)\), read “the probability of \(j\) given \(i\)”: the probability that the next configuration is \(j\) when the current one is \(i\). Some next configuration must occur, so the probabilities on the arrows leaving a configuration add to \(1\). Such a rule is probabilistic.

Our example is COIN: whatever the bit holds, replace it by a fair coin flip. Every arrow carries \(1/2\).

What is the probability that a run from \(0\) ends at \(0\)? Take one path, \(0\to1\to0\). The first arrow is followed with probability \(1/2\). Given that it was, the second is followed with probability \(1/2\). The path therefore has probability \(1/2\cdot1/2=1/4\). We have used that each step depends only on the current configuration, not on how the run reached it; a process with this property is a Markov process.

Two paths end at \(0\). A run follows exactly one path, so these alternatives cannot both happen, and their probabilities add:

\[P(c_2=0)=\tfrac14+\tfrac14=\tfrac12.\]

Likewise \(P(c_2=1)=1/2\). A fair coin flipped twice is still fair.

What does a probability tell us about a single run? Nothing definite: a single run ends at \(0\) or at \(1\). The probability predicts how often each happens when the run is repeated many times.

3.2

Sum and Product Rules

Three kinds of rule have produced three calculations. If a new kind of transition is to be compared with them, all three need a single description. We find it in two rules for combining weights: a product along each path and a sum across paths. Extending these rules from a definite start to a state, a weight on each configuration, makes one step a single update of the state.

3.2.1 The product rule along a path§

Look back at the three calculations. Each time we did two things: we combined the arrows along a path, and then we combined the paths ending at the same configuration. Can one recipe cover all three kinds of rule?

Give every arrow a weight: \(1\) for an arrow of a deterministic or nondeterministic rule, \(P(j\mid i)\) for an arrow of a probabilistic rule, and \(0\) for an arrow the rule does not have. Along a path, multiply.

Product rule. The weight of a path is the product of the weights of its arrows:

\[w(i\to j\to k)=w(j\to k)\,w(i\to j).\]

Does this give the right answer each time? For a deterministic rule, the product is \(1\) along the run and \(0\) on any path that uses a missing arrow. For a nondeterministic rule, a product of ones and zeros is \(1\) exactly when every arrow on the path is allowed. For a probabilistic rule, it is the probability of the path, as we found for COIN. Under COIN, every path of \(n\) steps has weight \((1/2)^n\).

3.2.2 The sum rule across paths§

Now combine the paths. Several paths can end at the same configuration, and we add their weights.

Sum rule. The weight of reaching \(k\) from \(i\) is the sum of the weights of all paths from \(i\) to \(k\). In two steps the paths differ only in the intermediate configuration \(j\), so

\[w(i\Rightarrow k)=\sum_j w(j\to k)\,w(i\to j),\]

where the sum runs over all configurations \(j\). For a probabilistic rule this is the calculation we made for COIN:

\[P(k\mid i)=\sum_jP(k\mid j)\,P(j\mid i)=\tfrac14+\tfrac14=\tfrac12.\]

What does the sum mean for the other kinds of rule? For a deterministic rule, at most one path has weight \(1\), so the sum is \(1\) if the run ends at \(k\) and \(0\) otherwise. For a nondeterministic rule, the sum counts the possible paths, and \(k\) is reachable when the count is positive.

Could adding a path ever lower the weight of reaching a configuration? Not with any of these rules: none of their weights is negative, so every path adds something.

3.2.3 States and steps§

So far each run started from a definite configuration. What if we know the configuration only with some probability? We then describe the register by a state: a weight \(v_j\) for each configuration \(j\). The definite configuration \(i\) is the state with weight \(1\) on \(i\) and \(0\) elsewhere; a probability distribution is a state whose weights are nonnegative and add to \(1\).

How does one step change a state? The weight \(v_i\) travels along each arrow \(i\to j\) and is multiplied by \(w(i\to j)\), by the product rule. At \(j\), the arriving contributions add, by the sum rule:

\[v^\prime_j=\sum_i w(i\to j)\,v_i.\]

Under COIN, every probability distribution goes to the state with weights \(1/2\) and \(1/2\).

When can a step be undone, so that a second rule brings every state back to where it started? For a deterministic rule, exactly when one arrow leaves and one arrow enters each configuration; reversing every arrow undoes it. The reversible gates are of this kind. CNOT, for example, acts on two bits by the arrows \(00\to00\), \(01\to01\), \(10\to11\), and \(11\to10\). RESET and COIN send different states to the same state. Nothing can undo them, because the result does not record where they started.

3.3

Signed Weights

So far every weight has been nonnegative: it counted paths or gave a probability. Is that enough to describe every physical process? We look at a bit carried by a single atom, where an experiment shows that it is not. The experiment forces three steps: weights that can be negative, a rule that turns such weights into probabilities, and, from the observations, the weights of the operation itself.

3.3.1 An operation that probability cannot describe§

The bits in a computer are held by devices made of very many atoms. What happens when a bit is carried by a single atom?

Choose two distinguishable conditions of the atom, such as two of its energy levels, and label them \(0\) and \(1\). A two-state system of this kind is a qubit, short for quantum bit. Looking at it, which is called a measurement, gives one of the two labels.

Experiments with qubits reveal an operation, which we call \(H\), with the following behaviour.

  1. Applied once to \(0\) or to \(1\) and then measured, it gives \(0\) or \(1\), each with probability \(1/2\).
  2. Applied twice to \(0\) and then measured, it gives \(0\) with certainty; applied twice to \(1\), it gives \(1\) with certainty.
  3. Applied, measured, applied again, and measured, it gives \(0\) or \(1\), each with probability \(1/2\).

Observation 1 looks familiar: one application of \(H\) behaves like COIN. Observation 2 does not. Can the rules we already have describe it? To put the question precisely, we assume as little as possible.

Assumption 1. Each arrow \(i\to j\) of \(H\) has a weight \(H(i\to j)\), and repeated applications compose by the product and sum rules. The probability of a measurement outcome is \(f(w)\), where \(w\) is the weight of reaching that outcome, and \(f(w)=0\) exactly when \(w=0\).

Proposition. No nonnegative weights satisfy observations 1 and 2.

Proof. By observation 1, outcome \(1\) has nonzero probability after one step from \(0\) and after one step from \(1\), so \(H(0\to1)\) and \(H(1\to1)\) are nonzero, hence positive. The two paths from \(0\) to \(1\) give the weight \(H(0\to0)H(0\to1)+H(0\to1)H(1\to1)\geq H(0\to1)H(1\to1)\gt 0\). Outcome \(1\) then has nonzero probability, contradicting observation 2. \(\square\)

If the product and sum rules hold at all, then, some weight of \(H\) must be negative, and the two paths from \(0\) to \(1\) must cancel. Observation 3 adds a clue: when the qubit is measured between the steps, they do not cancel.

Quantum mechanics is the physical theory of systems such as qubits. We now find its rules for a qubit, starting from Assumption 1 and the three observations.

3.3.2 From weights to probabilities§

Once weights can be negative, a weight is no longer a probability. How, then, do we obtain probabilities from weights?

First some notation. The state of a qubit is a weight for each configuration, \(v_0\) and \(v_1\). We write it \(v_0\ket0+v_1\ket1\), where \(\ket0\), read “ket zero,” stands for the definite configuration \(0\), and \(\ket1\) for \(1\). When both weights are nonzero, the state is a superposition.

What must the function \(f\) satisfy? A probability is never negative, so \(f\) must be nonnegative even for negative weights. And the probabilities of the two outcomes must add to \(1\) for every state an operation can produce. The simplest candidates are powers of the magnitude.

Assumption 2. \(f(w)=|w|^p\) for some \(p\gt 0\).

Every operation must then leave \(\sum_j|v_j|^p\) unchanged, whatever the state. Which operations do that? For most values of \(p\), very few.

Theorem (quoted without proof). For \(p\neq2\), the only operations that leave \(\sum_j|v_j|^p\) unchanged for every state are those in which exactly one arrow leaves and exactly one arrow enters each configuration, with weight \(+1\) or \(-1\).

Such an operation sends each configuration to a single configuration, so it can never produce the coin-like result of observation 1. Only \(p=2\) remains.

Measurement rule. Measuring the state \(v_0\ket0+v_1\ket1\) gives outcome \(j\) with probability \(v_j^2\), and \(v_0^2+v_1^2=1\).

What does this demand of an operation? It must leave the total squared weight unchanged for every state. Start from the definite configuration \(i\): after one step the weights are \(w(i\to j)\), so their squares must add to \(1\). Now start from the state with weight \(1/\sqrt2\) on \(i\) and on another configuration \(k\). After one step, \(j\) has weight \(\bigl(w(i\to j)+w(k\to j)\bigr)/\sqrt2\), and the total squared weight works out to \(1+\sum_jw(i\to j)\,w(k\to j)\). For this to be \(1\), the last sum must vanish. So every operation satisfies

\[\sum_j w(i\to j)^2=1,\qquad \sum_j w(i\to j)\,w(k\to j)=0\quad(i\neq k).\]

These conditions have a consequence: every operation can be undone. Reverse each arrow and keep its weight. Applying the operation and then this reverse, the paths from \(i\) to \(k\) give the weight \(\sum_jw(i\to j)\,w(k\to j)\), which is \(1\) when \(k=i\) and \(0\) otherwise. Every configuration returns to where it started.

Which of the rules we know qualify? A reversible deterministic rule satisfies both conditions, so every reversible gate is a valid operation on qubits. COIN does not: the squares of the weights leaving \(0\) add to \(1/2\). Nor does RESET: applied to \((\ket0-\ket1)/\sqrt2\), it gives the weight \(1/\sqrt2-1/\sqrt2=0\) at \(0\) and \(0\) at \(1\), so no outcome has any probability.

3.3.3 The Hadamard step§

We can now find the weights of \(H\) itself. Observation 1 says that one step from either configuration gives each outcome with probability \(1/2\). By the measurement rule, every weight has square \(1/2\), so each is \(\pm1/\sqrt2\). Which signs?

Observation 2 decides. Two steps must return each configuration, so the paths from \(0\) to \(1\) must cancel, and the paths from \(0\) to \(0\) must add to \(1\):

\[H(0\to0)H(0\to1)+H(0\to1)H(1\to1)=0,\qquad H(0\to0)^2+H(0\to1)H(1\to0)=1.\]

Since \(H(0\to1)\neq0\), the first equation gives \(H(1\to1)=-H(0\to0)\). The second gives \(H(0\to1)H(1\to0)=1/2\), so \(H(0\to1)=H(1\to0)\). The signs of \(H(0\to0)\) and \(H(0\to1)\) are left free; choosing both positive,

\[H(0\to0)=H(0\to1)=H(1\to0)=\tfrac1{\sqrt2},\qquad H(1\to1)=-\tfrac1{\sqrt2},\]

so that

\[H\ket0=\frac{\ket0+\ket1}{\sqrt2},\qquad H\ket1=\frac{\ket0-\ket1}{\sqrt2}.\]

Are these weights a valid operation? The squares leaving each configuration add to \(1/2+1/2=1\), and \(H(0\to0)H(1\to0)+H(0\to1)H(1\to1)=1/2-1/2=0\). They are.

Now the cancellation can be seen directly. Each two-step path from \(0\) has weight \(\pm1/2\), and

\[\text{weight of reaching }0=\tfrac12+\tfrac12=1,\qquad\text{weight of reaching }1=\tfrac12-\tfrac12=0.\]

The paths to \(1\) cancel because the arrow \(1\to1\) carries \(-1/\sqrt2\). The arrows of COIN have the same size, but none is negative, so nothing can cancel.

3.4

Complex Amplitudes and Interference

Signed weights describe the single-atom experiment. Physical processes, however, run continuously in time, and stopping one partway gives operations that signed weights cannot describe: the weights must be complex. These complex weights, called amplitudes, make the contributions to an outcome reinforce, cancel, or anything in between, depending on their phases, and whether they cancel depends also on what else a step leaves behind.

3.4.1 Complex weights§

Are negative weights enough? Ask a simple question: is there an operation that, applied twice, acts as NOT, half of a NOT?

There must be one if operations come from physical processes that run continuously in time: stop the process halfway.

Assumption 3. Every operation has a square root: an operation that, applied twice, equals it.

NOT is a valid operation, since it is a reversible gate. Suppose \(S\) has real weights and two steps of \(S\) give NOT. The paths from \(0\) and from \(1\) give

\[S(0\to0)^2+S(0\to1)S(1\to0)=0,\qquad S(0\to1)\bigl(S(0\to0)+S(1\to1)\bigr)=1,\]

\[S(1\to1)^2+S(1\to0)S(0\to1)=0,\qquad S(1\to0)\bigl(S(0\to0)+S(1\to1)\bigr)=1.\]

The two equations on the right show that \(S(0\to1)\) and \(S(1\to0)\) are nonzero with the same sign, so their product is positive. The first equation then asks for \(S(0\to0)^2\lt 0\). No real number has a negative square, so real weights are not enough.

We need numbers whose squares can be negative. A complex number is \(z=a+ib\) with \(a,b\) real and \(i^2=-1\). Its conjugate is \(z^*=a-ib\), and its magnitude \(|z|\) satisfies \(|z|^2=z^*z=a^2+b^2\). In polar form \(z=re^{i\phi}\), with \(r=|z|\), phase \(\phi\), and \(e^{i\phi}=\cos\phi+i\sin\phi\). Multiplication multiplies magnitudes and adds phases; \(+1\) and \(-1\) have phases \(0\) and \(\pi\).

Complex weights are called amplitudes. What changes in our rules? A probability must be real and nonnegative, so in the measurement rule the square becomes the squared magnitude.

Measurement rule. Measuring the state \(v_0\ket0+v_1\ket1\) gives outcome \(j\) with probability \(|v_j|^2\), and \(|v_0|^2+|v_1|^2=1\).

Repeating the argument of the previous section with magnitudes, every operation satisfies

\[\sum_j|w(i\to j)|^2=1,\qquad \sum_j w(i\to j)^*\,w(k\to j)=0\quad(i\neq k),\]

and is undone by reversing every arrow and conjugating its weight. An operation satisfying these conditions is unitary.

And half of a NOT now exists. Take

\[S(0\to0)=S(1\to1)=\frac{1+i}2,\qquad S(0\to1)=S(1\to0)=\frac{1-i}2.\]

It is unitary, and two steps of \(S\) give NOT: from \(0\), the weight of reaching \(0\) is \(\tfrac14\bigl((1+i)^2+(1-i)^2\bigr)=0\), and the weight of reaching \(1\) is \(\tfrac14(1-i)\cdot2(1+i)=1\).

The four kinds of rule now sit side by side. Along and across paths the arithmetic is the same; only the kind of weight changes.

3.4.2 Interference and phase§

Two paths to the same outcome can now carry amplitudes such as \(1/2\) and \(i/2\), which neither reinforce nor cancel completely. What, in general, decides the probability of an outcome?

When contributions to the same outcome reinforce one another, they interfere constructively; when they cancel, partly or completely, they interfere destructively. In either case the probability of an outcome \(k\) is

\[p(k)=\Bigl|\sum_{\text{paths to }k}\text{path amplitude}\Bigr|^2.\]

What if we squared each path first? For two applications of \(H\) from \(0\), we would get \(1/4+1/4=1/2\) for each outcome, which is exactly the prediction of COIN. The order matters: add, then square.

Did the qubit pass through \(0\) or through \(1\) between the steps? The calculation does not say. Had it been in a definite configuration, we would see observation 3, not observation 2. The intermediate configuration is a label we sum over, not an event that took place. Paths whose amplitudes are added in this way are coherent alternatives.

The probabilities still add to \(1\), so interference that raises one outcome lowers another. This is what a quantum algorithm exploits: it arranges its operations so that paths to correct answers reinforce and paths to wrong answers cancel.

Which features of a state actually matter? Multiply every amplitude by the same \(e^{i\theta}\). By the sum and product rules every later amplitude is multiplied by the same factor, and \(|e^{i\theta}z|=|z|\), so no probability ever changes. Such a factor is a global phase, and states that differ by one are physically the same.

A difference of phase between amplitudes, a relative phase, is another matter. Take

\[\frac1{\sqrt2}\bigl(\ket0+e^{i\phi}\ket1\bigr).\]

Measured directly, it gives \(0\) and \(1\) with probability \(1/2\) for every \(\phi\). After \(H\), the two paths to \(0\) give the amplitude \((1+e^{i\phi})/2\), so \(p(0)=(1+\cos\phi)/2\). The relative phase is invisible at first and decisive one step later.

The operation \(Z\), with \(Z(0\to0)=1\) and \(Z(1\to1)=-1\), shifts the relative phase by \(\pi\). Applying \(H\), \(Z\), \(H\) to \(\ket0\) gives \(\ket1\), while applying \(H\) twice gives \(\ket0\).

3.4.3 Path information and interference§

Measuring the qubit between the two steps destroys the cancellation. Does it take a measurement? Suppose instead that a second bit quietly copies the path.

Let this record start at \(0\), and write two-bit configurations with the qubit first. Insert CNOT, with the qubit as control and the record as target, between the two applications of \(H\). \(H\) acts on the qubit only:

\[\ket{00}\xrightarrow{H}\tfrac1{\sqrt2}\bigl(\ket{00}+\ket{10}\bigr)\xrightarrow{\text{CNOT}}\tfrac1{\sqrt2}\bigl(\ket{00}+\ket{11}\bigr)\xrightarrow{H}\tfrac12\bigl(\ket{00}+\ket{10}+\ket{01}-\ket{11}\bigr).\]

Look at the amplitudes for qubit outcome \(1\): still \(+1/2\) and \(-1/2\). They now belong to different configurations, \(10\) and \(11\), because the record differs. The sum rule adds only paths that end in the same configuration, so nothing cancels, and the qubit gives \(1\) with probability \(1/4+1/4=1/2\). Nobody looked at the record; its existence is enough.

Can the damage be repaired? Apply CNOT once more, before the final \(H\). The record returns to \(0\) on both paths, the state is again \((\ket{00}+\ket{10})/\sqrt2\), and the final \(H\) gives \(\ket{00}\). This is uncomputation, here used to restore interference.

In general it is a matter of degree. Identical records keep the interference, perfectly distinguishable records destroy it, and partly distinguishable records reduce it; Chapter 5 makes this precise. The practical lesson for quantum computation: any workspace that records which path was taken must be uncomputed before the paths are brought together.
