5.1

Quantum Model of Computation

The model has three stages: specify an input state, evolve it by a prescribed unitary operation, and measure an output. We first describe this overall structure, then work through its simplest instance: computation with one qubit.

5.1.1 Input, evolution, and output§

A computation begins with a task: which input is supplied, and what output would count as a successful answer? In the quantum model, we encode the input in a state \(\ket{\psi_{\mathrm{in}}}\), apply a prescribed unitary operation \(U_f\), and obtain

\[\ket{\psi_{\mathrm{out}}}=U_f\ket{\psi_{\mathrm{in}}}.\]

Measurement then produces a classical result \(y\). The output state determines the probabilities of the possible results; it is not itself a classical answer that can be read out in full. In particular, one measurement does not reveal the entire list of amplitudes.

Here \(U_f\) denotes the complete unitary evolution chosen for the task. The label does not promise that an arbitrary classical function can be applied irreversibly to a quantum state, nor that a whole computation costs one step. The construction and cost of this operation are part of the algorithm.

The diagram describes a computation with a final measurement. A more general procedure may include intermediate measurements and later operations selected by their recorded results. We begin with the simpler arrangement so that the relation between the input state, evolution, and readout remains visible.

We will draw this model as a circuit. Read it from left to right: a solid horizontal wire carries the quantum system, and a gate box specifies the operation applied there. The input ket is written at the left. A box marked M measures the system; the double line after it carries the classical result. A box for a complete unitary can hide many elementary gates, so its size on the page says nothing about its cost.

5.1.2 Composition and interference§

A gate is an elementary unitary operation available to the computation. A program specifies an ordered sequence of such operations. If \(U_1\) acts first and \(U_T\) acts last, their combined action is

\[U_f=U_T\cdots U_2U_1,\qquad\ket{\psi_{\mathrm{out}}}=U_T\cdots U_1\ket{\psi_{\mathrm{in}}}.\]

The rightmost factor acts first because it is applied directly to the input. Each gate preserves normalization for every state, so the complete unitary sequence preserves the probability interpretation as well. The number \(T\) counts the gates in this sequence; naming their product \(U_f\) does not remove their implementation cost.

Linearity applies each operation to every component of a superposition. Amplitudes multiply along paths and add at common endpoints. A computation uses these sums to make useful outcomes more likely and unwanted outcomes less likely. An intermediate superposition is not an answer: its relative phases matter because later operations can turn them into different output probabilities.

For example, \(HH=I\), while \(HZH=X\). Here \(I\) leaves a qubit unchanged, \(X\) exchanges its two basis states, and \(Z\) changes the sign of the amplitude at \(1\). The same two Hadamard steps therefore have different results when a phase change is inserted between them. Section 5.2 follows those amplitudes explicitly.

5.1.3 Readout and computational cost§

For an ideal final measurement in the computational basis, the probability of result \(y\) is

\[p(y)=|\braket y{\psi_{\mathrm{out}}}|^2=|\bra yU_f\ket{\psi_{\mathrm{in}}}|^2.\]

The input specification, available operations, measurement, and interpretation of its result together define a computational procedure. For a task depending on an input \(x\), the input state or the prescribed operations may depend on information supplied about \(x\). The procedure must state what information is actually available; it cannot assume that the answer has already been encoded for free.

Each run returns one outcome. If success is probabilistic, the algorithm must give its success probability for the promised inputs. Repeated runs require fresh initialization and cost additional work. Measurement during a run changes the state conditional on its result, so it cannot generally be inserted without changing the later interference. A recorded result can also determine a later operation; this is classical control.

Resources include the number of qubits, elementary gates, sequential operation stages, repetitions, and the work needed to initialize the input and interpret the output. On a single qubit, successive gates must be applied in order. The next chapter extends the model to several qubits, where operations on different parts and joint operations must be distinguished.

A one-qubit example illustrates the model, but does not by itself establish a computational speedup. Such a claim needs a family of growing tasks and a comparison of costs under stated access rules.

5.2

Single-Qubit Computation

One qubit is enough to see the role of gates, relative phase, interference, and measurement. We introduce circuit notation for this single system and calculate its output from beginning to end.

5.2.1 A single-qubit circuit§

The simplest register contains one qubit. Its input state is \(\ket{\psi_{\mathrm{in}}}=a\ket0+b\ket1\), where \(|a|^2+|b|^2=1\). For a definite classical input bit \(x\), choose \(\ket x\). One way to start is to initialize the qubit to \(\ket0\) and apply \(X\) if the specified input is one.

A circuit represents the ordered operations from left to right. A horizontal line, called a wire, tracks this qubit. Its initial state is written at the left. A box labelled H, X, or Z applies that operation; an uninterrupted segment leaves the state unchanged. The wire describes the ordering of operations, not the physical path of a particle.

A box labelled M here means a computational-basis measurement. After it, a double line carries the classical result. These are different descriptions: before measurement the wire carries a quantum state with amplitudes; the recorded output is a bit, zero or one.

In the example below, H sends \(\ket0\) to \((\ket0+\ket1)/\sqrt2\). The measurement returns either bit with probability \(1/2\). Writing and reading this simple circuit requires only one wire; controlled gates and multiple wires enter with the multi-qubit model in Chapter 6.

5.2.2 A complete one-qubit computation§

Consider the task of reversing an input bit: output one for input zero, and zero for input one. X does this directly. We can also implement the same task using interference, with H, then Z, then H. For input zero,

\[\ket0\xrightarrow{H}\frac{\ket0+\ket1}{\sqrt2}\xrightarrow{Z}\frac{\ket0-\ket1}{\sqrt2}\xrightarrow{H}\ket1.\]

After the first H, both computational-basis outcomes would have probability \(1/2\). Z changes their relative sign without changing those immediate probabilities. The final H combines the two paths to each endpoint. At zero the contributions are \(1/2\) and \(-1/2\), which cancel; at one they are both \(1/2\), which add to one. The final measurement returns one with certainty.

We must also check the other allowed input. Starting from one,

\[\ket1\xrightarrow{H}\frac{\ket0-\ket1}{\sqrt2}\xrightarrow{Z}\frac{\ket0+\ket1}{\sqrt2}\xrightarrow{H}\ket0.\]

The circuit therefore implements NOT on both classical inputs. By linearity, its action on an arbitrary input is \(a\ket0+b\ket1\mapsto b\ket0+a\ket1\), agreeing with \(HZH=X\). This construction uses three gates instead of the single X gate; its purpose is to expose how interference computes the result.

If Z is omitted, the two H operations cancel and the input is returned unchanged. If a computational-basis measurement is inserted after the first H, either selected basis state gives equal final probabilities after Z and the last H. Thus both the relative phase and the absence of an intervening measurement are essential to this particular implementation.

5.2.3 Phase and output probabilities§

Replace Z by a phase operation \(R_\phi\) that leaves \(\ket0\) unchanged and multiplies the amplitude of \(\ket1\) by \(e^{i\phi}\):

\[R_\phi\ket0=\ket0,\qquad R_\phi\ket1=e^{i\phi}\ket1.\]

This factor has magnitude one, so the operation preserves normalization. The angle \(\phi\) specifies the phase shift. For input zero, the complete evolution is

\[\ket0\xrightarrow{H}\frac{\ket0+\ket1}{\sqrt2}\xrightarrow{R_\phi}\frac{\ket0+e^{i\phi}\ket1}{\sqrt2}\xrightarrow{H}\frac{1+e^{i\phi}}2\ket0+\frac{1-e^{i\phi}}2\ket1.\]

We can now read the probabilities from the final amplitudes:

\[p(0)=\left|\frac{1+e^{i\phi}}2\right|^2=\frac{1+\cos\phi}{2},\qquad p(1)=\frac{1-\cos\phi}{2}.\]

At \(\phi=0\), the middle operation is I and the output is certainly zero. At \(\phi=\pi\), it is Z and the output is certainly one. At \(\phi=\pi/2\), the two outcomes are equally likely. In every case the state just before the final H has the same basis probabilities, \(1/2,1/2\); the final gate converts its relative phase into a measurable difference.

This illustrates the model on one qubit: specify an input, compose unitary operations, calculate the output state, and obtain a classical result with the stated probability. Before enlarging the register in Chapter 6, we examine how the Pauli operations describe general single-qubit transformations.

5.3

Pauli Completeness

X and Z have already appeared in our computations. Adding Y and the identity gives a complete basis for describing single-qubit operators. We will distinguish this algebraic completeness from the ability to construct a gate by a circuit.

5.3.1 The Pauli operations§

The single-qubit examples have used X to exchange the two configurations and Z to change their relative sign. A third operation combines exchange with opposite phase factors:

\[Y\ket0=i\ket1,\qquad Y\ket1=-i\ket0.\]

The three operations X, Y, and Z are the Pauli gates. Including the identity I, their matrices in the ordered basis \(\ket0,\ket1\) are

\[I=\begin{pmatrix}1&0\\0&1\end{pmatrix},\quad X=\begin{pmatrix}0&1\\1&0\end{pmatrix},\quad Y=\begin{pmatrix}0&-i\\i&0\end{pmatrix},\quad Z=\begin{pmatrix}1&0\\0&-1\end{pmatrix}.\]

Each column lists the amplitudes produced from the corresponding input configuration. On an arbitrary state, their actions are

\[X(a\ket0+b\ket1)=b\ket0+a\ket1,\]

\[Y(a\ket0+b\ket1)=-ib\ket0+ia\ket1,\qquad Z(a\ket0+b\ket1)=a\ket0-b\ket1.\]

Each operation preserves normalization, and each undoes itself: \(X^2=Y^2=Z^2=I\). For Y, applying it twice to zero gives \(i(-i)\ket0=\ket0\); the same check works for one.

The order of different Pauli operations matters. Applying Z and then X gives \(XZ\); applying X and then Z gives \(ZX=-XZ\). Moreover, \(Y=iXZ\). Thus products of Pauli gates reduce to I, X, Y, or Z multiplied by a common phase. For a standalone single-qubit computation, that common phase does not affect outcome probabilities.

5.3.2 Completeness and its meaning§

There is a precise sense in which these four matrices describe every single-qubit linear operation. Consider an arbitrary matrix

\[A=\begin{pmatrix}a&b\\c&d\end{pmatrix}.\]

The diagonal entries can be supplied by I and Z: their sum gives equal diagonal entries, while their difference distinguishes the two positions. The off-diagonal entries can be supplied by X and Y: X contributes equally to both positions, while Y supplies opposite imaginary factors. Matching the four entries gives

\[A=\frac{a+d}{2}I+\frac{b+c}{2}X+\frac{c-b}{2i}Y+\frac{a-d}{2}Z.\]

For example, the upper-right entry of this expression is \((b+c)/2-(c-b)/2=b\), and the lower-left entry is \((b+c)/2+(c-b)/2=c\). The diagonal entries are a and d. These coefficients are uniquely determined, so I, X, Y, and Z form a complete basis for single-qubit operators. An operator here is a linear transformation of the state vector; it need not be a physically allowed gate. A unitary matrix is one important case.

The Hadamard and the phase gate from the preceding section have particularly simple expansions:

\[H=\frac{X+Z}{\sqrt2},\qquad R_\phi=\frac{1+e^{i\phi}}2I+\frac{1-e^{i\phi}}2Z.\]

Completeness here concerns linear combinations of matrices, not successive application of gates. A circuit containing X followed by Z implements the product ZX; it does not implement the sum \((X+Z)/\sqrt2\). Nor does randomly choosing X or Z produce that coherent sum.

Starting from \(\ket0\), any sequence of Pauli gates leaves a basis state, up to a common phase. It cannot produce \(H\ket0=(\ket0+\ket1)/\sqrt2\). Thus the Pauli gates alone are not a universal gate set, even for one qubit. An arbitrary linear combination of them is not necessarily unitary either: \(I+Z\), for example, sends \(\ket0\) to \(2\ket0\) and \(\ket1\) to zero.

Continuous rotations generated by the Paulis provide additional operations. For example, define

\[R_x(\theta)=\cos(\theta/2)I-i\sin(\theta/2)X.\]

For real \(\theta\), this is unitary: multiplying by its adjoint cancels the cross terms and gives \((\cos^2(\theta/2)+\sin^2(\theta/2))I=I\). It sends \(\ket0\) to \(\cos(\theta/2)\ket0-i\sin(\theta/2)\ket1\), allowing continuously varying amplitudes. Choosing an arbitrary angle is an extra capability beyond applying the fixed X gate.

We therefore have a compact language for describing single-qubit operations, while the separate problem of constructing them from available gates remains. Chapter 6 now extends the state and computation model to multiple qubits; the later chapter on universality returns to gate construction.
