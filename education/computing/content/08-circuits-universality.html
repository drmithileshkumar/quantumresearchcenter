8.1

Circuit Representation

We have drawn circuits since the first one-qubit program. With several wires, two new questions arise in reading them: which gates can run at the same time, and whether a control is a qubit or a measured bit. A third concerns what a labelled box conceals.

8.1.1 Wires and gate ordering§

What does a circuit with several wires tell us? It draws one wire per qubit and one box per operation, with time running left to right. A wire names a subsystem; it need not carry a definite zero or one. Once the wires are entangled, we follow the joint state of all of them.

The drawing’s left-to-right order and the matrix product’s right-to-left order describe the same sequence: if \(U\) acts first and \(V\) second, the state becomes \(VU\ket\psi\).

Can two gates in a diagram run at the same time? If they act on different wires, yes, and their order does not matter. A gate on the first wire changes only the first label and a gate on the second changes only the second, so either order sends \(\ket{ij}\) along the same arrows:

\[(U\otimes I)(I\otimes V)=(I\otimes V)(U\otimes I)=U\otimes V.\]

Gates that share a wire generally do not commute; \(XZ=-ZX\) is an example. So the diagram shows which work could proceed in parallel, while the actual scheduling belongs to the hardware.

8.1.2 Circuits for query and search algorithms§

What does a labelled box conceal? In Deutsch’s circuit, the first pair of \(H\) gates prepares \(\ket+\ket-\), the oracle puts the function into signs, and the last \(H\) exposes their relation. The box labelled \(U_f\) specifies what the oracle does, not how it is built or what it costs.

Search will use a repeated pattern of two such boxes: one marks the wanted strings with a sign, and one reflects the state about a prepared superposition. Before counting how often they are repeated, we need to know what each box costs. Building both from elementary gates is the next task.

8.1.3 Measurement and classical control§

Does it matter whether a gate is controlled by a qubit or by a measured bit? Try both on the same input. Start with \(\ket+\ket0\), where \(\ket+=(\ket0+\ket1)/\sqrt2\).

A coherent controlled gate acts on the unmeasured control. CNOT turns \(\ket+\ket0\) into \((\ket{00}+\ket{11})/\sqrt2\), a Bell state. Now measure the control first, write the result as a bit, and apply X to the target if the bit is \(1\). This is a classically controlled gate. Each run ends in \(\ket{00}\) or \(\ket{11}\), half the time each: the coin mixture, not the Bell state. A measurement in the X basis on each qubit tells the two apart.

In drawings, single lines carry quantum systems; double lines after a measurement, and the connections they drive, carry classical records. A measurement symbol produces a classical result. The qubit itself may remain, in its state after the measurement.

Teleportation uses both kinds. Alice’s CNOT is coherent; Bob’s correction is chosen by bits she sends. Replacing her CNOT by a measured control would destroy the protocol. Making Bob’s correction coherent would need her qubits rather than her message.

8.2

Gate Constructions

A circuit is built from elementary gates. Which single-qubit gates do we need, how does a gate act only when a control is \(1\), and how are the two boxes that search needs, a phase oracle and a reflection, built from these pieces?

8.2.1 Pauli, Hadamard, and rotation gates§

Which one-qubit gates do we need? We have used the Pauli matrices \(I\), \(X\), \(Y\), \(Z\) and the Hadamard

\[H=\frac1{\sqrt2}\begin{pmatrix}1&1\\1&-1\end{pmatrix}.\]

Fixed gates change amplitudes by fixed amounts. A general operation, such as the square root of NOT, needs a continuous family. We met one such family, \(R_x(\theta)\), built from \(X\). The same construction works for any Pauli matrix \(P\), giving the rotation gate

\[R_P(\theta)=\cos\tfrac\theta2\,I-i\sin\tfrac\theta2\,P.\]

Is it unitary? Each Pauli matrix equals its own adjoint: transposing and conjugating \(Y\), for instance, gives \(Y\) back. Using \(P^\dagger=P\) and \(P^2=I\), the cross terms of \(R_P(\theta)^\dagger R_P(\theta)\) cancel and leave \(\cos^2\tfrac\theta2\,I+\sin^2\tfrac\theta2\,I=I\).

When gates must come from a finite list, two fixed members of the phase family \(R_\phi\) matter. They are the phase gates

\[S=R_{\pi/2}=\begin{pmatrix}1&0\\0&i\end{pmatrix},\qquad T=R_{\pi/4}=\begin{pmatrix}1&0\\0&e^{i\pi/4}\end{pmatrix},\]

which change the relative phase of \(\ket1\) by \(\pi/2\) and \(\pi/4\). Squaring doubles the phase, so \(S^2=Z\) and \(T^2=S\). The phase gate \(S\) is different from \(\sqrt X\), the square root of NOT.

8.2.2 Controlled and entangling gates§

How do we make a gate act on a target only when a control is \(1\)? Follow the arrows on the joint configurations. When the control is \(0\), every target arrow is the identity; when it is \(1\), the target arrows are those of \(U\). The projectors \(\ketbra00\) and \(\ketbra11\) keep the component of the control along \(\ket0\) or \(\ket1\), so

\[\text{controlled-}U=\ketbra00\otimes I+\ketbra11\otimes U.\]

Here \(A\otimes B\) applies \(A\) to the first label and \(B\) to the second, with arrow weights \(\bra{jk}A\otimes B\ket{il}=\bra jA\ket i\bra kB\ket l\), the same rule that defined \(U\otimes I\).

CNOT is controlled-\(X\). Controlled-\(Z\) multiplies only \(\ket{11}\) by \(-1\). Can one be made from the other? Multiplying matrices,

\[HXH=\frac12\begin{pmatrix}1&1\\-1&1\end{pmatrix}\begin{pmatrix}1&1\\1&-1\end{pmatrix}=\begin{pmatrix}1&0\\0&-1\end{pmatrix}=Z,\]

so applying \(H\) to the target before and after a CNOT gives controlled-\(Z\).

Do controlled gates always entangle? Not on every input: CNOT leaves \(\ket0\ket0\) a product state. On \(\ket+\ket0\), however, it produces a Bell state.

8.2.3 Oracle and reflection circuits§

Suppose we search \(N=2^n\) bit strings for a marked string \(w\). Search will need two operations: one that changes the sign of the amplitude of \(w\), and one that reflects the state about the uniform superposition of all strings. How are they built from gates?

Write \(\ket{0^n}\) for all \(n\) qubits in \(\ket0\), and \(H^{\otimes n}\) for \(H\) applied to each of them. Each \(H\) sends \(\ket0\) to an equal superposition, so

\[\ket s=H^{\otimes n}\ket{0^n}=\frac1{\sqrt N}\sum_{x}\ket x.\]

Start with the sign change for one string. Controlled-\(Z\) on all \(n\) qubits multiplies only \(\ket{1\cdots1}\) by \(-1\). To mark \(w\) instead, first apply \(X\) to each position where \(w\) has a \(0\). That sends \(\ket w\) to \(\ket{1\cdots1}\); after the phase flip, the same \(X\) gates undo the relabelling. For a predicate computed by a circuit, compute, phase, uncompute does the same job.

Now the reflection. What does \(D=2\ketbra ss-I\) do? The projector \(\ketbra ss\) keeps the component of a state along \(\ket s\). So \(D\ket\psi\) keeps that component and negates the rest: a reflection about the direction \(\ket s\). Reflecting about \(\ket{0^n}\) is easier, and Hadamard layers carry one into the other:

\[D=H^{\otimes n}\bigl(2\ketbra{0^n}{0^n}-I\bigr)H^{\otimes n}.\]

For two qubits, \(2\ketbra{00}{00}-I\) is the diagonal matrix with entries \(1,-1,-1,-1\). The circuit in the drawing applies \(X\otimes X\), then controlled-\(Z\), then \(X\otimes X\). The \(X\) gates move the \(-1\) of controlled-\(Z\) from \(\ket{11}\) to \(\ket{00}\), giving \(-1,1,1,1\): exactly \(-(2\ketbra{00}{00}-I)\). So the circuit produces \(-D\). The overall sign is a global phase when the circuit runs on its own, but it must be kept if the circuit is itself controlled.

For \(n\) qubits, the controlled-\(Z\) on all of them is the main cost. It can be assembled from Toffoli gates and a few ancillas with a number of gates proportional to \(n\); we quote this construction rather than derive it.

8.3

Universal Gate Sets

Having built particular operations, we ask whether every operation can be built from a fixed collection of gates, and what such a collection requires. Entanglement sets the first requirement. Real hardware sets the second: it offers only finitely many gates, which forces us to say what building an operation means when exact construction is impossible.

8.3.1 Limits of local operations§

Can one-qubit gates alone produce every operation? A circuit of one-qubit gates acts as \(U_1\otimes\cdots\otimes U_n\). On a product state it gives another product state:

\[(U_1\otimes\cdots\otimes U_n)(\ket{\psi_1}\otimes\cdots\otimes\ket{\psi_n})=U_1\ket{\psi_1}\otimes\cdots\otimes U_n\ket{\psi_n}.\]

It can never prepare a Bell state from \(\ket{00}\), however many gates it uses. So a universal set needs a gate that lets qubits affect one another.

8.3.2 Entangling gates and universality§

Is one entangling gate enough? The quoted answer is a universality theorem: CNOT together with arbitrary one-qubit unitaries can construct every unitary on a finite register. The statement is about the whole set. An entangling gate without adequate one-qubit gates is not enough.

One proof first writes a unitary as a product of operations that each act on just two basis states, then builds each of those from controlled operations and one-qubit gates. We state the theorem and do not reproduce its proof.

Universality settles what can be built, not what it costs. How long must a circuit for a typical unitary be? Count parameters. A \(2^n\times2^n\) unitary is fixed by \(4^n\) real numbers. Each gate from a fixed set acts on at most two qubits and contributes at most a fixed number of adjustable parameters, say \(k\). A circuit of \(L\) gates therefore has at most \(kL\) parameters, and reaching a typical unitary needs \(kL\ge4^n\). Most unitaries need circuits whose length grows exponentially with \(n\). Useful algorithms work because their operations have extra structure, as our oracle and reflection circuits do.

8.3.3 Exact synthesis and approximation§

Real hardware offers finitely many gates. Can a finite list build every unitary exactly? No. There are finitely many circuits of each length, so all circuits can be listed one after another, while unitaries vary continuously. A list cannot reach every point of a continuum. Approximation is the achievable goal.

How close must an approximation be? Measure the error by the worst case over inputs: the largest distance \(\|(U-V)\ket\psi\|\) between the two outputs, over all unit states \(\ket\psi\). This number is written \(\|U-V\|\), the operator-norm error. A bound \(\|U-V\|\le\epsilon\) guarantees that the two output vectors differ by at most \(\epsilon\) on every input. Since a global phase is unobservable, we first choose the phases of \(U\) and \(V\) to bring them as close as possible. If the operation will itself be controlled, its phase must be fixed, because it becomes a relative phase of the larger circuit.

Which finite sets suffice? A standard one, called Clifford+T, consists of \(H\), \(S\), CNOT, and \(T\). It approximates every unitary to any desired \(\epsilon\), up to a global phase; we quote this result.

How do errors add up in a long circuit? For two gates, write \(V_2V_1-U_2U_1=V_2(V_1-U_1)+(V_2-U_2)U_1\). A unitary does not change lengths, so the error is at most \(\|V_1-U_1\|+\|V_2-U_2\|\). Repeating the step, a circuit of \(L\) approximated gates has total error at most \(\sum_i\epsilon_i\). To meet a budget \(\epsilon\), we can give each gate tolerance \(\epsilon/L\).

So an approximation claim has two parts: can we reach the tolerance, and how many gates does that take? Universality answers only the first.

8.4

Implementation Resources

Universality says that an operation can be built, but not at what cost. An advantage is a statement about cost, so we measure circuits, first on paper and then on a device, where qubits interact only with some neighbours, data must be loaded, and gates make errors. An advantage counted in queries must survive all of these to be an advantage in practice.

8.4.1 Gate count, depth, and workspace§

What does a circuit cost? Three measures matter: the gate count, the total number of elementary gates; the depth, the number of layers of gates that must run one after another; and the width, the number of qubits, including the ancillas, the working qubits that start in \(\ket0\).

These trade off. More workspace can reduce depth, while recomputing an intermediate value instead of storing it can save qubits. Ancillas must start in a known state and are usually returned to it by uncomputation, so that they can be reused.

There is a subtler cost. An algorithm needs a circuit for every input length \(n\). A circuit family is uniform if a classical procedure produces the circuit for each \(n\), and the family counts as efficient only if that procedure is efficient too. Otherwise a short circuit could hide hard work in its design.

8.4.2 Connectivity and data preparation§

Can any two qubits interact? In a circuit diagram, yes; in a device, often only neighbouring qubits can. Gates between distant qubits then need SWAP gates to bring them together, which adds to the count and the depth.

Is loading data free? Preparing an arbitrary list of amplitudes can take work proportional to the length of the list, even though the register holding it is small. Likewise, the arithmetic that implements a predicate can cost far more than the number of oracle calls suggests.

A resource estimate must therefore state the gate set, the connectivity, how inputs are prepared, and how outputs are read, before an asymptotic advantage can become a claim about real machines.

8.4.3 Error accumulation and reliability§

A circuit can be correct on paper and still run imperfectly. Approximation error concerns the ideal circuit we chose; physical noise concerns how a device carries it out. Can a computation protect itself against noise without copying its unknown state, which no-cloning forbids?

Try the simplest noise: one qubit may be flipped. Encode \(a\ket0+b\ket1\) with two CNOTs onto two ancillas, giving \(a\ket{000}+b\ket{111}\). This is one joint state, not three copies. Suppose the second qubit is flipped, giving \(a\ket{010}+b\ket{101}\). How do we find the error without measuring \(a\) or \(b\)?

Ask about parities instead of values. Is qubit one equal to qubit two? Is qubit two equal to qubit three? Both configurations, \(010\) and \(101\), give "different" to both questions. CNOTs from the data qubits onto fresh ancillas compute these parities, and measuring the ancillas reveals the pair of answers without distinguishing the two terms. The answers point to the second qubit, and an \(X\) there restores \(a\ket{000}+b\ket{111}\). The parity results are the syndrome.

This is quantum error correction in its simplest form: spread the information over a joint state, measure only properties that do not reveal it, and correct according to the syndrome. This code handles one bit flip. Sign errors, and errors in the correcting gates themselves, need larger codes and fault-tolerant design, which lie beyond this book. An algorithm proved correct in the ideal model must still be run reliably.
