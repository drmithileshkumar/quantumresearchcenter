We now have the rules for registers of qubits. How can they compute something faster than a classical computer? To compare the two fairly, we need a task whose cost is easy to count. A natural one is to learn a property of a function that can be consulted only through queries: each query reveals one value, and we count how many are needed.

We pose the simplest such question: is a one-bit function constant or balanced? A classical algorithm needs two queries. A quantum query must be reversible, so we build it from the reversible embedding of the function and apply it to a superposition of inputs. This alone does not help: a measurement returns one value, and the target keeps a record that prevents interference. Choosing the target to be an eigenvector of the bit flip removes the record and moves the function’s value into a sign, an effect called phase kickback. A final Hadamard turns the relative sign into the answer. This is Deutsch’s algorithm, which needs a single query.

The next chapter uses the same phase mark for a harder task: finding a marked item among many.

Can we learn a relation among answers without learning the individual answers themselves?

One quantum query can reveal whether \(f(0)\) equals \(f(1)\), although no measurement reveals either value.

Reading guide · preparation, aims, and assumptions

Use a reversible query to encode a property in relative phase and read it through interference.

Before you begin

Use reversible target updates, the Hadamard transformation, and joint-state notation.

What you should be able to do

  • Derive phase kickback using \(\ket-\).
  • Calculate the output of Deutsch’s algorithm.
  • State exactly what a query advantage counts.

The example to follow

The reversible target update of a function becomes a phase mark, and two-path interference becomes the readout.

Scope and assumptions

Deutsch’s task here uses a one-bit Boolean function and an ideal reversible oracle. A single query does not reveal every function value.

7.1

Function Queries

To compare quantum and classical computers fairly, we count a resource that both use in the same way. Let the function be accessible only through a box that answers queries, and count the queries. The simplest question about a one-bit function, whether its two values are equal, needs two classical queries. A quantum computer must use the same box through a reversible operation, and the reversible embedding of the function provides one.

7.1.1 Constant and balanced Boolean functions§

constant · balanced · promise

Here is a small question about a function \(f:\{0,1\}\to\{0,1\}\): is \(f(0)\) equal to \(f(1)\)? If they are equal, \(f\) is constant; if they differ, \(f\) is balanced. For a one-bit input, every function is one or the other.

What do we actually need to learn? One bit: equal or different. We do not need the values \(f(0)\) and \(f(1)\) themselves. Can an algorithm learn that one bit without learning both values? The gap between the answer we want and the full data is what the quantum algorithm will exploit.

For inputs of more bits, a function need not be constant or balanced. Restricting attention to those two cases is then a promise about the input.

The following circuits represent the four functions while retaining the input bit. The first wire holds \(x\); the second holds \(y\), which is replaced by \(y\oplus f(x)\). With \(y=0\), the second wire ends at \(f(x)\). This reversible form lets us compare ordinary basis-input queries with coherent quantum queries; Section 7.1.3 defines the oracle access precisely.

Problems

  1. List the four functions \(f:\{0,1\}\to\{0,1\}\) as pairs \((f(0),f(1))\), and classify each as constant or balanced.

    Show solutionHide solution

    \((0,0)\) and \((1,1)\) are constant; \((0,1)\) and \((1,0)\) are balanced.

  2. Among the functions \(f:\{0,1\}^2\to\{0,1\}\), how many are constant, how many are balanced (output \(1\) on exactly half the inputs), and how many are neither?

    Show solutionHide solution

    There are \(2^4=16\) functions. Two are constant. A balanced function outputs \(1\) on exactly two of the four inputs, chosen in \(\binom42=6\) ways. The remaining \(16-2-6=8\) are neither, which is why the promise is needed.

  3. For \(f\) on \(n\)-bit inputs, promised to be constant or balanced, show that a deterministic classical algorithm can decide which with \(2^{n-1}+1\) queries, and that \(2^{n-1}\) queries do not always suffice.

    Show solutionHide solution

    If two queried values differ, \(f\) is balanced. If \(2^{n-1}+1\) queried values all agree, \(f\) cannot be balanced, since a balanced function takes each value on only \(2^{n-1}\) inputs; so \(f\) is constant. With only \(2^{n-1}\) queries all returning \(0\), \(f\) could be the constant \(0\) or the balanced function that is \(1\) on all the unqueried inputs, so the algorithm cannot be sure.

7.1.2 Classical query access§

query

Suppose the only access to \(f\) is a query: we choose \(x\) and receive \(f(x)\). How many queries does a classical algorithm need to answer with certainty?

After one query, say with the reply \(f(0)=0\), both possibilities remain: \(f(1)=0\) makes \(f\) constant, and \(f(1)=1\) makes it balanced. One query cannot settle the question; two clearly suffice.

This count belongs to the stated access model. If \(f\) were given in another form, for instance as a formula we could inspect, the comparison could change.

Problems

  1. A classical algorithm queries \(f(1)\) and receives \(1\). Which of the four functions remain possible?

    Show solutionHide solution

    \((0,1)\), which is balanced, and \((1,1)\), which is constant. One reply is consistent with both answers.

  2. For \(f\) on two-bit inputs, promised constant or balanced, an algorithm queries \(f(00)\) and \(f(01)\). If they differ it answers “balanced”; otherwise it makes one more query. Complete the algorithm, and give its number of queries in the worst case.

    Show solutionHide solution

    If \(f(00)=f(01)\), query \(f(10)\). If it differs, answer “balanced”; if it agrees, three of the four values agree, which rules out a balanced function, so answer “constant.” The worst case uses three queries, matching \(2^{n-1}+1\) for \(n=2\).

  3. Show that no one-query classical algorithm for \(f:\{0,1\}\to\{0,1\}\), even one that chooses its query at random, is correct with probability greater than \(1/2\) on every function.

    Show solutionHide solution

    Average the success probability over the four functions, each weighted \(1/4\). Whatever input \(x\) is queried and whatever value \(v\) is returned, exactly two functions are consistent with the reply, one constant and one balanced, and they are equally weighted. So any answer is right for exactly one of them, and the average success is \(1/2\). Some function must therefore have success probability at most \(1/2\).

7.1.3 Reversible quantum oracles§

oracle · black-box

How can a quantum computation query \(f\)? A query must be a valid operation, hence unitary, while \(f\) itself may merge its inputs. The reversible embedding of a function solves this: keep the input and add \(f(x)\) to a target bit.

\[U_f\ket{x,y}=\ket{x,\,y\oplus f(x)}.\]

On the four configurations, \(U_f\) is a rearrangement: it exchanges \((x,0)\) and \((x,1)\) when \(f(x)=1\) and leaves them alone otherwise. Its matrix is a permutation matrix, so it is unitary, and applying it twice restores every configuration.

What counts as one query? One use of \(U_f\), whatever state it is applied to, including a superposition. This is the black-box, or oracle, model: it counts the uses of \(U_f\) and ignores how \(U_f\) is built. The construction costs return when circuits are analysed in detail.

Problems

  1. Write the action of \(U_f\) on the four basis states for \(f=(1,0)\), that is, \(f(0)=1\) and \(f(1)=0\).

    Show solutionHide solution

    \(\ket{00}\to\ket{01}\), \(\ket{01}\to\ket{00}\), \(\ket{10}\to\ket{10}\), and \(\ket{11}\to\ket{11}\): the target flips when the input is \(0\).

  2. Write the matrix of \(U_f\) for \(f=(0,1)\) in the order \(00,01,10,11\), and check that it is unitary.

    Show solutionHide solution

    \(U_f\) fixes \(\ket{00}\) and \(\ket{01}\) and exchanges \(\ket{10}\) and \(\ket{11}\): the matrix of CNOT. It is a permutation matrix, whose columns are distinct basis vectors and hence orthonormal, so \(U_f^\dagger U_f=I\).

  3. Show that the map \(\ket{x,y}\mapsto\ket{x,f(x)}\), which overwrites the target, is not unitary for any \(f\), and that \(\ket x\mapsto\ket{f(x)}\) is not unitary when \(f\) is constant.

    Show solutionHide solution

    Overwriting sends \(\ket{x,0}\) and \(\ket{x,1}\) to the same state \(\ket{x,f(x)}\), so it is not one-to-one, and a unitary is invertible. For constant \(f\), \(\ket0\) and \(\ket1\) both go to \(\ket{f(0)}\), again merging two orthogonal states. Keeping the input and adding into the target avoids both problems.

7.2

Coherent Function Evaluation

A reversible query can act on a superposition of inputs. We follow what one such query produces, and ask what can be read from it: by measuring directly, or by interference, as in the two-step experiment with \(H\). Both attempts fail, and the reason for the second failure shows what the query must avoid.

7.2.1 Oracle action on superpositions§

A query is a reversible evaluation, so quantum parallelism applies to it. What happens if we query \(f\) on both inputs at once? Prepare the input in \((\ket0+\ket1)/\sqrt2\) and the target in \(\ket0\). By linearity, \(U_f\) acts on each configuration separately:

\[U_f\left(\frac{\ket0+\ket1}{\sqrt2}\otimes\ket0\right)=\frac{\ket{0,f(0)}+\ket{1,f(1)}}{\sqrt2}.\]

Have we computed both values? Both appear in the state, but, as with any parallel evaluation, nothing has read them. Whether this helps depends on what we do next.

Problems

  1. Apply \(U_f\) for \(f=(1,1)\) to \(\tfrac{\ket0+\ket1}{\sqrt2}\otimes\ket0\).

    Show solutionHide solution

    Both inputs flip the target: \((\ket{01}+\ket{11})/\sqrt2=\ket+\ket1\), a product state.

  2. For each of the four functions, write \(U_f\bigl(\tfrac{\ket0+\ket1}{\sqrt2}\otimes\ket0\bigr)\), and say which results are entangled.

    Show solutionHide solution

    \((0,0)\): \(\ket+\ket0\). \((1,1)\): \(\ket+\ket1\). \((0,1)\): \((\ket{00}+\ket{11})/\sqrt2\). \((1,0)\): \((\ket{01}+\ket{10})/\sqrt2\). The constant functions give product states; the balanced ones give entangled states.

  3. With \(n\) input qubits in the uniform superposition and a clean target, \(U_f\) produces \(2^{-n/2}\sum_x\ket x\ket{f(x)}\). Measuring both registers gives a uniformly random \(x\) with \(f(x)\). About how many runs are needed, on average, before every value \(f(x)\) has been seen?

    Show solutionHide solution

    Each run reveals one input chosen uniformly from \(N=2^n\). After \(k\) distinct inputs have been seen, a new one appears with probability \((N-k)/N\), taking \(N/(N-k)\) runs on average. Summing, \(N\bigl(1+\tfrac12+\dots+\tfrac1N\bigr)\approx N\ln N\) runs are needed, more than the \(N\) queries of a classical algorithm that simply asks each input once.

7.2.2 Register measurement§

Measure the joint state immediately after the query and you obtain one pair \((x,f(x))\), chosen at random. The other function value does not appear as a second answer in the detector.

Repeating the preparation obtains more samples, but a classical method can query randomly chosen inputs too. Merely placing both function values in a state has not produced an advantage.

The useful target is narrower: make “equal” and “different” lead to distinguishable final states. The remaining gates must act before measurement, while there are still coherent amplitudes to combine.

Problems

  1. Measure both registers of \((\ket{00}+\ket{11})/\sqrt2\). What are the possible results and their probabilities? How many function values does one run reveal?

    Show solutionHide solution

    \(00\) and \(11\), each with probability \(1/2\). One run reveals one pair \((x,f(x))\), a single function value.

  2. To decide constant or balanced, we repeatedly prepare \((\ket{0,f(0)}+\ket{1,f(1)})/\sqrt2\) and measure both registers until both inputs have been seen. How many runs does this take on average?

    Show solutionHide solution

    The first run shows one input. Each later run shows the other input with probability \(1/2\), taking \(2\) runs on average. The total is \(1+2=3\) runs on average, worse than the two classical queries.

  3. Show that measuring only the input register of \((\ket{0,f(0)}+\ket{1,f(1)})/\sqrt2\) gives \(0\) and \(1\) with probability \(1/2\) each for all four functions.

    Show solutionHide solution

    The probability of input \(x\) is the total squared amplitude of the configurations beginning with \(x\). There is exactly one, \(\ket{x,f(x)}\), with amplitude \(1/\sqrt2\), whatever \(f\) is. The input register alone reveals nothing about \(f\).

7.2.3 Workspace entanglement§

The blank target creates a problem. If \(f(0)\ne f(1)\), it holds an orthogonal record of which input branch occurred. Applying \(H\) to the input alone gives a random computational-basis outcome; the two contributions now end with different target labels and cannot cancel each other.

This is the path-record example from Chapter 3 in a new setting. The question is no longer whether we can evaluate the function. It is whether we can use the evaluation without keeping a record that spoils the readout.

We need a target preparation that remains the same physical state under either possible update, while still allowing the updates to contribute different phases. Eigenstates of the target flip provide exactly that possibility.

Problems

  1. For \(f=(0,1)\), apply \(H\) to the input of \((\ket{00}+\ket{11})/\sqrt2\), and find the probability of each input outcome.

    Show solutionHide solution

    \(H\) on the first qubit gives \(\tfrac12(\ket{00}+\ket{10}+\ket{01}-\ket{11})\). The input is \(0\) with probability \(\tfrac14+\tfrac14=\tfrac12\), and \(1\) with probability \(\tfrac12\). The target record prevents any cancellation.

  2. For the constant function \(f=(0,0)\), repeat the calculation: start from \(\tfrac{\ket0+\ket1}{\sqrt2}\otimes\ket0\), apply \(U_f\), then \(H\) to the input.

    Show solutionHide solution

    \(U_f\) leaves \(\ket+\ket0\) unchanged, and \(H\) turns it into \(\ket0\ket0\). The input is \(0\) with certainty: here the target holds no record, because it is the same in both branches.

  3. Combining the two previous problems, design a one-query procedure with a clean target that never wrongly answers “balanced.” With what probability does it detect a balanced function?

    Show solutionHide solution

    Run \(U_f\) on \(\ket+\ket0\), apply \(H\) to the input, and measure it. Constant functions always give \(0\); balanced ones give \(0\) or \(1\) with probability \(1/2\) each. Answer “balanced” on outcome \(1\), and “not sure” on \(0\). The answer “balanced” is never wrong, but it is given for a balanced function only half the time. Deutsch’s algorithm, whose target leaves no record, succeeds every time.

7.3

Phase Kickback

The question left open is how a query can respond to the function without leaving a record. The answer, phase kickback, moves the value of the function out of the target and into a sign on the input. It requires one particular target state, and when the function is computed by a circuit, a further step: the circuit’s workspace keeps a record of its own, which running the circuit backward removes.

7.3.1 Bit-flip eigenstates§

The oracle either flips the target or leaves it alone. Which target states does a flip leave unchanged, apart from a factor? The eigenvectors of \(X\):

\[X\ket+=\ket+,\qquad X\ket-=-\ket-,\]

since \(X(\ket0-\ket1)=\ket1-\ket0\).

A flip therefore multiplies \(\ket-\) by \(-1\), and no flip leaves it with the factor \(+1\): the target state stays the same while the factor records whether a flip occurred. The state \(\ket+\) is unchanged in both cases and cannot tell them apart. The target we want is \(\ket-\).

Problems

  1. Compute \(X(\ket0+i\ket1)/\sqrt2\). Is \((\ket0+i\ket1)/\sqrt2\) an eigenvector of \(X\)?

    Show solutionHide solution

    \(X(\ket0+i\ket1)/\sqrt2=(i\ket0+\ket1)/\sqrt2=i(\ket0-i\ket1)/\sqrt2\). This is not a multiple of \((\ket0+i\ket1)/\sqrt2\), so it is not an eigenvector.

  2. Find every state that \(X\) leaves unchanged apart from a factor, by solving \(X(a,b)^T=\lambda(a,b)^T\).

    Show solutionHide solution

    \(X(a,b)^T=(b,a)^T\), so \(b=\lambda a\) and \(a=\lambda b\), giving \(\lambda^2=1\). For \(\lambda=1\), \(a=b\): the state \(\ket+\). For \(\lambda=-1\), \(b=-a\): the state \(\ket-\). Up to global phase, these are the only two.

  3. The target is prepared in \(\cos\theta\ket0+\sin\theta\ket1\), with real \(\theta\), and the oracle flips it. Show that its overlap with the original target is \(\sin2\theta\), and that the target keeps no record of the flip only when it is \(\ket+\) or \(\ket-\).

    Show solutionHide solution

    \(X(\cos\theta,\sin\theta)^T=(\sin\theta,\cos\theta)^T\), whose overlap with the original is \(2\cos\theta\sin\theta=\sin2\theta\). The target keeps no record when the flipped state equals the original up to a factor, which requires an overlap of magnitude \(1\): \(\sin2\theta=\pm1\), so \(\theta=\pm\pi/4\) up to multiples of \(\pi\). These are \(\ket+\) and \(\ket-\), up to sign. For any other target, the flip leaves a partial record that reduces the interference.

7.3.2 Phase-oracle construction§

phase kickback

Apply \(U_f\) to \(\ket x\ket-\). If \(f(x)=0\), nothing happens; if \(f(x)=1\), the target flips, which multiplies the state by \(-1\):

\[U_f\ket x\ket-=(-1)^{f(x)}\ket x\ket-.\]

With the input in \(\ket+\),

\[U_f\ket+\ket-=\frac{(-1)^{f(0)}\ket0+(-1)^{f(1)}\ket1}{\sqrt2}\otimes\ket-.\]

The target ends in \(\ket-\) whatever \(x\) is, so it holds no record of the input. The function value has moved into the sign of the input amplitude. This is phase kickback.

What do the signs mean? If \(f\) is constant, the two signs are equal and the input is \(\pm\ket+\); the common sign is a global phase. If \(f\) is balanced, the signs differ and the input is \(\pm\ket-\). The answer has become a relative phase.

Problems

  1. For \(f=(1,0)\), compute \(U_f\ket+\ket-\).

    Show solutionHide solution

    The signs are \((-1)^{f(0)}=-1\) and \((-1)^{f(1)}=+1\), so the result is \(\tfrac{-\ket0+\ket1}{\sqrt2}\otimes\ket-=-\ket-\ket-\).

  2. Prepare the input in \(\ket+\), but mistakenly prepare the target in \(\ket+\) too. Find the output of \(U_f\) for each of the four functions. Does leaving the target unentangled suffice to obtain useful phase kickback?

    Show solutionHide solution

    Since \(X\ket+=\ket+\), either value of \(f(x)\) leaves the target unchanged with eigenvalue \(+1\). For all four functions the output is \(\ket+\ket+\). The target is unentangled, but no information about \(f\) reaches the input. The \(\ket-\) preparation matters because a flip has eigenvalue \(-1\), giving different phases to different function values.

  3. With \(n\) input qubits and the target in \(\ket-\), show that \(U_f\bigl(2^{-n/2}\sum_x\ket x\bigr)\ket-=\bigl(2^{-n/2}\sum_x(-1)^{f(x)}\ket x\bigr)\ket-\), and that the target ends in \(\ket-\) for every \(f\).

    Show solutionHide solution

    For each basis input, \(U_f\ket x\ket-=(-1)^{f(x)}\ket x\ket-\), because a flip multiplies \(\ket-\) by \(-1\) and no flip leaves it alone. By linearity, the superposition becomes \(\sum_x(-1)^{f(x)}\ket x\ket-\), up to the factor \(2^{-n/2}\). The target factors out as \(\ket-\), so it carries no record of \(x\).

7.3.3 Coherent uncomputation§

compute, phase, uncompute

What if \(f\) is not given as an oracle but computed by a circuit \(A\) that uses workspace, \(A\ket{x,0,0}=\ket{x,f(x),g(x)}\)? Apply \(Z\) to the answer bit, which multiplies the state by \((-1)^{f(x)}\), then run \(A\) backward:

\[A^\dagger Z_{\mathrm{answer}}A\ket{x,0,0}=(-1)^{f(x)}\ket{x,0,0}.\]

The workspace returns to \(0\), and the sign remains. This is compute, phase, uncompute. It is not free: it uses \(A\) and its inverse, and an honest count of the cost must include both.

Problems

  1. For \(f(x)=x\), computed into a clean answer bit by CNOT, compute \(\mathrm{CNOT}\,(I\otimes Z)\,\mathrm{CNOT}\) on \(\ket{0,0}\) and \(\ket{1,0}\).

    Show solutionHide solution

    \(\ket{00}\) passes unchanged, with \(Z\) acting on \(0\): the result is \(\ket{00}\). For \(\ket{10}\): CNOT gives \(\ket{11}\), \(Z\) gives \(-\ket{11}\), and CNOT gives \(-\ket{10}\). The phases are \((-1)^x\), and the answer bit is back to \(0\).

  2. Compute \(\mathrm{CNOT}\,(I\otimes Z)\,\mathrm{CNOT}\) on all four basis states, and identify the operation. Why does compute, phase, uncompute need the workspace to start at \(0\)?

    Show solutionHide solution

    On \(\ket{x,y}\): CNOT gives \(\ket{x,y\oplus x}\), \(Z\) multiplies by \((-1)^{x\oplus y}\), and CNOT restores \(\ket{x,y}\). The operation is \(\ket{x,y}\mapsto(-1)^{x\oplus y}\ket{x,y}\), that is, \(Z\otimes Z\). Only when \(y=0\) is the phase \((-1)^{f(x)}\); a workspace starting elsewhere adds an unwanted phase.

  3. Omit the uncomputation: compute \(f(x)=x\) into the answer bit with CNOT and apply \(Z\) to the answer bit, but do not run CNOT again. Starting from \(\ket+\ket0\), apply \(H\) to the input at the end. Show that the outcome is random, whereas with uncomputation it is certain.

    Show solutionHide solution

    CNOT gives \((\ket{00}+\ket{11})/\sqrt2\), and \(Z\) gives \((\ket{00}-\ket{11})/\sqrt2\). \(H\) on the input gives \(\tfrac12(\ket{00}+\ket{10}-\ket{01}+\ket{11})\), so the input is \(0\) or \(1\) with probability \(1/2\) each. With uncomputation, the state before \(H\) is \((\ket0-\ket1)\ket0/\sqrt2=\ket-\ket0\), and \(H\) gives \(\ket1\ket0\): outcome \(1\) with certainty. The answer bit left behind is a record that blocks the interference.

7.4

Deutsch’s Algorithm

After phase kickback, whether the function is constant or balanced is held in the relative sign of the two input amplitudes. A measurement in the computational basis cannot see a relative sign, but a Hadamard turns the two possible signs into two different configurations. With this last step the algorithm is complete: one query decides what classically needs two. Its stages then show which parts were essential, and what the comparison does and does not claim.

7.4.1 Interference and readout§

After the query, the input is \((s_0\ket0+s_1\ket1)/\sqrt2\), with \(s_x=(-1)^{f(x)}\). How do we read the relative sign? Apply \(H\), which sends \(\ket+\) to \(\ket0\) and \(\ket-\) to \(\ket1\):

\[H\,\frac{s_0\ket0+s_1\ket1}{\sqrt2}=\frac{s_0+s_1}2\ket0+\frac{s_0-s_1}2\ket1.\]

Equal signs give \(0\) with certainty; opposite signs give \(1\) with certainty. In terms of paths, the two contributions to the wrong answer cancel.

The outcome depends only on whether \(s_0\) and \(s_1\) agree, never on \(f(0)\) or \(f(1)\) separately. We learn the one bit we wanted, and nothing more.

Problems

    \(-\tfrac{H\ket0}{\sqrt2}+\tfrac{H\ket1}{\sqrt2}=\tfrac12\bigl(-(\ket0+\ket1)+(\ket0-\ket1)\bigr)=-\ket1\).

  2. For each of the four functions, compute the final input amplitudes \((s_0+s_1)/2\) and \((s_0-s_1)/2\).

    Show solutionHide solution

    \((0,0)\): \(s=(1,1)\), amplitudes \((1,0)\). \((1,1)\): \(s=(-1,-1)\), amplitudes \((-1,0)\). \((0,1)\): \(s=(1,-1)\), amplitudes \((0,1)\). \((1,0)\): \(s=(-1,1)\), amplitudes \((0,-1)\). The constant functions give \(0\) and the balanced ones give \(1\), each up to sign.

  3. Show that if the final \(H\) is omitted, or replaced by \(X\), the measurement gives \(0\) and \(1\) with probability \(1/2\) each, for every function.

    Show solutionHide solution

    Before the final step the input is \((s_0\ket0+s_1\ket1)/\sqrt2\) with \(s_x=\pm1\), so each outcome has probability \(1/2\). \(X\) only swaps the two amplitudes, leaving both probabilities at \(1/2\). Only an operation that combines the two amplitudes, such as \(H\), turns the relative sign into a definite outcome.

7.4.2 Quantum and classical query counts§

Deutsch’s algorithm · query separation

Prepare \(\ket0\ket1\), apply \(H\) to each qubit, query \(U_f\) once, apply \(H\) to the input, and measure that input. Outcome zero means constant; outcome one means balanced. This is Deutsch’s algorithm, with exact success in the ideal model.

An exact classical value-query method needs two queries in the worst case. The comparison uses the same underlying function but different allowed access: classical queries supply a basis input and read a value; the quantum algorithm applies its specified reversible oracle coherently to a superposition. That access assumption is part of the model.

The result is a one-versus-two query separation, not a claim that this tiny circuit runs faster on actual hardware. It matters because the entire mechanism is visible: choose a property, encode it in phase, and turn that phase into an observable answer.

Predict first. Compare a constant function with a balanced function. Before running the circuit, predict whether the final input bit is 0 or 1. Would complementing every function value change that bit?

Prepare the input in \(\ket{+}\) and the target in \(\ket{-}\). The oracle leaves the target unchanged and multiplies each input amplitude by \((-1)^{f(x)}\). A final Hadamard makes the relative sign observable.

Both input amplitudes have the same sign.

Choose a function, then apply its oracle.

A common sign changes no probabilities. Opposite signs change the result after the final Hadamard.

A constant function gives 0; a balanced function gives 1. Complementing the function multiplies the state after the phase oracle by a common minus sign, so it does not change the final measurement.

Problems

  1. Count the queries and the other operations in Deutsch’s algorithm, starting from \(\ket{00}\).

    Show solutionHide solution

    One query to \(U_f\). Besides it: one \(X\) to prepare \(\ket1\), two \(H\) gates to prepare \(\ket+\ket-\), one final \(H\), and one measurement.

  2. Run Deutsch’s algorithm for \(f=(1,0)\), giving the state after each step.

    Show solutionHide solution

    \(\ket0\ket1\to\ket+\ket-\to-\ket-\ket-\to-\ket1\ket-\). The input gives \(1\): balanced.

  3. With \(n\) input qubits, after the query and \(H\) applied to each input qubit, show that the amplitude of the input configuration \(0^n\) is \(2^{-n}\sum_x(-1)^{f(x)}\). Deduce that one query distinguishes constant from balanced functions with certainty.

    Show solutionHide solution

    \(H\) on each qubit sends every \(\ket x\) to a superposition in which \(\ket{0^n}\) has amplitude \(2^{-n/2}\). Applied to \(2^{-n/2}\sum_x(-1)^{f(x)}\ket x\), it gives \(\ket{0^n}\) the amplitude \(2^{-n}\sum_x(-1)^{f(x)}\). For constant \(f\), this is \(\pm1\), so the outcome is \(0^n\) with certainty; for balanced \(f\), the signs cancel exactly and the outcome is never \(0^n\). One query suffices, against \(2^{n-1}+1\) classically.

7.4.3 Preparation, oracle evaluation, and measurement§

The circuit has four jobs: prepare coherent alternatives, encode the desired property, recombine the amplitudes, and read the result. A missing job gives a specific failure.

A target starting in \(\ket0\) can keep a branch record. A target starting in \(\ket+\) keeps no such record, but contributes no distinguishing phase either. The choice \(\ket-\) avoids both problems: it remains factored from the input while supplying the required signs.

Without the final \(H\), those signs still give the same zero–one probabilities. Correctness therefore belongs to the whole preparation–query–readout chain, not to the oracle alone. Search will use the same phase-marking idea, but its readout needs repeated reflections to make a marked label likely.

Problems

  1. Name the four stages of Deutsch’s algorithm and the operations used in each.

    Show solutionHide solution

    Prepare: \(X\) and two \(H\) gates make \(\ket+\ket-\). Encode: one query to \(U_f\) puts \(f\) into relative phase. Recombine: \(H\) on the input. Measure: the input in the computational basis.

  2. Replace the target \(\ket-\) by \(\ket+\), and run the algorithm for \(f=(0,1)\). What does the measurement give?

    Show solutionHide solution

    \(X\ket+=\ket+\), so \(U_f\) leaves \(\ket+\ket+\) unchanged, and the final \(H\) gives \(\ket0\). The algorithm reports “constant” for a balanced function: with the wrong target, the function leaves no mark at all.

  3. Leave out the first \(H\) on the input, so that the input stays \(\ket0\). Show that the algorithm then gives each outcome with probability \(1/2\) for every function.

    Show solutionHide solution

    \(U_f\ket0\ket-=(-1)^{f(0)}\ket0\ket-\), which depends only on \(f(0)\), and only through a global sign. The final \(H\) gives \(\pm\ket+\), so each outcome has probability \(1/2\). Without a superposition of inputs, the query sees only one input, and no relative phase forms.

Summary

  • Queries make comparisons fair. When a function is available only through a black box, we count its uses. Deciding whether a one-bit function is constant or balanced needs two classical queries, because one value leaves both possibilities open.
  • Quantum queries are reversible. The oracle is the reversible embedding \(U_f\ket{x,y}=\ket{x,\,y\oplus f(x)}\), and one use of it, on any state, is one query.
  • Holding both values is not knowing both. Querying a superposition places both function values in the state, but measuring returns one random pair. A blank target also records the input branch, which blocks the interference needed for readout.
  • Phase kickback. With the target in \(\ket-\), \(U_f\ket x\ket-=(-1)^{f(x)}\ket x\ket-\). The target keeps no record, and the function value becomes a sign on the input amplitude. If \(f\) is computed by a circuit, compute–phase–uncompute does the same, at the cost of running the circuit and its inverse.
  • Deutsch’s algorithm. Prepare \(\ket+\ket-\), query once, apply \(H\) to the input and measure: \(0\) means constant and \(1\) means balanced, with certainty. The outcome depends only on whether the two signs agree, never on the individual values.
  • What the separation means. One query against two is a statement about a stated access model with coherent oracle use, not about hardware speed. It needs all four stages: coherent preparation, phase encoding, recombination and readout.

2. Quick check §

A programmer prepares the target of Deutsch’s algorithm as \(\ket1\) but forgets the Hadamard on it, so the query acts on \(\ket+\ket1\). For the balanced function \(f=(0,1)\), find the state after the query and the probability that the final input measurement gives the correct answer \(1\).

Hint 1

\(U_f\ket x\ket1=\ket x\ket{1\oplus f(x)}\).

Hint 2

Do the two input branches end with the same target label?

Worked solution

The query gives \(\frac{1}{\sqrt2}(\ket0\ket1+\ket1\ket0)\): the target now records the input branch, exactly as with a blank target. After \(H\) on the input, the state is \(\frac12(\ket0\ket1+\ket1\ket1+\ket0\ket0-\ket1\ket0)\), and the input reads \(1\) with probability \(\frac14+\frac14=\frac12\). The target \(\ket1\) is a basis state, not an eigenstate of the flip, so the function value is written into the target instead of being kicked back as a sign. Only \(\ket-\) works.

3. Quick check §

For \(n=3\) input bits under the constant-or-balanced promise, how many queries does an exact deterministic classical algorithm need in the worst case? A randomized algorithm queries \(k\) inputs chosen uniformly at random (with replacement) and answers “constant” if all values agree. With what probability can it be wrong on a balanced function, and how large must \(k\) be for an error below \(1\%\)?

Hint 1

The worst case for a deterministic algorithm sees half the inputs agree.

Hint 2

On a balanced function, all \(k\) values agree with probability \(2\cdot2^{-k}\).

Worked solution

Deterministically, \(2^{n-1}+1=5\) queries are needed: after \(4\) equal answers the function could still be balanced. The randomized algorithm is never wrong on a constant function. On a balanced one, each query returns \(0\) or \(1\) with probability \(\frac12\), and all \(k\) agree with probability \(2^{1-k}\). That is below \(0.01\) for \(k\ge8\). Deutsch–Jozsa uses one query and never errs, but against algorithms allowed a small error the classical cost stays constant as \(n\) grows. The size of a quantum advantage depends on which classical success criterion is used for comparison.

5. Worked problem §

With the target in \(\ket-\), the query acts on the input as the phase oracle \(O_f=\mathrm{diag}\big((-1)^{f(0)},(-1)^{f(1)}\big)\). Write \(O_f\) for each of the four functions, and compute \(HO_fH\) in each case. Use the result to describe Deutsch’s algorithm as a single one-qubit operation.

Hint 1

The four phase oracles are \(I\), \(-I\), \(Z\), and \(-Z\).

Hint 2

\(HZH=X\) and \(HIH=I\).

Worked solution

For \(f=(0,0)\), \(O_f=I\); for \((1,1)\), \(-I\); for \((0,1)\), \(Z\); for \((1,0)\), \(-Z\). Conjugating by \(H\): \(HIH=I\), \(H(-I)H=-I\), \(HZH=X\), and \(H(-Z)H=-X\). So on the input qubit, Deutsch’s algorithm applies \(\pm I\) for a constant function and \(\pm X\) for a balanced one, to the input \(\ket0\). The result is \(\pm\ket0\) or \(\pm\ket1\), and the measurement reads the class with certainty. The signs are global phases, which is why the algorithm cannot reveal which constant or which balanced function was used.

6. Worked problem §

Let \(f(x_1,x_2)=x_1\land x_2\) be computed by a Toffoli gate into an answer bit starting at \(0\). Apply compute, phase, uncompute: Toffoli, then \(Z\) on the answer bit, then Toffoli again. Show that the net operation on \(\ket{x_1x_2}\ket0\) is the controlled-\(Z\) gate on the two inputs, and that the answer bit returns to \(0\).

Hint 1

Track a basis input \(\ket{x_1x_2}\ket0\) through the three steps.

Hint 2

Controlled-\(Z\) multiplies \(\ket{11}\) by \(-1\) and leaves the other basis states alone.

Worked solution

On \(\ket{x_1x_2}\ket0\), the first Toffoli gate gives \(\ket{x_1x_2}\ket{x_1x_2}\). Then \(Z\) multiplies by \((-1)^{x_1x_2}\). The second Toffoli gate adds \(x_1x_2\) to the answer bit again, returning it to \(0\). The result is \((-1)^{x_1x_2}\ket{x_1x_2}\ket0\): a sign \(-1\) only on \(\ket{11}\), which is controlled-\(Z\), with the answer bit cleanly factored out. By linearity this holds for every superposition of inputs. The phase oracle of AND costs two Toffoli gates and one \(Z\), with one temporary bit, and the clean workspace is what allows the inputs’ signs to interfere later.

7. Worked problem §

A circuit for \(f(x_1,x_2)=x_1\oplus x_2\) first copies \(x_1\) into a workspace bit \(w\), then forms the answer \(w\oplus x_2\). A programmer applies \(Z\) to the answer and uncomputes the answer step only, leaving \(w=x_1\). Starting from the uniform input superposition, apply \(H\) to both inputs and find the outcome distribution. Compare with the clean version.

Hint 1

Before the final Hadamards the state is \(\frac12\sum_x(-1)^{x_1\oplus x_2}\ket{x_1x_2}\ket{x_1}\).

Hint 2

Group the terms by the value of \(w\).

Worked solution

Group by \(w\). For \(w=0\) the input part is \(\frac12(\ket{00}-\ket{01})=\frac{1}{\sqrt2}\ket0\ket-\); for \(w=1\) it is \(\frac12(-\ket{10}+\ket{11})=-\frac{1}{\sqrt2}\ket1\ket-\). After \(H\otimes H\) these become \(\frac{1}{\sqrt2}\ket+\ket1\ket0\) and \(-\frac{1}{\sqrt2}\ket-\ket1\ket1\). The second input reads \(1\) with certainty, but the first input is \(\ket+\) on one record and \(\ket-\) on the other, so it reads \(0\) or \(1\) with probability \(\frac12\). The outcomes are \(01\) and \(11\), each with probability \(\frac12\). The clean version gives \(11\) with certainty. The garbage records \(x_1\), so it destroys exactly the interference that would reveal the \(x_1\) part of the answer, while the \(x_2\) part survives.

8. Misconception §

A student claims: “Deutsch’s algorithm evaluates \(f(0)\) and \(f(1)\) in one query, so with a better readout it could report both values.” Write the full two-qubit output state in terms of \(f(0)\) and \(d=f(0)\oplus f(1)\), and explain why no measurement of it can reveal \(f(0)\).

Hint 1

Factor out \((-1)^{f(0)}\) from the final input amplitudes.

Hint 2

Which part of the state depends on \(f(0)\) alone?

Worked solution

After the final Hadamard, the input is \(\frac{s_0+s_1}{2}\ket0+\frac{s_0-s_1}{2}\ket1\) with \(s_x=(-1)^{f(x)}\). Factoring out \(s_0\), this is \((-1)^{f(0)}\ket d\), so the output is \((-1)^{f(0)}\ket d\ket-\). The value \(f(0)\) appears only in a global phase, which no measurement detects, and the target \(\ket-\) is the same for every function. So the output carries exactly one bit, \(d\). The query did act on both inputs, but the interference that made \(d\) certain also discarded every other distinction. One query of this kind reveals at most one bit about \(f\), not both values.

Show that Deutsch’s algorithm gives the same outcome for \(f\) and for its complement \(1-f\), and that the outcome depends only on \(f(0)\oplus f(1)\).

Hint 1

Complementing \(f\) multiplies both signs by \(-1\).

Hint 2

The final amplitudes are \((s_0\pm s_1)/2\).

For \(1-f\), each sign \((-1)^{f(x)}\) is multiplied by \(-1\), a global phase that changes no probability. The outcome is \(1\) exactly when \(s_0\neq s_1\), that is, when \(f(0)\oplus f(1)=1\). The algorithm extracts this one bit and nothing more about \(f\).

10. Extension §

A two-bit function is promised to have the form \(f(x)=s_1x_1\oplus s_2x_2\) for an unknown string \(s=s_1s_2\). Run the two-qubit version of the algorithm (Hadamards on both inputs, target \(\ket-\), one query, Hadamards on both inputs) for \(s=10\) and \(s=11\), and show that the measurement returns \(s\). How many classical queries are needed to learn \(s\)?

Hint 1

After the query the input amplitudes are \(\frac12(-1)^{s\cdot x}\).

Hint 2

\((-1)^{s_1x_1}(-1)^{s_2x_2}\) is a product of one-qubit sign patterns.

Worked solution

After the query the input state is \(\frac12\sum_x(-1)^{s_1x_1}(-1)^{s_2x_2}\ket{x_1x_2}=\frac{\ket0+(-1)^{s_1}\ket1}{\sqrt2}\otimes\frac{\ket0+(-1)^{s_2}\ket1}{\sqrt2}\). Each factor is \(\ket+\) if \(s_i=0\) and \(\ket-\) if \(s_i=1\), and \(H\) maps them to \(\ket0\) and \(\ket1\). So the output is \(\ket{s_1s_2}\) with certainty: \(10\) gives \(\ket{10}\) and \(11\) gives \(\ket{11}\). Classically each query returns one bit, \(s\cdot x\), and there are four possible strings, so two queries are necessary (and \(x=10,01\) suffice). With \(n\) bits the gap is one query against \(n\). This is the Bernstein–Vazirani problem, developed in Quantum Algorithms.
