19.1 Performance Measures

A processor with more qubits is not necessarily the processor that completes a specified computation more accurately or sooner. Evaluation begins by fixing the task.

Predict before calculating. An experiment observes no failures. Has it demonstrated zero error probability?

Compare your reasoning

No. A finite independent sample supports an upper confidence bound, not an exact zero. Systematic bias and drift need additional analysis.

19.1.1 Physical metrics

A physical metric is the result of a particular experiment and inference. A T₁ experiment tracks excited population; a Ramsey experiment tracks coherence in a chosen sequence; a readout calibration estimates an assignment matrix. They are not interchangeable probabilities.

For example, an excited state idling for 1 μs with \(T_1=100\) μs decays with probability \(1-e^{-0.01}\simeq0.00995\). A superposition, a driven state, and a qubit exposed to crosstalk need different calculations. The measurement must resolve the phenomenon used in the model: report leakage if the model assumes two levels, and simultaneous-gate behavior if the schedule uses parallel operations. More decimal places in a fitted lifetime do not remove those differences.

19.1.2 Logical metrics

Logical error is defined relative to an encoded task and recovery procedure. A logical memory error per round answers a storage question. A logical entangling-gate error adds operations, while universal computation can add auxiliary-state production and adaptive measurements.

Translate the metric into a target use. If independent cycles fail with probability \(p_L\), survival through K cycles is \((1-p_L)^K\). For small \(Kp_L\), total failure is approximately \(Kp_L\). Compare code distances using matched preparation, extraction, decoder, and physical conditions. A memory that improves with distance provides stronger evidence than one favorable distance, but it still does not by itself certify every logical gate at the same error rate.

Problem 19.1. Why is a long T1 insufficient to predict circuit accuracy?

Worked solution

Dephasing, control error, leakage, readout, and interactions can dominate even when relaxation is weak. The circuit schedule determines how much each mechanism matters.

19.2 Workload Evaluation

19.2.1 Compilation and execution cost

Choose an output before comparing devices: for example, a Bell-pair correlation estimate with stated uncertainty. Compile the full sequence, including routing, initialization, acquisition, reset, and rejected attempts. Useful output rate is accepted results divided by elapsed time.

If an attempt takes τ, accepts with probability s, and requires independent retries, accepted rate is \(s/\tau\), not \(1/\tau\). Calibration and other overhead reduce it further. Under an illustrative independent event model, G equal failure opportunities have no-fault probability \((1-p)^G\). This can guide a resource estimate, but coherent cancellation, fault correction, and correlated errors can invalidate its interpretation as circuit success. Use a model that matches the actual noise and requested output.

19.2.2 Statistical uncertainty

Let independent trials return success bits \(X_i\). Each has mean p and variance \(p(1-p)\). The average \(\hat p=N^{-1}\sum_iX_i\) therefore has variance \(p(1-p)/N\). Replacing the unknown p by its estimate gives standard error \(\sqrt{\hat p(1-\hat p)/N}\) away from boundaries.

At 9000 successes in 10,000 shots, this is 0.003, or 0.3 percentage points. Zero failures needs another calculation. The chance of zero failures when failure probability is q equals \((1-q)^N\). Setting this to 0.05 gives the one-sided 95% upper bound \(q=1-0.05^{1/N}\), approximately \(3/N\). With N=1000 the bound is about 0.00299. These statements require independent trials and do not account for drift or systematic bias.

Problem 19.2. In 10,000 independent trials, 9,000 succeed. Estimate one standard error.

Worked solution

The estimate is √(0.9 × 0.1/10,000) = 0.003, or 0.3 percentage points. It quantifies sampling variation under the model, not calibration bias or drift.

19.3 Comparative Assessment

19.3.1 Matched resource models

Construct a comparison table whose rows are physical assumptions and whose columns are complete implementations of the same task. Include native operations, routing cost, parallelism, measurement time, accepted fraction, calibration duty cycle, and uncertainty. Label measured parameters and assumed ones separately.

Suppose A accepts 90% of attempts every 100 μs and B accepts 99% every 1 ms. Their illustrative accepted rates are 9000 s⁻¹ and 990 s⁻¹. B may produce a more accurate conditional state, but that is a different axis from rate. Choose the allowed output error before deciding whether either meets the task. If neither does, error correction or additional resources must enter the comparison rather than a ranking of their isolated numbers.

19.3.2 A complete implementation study

For a final study, prepare a Bell pair and separately store an encoded qubit through repeated checks. Specify physical states, Hamiltonians, pulse schedule, readout rule, and noise assumptions. Derive the expected populations and at least one coherence-sensitive observable, then estimate the number of trials needed to distinguish the prediction from the relevant alternative.

Change one bottleneck and recompute. Would faster readout help if calibration dominates elapsed time? Would a stronger interaction help if leakage dominates error? Record what would need experimental validation, including neglected levels or error correlations. This closes the course’s chain of reasoning: the task specifies a circuit, the circuit specifies physical operations, and their measured or assumed dynamics determine a distribution of outputs and its cost.

Problem 19.3. No failures occur in 1,000 independent trials. What upper error bound follows at 95% confidence?

Worked solution

The exact one-sided bound is 1 − 0.05^(1/1000) ≈ 0.00299. Reporting “zero error” would discard the uncertainty that the experiment actually leaves.

The full cycle is now visible: a computational task determines a circuit, the circuit demands physical operations, and the physical error and resource budgets determine whether the task succeeds. Return to the algorithms and programming courses with these budgets attached to every abstract operation.

Worked model check. No failures occur in 10,000 independent trials. What is the one-sided 95% upper failure bound, and what uncertainty does it omit?

Worked solution

\(1-0.05^{1/10000}\simeq0.00029953\), about three in ten thousand. It describes finite-sample uncertainty under independent identical trials, not drift or systematic bias.
