19.1 Performance Measures

A processor with more qubits is not necessarily the processor that completes a specified computation more accurately or sooner. Evaluation begins by fixing the task.

19.1.1 Physical metrics

Physical metrics describe components: coherence times, gate durations, leakage, readout errors, connectivity, loss, and simultaneous-operation performance. Each answers a different question. Specify the experiment and inference model behind a reported number. In particular, randomized benchmarking error, assignment error, and worst-case circuit error are not interchangeable probabilities that can simply be added into a universal score.

19.1.2 Logical metrics

Logical metrics describe encoded behaviour: memory error per correction cycle, logical gate error, cycle time, and resources required at the target reliability. Compare several code distances under matched conditions when claiming error suppression. A logical memory experiment is valuable but does not establish equally reliable universal logical gates. Include the auxiliary-state production and measurement operations needed by the intended computation.

Problem 19.1. Why is a long T1 insufficient to predict circuit accuracy?

Worked solution

Dephasing, control error, leakage, readout, and interactions can dominate even when relaxation is weak. The circuit schedule determines how much each mechanism matters.

19.2 Workload Evaluation

19.2.1 Compilation and execution cost

Compile a representative algorithm to each architecture, then include state preparation, routing, readout, reset, retries, and calibration. For probabilistic protocols, count rejected attempts. Report both elapsed time and the number of useful outputs. A postselected high-fidelity sample is not directly comparable with an unconditional output unless acceptance and resource costs are also supplied.

19.2.2 Statistical uncertainty

For independent Bernoulli outcomes, the estimated success fraction \(\hat p\) has approximate standard error \(\sqrt{\hat p(1-\hat p)/N}\) away from extreme probabilities. Drift and correlations invalidate the independent-trial interpretation. Zero observed failures does not establish zero error; for independent trials a one-sided 95% upper bound is \(1-0.05^{1/N}\), approximately \(3/N\).

Problem 19.2. In 10,000 independent trials, 9,000 succeed. Estimate one standard error.

Worked solution

The estimate is √(0.9 × 0.1/10,000) = 0.003, or 0.3 percentage points. It quantifies sampling variation under the model, not calibration bias or drift.

19.3 Comparative Assessment

19.3.1 Matched resource models

Fix an output task, acceptable error, and resource accounting before comparing platforms. One device may trade slower gates for longer coherence, another more auxiliaries for faster correction, and another loss for heralded retries. Present these tradeoffs as a table of assumptions and outcomes. Without a matched workload, a single ranking conceals the choices that determine it.

19.3.2 A complete implementation study

As a final study, choose a short entangling circuit and an encoded memory experiment. Specify physical states and interactions, compile the schedules, model noise, and predict observed distributions with uncertainty. List which parameters are measured and which are assumed. Then change one bottleneck and recompute the result. This connects the course’s microscopic models to an honest system-level engineering decision.

Problem 19.3. No failures occur in 1,000 independent trials. What upper error bound follows at 95% confidence?

Worked solution

The exact one-sided bound is 1 − 0.05^(1/1000) ≈ 0.00299. Reporting “zero error” would discard the uncertainty that the experiment actually leaves.

The full cycle is now visible: a computational task determines a circuit, the circuit demands physical operations, and the physical error and resource budgets determine whether the task succeeds. Return to the algorithms and programming courses with these budgets attached to every abstract operation.
