# Quantum Hardware

Nineteen initial teaching chapters on physical implementation, following Quantum
Computing. Topics range from energy levels, control, and measurement through
hardware platforms, encodings, infrastructure, architectures, and fault tolerance.

Edit content/*.html, not generated pages. The chapter plan lives in chapters.json;
follow AGENTS.md. Build with `python3 education/hardware/build.py`.

Small-instance checks: `python3 education/hardware/checks/worked_examples.py`
(requires NumPy). Site integration and rendering use education/checks.
Examples are illustrative physical models; no current device specification,
commercial ranking, or hardware execution result is implied.
