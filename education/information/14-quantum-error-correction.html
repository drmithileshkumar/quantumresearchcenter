Quantum Error Correction

How can an unknown state be protected without learning or copying its amplitudes?

Chapter direction

Starting point: Chapters 4–7 and 9; code spaces and syndrome measurements are developed through circuits.

Anchor example: Encode a qubit into a three-qubit code and correct a single bit flip.

This lesson includes explanations, worked examples, and problems with solutions. Advanced results whose proofs are outside the chapter are identified explicitly.

  1. 14.1 Encoding
  2. 14.2 Detection and Recovery
  3. 14.3 Correction Conditions

14.1 Encoding

An unknown qubit cannot be copied into three independent specimens. Yet it can be encoded into a joint three-qubit state whose error can be diagnosed without learning its amplitudes.

14.1.1 Redundancy without cloning

With two zero auxiliaries, apply CNOTs from the input to each auxiliary. The result is \(\alpha\ket{000}+\beta\ket{111}\), not \((\alpha\ket0+\beta\ket1)^{\otimes3}\). The two-dimensional span of 000 and 111 is the code space. It stores one logical qubit across three physical qubits. The encoding respects no-cloning because the information is in the joint state.

14.1.2 Errors on joint states

A bit flip on qubit one, with labels 1,2,3 from left to right, produces \(\alpha\ket{100}+\beta\ket{011}\). Neither amplitude is revealed by the fact that one bit disagrees with its neighbors. Single X errors move the code into distinct two-dimensional subspaces. A phase flip Z instead changes the relative sign within the code, an error this repetition code will not detect.

Problem 14.1. An observed syndrome is (−,−). Which correction is used?

Worked solution

Apply X to the middle data qubit. It anticommutes with both parity checks, producing two negative signs.

14.2 Detection and Recovery

14.2.1 Syndromes without logical readout

Measure the commuting parity observables Z1Z2 and Z2Z3. The no-error syndrome is (+,+); X1 gives (−,+), X2 gives (−,−), and X3 gives (+,−). Each parity can be measured by computing the XOR of its two data bits into a zero auxiliary with two CNOTs and measuring only that auxiliary. Both logical codewords have the same parity, so the result reveals the error class without distinguishing α from β.

14.2.2 Conditional recovery

Apply the corresponding X correction to the indicated qubit. Then decode with the inverse of the two encoding CNOTs if the logical state is needed on one wire. For a coherent combination of correctable errors, syndrome measurement separates branches, and each recovery returns the same logical state. The measurement is allowed to learn the error, but not the encoded amplitudes. Faulty syndrome circuits require additional design; this ideal recovery is not yet fault tolerance.

Problem 14.2. Why not measure all three data bits and take a majority?

Worked solution

That would distinguish 000 from 111 and collapse the logical superposition. Parity measurements reveal only the relative disagreement, leaving α and β coherent.

14.3 Correction Conditions

14.3.1 Correctable error sets

For a code projector P and error operators Ea, exact correction is possible precisely when \(P E_a^\dagger E_b P=c_{ab}P\). This Knill–Laflamme criterion says the overlaps of error images do not reveal which logical state was present. For the repetition code and {I,X1,X2,X3}, different error images are orthogonal and equal-error overlaps are P, so the criterion holds. It also covers linear combinations of those operators. Correcting arbitrary single-qubit noise would require handling X,Y,Z on each qubit, a larger error set.

14.3.2 Code capabilities and limitations

Two bit flips can mimic the syndrome of the remaining single flip. Majority recovery then makes a logical error. Under independent bit-flip probability p, the failure probability is 3p²−2p³, matching the classical repetition expression, but the recovered object is a coherent logical qubit. A single Z1 acts as logical Z without changing either parity, so this code offers no general phase protection. Always name the corrected error set and the assumptions on the recovery hardware.

Problem 14.3. Does Z1 satisfy the correction criterion together with identity?

Worked solution

No. PZ1P acts differently on the two logical basis states and is not a scalar multiple of P. The environment could distinguish a logical phase effect.

Codes protect states across repeated noisy uses. Channel capacity asks the best rate achievable by all such coding strategies.

Sources and further study: Knill and Laflamme, A Theory of Quantum Error-Correcting Codes.
