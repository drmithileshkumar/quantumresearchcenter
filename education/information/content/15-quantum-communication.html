We now know how to protect a qubit against a known set of errors, at the price of using several physical qubits for one logical qubit. Classically, Shannon's capacity told us the best rate any code can achieve over a noisy channel, and the Holevo bound limits the bits that one encoding can deliver.

A quantum channel raises a sharper version of the capacity question, because it can be asked to carry different things. It may carry classical bits or unknown quantum states, with or without shared entanglement as help. What is the best rate for each task? A simple channel that sometimes loses its qubit, and says so, lets us compute every answer. We first separate the tasks and the resources they may use. Then we define what a capacity claim asserts. The Holevo information gives the classical rate, with a subtlety when inputs are entangled across uses. A Bell pair sent through the channel gives the entanglement-assisted rate. The entanglement that survives with a reference gives the quantum rate.

15.1 Communication Tasks

What does it mean to send information through a quantum channel? We introduce a channel that either delivers a qubit intact or replaces it with a flag. Comparing what a classical message and a quantum message need from it shows that they are different tasks. Teleportation and dense coding then show that the answer also depends on what other resources are free.

15.1.1 Classical and quantum messages§

A qubit erasure channel delivers its input unchanged with probability \(1-e\). With probability \(e\) it replaces the input with a flag state \(\ket\perp\), which is orthogonal to both \(\ket0\) and \(\ket1\). The output therefore lives in three dimensions, and its density matrix has two blocks:

\[\mathcal N_e(\rho)=\begin{pmatrix}(1-e)\rho&0\\0&e\end{pmatrix},\]

a \(2\times2\) block for the delivered qubit and a single entry for the flag. This is often written \((1-e)\rho\oplus e\ket\perp\bra\perp\). The blocks carry classical probabilities; the output is not a superposition of a qubit and a flag.

Send \(\ket+\) with \(e=1/4\). Three quarters of uses deliver plus exactly, and one quarter deliver the flag. Bob can ask "erased or not?" with the projective measurement onto the flag and onto the qubit subspace. Because the flag is orthogonal to the whole qubit subspace, this question does not disturb a delivered qubit. He learns where the losses are, but not what was lost.

What should count as success? For a classical message, Bob must identify Alice's label. For a quantum message, an unknown state must arrive intact, including any entanglement it has with a reference system that never enters the channel. The two can differ sharply. A device that measures Z and resends the result is a perfect channel for the labels 0 and 1, yet it destroys every superposition. So the success criterion must match the kind of information requested.

15.1.2 Assistance and resource models§

Does teleportation make sending qubits the same as sending classical bits? With one ebit in hand, two classical bits deliver one qubit. Dense coding runs the other way: with an ebit, one qubit delivers two classical bits. So the rate a channel supports depends on what else Alice and Bob may use for free.

We therefore always name the resource model. An unassisted code uses only the channel. An entanglement-assisted code may also use any number of ebits shared in advance. Some codes may also use classical communication, one way or in both directions. Each model has its own capacity, and rates from different models cannot be compared without counting the extra resources.

Problems

Problem 15.1. Why does a known erasure differ from an unflagged bit flip?

Worked solution

The receiver knows the failed positions and can adapt decoding to that side information. The channel output alphabet includes a flag distinct from the qubit subspace.

15.2 Coding and Rates

For each task and resource model we want the best rate. What does a claim that a rate is "best" actually assert? We state the two halves of a capacity theorem. Then we find the classical rate of the erasure channel, first with a simple code and then with the Holevo information, and ask what changes when inputs may be entangled across uses. Adding shared entanglement doubles the rate, as dense coding suggests.

15.2.1 Achievability and converse statements§

Classically, a capacity was a rate below which long codes work and above which none do. The same two halves define every quantum capacity. A rate \(R\) is achievable if there are codes using the channel \(n\) times that carry about \(nR\) bits or qubits with error tending to zero as \(n\) grows. A converse shows that no rate above the capacity is achievable under the same error criterion.

A rate counts message size divided by all channel uses, including the erased ones, since the code is chosen before anyone knows which uses will fail. And a finite demonstration with a small error establishes neither half of a capacity theorem. Throughout, we assume a memoryless channel: independent uses of the same channel, \(\mathcal N^{\otimes n}\), on finite-dimensional systems.

15.2.2 Classical and entanglement-assisted capacities§

How many classical bits per use can the erasure channel carry? Send \(\ket0\) or \(\ket1\) with equal probability. When the qubit arrives, Bob reads the bit exactly. When it is erased, the bit stays fair. So \(H(X\mid Y)=e\), and the mutual information is \(1-e\) bits per use.

Could cleverer inputs beat \(1-e\)? For any encoding, Bob's information is limited by the Holevo information of the output states, \(\chi\). The output for input \(\rho_x\) is \((1-e)\rho_x\oplus e\ket\perp\bra\perp\). Its entropy has a term \(h_2(e)\) for which block occurred, plus \((1-e)S(\rho_x)\) from the qubit block. The flag block is the same for every \(x\), so it cancels in \(\chi\), leaving \(\chi=(1-e)\bigl[S(\bar\rho)-\sum_xp_xS(\rho_x)\bigr]\leq1-e\). For one use, orthogonal inputs are already the best.

Two refinements turn this into a capacity. Write \(\chi^*(\mathcal N)\) for the largest Holevo information of the outputs over all input ensembles. We quote the theorem of Holevo (1998) and of Schumacher and Westmoreland (1997): unentangled inputs, with Bob measuring long blocks of outputs together, achieve rate \(\chi^*\). But Alice may also feed the channel inputs entangled across several uses. To allow that, apply the same quantity to \(n\) uses at once and divide by \(n\):

\[C(\mathcal N)=\lim_{n\to\infty}\frac1n\,\chi^*\bigl(\mathcal N^{\otimes n}\bigr).\]

Taking the \(n\)-use quantity, dividing by \(n\) and letting \(n\) grow is called regularization. It cannot be dropped in general: Hastings (2009) showed that for some channels entangled inputs do better than \(\chi^*\). For the erasure channel they do not, and \(C=1-e\) is a proved channel-specific result (Bennett, DiVincenzo and Smolin, 1997).

With unlimited shared entanglement the answer changes. We quote the theorem of Bennett, Shor, Smolin and Thapliyal (2002): the entanglement-assisted classical capacity is the largest \(I(R:B)\) obtained by sending the system \(A\) of a pure state \(\ket\psi_{RA}\) through the channel, with \(R\) kept as a reference. No regularization is needed. For the erasure channel send one half of a Bell pair. On delivery, \(RB\) is a Bell pair; on erasure, \(R\) is \(I/2\) and \(B\) holds the flag. The joint state has eigenvalues \(1-e\), \(e/2\) and \(e/2\), so \(S(RB)=h_2(e)+e\). Bob's output has eigenvalues \((1-e)/2\), \((1-e)/2\) and \(e\), so \(S(B)=h_2(e)+(1-e)\). With \(S(R)=1\),

\[I(R:B)=1+\bigl[h_2(e)+1-e\bigr]-\bigl[h_2(e)+e\bigr]=2(1-e).\]

At \(e=0\) this is dense coding's two bits per qubit.

Problems

Problem 15.2. For a fair classical bit through an erasure channel with e=1/2, compute the mutual information.

Worked solution

The input entropy is one bit. On half the trials the output reveals it completely; on the other half it reveals only an erasure flag, leaving one bit of uncertainty. Thus H(X|Y)=1/2 and I(X:Y)=1/2 bit per use.

15.3 Quantum Transmission

For a quantum message, what must survive is the entanglement between the transmitted system and a reference. How do we measure how much survives one use of the channel? Negative conditional entropy signalled entanglement, so we use its negative, the coherent information. A cited theorem turns it into the quantum capacity, and the erasure channel shows all three capacities side by side, together with a reason why its quantum capacity vanishes at \(e=1/2\).

15.3.1 Coherent information and quantum capacity§

Send half of a Bell pair through the erasure channel, keeping the reference \(R\). How much of the entanglement with \(R\) is still in Bob's hands? A negative conditional entropy \(S(R\mid B)\) meant that \(B\) holds part of a purification of \(R\). So we measure the surviving entanglement by its negative,

\[I_c=-S(R\mid B)=S(B)-S(RB).\]

This is the coherent information of the input through the channel. When the state matters we write \(S(B)_\omega\) for the entropy of \(B\) in the output state \(\omega_{RB}\). For the erasure channel, the entropies we just computed give \(I_c=\bigl[h_2(e)+1-e\bigr]-\bigl[h_2(e)+e\bigr]=1-2e\). The term \(h_2(e)\), which records whether an erasure happened, cancels.

Is coherent information the quantum capacity? We quote the theorem of Lloyd, Shor and Devetak: the unassisted quantum capacity is

\[Q(\mathcal N)=\lim_{n\to\infty}\frac1n\max_{\rho_n}I_c\bigl(\rho_n,\mathcal N^{\otimes n}\bigr),\]

maximized over inputs to \(n\) uses at once. The regularization matters here too: for some channels, inputs entangled across uses give more than any single-use value. A positive coherent information for one input shows an achievable rate. It does not by itself give the capacity.

15.3.2 Regularization and finite-resource limitations§

What are the three capacities of the erasure channel? For this channel they are known exactly, by channel-specific theorems (Bennett, DiVincenzo and Smolin, 1997, and the entanglement-assisted theorem above):

\[C=1-e,\qquad C_E=2(1-e),\qquad Q=\max(0,\,1-2e).\]

At \(e=1/4\) they are \(3/4\) bit, \(3/2\) bits and \(1/2\) qubit per use.

Why does \(Q\) reach zero at \(e=1/2\)? Picture the environment receiving the qubit whenever Bob receives the flag. At \(e=1/2\) Bob and the environment are in identical positions. If Bob could decode an unknown state, the environment could decode the same state by the same method, and the state would have been cloned. So no quantum message gets through.

At \(e=3/4\), the Bell-half input has coherent information \(1-2e=-1/2\). A capacity cannot be negative, because sending nothing achieves rate zero. That is why the formula has the maximum with zero. It is a theorem about this channel, not permission to replace the regularized formula by one example in general.

The model matters to the end. Two-way classical communication would raise the quantum rate, so it must not slip into an unassisted claim. And finite block lengths, decoding effort and experimental noise remain practical limits on any real code.

These rates describe reliable delivery. Can the same physics, no-cloning and the disturbance caused by measurement, also keep a message secret from an eavesdropper?

Sources and further study: Holevo, Capacity with general signal states; Bennett et al., Entanglement-assisted capacity; Devetak, Private classical and quantum capacity; Bennett et al., Erasure channel capacities.

Problems

Problem 15.3. Why is a single-use coherent information not generally “the quantum capacity”?

Worked solution

Block encodings can use correlations across channel inputs and improve the per-use value. The regularized maximization is essential without a theorem proving additivity for the channel.

Transfer problem. Compute the three stated erasure capacities at e=3/4. Why does the positive entanglement-assisted classical rate not contradict zero unassisted quantum capacity?

Worked solution

The classical capacity is 1/4 bit per use, entanglement-assisted classical capacity is 1/2 bit per use, and unassisted quantum capacity is zero. The positive rate concerns classical labels with prior shared entanglement; the zero rate concerns unknown quantum states without that resource. Teleportation would consume additional ebits and classical communication.
