Predict before calculating. Is |+⟩ resourceful without specifying a basis or an operational restriction?

9.1 Choosing a resource theory

9.1.1 Free states alone are not enough

A resource theory specifies a set of free states \(\mathcal F\) and a collection of allowed channels that preserve this set. Identity and composition should be allowed; tensor-product rules must also be stated for multi-system tasks. A state outside \(\mathcal F\) is a resource only relative to these restrictions. Unrestricted quantum operations could simply prepare the desired state, making the conversion problem trivial.

For entanglement, free states are separable and a physically motivated operation class is LOCC. For basis coherence, free states are diagonal in a declared basis. Different operation classes can preserve those same diagonal states while permitting different transformations. Calling an operation “free” is therefore a substantive modeling choice, not a consequence of a preferred numerical measure. The broad framework is surveyed by Chitambar and Gour.

Take a qubit whose free basis is |0⟩,|1⟩. The state |+⟩ has coherence, but |0⟩ does not. In the X eigenbasis, these roles change. This is not an inconsistency: the laboratory’s reference frame and permitted controls determine which basis has physical significance. For asymmetry under a symmetry group, free states are invariant and free channels are typically chosen covariant with that group; arbitrary basis dephasing is not a substitute for specifying the symmetry.

Worked check 9.1. Is the Hadamard gate free in a resource theory where all diagonal states must remain diagonal?

Reasoned solution

No. It sends the free state |0⟩⟨0| to the coherent state |+⟩⟨+|. The preservation requirement already excludes it.

9.2 Relative-entropy monotones

9.2.1 A general proof and a qubit calculation

Define \(R(\rho)=\inf_{\sigma\in\mathcal F}D(\rho\|\sigma)\). If a channel \(\Lambda\) maps every free state to a free state, then \(R(\Lambda\rho)\le D(\Lambda\rho\|\Lambda\sigma)\le D(\rho\|\sigma)\) for any free \(\sigma\). Taking the infimum proves monotonicity. The first inequality uses free-state preservation; the second is data processing. This short proof shows exactly which physical assumption supports the bound.

For coherence, write \(\Delta\) for complete dephasing in the chosen basis. If \(\delta\) is diagonal, then \(\tr\rho\log\delta=\tr\Delta(\rho)\log\delta\). Adding and subtracting \(S(\Delta\rho)\) gives \(D(\rho\|\delta)=S(\Delta\rho)-S(\rho)+D(\Delta\rho\|\delta)\). Nonnegativity makes the optimum occur at \(\delta=\Delta\rho\). Thus \(C_r(\rho)=S(\Delta\rho)-S(\rho)\).

For \(\rho=\begin{pmatrix}1/2&r/2\\r/2&1/2\end{pmatrix}\), with real \(|r|\le1\), the eigenvalues are \((1\pm r)/2\). Therefore \(C_r=1-h_2((1+r)/2)\). At r=0 the state is free and the value is zero; at r=1 it is |+⟩ and the value is one. The formula was derived for a fixed basis and should not be presented as basis independent.

Worked check 9.2. Compute Cᵣ for r=0.6.

Reasoned solution

The eigenvalues are (0.8,0.2), so Cᵣ=1−h₂(0.2)≈0.278072 bits of relative-entropy coherence.

9.3 Conversion bounds and their limits

9.3.1 Monotones constrain protocols

If \(\rho\) converts deterministically to \(\tau\) by a free channel, every monotone obeys \(R(\rho)\ge R(\tau)\). A violated inequality rules out the conversion. A satisfied inequality alone usually does not prove a protocol exists. Entanglement majorization provided a complete family of inequalities for a special pure-state problem; a single entropy loses part of that ordering information.

If a monotone is additive, an exact conversion from n copies of \(\rho\) to m copies of \(\tau\) implies \(nR(\rho)\ge mR(\tau)\). When the target value is positive, this yields \(m/n\le R(\rho)/R(\tau)\). Relative-entropy coherence is additive because both entropy and dephasing factor on product inputs. Extending an exact bound to approximate asymptotic conversion requires an appropriate continuity argument; it does not follow just by deleting the word “exact.”

Catalysts add another resource question: an auxiliary state participates and must be returned according to a stated criterion. Exact return as an uncorrelated product, approximate return, and returning only the same marginal are different requirements. A resource accounting that hides correlations with the catalyst can produce misleading conclusions. A research calculation should name its free operations, error tolerance, and return condition before optimizing a conversion rate.

Worked check 9.3. What exact conversion bound follows from an input with Cᵣ≈0.278072 per copy to |+⟩ copies?

Reasoned solution

For free operations preserving diagonality, additivity and monotonicity require m/n≤0.278072. This is only a necessary condition; the calculation alone does not construct an exact distillation protocol.
