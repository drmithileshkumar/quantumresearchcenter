Deutsch’s algorithm worked because a function value became a sign. That trick generalizes. Any operation that changes a particular state only by a phase can transfer the phase to a controlling register, where interference can read it. This section states the general mechanism, builds a circuit that measures a phase, and sorts out exactly how bit oracles and phase oracles relate.

The \(\ket-\) target worked because flipping it only multiplied it by \(-1\). Look for the same property in any unitary \(V\): a state \(\ket u\) that \(V\) changes only by a phase,

\[V\ket u=e^{i\phi}\ket u.\]

Such a state is an eigenstate of \(V\), and \(e^{i\phi}\) is its eigenvalue. Because \(V\) is unitary, it preserves lengths, so the eigenvalue has magnitude one: it is a pure phase. For \(V=X\), the eigenstates are \(\ket+\) with eigenvalue \(1\) and \(\ket-\) with eigenvalue \(-1\).

Now control \(V\) with a qubit in \(\ket+\):

\[\mathrm{C}V\,\frac{\ket0+\ket1}{\sqrt2}\ket u=\frac{\ket0\ket u+\ket1\,e^{i\phi}\ket u}{\sqrt2}=\frac{\ket0+e^{i\phi}\ket1}{\sqrt2}\otimes\ket u.\]

The target is untouched and factors out. The phase \(e^{i\phi}\), which was a global phase of \(V\ket u\) and therefore unobservable, is now a relative phase between the control branches. This is phase kickback in its general form. It needs three things: a target prepared in an eigenstate, controlled access to \(V\), and the eigenvalue being the information we want.

All three are real requirements. If \(\ket u\) is not an eigenstate, the target becomes entangled with the control and the clean factorization fails. If only an uncontrolled \(V\) is available, the phase stays global. And if many eigenstates are present at once, each contributes its own phase on its own branch; Chapter 4 shows that this produces a random sample of the eigenvalues rather than all of them.

  1. Find the eigenstates and eigenvalues of \(Z\) and of \(S=\mathrm{diag}(1,i)\). What does controlled-\(S\) do to \(\ket+\ket1\)?

    \(Z\) has \(\ket0\) (eigenvalue \(1\)) and \(\ket1\) (eigenvalue \(-1\)). \(S\) has \(\ket0\) (eigenvalue \(1\)) and \(\ket1\) (eigenvalue \(i\)). Controlled-\(S\) on \(\ket+\ket1\) gives \(\frac{1}{\sqrt2}(\ket0+i\ket1)\ket1\): the phase \(i\) is kicked back onto the control.

  2. Apply controlled-\(X\) to \(\ket+\ket0\). Is \(\ket0\) an eigenstate of \(X\)? What goes wrong?

    The result is \(\frac{1}{\sqrt2}(\ket{00}+\ket{11})\), an entangled state. \(\ket0\) is not an eigenstate of \(X\), so the target does not factor out: it records the control branch. This is the which-path record of Chapter 1 in eigenstate language.

  3. Show that if \(V\ket u=e^{i\phi}\ket u\), then controlled-\(V^k\) kicks back \(e^{ik\phi}\). Why does this make powers of \(V\) useful for learning \(\phi\) precisely?

    \(V^k\ket u=V^{k-1}e^{i\phi}\ket u=\cdots=e^{ik\phi}\ket u\), so the kicked-back phase is \(k\phi\). A small change in \(\phi\) becomes a \(k\)-times larger change in the measured phase, so interference experiments with large \(k\) are more sensitive. Phase estimation in Chapter 4 uses \(k=1,2,4,\ldots\) to read successive binary digits of \(\phi\). The price is that \(V^k\) costs up to \(k\) uses of \(V\).

Once a phase is on the control, a Hadamard turns it into a probability. Apply \(H\) to \((\ket0+e^{i\phi}\ket1)/\sqrt2\):

\[\frac{1+e^{i\phi}}{2}\ket0+\frac{1-e^{i\phi}}{2}\ket1,\qquad \Pr[0]=\left|\frac{1+e^{i\phi}}{2}\right|^2=\frac{1+\cos\phi}{2}.\]

So measuring the control is a coin whose bias reveals \(\cos\phi\). This circuit, \(H\), controlled-\(U\), \(H\), measure, is the Hadamard test. It works even when the target is not an eigenstate. For a general state \(\ket\psi\), the same calculation gives

\[\Pr[0]=\frac{1+\operatorname{Re}\bra\psi U\ket\psi}{2}.\]

To see this, write the state before the final Hadamard as \(\frac{1}{\sqrt2}(\ket0\ket\psi+\ket1U\ket\psi)\). The Hadamard puts amplitude \(\frac12(\ket\psi+U\ket\psi)\) on control outcome \(0\), whose squared length is \(\frac14(2+\bra\psi U\ket\psi+\bra\psi U^\dagger\ket\psi)=\frac12(1+\operatorname{Re}\bra\psi U\ket\psi)\). Inserting \(S^\dagger\) on the control before the final Hadamard gives \(\frac12(1+\operatorname{Im}\bra\psi U\ket\psi)\) instead.

The Hadamard test is the simplest phase-reading circuit, and its limitation is instructive. One run gives one bit. To estimate \(\cos\phi\) to precision \(\epsilon\) we need on the order of \(1/\epsilon^2\) runs, by the Chebyshev argument of Section 1.4.2. And \(\cos\phi\) does not distinguish \(\phi\) from \(-\phi\). Phase estimation (Chapter 4) and iterative estimation (Chapter 11) do better by combining tests with controlled powers.

  1. Apply the Hadamard test with \(U=Z\) and \(\ket\psi=\ket+\). Compute \(\Pr[0]\) both from the formula and directly.

    \(\bra+Z\ket+=\braket{+}{-}=0\), so \(\Pr[0]=\frac12\). Directly: controlled-\(Z\) on \(\ket+\ket+\) gives \(\frac12(\ket0(\ket0+\ket1)+\ket1(\ket0-\ket1))\); after \(H\) on the control the outcome-\(0\) branch is \(\frac{1}{2\sqrt2}\cdot2\ket0=\frac{1}{\sqrt2}\ket0\), with probability \(\frac12\).

  2. For an eigenstate with \(\phi=\pi/3\), what is \(\Pr[0]\)? How many runs are needed so that, by Chebyshev’s bound, the estimate of \(\Pr[0]\) is within \(0.01\) with probability at least \(0.9\)?

    \(\Pr[0]=(1+\frac12)/2=\frac34\). Chebyshev with variance at most \(1/(4R)\): \(1/(4R\cdot10^{-4})\le0.1\) gives \(R\ge25{,}000\). Using the actual variance \(p(1-p)=3/16\) instead of \(1/4\) reduces this to \(18{,}750\).

  3. The Hadamard test estimates \(\cos\phi\). Explain why the outcomes for \(\phi\) and \(2\pi-\phi\) are identical, and how the \(S^\dagger\) variant resolves the ambiguity.

    \(\cos(2\pi-\phi)=\cos\phi\), so the real-part test cannot tell them apart. The \(S^\dagger\) variant measures \(\sin\phi\), and \(\sin(2\pi-\phi)=-\sin\phi\). Together, \(\cos\phi\) and \(\sin\phi\) determine \(\phi\) modulo \(2\pi\). Running both tests is the classical analogue of measuring both quadratures of a wave.

Two forms of Boolean oracle appear in the literature: the bit oracle \(U_f\ket x\ket y=\ket x\ket{y\oplus f(x)}\) and the phase oracle \(O_f\ket x=(-1)^{f(x)}\ket x\). How do they relate?

From a bit oracle to a phase oracle is one query: put the target in \(\ket-\), as in Chapter 1. Or, if \(U_f\) is built by compute–copy–uncompute, replace the copy by a \(Z\) gate and save the target entirely.

The other direction is subtler. A phase oracle \(O_f\) cannot distinguish \(f\) from \(1\oplus f\): their phase oracles differ by the global factor \(-1\). A bit oracle can, since \(U_f\ket x\ket0\) and \(U_{1\oplus f}\ket x\ket0\) give different target values. So an uncontrolled phase oracle alone cannot implement a bit oracle. With a controlled phase oracle it can. Apply \(H\) to the target \(\ket y\), use the target as the control of \(O_f\), and apply \(H\) again:

\[\ket x\ket y\xrightarrow{H}\ket x\tfrac{1}{\sqrt2}\textstyle\sum_b(-1)^{yb}\ket b\xrightarrow{\mathrm{C}O_f}\ket x\tfrac{1}{\sqrt2}\sum_b(-1)^{b(y\oplus f(x))}\ket b\xrightarrow{H}\ket x\ket{y\oplus f(x)}.\]

The controlled version fixes the global phase: the control-\(0\) branch gets no sign at all, so \(f\) and \(1\oplus f\) become distinguishable. This is the controlled-access lesson of Section 2.4.2 in a specific case. When a paper says “given a phase oracle”, check whether controlled access is assumed.

  1. Verify the bit-from-phase construction on \(\ket x\ket0\) when \(f(x)=1\).

    \(H\) gives \(\ket x\frac{1}{\sqrt2}(\ket0+\ket1)\). Controlled-\(O_f\) multiplies the \(b=1\) branch by \((-1)^{f(x)}=-1\): \(\ket x\frac{1}{\sqrt2}(\ket0-\ket1)\). \(H\) gives \(\ket x\ket1=\ket x\ket{0\oplus1}\).

  2. Show that one query to the bit oracle \(U_f\) implements the controlled phase oracle \(\ket c\ket x\mapsto(-1)^{c f(x)}\ket c\ket x\).

    Use an extra target qubit in \(\ket0\). A CNOT from \(c\) gives \(\ket c\), and a Hadamard turns it into \(\ket+\) when \(c=0\) and \(\ket-\) when \(c=1\). Query \(U_f\): the \(\ket+\) target is unchanged by a flip and the \(\ket-\) target kicks back \((-1)^{f(x)}\), so the phase is \((-1)^{cf(x)}\) with no record left. Undo the Hadamard and the CNOT to return the target to \(\ket0\). By linearity this works on superpositions of \(c\) and \(x\). One query suffices.

  3. A phase oracle \(O_f\) is used in Deutsch–Jozsa. Does it matter that it cannot distinguish \(f\) from \(1\oplus f\)?

    No. Deutsch–Jozsa asks only whether \(f\) is constant or balanced, and \(f\) and \(1\oplus f\) are in the same class. The global sign multiplies the final state and changes no probability. The ambiguity matters only for tasks whose answer distinguishes \(f\) from its complement.

Chapter 1 read one sign pattern on one qubit. Here the pattern lives on \(n\) qubits: one query writes \((-1)^{f(x)}\) on all \(2^n\) inputs at once, and a layer of Hadamards turns the pattern into a measurement outcome. The key is a formula for what \(n\) Hadamards do, which makes the analysis of a whole family of inputs a single calculation.

On one qubit, \[H\ket x=\frac{1}{\sqrt2}\big(\ket0+(-1)^x\ket1\big)=\frac{1}{\sqrt2}\sum_{z\in\{0,1\}}(-1)^{xz}\ket z\]. On \(n\) qubits, apply \(H\) to each and multiply out:

\[H^{\otimes n}\ket x=\bigotimes_{j=1}^n\frac{1}{\sqrt2}\sum_{z_j}(-1)^{x_jz_j}\ket{z_j}=\frac{1}{\sqrt{2^n}}\sum_{z\in\{0,1\}^n}(-1)^{x\cdot z}\ket z,\]

where \(x\cdot z=x_1z_1\oplus\cdots\oplus x_nz_n\) is the bitwise inner product modulo two. The sign of each term is the parity of the positions where both strings have a \(1\). This is the Hadamard transform.

Two consequences carry the whole section. First, \(H^{\otimes n}\ket{0^n}\) is the uniform superposition, since \(0\cdot z=0\) for every \(z\). Second, \(H^{\otimes n}\) is its own inverse, because each \(H\) is. So if a state has the form \(2^{-n/2}\sum_x(-1)^{s\cdot x}\ket x\) for some string \(s\), then \(H^{\otimes n}\) maps it exactly to \(\ket s\). Sign patterns of this special “linear” form are read perfectly by one layer of Hadamards.

The rows of the table are orthogonal: for \(s\neq s'\), \[\sum_x(-1)^{s\cdot x}(-1)^{s'\cdot x}=\sum_x(-1)^{(s\oplus s')\cdot x}=0\], since a nonzero string \(t=s\oplus s'\) has \(t\cdot x=1\) for exactly half the \(x\). This cancellation identity is the binary analogue of the roots-of-unity cancellation that drives Fourier methods in Chapter 4.

  1. Write \(H^{\otimes2}\ket{11}\) explicitly.

    The signs are \((-1)^{11\cdot z}\): \(+\) for \(z=00\), \(-\) for \(01\), \(-\) for \(10\), \(+\) for \(11\). So \(H^{\otimes2}\ket{11}=\frac12(\ket{00}-\ket{01}-\ket{10}+\ket{11})=\ket-\ket-\).

  2. Show that for a nonzero string \(t\), exactly half of all \(x\in\{0,1\}^n\) have \(t\cdot x=1\).

    Pick a position \(j\) with \(t_j=1\). Pair each \(x\) with \(x\) flipped in position \(j\). Flipping \(x_j\) changes \(t\cdot x\) by \(t_j=1\), so each pair contains one \(x\) with \(t\cdot x=0\) and one with \(t\cdot x=1\). The pairs partition all \(2^n\) strings.

  3. Express the zero-outcome amplitude after \(H^{\otimes n}O_fH^{\otimes n}\ket{0^n}\) for an arbitrary Boolean \(f\), and interpret it.

    The amplitude of \(\ket{0^n}\) is \(\frac{1}{2^n}\sum_x(-1)^{f(x)}=1-2\frac{|f^{-1}(1)|}{2^n}\): one minus twice the fraction of ones. It is the average value of \((-1)^{f(x)}\). The circuit estimates the bias of \(f\), with outcome probability equal to the square of that bias.

Suppose \(f_s(x)=s\cdot x\) for a hidden string \(s\in\{0,1\}^n\), and we have a clean oracle for \(f_s\). The task is to find \(s\).

A classical query returns one bit, \(s\cdot x\), which is one linear equation for the unknown \(s\). Querying \(x=e_j\) (a single \(1\) in position \(j\)) returns \(s_j\), so \(n\) queries suffice. They are also necessary for any classical algorithm: there are \(2^n\) possible strings, and \(k\) queries return \(k\) bits, which can distinguish at most \(2^k\) cases.

The quantum algorithm uses one query. Prepare \(H^{\otimes n}\ket{0^n}\) and the target \(\ket-\), query, and apply \(H^{\otimes n}\):

\[\ket{0^n}\xrightarrow{H^{\otimes n}}\frac{1}{\sqrt{2^n}}\sum_x\ket x\xrightarrow{O_{f_s}}\frac{1}{\sqrt{2^n}}\sum_x(-1)^{s\cdot x}\ket x\xrightarrow{H^{\otimes n}}\ket s.\]

The last step is the observation of Section 3.2.1: the phase pattern is a row of the Hadamard table, so the Hadamard layer maps it to the corresponding basis state. Measuring returns \(s\) with certainty.

Here is an \(n=3\) example with \(s=101\). The signs \((-1)^{s\cdot x}\) on \(x=000,001,\ldots,111\) are \(+,-,+,-,-,+,-,+\). The final amplitude of \(z\) is \(\frac18\sum_x(-1)^{(s\oplus z)\cdot x}\), which is \(1\) for \(z=101\) and \(0\) otherwise.

This is the Bernstein–Vazirani algorithm (1993/1997). Its query separation, one versus \(n\), holds for any success criterion, since the classical bound is an information count. Its cost is otherwise ordinary: \(2n+1\) Hadamards and \(n\) measurements around the oracle. And if \(f_s\) is given as a circuit we can read, \(s\) could often be found by inspecting the circuit; the speedup is relative to black-box access.

  1. For \(n=2\) and \(s=11\), list the four signs after the query and verify that the Hadamards produce \(\ket{11}\).

    Signs \((-1)^{x_1\oplus x_2}\) on \(00,01,10,11\): \(+,-,-,+\). The state is \(\frac12(\ket{00}-\ket{01}-\ket{10}+\ket{11})=\ket-\ket-\), and \(H\otimes H\) maps it to \(\ket1\ket1\).

  2. Suppose the oracle is promised to compute \(s\cdot x\oplus b\) for unknown \(s\) and an unknown bit \(b\). What does the circuit return, and can it learn \(b\)?

    The extra \(b\) multiplies every amplitude by \((-1)^b\), a global phase. The circuit still returns \(s\) with certainty but learns nothing about \(b\). One classical query at \(x=0^n\) returns \(b\) directly.

  3. An implementation of the oracle leaves the garbage bit \(x_1\) in its workspace. What does the circuit return for \(s=000\)?

    With \(s=0^n\) there are no signs, but the workspace records \(x_1\). Branches with \(x_1=0\) and \(x_1=1\) cannot interfere, so the first qubit after its Hadamard is a fair coin instead of \(0\); the other qubits still give \(0\). The output is \(000\) or \(100\), each with probability \(\frac12\). Garbage converts an exact algorithm into a wrong one.

The Deutsch–Jozsa algorithm is the same circuit with a different promise. For any Boolean \(f\), the final amplitude of \(\ket{0^n}\) is the average of \((-1)^{f(x)}\), as Problem 3 of Section 3.2.1 showed. Under the promise that \(f\) is constant or balanced, that average is \(\pm1\) or \(0\), so the circuit outputs \(0^n\) with certainty for constant \(f\) and never for balanced \(f\). One query decides this promise problem exactly.

What about functions outside the promise? If \(f\) takes the value \(1\) on \(k\) of the \(2^n\) inputs, the zero outcome has probability \(\big(1-2k/2^n\big)^2\). For \(n=3\):

Only \(k=0\), \(k=8\) (constant) and \(k=4\) (balanced) give certain answers. A function with \(k=3\) gives zero with probability \(1/16\). An algorithm that announced “balanced” whenever the outcome is nonzero would be making claims about inputs the problem never covered.

The classical comparison depends heavily on the success criterion, as Section 1.5.2 showed. Exact deterministic classical algorithms need \(2^{n-1}+1\) queries in the worst case. Randomized algorithms with error \(\delta\) need only \(O(\log(1/\delta))\). So Deutsch–Jozsa separates exact quantum and exact classical query complexity exponentially, but bounded-error classical algorithms close the gap. Bernstein–Vazirani’s separation is smaller (one versus \(n\)) but survives randomization. Simon’s problem, next, gives an exponential separation that survives randomization.

  1. For \(n=4\), compute the zero-outcome probability when \(f\) is \(1\) on 6 inputs.

    \(1-2\cdot6/16=1/4\), so the probability is \(1/16\).

  2. Show that for a balanced \(f\), every nonzero outcome \(z\) is possible in principle but the probability distribution depends on \(f\). Give an example for \(n=2\).

    The amplitude of \(z\) is \(\frac{1}{2^n}\sum_x(-1)^{f(x)\oplus z\cdot x}\). For \(f(x)=x_1\) (balanced), the pattern is a Hadamard row and the output is \(10\) with certainty. For \(f\) with values \(0,1,1,0\) on \(00,01,10,11\), the output is \(11\). For \(f\) with values \(0,1,0,1\), it is \(01\). Different balanced functions give different nonzero distributions; the promise guarantees only that \(00\) never occurs.

  3. A test suite checks a Deutsch–Jozsa implementation on the two constant functions and on \(f(x)=x_1\) only. Name an implementation bug that would pass this suite.

    An oracle that reads only \(x_1\), computing \(x_1\) whenever it should compute some other balanced function, passes: on the three tested functions it is correct. So does a circuit that omits the final Hadamards on every qubit except the first, since for these functions the other qubits are \(\ket+\) before the final layer and are measured as random bits that the test may not check. A useful test suite includes balanced functions depending on every input bit and checks the full output string.

Bernstein–Vazirani read a hidden string in one shot because the phase pattern was exactly a row of the Hadamard table. Most hidden structure does not produce such a perfect pattern. Simon’s problem shows what happens instead: each run returns a random constraint on the hidden structure, and classical post-processing combines a modest number of constraints into the answer. This pattern, quantum sampling followed by classical algebra, is the template for Shor’s algorithm.

Let \(f:\{0,1\}^n\to\{0,1\}^n\) satisfy, for some hidden nonzero \(s\),

\[f(x)=f(y)\iff y=x\ \text{or}\ y=x\oplus s.\]

So \(f\) is two-to-one, and its collisions are exactly the pairs \(\{x,x\oplus s\}\). The task of Simon’s problem is to find \(s\).

Classically, the only way to learn about \(s\) is to find a collision \(f(x)=f(y)\), which reveals \(s=x\oplus y\). With \(k\) queries there are about \(k^2/2\) pairs, each colliding with probability about \(2^{-n}\), so on the order of \(2^{n/2}\) queries are needed. Simon proved this is a lower bound for any bounded-error classical algorithm.

The quantum circuit uses a clean bit oracle with an \(n\)-qubit output register. Prepare the uniform superposition, query, and measure the output register:

\[\frac{1}{\sqrt{2^n}}\sum_x\ket x\ket{f(x)}\ \xrightarrow{\text{measure output, see }f(x_0)}\ \frac{\ket{x_0}+\ket{x_0\oplus s}}{\sqrt2}.\]

The measurement leaves a superposition of the two inputs consistent with the observed value. We do not learn \(x_0\) usefully: it is random. But the difference between the two branches is \(s\), wherever they sit. Now apply \(H^{\otimes n}\). The amplitude of \(z\) is

\[\frac{1}{\sqrt{2^{n+1}}}\Big((-1)^{x_0\cdot z}+(-1)^{(x_0\oplus s)\cdot z}\Big)=\frac{(-1)^{x_0\cdot z}}{\sqrt{2^{n+1}}}\big(1+(-1)^{s\cdot z}\big).\]

It is zero whenever \(s\cdot z=1\), and has magnitude \(2/\sqrt{2^{n+1}}\) whenever \(s\cdot z=0\). The random \(x_0\) contributes only a phase. So each run returns a uniformly random \(z\) satisfying \(s\cdot z=0\).

Measuring the output register is not essential; leaving it unmeasured gives the same statistics for \(z\), since the output is never used again. It is a convenient way to see the state. The algorithm is due to Simon, On the Power of Quantum Computation (1994/1997).

  1. For \(n=3\) and \(s=110\), list the four collision pairs and the strings \(z\) the circuit can return.

    Pairs: \(\{000,110\}\), \(\{001,111\}\), \(\{010,100\}\), \(\{011,101\}\). Allowed \(z\) satisfy \(z_1\oplus z_2=0\): \(000,001,110,111\), each with probability \(\frac14\).

  2. Why does the random \(x_0\) not spoil the result, even though different runs collapse onto different pairs?

    \(x_0\) enters the amplitude of \(z\) only through the factor \((-1)^{x_0\cdot z}\), which has magnitude one. Whether \(z\) is allowed depends only on \(s\cdot z\). The Hadamard transform converts a shift of the pair, which is unknown, into a phase, which is invisible to measurement, while the spacing of the pair, which is \(s\), determines which outcomes occur.

  3. What does the circuit return if \(f\) is one-to-one (equivalently, \(s=0^n\))? How could an algorithm detect this case?

    After measuring the output, the input is a single basis state \(\ket{x_0}\), and \(H^{\otimes n}\) gives every \(z\) with probability \(2^{-n}\). The samples then span all of \(\{0,1\}^n\) after about \(n\) runs, so no nonzero \(s\) satisfies all equations. The algorithm can detect this and report “one-to-one”, after confirming with classical checks if needed.

Each run gives one equation \(s\cdot z=0\) over bits. These are linear equations modulo two, and solving them is linear algebra over GF(2), arithmetic in which \(1+1=0\). Collect \(n-1\) linearly independent equations; then the solution space is \(\{0^n,s\}\), and the nonzero solution is \(s\). Gaussian elimination finds it in \(O(n^3)\) classical bit operations.

Continue the example \(s=110\). Suppose the runs return \(z=001\) and then \(z=111\). The equations are \(s_3=0\) and \(s_1\oplus s_2\oplus s_3=0\), so \(s_1=s_2\). The nonzero solution is \(s=110\). If the second run had returned \(000\) or \(001\) again, it would add no information, and we would run again.

How many runs are needed? The samples are uniform over the \((n-1)\)-dimensional space of strings orthogonal to \(s\). If we already have \(k\) independent samples, a new one is dependent with probability \(2^{k}/2^{n-1}\). Summing the expected waiting times, the expected number of runs to collect \(n-1\) independent samples is less than \(n+1\). With \(n+O(\log(1/\delta))\) runs, failure probability is below \(\delta\).

Simon’s algorithm uses \(O(n)\) queries against the classical \(\Omega(2^{n/2})\), an exponential separation for bounded-error algorithms in the black-box model. Its structure is the template for period finding: a coherent query, a measurement that collapses onto a coset of the hidden structure, a Fourier-type transform that turns the unknown shift into a harmless phase, and classical post-processing of several samples. In Chapter 4 the group \(\{0,1\}^n\) with XOR becomes the integers modulo \(N\) with addition, the Hadamard transform becomes the quantum Fourier transform, and Gaussian elimination becomes continued fractions.

  1. For \(n=3\), suppose the samples are \(110\) and \(111\). Find \(s\).

    Equations: \(s_1\oplus s_2=0\) and \(s_1\oplus s_2\oplus s_3=0\). Subtracting gives \(s_3=0\), and \(s_1=s_2\). Nonzero solution: \(s=110\).

  2. For \(n=4\), what is the probability that three samples are linearly independent?

    The space has dimension 3, with 8 elements. The first sample must be nonzero: \(7/8\). The second must avoid the span of the first (2 elements): \(6/8\). The third must avoid a span of 4: \(4/8\). Product: \(\frac{7\cdot6\cdot4}{512}=\frac{168}{512}\approx0.33\). Low, but each extra run raises the chance quickly; the expected number of runs is below 5.

  3. Is the speedup of Simon’s algorithm a speedup for any practical problem?

    Not directly: the problem is artificial, and its value is as a demonstration that black-box quantum query complexity can be exponentially smaller than bounded-error classical query complexity. Its structure inspired Shor’s algorithm, and variants of it have been used to attack certain symmetric-key constructions when an adversary has coherent access to a keyed function, an access assumption that must be stated with the claim.

So far every phase has been a sign, \(\pm1\). Many algorithms need finer phases: \(e^{2\pi iv/M}\) for a computed integer \(v\), or \(e^{i\theta(x)}\) for a computed angle. This section shows two ways to produce such phases cleanly and how to account for their precision.

Suppose a clean computation writes an \(m\)-bit integer \(v=\sum_jv_j2^j\) into a register, and we want the phase \(e^{2\pi iv/2^m}\). The exponent splits into a sum over bits, so the phase splits into a product:

\[e^{2\pi iv/2^m}=\prod_{j=0}^{m-1}e^{2\pi iv_j2^j/2^m}=\prod_{j=0}^{m-1}P\!\left(\frac{2\pi}{2^{m-j}}\right)^{v_j},\]

where \(P(\theta)=\mathrm{diag}(1,e^{i\theta})\) is the phase gate. So apply \(P(2\pi/2^{m-j})\) to bit \(j\), one gate per bit, then uncompute \(v\). The highest bit gets \(P(\pi)=Z\), the next \(P(\pi/2)=S\), then \(P(\pi/4)=T\), and so on. The quantity \(v/2^m\) is the binary fraction \(0.v_{m-1}\cdots v_0\), and each bit contributes its own share of a full turn.

For \(m=3\) and \(v=5=101_2\): \(Z\) on \(v_2=1\) gives \(-1\), \(S\) on \(v_1=0\) gives \(1\), \(T\) on \(v_0=1\) gives \(e^{i\pi/4}\). The product is \(-e^{i\pi/4}=e^{i5\pi/4}=e^{2\pi i\cdot5/8}\). Correct.

The same idea applies with a real angle: if \(\theta(x)\) is computed to \(m\) bits as an approximation, applying the phase gates gives \(e^{i\tilde\theta(x)}\) with \(\tilde\theta\) the rounded angle. The cost is \(m\) controlled rotations plus computing and uncomputing \(\tilde\theta\). Small-angle rotations are not elementary in fault-tolerant gate sets; each must itself be synthesized to some accuracy, which Section 3.4.3 accounts for.

  1. Which phase gates produce \(e^{2\pi iv/16}\) for a four-bit \(v\), and what is the phase for \(v=6\)?

    \(P(\pi)\) on \(v_3\), \(P(\pi/2)\) on \(v_2\), \(P(\pi/4)\) on \(v_1\), \(P(\pi/8)\) on \(v_0\). For \(v=6=0110_2\): \(S\) and \(T\) act, giving \(e^{i\pi/2}e^{i\pi/4}=e^{i3\pi/4}=e^{2\pi i\cdot6/16}\).

  2. Does the bitwise product formula still produce \(e^{2\pi iv/3}\) for an \(m\)-bit \(v\)? What changes in practice?

    Yes: \(e^{2\pi iv/3}=\prod_jP(2\pi2^j/3)^{v_j}\) holds for any modulus, since the exponent is still a sum over bits. What changes is that the angles \(2\pi2^j/3\) are not multiples of \(\pi/2^k\), so they are not among the exactly implementable gates \(Z,S,T\) of a Clifford+\(T\) gate set. Each rotation must be synthesized approximately, and its error counted as in Section 3.4.3.

  3. A student applies the phase gates to the bits of \(v\) but forgets to uncompute \(v\). Describe the resulting state for an input superposition \(\sum_x\alpha_x\ket x\).

    The state is \(\sum_x\alpha_xe^{2\pi iv(x)/2^m}\ket x\ket{v(x)}\) plus any garbage. The phases are present but the register \(\ket{v(x)}\) is a which-path record: branches with different \(v\) cannot interfere, so the phases are useless for any later interference on \(x\) alone.

There is a second way, which reuses arithmetic instead of rotation gates. On an \(m\)-qubit register with \(M=2^m\), prepare the state

\[\ket\chi=\frac{1}{\sqrt M}\sum_{y=0}^{M-1}e^{-2\pi iy/M}\ket y.\]

Adding an integer \(v\) modulo \(M\) to this register multiplies it by a phase. Indeed, substituting \(z=y+v\bmod M\),

\[\frac{1}{\sqrt M}\sum_ye^{-2\pi iy/M}\ket{y+v}=\frac{1}{\sqrt M}\sum_ze^{-2\pi i(z-v)/M}\ket z=e^{2\pi iv/M}\ket\chi.\]

The phase is consistent modulo \(M\) because \(e^{-2\pi iM/M}=1\). So \(\ket\chi\) is an eigenstate of “add \(v\)”, with eigenvalue \(e^{2\pi iv/M}\). Section 3.1.1 then says what to do: control the addition by the input. If a clean computation produces \(v(x)\) and we add it into \(\ket\chi\), the phase \(e^{2\pi iv(x)/M}\) is kicked back onto \(\ket x\), and \(\ket\chi\) is untouched.

This construction, sometimes called the phase-gradient trick, turns an adder into a bank of phase rotations. The state \(\ket\chi\) is prepared once and reused for every query, since it is never changed. It is a Fourier state: Chapter 4 shows it is the quantum Fourier transform of a basis state. The cost is a reversible adder per phase operation plus a one-time preparation.

  1. For \(m=1\) (\(M=2\)), what is \(\ket\chi\), and what does “add \(v\) mod 2” do to it?

    \(\ket\chi=\frac{1}{\sqrt2}(\ket0-\ket1)=\ket-\). Adding \(v\) mod 2 is \(X^v\), which multiplies \(\ket-\) by \((-1)^v=e^{2\pi iv/2}\). This is exactly the \(\ket-\) target of Chapter 1.

  2. For \(M=4\), verify by direct calculation that adding \(1\) maps \(\ket\chi\) to \(i\ket\chi\).

    \(\ket\chi=\frac12(\ket0-i\ket1-\ket2+i\ket3)\). Adding \(1\) gives \[\frac12(\ket1-i\ket2-\ket3+i\ket0)=\frac12(i\ket0+\ket1-i\ket2-\ket3)=i\cdot\frac12(\ket0-i\ket1-\ket2+i\ket3)\].

  3. Why must the adder be exactly modulo \(M\) for the trick to work? What happens with an adder into an \((m+1)\)-bit register that does not wrap?

    The proof substitutes \(z=y+v\bmod M\) and uses \(e^{-2\pi iM/M}=1\). Without wrapping, terms with \(y+v\ge M\) land outside the original register’s support, so the result is not proportional to \(\ket\chi\): the target changes and becomes entangled with \(v\), leaving a record.

Phases computed to finitely many bits are approximate. How much does that phase error matter? Suppose the intended phase oracle multiplies \(\ket x\) by \(e^{i\phi(x)}\), but the implementation uses \(\tilde\phi(x)\) with \(|\phi(x)-\tilde\phi(x)|\le\delta\) for every \(x\). On a basis state the error is

\[|e^{i\phi}-e^{i\tilde\phi}|=2\left|\sin\frac{\phi-\tilde\phi}{2}\right|\le|\phi-\tilde\phi|\le\delta.\]

On a normalized superposition \(\sum_x\alpha_x\ket x\), the error vector has squared length \(\sum_x|\alpha_x|^2|e^{i\phi(x)}-e^{i\tilde\phi(x)}|^2\le\delta^2\). So the state error is at most \(\delta\), for every input state. The largest such error over all normalized inputs is the operator norm of the difference of the two operations, here at most \(\delta\). Rounding \(\phi\) to the nearest multiple of \(2\pi/M\) gives \(\delta\le\pi/M\), so \(m=\log_2M\) bits give error \(O(2^{-m})\).

Errors add when operations are composed. If two operations have errors \(\delta_1\) and \(\delta_2\) in operator norm, their product has error at most \(\delta_1+\delta_2\): unitary operations preserve lengths, so an error introduced early is not amplified later. An algorithm using \(q\) approximate phase oracles therefore has total error at most \(q\delta\). To keep the total below \(\epsilon\), each oracle needs \(\delta\le\epsilon/q\), which costs only \(\log_2(q/\epsilon)\) bits of phase precision.

Precision is not the only failure mode. Every construction in this section computes an intermediate value and must uncompute it; a forgotten uncomputation leaves a record, and the phases become useless no matter how precise they are (Problem 3 of Section 3.4.1). With clean phase oracles of known precision in hand, we can ask what structured phase patterns reveal. Chapter 4 shows that patterns \(e^{2\pi ixy/N}\) are read by the quantum Fourier transform, which turns periodicity into a measurable frequency.

  1. An algorithm makes \(1000\) phase-oracle calls and needs total error at most \(10^{-3}\). How many bits of phase precision suffice per call?

    Each call needs \(\delta\le10^{-6}\). Rounding to \(m\) bits gives \(\delta\le\pi/2^m\), so \(2^m\ge\pi\times10^6\), \(m\ge22\).

  2. Show that the product of two operations with errors \(\delta_1\), \(\delta_2\) has error at most \(\delta_1+\delta_2\). Write the approximations as \(\tilde A=A+E\), \(\tilde B=B+F\) with \(A,B,\tilde A\) unitary.

    \[\tilde A\tilde B-AB=\tilde A(\tilde B-B)+(\tilde A-A)B=\tilde AF+EB\]. Since \(\tilde A\) and \(B\) are unitary they preserve lengths, so \(\|\tilde AF\psi\|=\|F\psi\|\le\delta_2\) and \(\|EB\psi\|\le\delta_1\) for normalized \(\psi\). The triangle inequality gives \(\delta_1+\delta_2\).

  3. If phase errors are random and independent across calls rather than worst-case, the total error often grows like \(\sqrt q\delta\) instead of \(q\delta\). Why should a resource estimate still usually state the worst-case bound?

    The \(\sqrt q\) behavior needs an assumption about the error distribution (independence, zero mean) that a deterministic rounding procedure need not satisfy: rounding errors can be systematic and add coherently. The linear bound holds unconditionally. A paper may use the statistical estimate if it states and justifies the assumption.
