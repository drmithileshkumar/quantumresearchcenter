Every oracle in Chapter 1 was handed to us as a perfect box. Real algorithms must build their oracles from gates, usually from an ordinary description of a function: a formula, a comparison, a piece of arithmetic. This section states exactly what a coherent function evaluation must do, shows how irreversible logic is made reversible, and runs a small arithmetic circuit on a superposition.

Suppose a search procedure must recognize three-bit strings satisfying \(f(a,b,c)=(a\land b)\oplus c\). In an ordinary program we would compute \(g=a\land b\), combine it with \(c\), and throw \(g\) away. In a quantum algorithm, throwing away is not an operation we have. Worse, Section 1.3.2 showed that a leftover bit which depends on the input can silently destroy interference. So before building anything, we state precisely what the finished subroutine is allowed to leave behind.

For an \(n\)-bit input \(x\) and an \(m\)-bit value \(f(x)\), the clean oracle contract is

\[\ket{x}\ket{y}\ket{0^w}\longmapsto\ket{x}\ket{y\oplus f(x)}\ket{0^w}\quad\text{for every }x\in\{0,1\}^n,\ y\in\{0,1\}^m.\]

The three registers have distinct roles. The input \(x\) is preserved. The output target \(y\) may start in any state, and \(f(x)\) is added into it bit by bit with XOR. The workspace, \(w\) ancilla qubits used as scratch, must start in \(\ket{0^w}\) and must be returned to \(\ket{0^w}\). The equation must hold exactly, including phase, on every basis state. Once it does, linearity fixes the action on every superposition:

\[\sum_{x,y}\alpha_{x,y}\ket{x}\ket{y}\ket{0^w}\longmapsto\sum_{x,y}\alpha_{x,y}\ket{x}\ket{y\oplus f(x)}\ket{0^w}.\]

Why keep \(x\)? Because the naive map \(\ket{x}\mapsto\ket{f(x)}\) is not reversible whenever two inputs share a value: it would send two orthogonal states to the same state. Preserving \(x\) and adding into a separate target makes the map a permutation of basis states for every \(f\). Applying it twice restores \(y\), since \(y\oplus f(x)\oplus f(x)=y\).

Why insist on returning the workspace? Because the workspace is outside the contract’s promise to the caller. A caller who uses the oracle inside an interference experiment, as Deutsch’s algorithm did, needs the branches for different \(x\) to differ only in what the contract says. Any extra input-dependent record in the workspace would be a which-path record.

  1. Write the clean contract for \(f(a,b)=a\land b\) with one output qubit and no workspace, and check that applying the map twice is the identity.

    \(\ket{a}\ket{b}\ket{y}\mapsto\ket{a}\ket{b}\ket{y\oplus ab}\). Applying it twice gives \(y\oplus ab\oplus ab=y\). This is exactly the Toffoli gate.

  2. An implementation of a predicate maps \(\ket{x}\ket{0}\ket{0}\mapsto\ket{x}\ket{f(x)}\ket{g(x)}\), where \(g\) is some intermediate value. For which functions \(g\) does it satisfy the clean contract with one ancilla?

    Only when \(g(x)=0\) for every \(x\). The contract requires the ancilla to return to \(\ket0\) on every basis input. Even a constant \(g\equiv1\) violates it as stated, though in that special case a single \(X\) gate would repair it because the record carries no information about \(x\).

  3. The contract demands that the map hold on all basis states with the stated phase. Give a map that sends every basis state \(\ket{x}\ket{y}\) to \(\ket{x}\ket{y\oplus f(x)}\) up to a phase \(e^{i\theta(x)}\) depending on \(x\), and explain why it does not satisfy the contract.

    For example \(\ket{x}\ket{y}\mapsto(-1)^{x_1}\ket{x}\ket{y\oplus f(x)}\). On any single basis state it looks correct, since a phase on one basis state is unobservable. On a superposition of inputs, however, it multiplies different branches by different signs, which changes later interference: in the Deutsch circuit it would flip the answer whenever \(x_1\) differs between the two inputs. Relative phases between basis inputs are part of what a unitary does, so the contract fixes them.

How do we build a clean oracle from an ordinary description of \(f\)? Any Boolean function has a circuit of AND, OR, and NOT gates. NOT is already reversible. AND is not: three of its four inputs give output \(0\). The Toffoli gate fixes this by keeping both inputs and adding the AND into a target,

\[\mathrm{TOF}\ket{a}\ket{b}\ket{t}=\ket{a}\ket{b}\ket{t\oplus ab}.\]

With \(t=0\), the target becomes \(ab\). OR follows from De Morgan’s law, \(a\lor b=\lnot(\lnot a\land\lnot b)\), so it costs a Toffoli and some \(X\) gates. XOR into an existing bit is a CNOT. So translate the circuit gate by gate: every AND or OR gets a fresh ancilla initialized to \(0\) as its target.

The translation works, but it leaves a trail. Every intermediate gate value now sits in its own ancilla. For our predicate \(f=(a\land b)\oplus c\), a direct translation computes \(g=ab\) into one ancilla, then \(t=g\oplus c\) into another:

The final values \((a,b,c,g,t)=(a,b,c,ab,f(a,b,c))\) contain the answer, but also the intermediate value \(ab\). That extra, input-dependent data is called garbage. In a classical computer garbage is merely wasteful; it can be overwritten later. In a quantum computer garbage is a which-path record that prevents the branches it distinguishes from interfering. The next section removes it.

A word on size. If the original circuit has \(G\) AND/OR gates, the direct translation uses \(G\) Toffolis and up to \(G\) ancillas, plus \(X\) and CNOT gates. The number of qubits can therefore grow with the running time of the classical computation, not just with its memory. Section 2.3 returns to this.

  1. Construct \(a\lor b\) into a fresh ancilla using one Toffoli and \(X\) gates, restoring \(a\) and \(b\) afterwards.

    Apply \(X\) to \(a\) and \(b\), Toffoli into the ancilla (now holding \(\bar a\bar b\)), \(X\) on the ancilla (now \(1\oplus\bar a\bar b=a\lor b\)), and \(X\) on \(a\) and \(b\) again to restore them. Five \(X\) gates and one Toffoli.

  2. Translate \(f(a,b,c)=(a\land b)\lor c\) directly into reversible gates. How many ancillas and Toffolis does the direct translation use, and what garbage remains?

    One Toffoli computes \(g=ab\) into ancilla 1. The OR \(g\lor c\) uses a second Toffoli (with \(X\) gates on \(g\) and \(c\) around it) into ancilla 2, followed by \(X\) on ancilla 2. Two ancillas, two Toffolis. Ancilla 2 holds \(f\); ancilla 1 holds the garbage \(ab\).

  3. Why can we not simply apply a “reset to \(0\)” operation to the garbage ancilla at the end of the circuit?

    Reset is not unitary: it maps both \(\ket0\) and \(\ket1\) to \(\ket0\). Physically it can be done by measuring and flipping, but measuring the garbage collapses the input superposition onto inputs consistent with the outcome, and discarding it without measuring leaves the input entangled with the environment. Either way the coherent superposition the algorithm needs is destroyed. Garbage must be removed reversibly.

A reversible circuit applies the same gate sequence to every basis component, so a classical reversible computation becomes a quantum one by linearity. Reversible arithmetic is the most important case: phase estimation, period finding, and amplitude estimation all need it.

Start with incrementing a two-bit register \(\ket{b_1b_0}\), where \(b_1\) is the high bit. Apply a CNOT from \(b_0\) to \(b_1\), then an \(X\) on \(b_0\). The CNOT flips the high bit exactly when the low bit is \(1\), which is when adding one produces a carry; the \(X\) then flips the low bit. Check all four inputs:

\[00\mapsto01,\qquad01\mapsto10,\qquad10\mapsto11,\qquad11\mapsto00.\]

This is modular addition: adding one modulo four. The word modulo specifies what happens on overflow: \(3+1\) wraps to \(0\) rather than needing a third bit. That wrap-around is what makes the map a permutation, and hence reversible.

On a superposition, nothing new is needed: \((\ket{00}+i\ket{11})/\sqrt2\mapsto(\ket{01}+i\ket{00})/\sqrt2\). No measurement, no classical branching. Reversing the gate order gives the inverse, subtraction of one.

The \(n\)-bit incrementer follows the same idea. Process target bits from highest to lowest: flip bit \(j\) if all lower bits are \(1\), then finally flip bit \(0\). Descending order matters, because each controlled flip reads the lower bits before they change. Bit \(j\) needs a \(j\)-controlled \(X\), which is not an elementary gate; with one or more ancillas it decomposes into \(O(j)\) Toffolis, so the whole incrementer costs \(O(n^2)\) Toffolis this way, and more careful constructions reach \(O(n)\). More generally, reversible adders computing \(\ket{a}\ket{b}\mapsto\ket{a}\ket{a+b\bmod2^n}\) are known with \(O(n)\) Toffoli and CNOT gates and one ancilla, for example the ripple-carry adder of Cuccaro, Draper, Kutin, and Moulton (2004). Modular multiplication and exponentiation, built from repeated addition, are the dominant cost of Shor’s algorithm in Chapter 4.

  1. Apply the two-bit incrementer to \(\frac12(\ket{00}+\ket{01}+\ket{10}+\ket{11})\). What changes?

    Each basis state maps to the next one mod 4, so the uniform superposition maps to itself. A permutation of basis states leaves the uniform superposition invariant; its effect becomes visible only on nonuniform amplitudes or phases.

  2. Reverse the two gates of the incrementer (first \(X\) on \(b_0\), then CNOT from \(b_0\) to \(b_1\)). What map results?

    \(00\to01\to11\), \(01\to00\to00\), \(10\to11\to01\), \(11\to10\to10\). That is \(0\to3\), \(1\to0\), \(2\to1\), \(3\to2\): subtraction of one mod 4. Each gate is self-inverse, but their ordered product is not, and reversing the order inverts it.

  3. Write a gate sequence for a three-bit incrementer using Toffoli, CNOT, and \(X\), and verify it on input \(011\).

    Toffoli with controls \(b_1,b_0\) targeting \(b_2\); CNOT from \(b_0\) to \(b_1\); \(X\) on \(b_0\). On \(011\): the Toffoli sees \(b_1=b_0=1\) and flips \(b_2\), giving \(111\); the CNOT flips \(b_1\), giving \(101\); the \(X\) flips \(b_0\), giving \(100\). That is \(3+1=4\). Doing the CNOT before the Toffoli would be wrong: \(b_1\) would already be changed when the Toffoli reads it.

The direct translation left garbage. Erasing it by measurement or reset would destroy coherence. The way out, discovered for classical reversible computing before quantum computing existed, is to keep the answer and then run the computation backwards. This section develops that pattern, turns it into a phase oracle, and shows concretely what happens if it is skipped.

Let \(C\) be the garbage-producing circuit of Section 2.1.2: Toffoli from \(a,b\) into \(g\), CNOT from \(g\) into \(t\), CNOT from \(c\) into \(t\). Afterwards \(g=ab\) and \(t=f(a,b,c)\). Now do three things.

  1. Compute: apply \(C\).
  2. Copy: CNOT from \(t\) into the external target \(y\).
  3. Uncompute: apply \(C^{-1}\), the gates of \(C\) in reverse order (each is its own inverse).

For a basis input \(x=(a,b,c)\), with register order \((x,g,t,y)\),

\[\ket{x,0,0,y}\xrightarrow{C}\ket{x,ab,f(x),y}\xrightarrow{\text{copy}}\ket{x,ab,f(x),y\oplus f(x)}\xrightarrow{C^{-1}}\ket{x,0,0,y\oplus f(x)}.\]

Why does the last step clear the workspace without disturbing \(y\)? Because \(C^{-1}\) does not touch \(y\), and the registers it does touch, \((x,g,t)\), are exactly as \(C\) left them: the copy only read \(t\). Undoing \(C\) on its own output returns its own input, \((x,0,0)\). The input \(x\) is what makes this possible, since it still contains everything needed to recompute and hence un-recompute the intermediate values.

Run the circuit on \((\ket{000}+\ket{110})/\sqrt2\) with \(g=t=y=0\). What is the state after the copy, and after uncomputation?

The inputs have \(f=0\) and \(f=1\). After compute and copy: \(\frac{1}{\sqrt2}(\ket{000}\ket0\ket0\ket0+\ket{110}\ket1\ket1\ket1)\). After uncomputation: \(\frac{1}{\sqrt2}(\ket{000}\ket0\ket0\ket0+\ket{110}\ket0\ket0\ket1)\). The workspace now factors out as \(\ket{00}\); only the requested output still distinguishes the branches.

This compute–copy–uncompute pattern is due to Bennett, Logical Reversibility of Computation (1973), who used it to show that any classical computation can be made reversible without accumulating garbage. Nothing in the argument depends on the input being a basis state, so by linearity it gives a clean quantum oracle. Notice what is not cleared: the output target still records \(f(x)\). Uncomputation removes everything the contract did not ask for and nothing it did.

  1. Trace the six registers through the circuit for input \(x=111\), \(y=0\).

    Compute: \(g=1\), then \(t=g\oplus c=0\). So \(f(111)=0\) and the state is \(\ket{111,1,0,0}\). Copy: \(y=0\). Uncompute: \(t\leftarrow t\oplus c=1\), \(t\leftarrow t\oplus g=0\), \(g\leftarrow g\oplus ab=0\). Final \(\ket{111,0,0,0}\), matching \(f(111)=0\).

  2. Count the gates in compute–copy–uncompute for this predicate and compare with the direct construction (Toffoli into \(y\), then CNOT from \(c\) into \(y\)).

    Compute–copy–uncompute: 2 Toffolis and 5 CNOTs on 6 qubits. Direct: 1 Toffoli and 1 CNOT on 4 qubits. Both satisfy the clean contract. The pattern is a general method that always works, not an optimal construction for every function.

  3. Does the copying CNOT violate the no-cloning theorem? Consider its action on \(\alpha\ket0+\beta\ket1\) in the \(t\) register.

    No. On \(\alpha\ket0+\beta\ket1\) with target \(\ket0\) it produces \(\alpha\ket{00}+\beta\ket{11}\), not \((\alpha\ket0+\beta\ket1)\otimes(\alpha\ket0+\beta\ket1)\). It copies basis values, creating correlation, not independent copies of an arbitrary state. That is exactly what the contract asks for: a coherent record of the classical value \(f(x)\) in each branch.

Chapter 1 used the phase oracle \(\ket{x}\mapsto(-1)^{f(x)}\ket{x}\). With a clean evaluation it comes for free: initialize the external target in \(\ket-\). The copy step is then a CNOT into \(\ket-\), which multiplies by \((-1)^{t}\) and leaves the target in \(\ket-\). After uncomputation,

\[\sum_x\alpha_x\ket{x}\ket{0^w}\ket-\longmapsto\sum_x\alpha_x(-1)^{f(x)}\ket{x}\ket{0^w}\ket-.\]

Both the workspace and the target factor out, unchanged. On the two-input example, \((\ket{000}+\ket{110})/\sqrt2\) becomes \((\ket{000}-\ket{110})/\sqrt2\). The sign is now a relative phase between input branches, available to later interference, with nothing else distinguishing them.

There is a slightly cheaper variant. Instead of copying into a \(\ket-\) target, apply a \(Z\) gate to \(t\) directly: \(Z\ket{t}=(-1)^t\ket t\). Then uncompute. This saves the target qubit. For multi-bit outputs, a phase \(e^{i\phi(v)}\) depending on a computed value \(v\) can be applied by phase gates on the bits of \(v\), as Chapter 3 develops.

Either way, the phase oracle costs about twice the gates of computing \(f\), since the computation runs forwards and backwards. Counting a phase query as “one query” in an algorithm’s analysis is legitimate in the oracle model; in a gate count, each such query costs a compute and an uncompute.

  1. Verify the \(Z\)-variant on input \(110\): compute, apply \(Z\) to \(t\), uncompute. What phase appears?

    Compute gives \(g=1\), \(t=1\oplus0=1\). \(Z\) on \(t\) gives a factor \(-1\). Uncompute restores \(g=t=0\). The result is \(-\ket{110}\ket{00}\), matching \((-1)^{f(110)}=-1\).

  2. For a two-bit computed value \(v=2v_1+v_0\), give phase gates that apply \(e^{2\pi iv/4}\) before uncomputation.

    \(e^{2\pi iv/4}=e^{i\pi v_1}e^{i\pi v_0/2}\). Apply \(Z\) to \(v_1\) and \(S=\mathrm{diag}(1,i)\) to \(v_0\), then uncompute. Check: \(v=3\) gives \((-1)\cdot i=-i=e^{2\pi i\cdot3/4}\).

  3. A student applies \(Z\) to the garbage bit \(g=ab\) instead of \(t\), then uncomputes. What oracle is implemented, and could it ever be useful?

    The phase is \((-1)^{ab}\), a phase oracle for \(a\land b\) rather than for \(f\). It is a perfectly clean operation, just for a different function. Any intermediate value can be turned into a phase; the error is only in which one. This flexibility is useful: algorithms often need phases of intermediate quantities.

It is worth seeing the damage concretely, with an experiment that distinguishes clean from dirty oracles. Prepare the input \((\ket{000}+\ket{110})/\sqrt2\) and run the phase-oracle construction twice: once with uncomputation, once without.

Clean. The input becomes \((\ket{000}-\ket{110})/\sqrt2\), with workspace \(\ket{00}\). Now apply a CNOT from the first input bit to the second, giving \((\ket{000}-\ket{100})/\sqrt2=\ket-\ket{00}\), and a Hadamard on the first bit. The first bit becomes \(\ket1\) with certainty.

Dirty. Without uncomputation the state is \((\ket{000}\ket{00}-\ket{110}\ket{11})/\sqrt2\). The same CNOT gives \((\ket{000}\ket{00}-\ket{100}\ket{11})/\sqrt2\). The two branches now differ in the workspace, \(\ket{00}\) versus \(\ket{11}\). The Hadamard on the first bit produces amplitudes \(\pm\frac12\) on four distinct complete configurations, and nothing cancels: the first bit is a fair coin.

From the input register’s point of view, the dirty state is indistinguishable from a random mixture: half the time \(\ket{000}\), half the time \(-\ket{110}\). The relative sign that the algorithm worked to create is no longer accessible to any operation on the input alone. Garbage behaves exactly like an environment that has measured the branch. This is why every oracle in the rest of the course is assumed clean, and why constructing one costs uncomputation.

  1. In the dirty case, compute the probability that the first input bit reads \(0\) after the CNOT and Hadamard, by listing the final amplitudes.

    After the CNOT, \((\ket{0}\ket{00}\ket{00}-\ket{1}\ket{00}\ket{11})/\sqrt2\) (first bit, other input bits, workspace). The Hadamard gives \(\frac12(\ket0+\ket1)\ket{00}\ket{00}-\frac12(\ket0-\ket1)\ket{00}\ket{11}\). The first bit is \(0\) with amplitudes \(\frac12\) (workspace \(00\)) and \(-\frac12\) (workspace \(11\)) on different configurations, so the probability is \(\frac14+\frac14=\frac12\).

  2. Suppose the garbage happened to be the same for both inputs, for instance \(g(x)=0\) on both. Would the dirty oracle still fail the test?

    No. If the workspace is identical on both branches, it factors out and interference proceeds as in the clean case. Garbage is harmful precisely to the extent that it distinguishes branches meant to interfere. A rigorous contract demands all-zero workspace because the oracle’s caller cannot know which branches will be combined.

  3. Could a later step “fix” the dirty state by applying \(C^{-1}\) after the Hadamard instead of before it?

    Not in general. \(C^{-1}\) is correct only when applied to registers in the state \(C\) produced. The Hadamard and CNOT have changed the input bits, so \(C^{-1}\) now reads different controls and does not clear the workspace. The order matters: uncompute while the inputs are still as the computation left them, then interfere.

Clean evaluation always works, but it is not free. It doubles gate counts, and the direct translation can demand as many ancillas as the original computation had gates. This section counts those costs and shows how time can be traded for space.

Suppose a reversible circuit \(C\) uses \(T\) gates, preserves its input, and computes an \(m\)-bit answer together with garbage. The gate count of compute–copy–uncompute is

\[T\ (\text{compute})+m\ (\text{copy CNOTs})+T\ (\text{uncompute})=2T+m\ \text{gates},\]

using the same workspace as \(C\) plus an \(m\)-qubit target. This is a construction bound, not a lower bound; clever circuits often do better. But it is a uniform bound: whatever classical algorithm computes \(f\) in \(T\) reversible gates, a clean quantum oracle costs about \(2T\).

What counts as one gate? In fault-tolerant quantum computers, the expensive operation is usually the \(T\) gate, \(T=\mathrm{diag}(1,e^{i\pi/4})\), not the CNOT. A Toffoli is not elementary there. A standard decomposition uses two Hadamards, six CNOTs, and seven \(T\) or \(T^\dagger\) gates. So a resource estimate might report Toffoli count or \(T\) count separately from CNOT count and depth. Multi-controlled gates must also be decomposed: a \(k\)-controlled \(X\) needs on the order of \(k\) Toffolis with \(k-2\) clean ancillas.

The lesson for reading algorithm papers is to check the unit. “\(O(n^2)\) gates” might count Toffolis, two-qubit gates, or \(T\) gates, and the conversions between them are constant factors that can be large in practice. A box in a circuit diagram labelled “\(U_f\)” or “modular exponentiation” might contain millions of elementary gates.

  1. A classical reversible circuit for \(f\) uses 1000 Toffolis and 3000 CNOTs and outputs 16 bits. Estimate the Toffoli and CNOT counts of a clean oracle built by compute–copy–uncompute.

    2000 Toffolis and \(6000+16=6016\) CNOTs. As a phase oracle via \(Z\) gates on a one-bit output, the copy step is replaced by one \(Z\); the counts are then 2000 Toffolis and 6000 CNOTs.

  2. Using the decomposition above, convert 2000 Toffolis into \(T\)-gate and CNOT counts.

    \(7\times2000=14{,}000\) \(T\)/\(T^\dagger\) gates and \(6\times2000=12{,}000\) additional CNOTs (plus 4000 Hadamards). Better decompositions exist for Toffolis that are later uncomputed, since a Toffoli followed by its inverse can share work; this is one reason exact counts depend on the construction.

  3. Two papers report “\(10^6\) gates” and “\(10^5\) gates” for the same oracle. What questions must you ask before concluding the second is ten times cheaper?

    Which gate set each counts (Clifford+\(T\), Toffoli+CNOT, arbitrary two-qubit gates), whether the counts include uncomputation, how many qubits each uses (a time–space tradeoff may explain the difference), whether depth or count is reported, and whether both implement the same contract (clean versus leaving garbage, exact versus approximate arithmetic).

The direct translation keeps every intermediate value until the end, so its workspace grows with the number of gates. For a long computation that is prohibitive. Can we free intermediate values earlier?

Consider a computation in stages: \(u_1=F_1(x)\), \(u_2=F_2(u_1)\), \(u_3=F_3(u_2)\), and so on up to \(u_k\). To compute \(u_3\) we need \(u_2\), but once \(u_3\) exists, \(u_2\) could be uncomputed, provided \(u_1\) is still present, because uncomputing \(u_2=F_2(u_1)\) requires \(u_1\). Then, to clear \(u_1\) later, we need \(x\). Clearing a value early saves space, but if a later uncomputation needs it, we must recompute it, which costs time. This is a time–space tradeoff.

This bookkeeping is a game called pebbling. Place a pebble on stage \(i\) (compute \(u_i\)) only if stage \(i-1\) has a pebble; remove it (uncompute) under the same condition. The goal is to end with pebbles on \(x\) and \(u_k\) only. Keeping everything uses \(k\) pebbles and \(2k\) moves. A recursive strategy does better on space: to reach stage \(k\), pebble stage \(k/2\), use it to pebble \(k\), then unpebble \(k/2\) by running the first half backwards. Each level of recursion triples the work and adds one pebble.

Bennett showed in 1989 that a computation using time \(T\) and space \(S\) can be made reversible in time \(O(T^{1+\epsilon})\) and space \(O(S\log T)\) for any fixed \(\epsilon>0\) (Bennett, Time/Space Trade-Offs for Reversible Computation). Practical quantum compilers use similar schedules, choosing when to uncompute to fit within a qubit budget. The central constraint is always the same: a value can be uncomputed only while the values it was computed from are still present, and the operations between compute and uncompute must leave those values unchanged.

  1. For a chain of \(k=4\) stages, give a pebbling that ends with pebbles only on \(u_4\) (besides \(x\)) and never uses more than three pebbles at once. Compare with keeping everything.

    Write \(+i\) for computing \(u_i\) and \(-i\) for uncomputing it. The sequence \(+1,+2,-1,+3,+4,-3,+1,-2,-1\) is valid: each move on stage \(i\) happens while stage \(i-1\) (or \(x\), for \(i=1\)) holds a pebble. The pebble sets are \[\{1\},\{1,2\},\{2\},\{2,3\},\{2,3,4\},\{2,4\},\{1,2,4\},\{1,4\},\{4\}\]: at most three, in 9 moves. Keeping everything uses four pebbles and 7 moves (\(+1,+2,+3,+4,-3,-2,-1\)). A search over all schedules shows that two pebbles cannot reach stage 4 at all.

  2. In the incorrect sequence “CNOT \(x\to g\); \(X\) on \(x\); CNOT \(x\to g\)”, intended to compute and then uncompute \(g=x\), what is left in \(g\)?

    After the first CNOT, \(g=x\). After the flip, the input is \(x\oplus1\). The second CNOT gives \(g=x\oplus(x\oplus1)=1\), not \(0\). The operation between compute and uncompute changed the value the uncomputation depends on.

  3. Why is the recursive pebbling strategy more important for quantum computers than for classical reversible hardware?

    Qubits are a scarce resource: early fault-tolerant machines will have limited numbers of logical qubits, each costing many physical qubits. Classical computers can simply erase garbage at an energy cost, so they rarely need reversibility at all. A quantum computer must stay reversible to preserve coherence, so the space cost of garbage is unavoidable unless traded for time.

A reusable subroutine needs more than a forward action. Later algorithms reflect about prepared states, apply controlled powers, and hand states to other routines. Each of these needs a specific form of access, and each has a construction cost when the subroutine is built from gates.

A preparation circuit \(A\) is a unitary with \(A\ket{0^n}=\ket\psi\). If its gates are known, reversing their order and inverting each gives \(A^\dagger\), which maps \(\ket\psi\) back to \(\ket{0^n}\). A supplied copy of \(\ket\psi\) does not give us this; neither does a box that applies \(A\) but cannot be run backwards.

Why would we want \(A^\dagger\)? To reflect about \(\ket\psi\). Let \(S_0=2\ket{0^n}\bra{0^n}-I\), which leaves \(\ket{0^n}\) unchanged and negates every orthogonal basis state. Then

\[R_\psi=A\,S_0\,A^\dagger=2\ket\psi\bra\psi-I.\]

Check on two kinds of input. On \(\ket\psi\): \(A^\dagger\) sends it to \(\ket{0^n}\), \(S_0\) leaves it, \(A\) restores \(\ket\psi\). On a state \(\ket\phi\) orthogonal to \(\ket\psi\): \(A^\dagger\ket\phi\) is orthogonal to \(\ket{0^n}\), because \(A^\dagger\) preserves inner products, so \(S_0\) negates it and \(A\) returns \(-\ket\phi\). A reflection about \(\ket\psi\) is exactly the map that fixes \(\ket\psi\) and negates everything orthogonal to it.

The zero-state reflection \(S_0\) itself is a clean phase oracle for the predicate “\(x\neq0^n\)”: it is \(-\)(phase oracle of \(x=0^n\)), which differs by a global sign. With \(X\) gates on every qubit and an \(n\)-controlled \(Z\), it costs \(O(n)\) Toffolis. Chapter 5 uses \(R_\psi\) to amplify success probabilities, at the cost of one \(A\) and one \(A^\dagger\) per reflection.

  1. For one qubit with \(A=H\), compute \(R_\psi=HS_0H\) as a matrix and identify it.

    \(S_0=\mathrm{diag}(1,-1)=Z\), so \(R_\psi=HZH=X\). Indeed \(X\) fixes \(\ket+\) and negates \(\ket-\): it is the reflection about \(\ket+\).

  2. Show that \(R_\psi^2=I\) and that \(R_\psi\) is Hermitian.

    \(R_\psi^2=4\ket\psi\braket{\psi}{\psi}\bra\psi-4\ket\psi\bra\psi+I=I\), using \(\braket\psi\psi=1\). And \((2\ket\psi\bra\psi-I)^\dagger=2\ket\psi\bra\psi-I\). Reflections are self-inverse, as geometric intuition suggests.

  3. Someone has a box \(B\) that outputs fresh copies of \(\ket\psi\) on demand, but no circuit for it. Can they implement \(R_\psi\) exactly?

    Not with the construction above, which needs \(A^\dagger\). With copies alone one can approximate \(e^{-i\ket\psi\bra\psi t}\) using many copies (a technique called density-matrix exponentiation), but not cheaply implement an exact reflection. Copies and a preparation circuit are different forms of access, and the algorithm must state which it assumes.

Phase estimation in Chapter 4 needs controlled-\(U\): apply \(U\) to a target register only on the branch where a control qubit is \(1\),

\[\mathrm{C}U=\ket0\bra0\otimes I+\ket1\bra1\otimes U.\]

Given a gate sequence \(U=G_k\cdots G_1\), we can build \(\mathrm{C}U\) by controlling each gate: \(\mathrm{C}U=\mathrm{C}G_k\cdots\mathrm{C}G_1\). This works because on the control-\(0\) branch every controlled gate does nothing, and on the control-\(1\) branch every one acts. A controlled single-qubit gate costs a few CNOTs and rotations; a controlled Toffoli is a three-controlled \(X\), and so on. So controlling a circuit multiplies its cost by a constant.

There is one subtlety. Uncontrolled, \(U\) and \(e^{i\theta}U\) are the same physical operation. Controlled, they differ: \(\mathrm{C}(e^{i\theta}U)=\mathrm{C}U\cdot(P(\theta)\otimes I)\), where \(P(\theta)=\mathrm{diag}(1,e^{i\theta})\) on the control. The global phase of \(U\) becomes a relative phase on the control. In phase estimation, that phase is exactly what is measured. So a controlled version is defined only once the global phase of \(U\) is fixed. A gate library that implements rotations “up to global phase” must be checked before its gates are controlled.

For a sealed box \(U\), no general procedure produces \(\mathrm{C}U\). This is a theorem, not a gap in our cleverness: given only black-box access to an unknown unitary, no circuit implements its controlled version, essentially because the box cannot reveal its own global phase (Araújo, Feix, Costa, and Brukner, 2014). Algorithms that need \(\mathrm{C}U\) must assume it as access, or construct \(U\) from known gates.

  1. Show that \(\mathrm{C}(-I)=Z\otimes I\) on a control and one target qubit.

    On control \(0\) nothing happens; on control \(1\) the target is multiplied by \(-1\). So \(\ket0\ket\phi\mapsto\ket0\ket\phi\) and \(\ket1\ket\phi\mapsto-\ket1\ket\phi\), which is \(Z\) on the control. Uncontrolled, \(-I\) does nothing observable; controlled, it is a \(Z\) gate.

  2. The rotation \(R_z(\theta)=\mathrm{diag}(e^{-i\theta/2},e^{i\theta/2})\) and the phase gate \(P(\theta)=\mathrm{diag}(1,e^{i\theta})\) differ by a global phase. What is the relative phase on the control between their controlled versions?

    \(P(\theta)=e^{i\theta/2}R_z(\theta)\). So \(\mathrm{C}P(\theta)=\mathrm{C}R_z(\theta)\cdot(P(\theta/2)\otimes I)\): the controlled versions differ by a phase gate \(P(\theta/2)\) on the control.

  3. In phase estimation, \(U\) has eigenvalue \(e^{2\pi i\phi}\) on \(\ket u\). If a compiler silently replaces \(U\) by \(e^{i\alpha}U\) before controlling it, what does phase estimation report?

    The eigenvalue becomes \(e^{i(2\pi\phi+\alpha)}\), so it reports \(\phi+\alpha/2\pi\) (mod 1). Every eigenphase shifts by the same amount. Differences between eigenphases are unaffected, but absolute phases, such as energies in Chapter 9, are wrong.

A clean oracle applied to a superposition produces \(\sum_x\alpha_x\ket{x}\ket{f(x)}\). It is tempting to say this “computes all values of \(f\).” It does not, in any sense a user can collect. Measuring yields one pair \((x,f(x))\) with probability \(|\alpha_x|^2\). Collecting all \(2^n\) values by repetition would take at least \(2^n\) runs, more than a classical program that simply evaluates each.

A state of this kind is useful only if the next coherent operation extracts a property from it: a phase pattern resolved by Hadamards (Chapter 3), a period resolved by a Fourier transform (Chapter 4), a marked component amplified by reflections (Chapter 5). The subroutine’s contract should therefore say what form its output takes and what the caller is expected to do with it.

We now have a concrete method for evaluating functions coherently, the costs it incurs, and the access a subroutine can offer: forward, inverse, controlled, and the reflection built from them. When the retained effect is a sign, the computation becomes a phase encoding. Chapter 3 uses phase encoding to recover a hidden string of any length and makes precise how a small interference example extends to a family.

  1. For \(n=10\) and the uniform superposition, how many runs of “evaluate and measure” are needed on average to see every input at least once?

    This is the coupon-collector problem: on average \(N(1+\frac12+\cdots+\frac1N)\approx N\ln N\) runs for \(N=1024\), about \(1024\times7.5\approx7700\). A classical program needs exactly 1024 evaluations.

  2. A subroutine’s output is “the state \(\sum_x\alpha_x\ket x\ket{f(x)}\) with a clean workspace.” Name two different follow-up operations from later chapters and the classical output each produces.

    (i) Uncompute and use the phase variant, then apply Hadamards and measure: Bernstein–Vazirani returns a hidden string \(s\) when \(f(x)=s\cdot x\). (ii) Measure the function register, then apply a Fourier transform to the input and measure: period finding returns a sample related to the period of \(f\). Each produces a short classical answer about a global property of \(f\), not the table of values.

  3. Why must a subroutine whose output is a quantum state specify its accuracy as a distance between states, rather than as an error in each amplitude?

    Small errors in each of \(2^n\) amplitudes can add up to a large total error, and errors in amplitudes that are tiny can be irrelevant. What matters for every later use is how different the measurement statistics can be, which is bounded by a state distance such as \(\|\ket\psi-\ket{\tilde\psi}\|\). For normalized states, a distance \(\|\ket\psi-\ket{\tilde\psi}\|\le\epsilon\) bounds the change in every outcome probability, for every measurement, by at most \(\epsilon\).
