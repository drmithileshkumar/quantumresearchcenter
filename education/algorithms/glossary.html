Reference

Glossary

Short definitions with links to the full explanations. A definition depends on the assumptions stated in its subsection.

1-norm

For a Hamiltonian written as Σ h_j P_j, the sum λ = Σ |h_j|, which is the LCU subnormalization and controls simulation cost.

Read the explanation →
Abelian group

A group in which the order of combination does not matter, a·b = b·a, such as bit strings under XOR or integers modulo N under addition.

Read the explanation →
Adiabatic evolution

Evolution under a slowly varying Hamiltonian H(s), which keeps a system near the instantaneous ground state when the change is slow compared with the gap.

Read the explanation →
Adiabatic optimization

Encoding an optimization problem’s cost in a final Hamiltonian and evolving adiabatically from an easy initial Hamiltonian.

Read the explanation →
Adiabatic theorem

A result giving conditions, in terms of the gap and the rate of change of H(s), under which evolution follows an instantaneous eigenstate.

Read the explanation →
Amplitude amplification

Repeated application of Q = R_ψ S_G, which rotates a prepared state by 2θ toward the good subspace, raising success from sin²θ to sin²((2k+1)θ).

Read the explanation →
Amplitude estimation

Phase estimation applied to the Grover iterate, estimating p to precision ε with O(1/ε) calls to A and A†.

Read the explanation →
Ancilla

An auxiliary qubit, usually initialized to |0⟩, used as scratch space by a subroutine.

Read the explanation →
Ansatz

The chosen structure of a parameterized circuit, encoding an assumption about where good answers lie.

Read the explanation →
Approximate QFT

The Fourier transform circuit with small-angle rotations omitted. Keeping rotations down to 2π/2^b gives error below 2πn/2^b with O(nb) gates.

Read the explanation →
Approximation error

The operator-norm distance between an implemented operation or block and the intended one.

Read the explanation →
Balanced function

A Boolean function that takes the value 1 on exactly half of its inputs.

Read the explanation →
Ballistic spreading

Growth of a walk’s typical distance linearly in time, as in quantum walks on a line.

Read the explanation →
Barren plateau

A parameter landscape whose gradients are exponentially small in the number of qubits, making training require exponentially many shots.

Read the explanation →
Benchmarking

Comparing an algorithm’s performance with strong alternatives across instance sizes, with full resource accounting.

Read the explanation →
Bernstein–Vazirani algorithm

A one-query algorithm that recovers a hidden string s from an oracle for f(x) = s·x by applying Hadamards, a phase query, and Hadamards. Classical algorithms need n queries.

Read the explanation →
Binary fraction

A number 0.b₁b₂…b_m = Σ b_j 2^{−j}. A phase e^{2πi·0.b₁b₂…} splits into one factor per bit.

Read the explanation →
Bit oracle

The oracle U_f|x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩, which adds the function value into a target register.

Read the explanation →
Bitwise inner product

x·z = x₁z₁ ⊕ … ⊕ xₙzₙ, the parity of the positions where two bit strings both have a 1.

Read the explanation →
Block encoding

A unitary U whose top-left block, with ancillas in |0⟩, equals A/α for a matrix A and subnormalization α ≥ ‖A‖.

Read the explanation →
Chebyshev polynomial

T_d(x) = cos(d arccos x), a degree-d polynomial bounded by 1 on [−1, 1]; the top-left entry of W(x)^d.

Read the explanation →
Chebyshev’s inequality

The bound Pr[|X − μ| > ε] ≤ Var(X)/ε². For an average of R independent bits it gives error probability at most 1/(4Rε²), so precision ε costs on the order of 1/ε² repetitions.

Read the explanation →
Classical baseline

The best known classical method for the same task, input model, and success criterion, against which a quantum method is compared.

Read the explanation →
Classical post-processing

The classical computation that turns measurement samples into the algorithm’s answer, such as solving equations or applying continued fractions.

Read the explanation →
Classical record

The bit string of measurement outcomes, stored classically and available to later operations.

Read the explanation →
Clean oracle

A coherent evaluation |x⟩|y⟩|0^w⟩ ↦ |x⟩|y ⊕ f(x)⟩|0^w⟩ that preserves its input, adds the answer into a target, and returns its workspace to zero on every basis input with no input-dependent phase.

Read the explanation →
Cluster state

An entangled resource state made by preparing qubits in |+⟩ and applying controlled-Z between neighbours on a graph.

Read the explanation →
Coherent access

Access in which one use of the input acts linearly on a superposition of questions, as a unitary operation. It is an assumption of the problem, not automatic.

Read the explanation →
Coherent sum

A superposition-based combination of operations that adds amplitudes, as opposed to a random choice that adds probabilities.

Read the explanation →
Coin register

The register in a coined walk that labels the direction of the next move, making the shift reversible.

Read the explanation →
Coined quantum walk

A discrete quantum walk on states |c, x⟩ that alternates a coin unitary on c with a shift of x conditioned on c.

Read the explanation →
Commutator

[A, B] = AB − BA. It vanishes when A and B commute and controls the error of product formulas.

Read the explanation →
Compute–copy–uncompute

Bennett’s pattern for clean reversible evaluation: compute the answer with garbage, copy the answer into a target, then run the computation backwards to clear the garbage.

Read the explanation →
Condition number

κ = σ_max/σ_min, the ratio of the largest to the smallest singular value of a matrix.

Read the explanation →
Continued fraction

A representation x = a₀ + 1/(a₁ + 1/(a₂ + …)) computed by Euclid’s algorithm. Its truncations are the convergents.

Read the explanation →
Continuous-time quantum walk

Evolution e^{−iHt} with H the (weighted) adjacency matrix of a graph.

Read the explanation →
Controlled access

The ability to apply a unitary conditioned on a control qubit. The global phase of the unitary then becomes physically significant.

Read the explanation →
Controlled phase gate

The two-qubit gate that multiplies |11⟩ by e^{iθ} and leaves other basis states unchanged. It is symmetric in its two qubits.

Read the explanation →
Controlled powers

The operations controlled-U^{2^j} used by phase estimation. By repetition they cost 2^m − 1 uses of controlled-U for m control qubits.

Read the explanation →
Controlled version

The operation |0⟩⟨0| ⊗ I + |1⟩⟨1| ⊗ U, which applies U only when a control qubit is 1. It depends on the global phase chosen for U.

Read the explanation →
Convergent

A fraction obtained by truncating a continued fraction. Any fraction p/q with |x − p/q| < 1/(2q²) is a convergent of x.

Read the explanation →
Coset

A shifted copy x·H of a subgroup H; in Simon’s problem the collision pair {x, x⊕s} is a coset of {0ⁿ, s}.

Read the explanation →
Cost function

The quantity a variational algorithm minimizes, usually an expectation value estimated by measurement.

Read the explanation →
Data loading

The process of turning classical data into a quantum state or a coherently queryable oracle. Its cost must be included in an end-to-end comparison.

Read the explanation →
Decision problem

A problem whose required output for each input is a single bit: yes or no.

Read the explanation →
Deferred measurement principle

A measurement followed by classically controlled operations gives the same output statistics as coherent control followed by measurement at the end.

Read the explanation →
Dequantization

Constructing classical algorithms that match a proposed quantum speedup when given comparable sampling access to the input.

Read the explanation →
Deutsch–Jozsa algorithm

A one-query quantum algorithm that decides whether an n-bit Boolean function promised to be constant or balanced is constant, by measuring the zero amplitude after Hadamards, a phase query, and Hadamards.

Read the explanation →
Deutsch’s problem

Given coherent access to a hidden function f from one bit to one bit, decide whether f(0) equals f(1). One quantum query suffices; two classical queries are necessary for an exact answer.

Read the explanation →
Diffusive spreading

Growth of a walk’s typical distance like √t, characteristic of classical random walks.

Read the explanation →
Dirty oracle

An oracle implementation that leaves input-dependent garbage in its workspace. It fails interference experiments that a clean oracle passes.

Read the explanation →
Eigenbasis expansion

Writing a state as a combination Σ c_s|u_s⟩ of eigenstates of an operator. Phase estimation then returns eigenphase φ_s with probability |c_s|².

Read the explanation →
Eigenstate

A state that an operation changes only by a factor: V|u⟩ = λ|u⟩. For a unitary V the eigenvalue λ has magnitude one.

Read the explanation →
Eigenvalue

The factor λ in V|u⟩ = λ|u⟩. For a unitary operation it is a phase e^{iφ}.

Read the explanation →
Eigenvalue transformation

A circuit that block-encodes f(H/α) = Σ f(λ_j/α)|v_j⟩⟨v_j| given a block encoding of H/α.

Read the explanation →
Element distinctness

Deciding whether a list of N items contains two equal entries; quantum walks solve it with O(N^{2/3}) queries, which is optimal.

Read the explanation →
Energy gap

The difference between the two smallest eigenvalues of a Hamiltonian, the energies of its ground state and first excited state.

Read the explanation →
Estimation problem

A problem whose required output is a number within a stated tolerance of a target quantity, with a stated failure probability.

Read the explanation →
Exact amplitude amplification

A modification of amplification, possible when p is known exactly, that reaches success probability exactly 1.

Read the explanation →
Expectation value

The average ⟨ψ|O|ψ⟩ of an observable’s measured values over many repetitions.

Read the explanation →
Exponential search

Amplification with a randomly chosen iteration count whose range grows geometrically, finding a marked item with O(1/√p) expected calls when p is unknown.

Read the explanation →
Expressiveness

The set of states a parameterized circuit can reach. Greater expressiveness costs more gates and parameters.

Read the explanation →
Factoring reduction

If r, the order of a mod L, is even and a^{r/2} ≢ −1, then gcd(a^{r/2} ± 1, L) are nontrivial factors of L.

Read the explanation →
Fair comparison

A comparison of methods at the same problem instance, error in the same norm, gate set, and access model, counting all overheads such as ancillas and rotation synthesis.

Read the explanation →
Feedforward

Using a mid-circuit measurement outcome to choose a later gate or measurement basis.

Read the explanation →
Fixed-point amplification

Amplification using modified phases so that success probability never decreases, whatever the unknown p.

Read the explanation →
Fourier mode

A Fourier basis state on a translation-invariant graph such as a cycle; each is an eigenvector of the adjacency matrix.

Read the explanation →
Fourier state

A state such as M^{−1/2} Σ_y e^{−2πiy/M}|y⟩, which is an eigenstate of adding a constant modulo M.

Read the explanation →
Frequency

An outcome of the Fourier transform. A pattern of period r in a register of size N produces frequencies at multiples of N/r.

Read the explanation →
Garbage

Input-dependent intermediate values left in the workspace by a reversible computation. In a quantum algorithm garbage acts as a which-path record.

Read the explanation →
Gate teleportation

Applying a gate by teleporting a state through an entangled resource and measuring in a chosen basis, followed by an outcome-dependent correction.

Read the explanation →
Global phase

A common factor e^{iθ} multiplying an entire state or operation. It has no observable effect unless the operation is controlled.

Read the explanation →
Glued trees

Two binary trees joined at their leaves by a random cycle, on which a continuous quantum walk traverses exponentially faster than any classical algorithm.

Read the explanation →
Good subspace

The span of basis states marked as successful by a predicate. Amplification increases the weight of a prepared state in this subspace.

Read the explanation →
Gradient descent

An optimization method that repeatedly moves parameters opposite to the gradient of the cost function.

Read the explanation →
Ground state

The eigenstate of a Hamiltonian with the lowest eigenvalue (energy).

Read the explanation →
Group

A set with an operation that is closed and associative, has an identity element, and gives every element an inverse; for example bit strings under XOR or integers modulo N under addition.

Read the explanation →
Grover iterate

The operator Q = R_ψ S_G, the product of a reflection about the marked subspace’s complement and a reflection about the prepared state.

Read the explanation →
Hadamard test

The circuit H, controlled-U, H, measure on a control qubit. Outcome 0 has probability (1 + Re⟨ψ|U|ψ⟩)/2.

Read the explanation →
Hadamard transform

The operation H^{⊗n}, which maps |x⟩ to 2^{−n/2} Σ_z (−1)^{x·z}|z⟩. It is its own inverse.

Read the explanation →
Hamiltonian

A Hermitian operator H that generates evolution e^{−iHt}; its eigenvalues are energies.

Read the explanation →
Hamiltonian simulation

Constructing a circuit V with ‖V − e^{−iHt}‖ ≤ ε for a given Hamiltonian H, time t, and error ε.

Read the explanation →
Hardware noise

Errors from decoherence and imperfect gates, which bias measured expectation values.

Read the explanation →
Heisenberg limit

Estimation error of order 1/N with N total uses of the evolution, achievable with coherent powers.

Read the explanation →
Heuristic

A procedure that may work well in practice without a proof of its performance.

Read the explanation →
Hidden string

An unknown bit string that determines an oracle’s behavior and that an algorithm must recover.

Read the explanation →
Hidden subgroup problem

Given a function on a group that is constant exactly on the cosets of an unknown subgroup, find the subgroup. Efficiently solvable by Fourier sampling for abelian groups.

Read the explanation →
Hitting time

The expected number of steps for a walk to first reach a marked set.

Read the explanation →
Input family

The set of all problem instances an algorithm must handle, usually indexed by a size parameter. Scaling claims are statements about the whole family.

Read the explanation →
Inverse access

The ability to apply the inverse of a given unitary. For a sealed box this is an additional assumption; for a known gate sequence it follows by reversing the gates.

Read the explanation →
Inverse quantum Fourier transform

F_N†, which maps the phase ramp N^{−1/2} Σ_k e^{2πijk/N}|k⟩ back to |j⟩.

Read the explanation →
Iterate eigenvalues

The eigenvalues e^{±2iθ} of the Grover iterate on the good–bad plane, which encode the success probability p = sin²θ.

Read the explanation →
Iterative phase estimation

Phase estimation with one control qubit, reading phase bits from last to first and using earlier outcomes to correct later stages.

Read the explanation →
Jacobi–Anger expansion

The Chebyshev expansion of cos(τx) and sin(τx) with Bessel-function coefficients, which decay rapidly beyond degree τ.

Read the explanation →
Johnson graph

The graph whose vertices are r-subsets of an N-element set, adjacent when they differ in one element.

Read the explanation →
Linear algebra over GF(2)

Solving linear equations in which variables are bits and addition is XOR. Gaussian elimination works as usual.

Read the explanation →
Linear combination of unitaries

A block encoding of Σ a_j U_j built from PREPARE, SELECT, and PREPARE†, with subnormalization Σ |a_j|.

Read the explanation →
Magic state

A resource state such as T|+⟩ that, consumed by Clifford operations and measurement, implements a non-Clifford gate.

Read the explanation →
Magic-state distillation

A Clifford-only protocol that converts many noisy magic states into fewer, higher-fidelity ones.

Read the explanation →
Majority vote

Combining independent runs of a decision algorithm by outputting the most common answer. It amplifies any fixed advantage over 1/2 exponentially in the number of runs.

Read the explanation →
Markov chain

A random process whose next state depends only on the current state, described by a transition matrix.

Read the explanation →
Measurement basis change

Single-qubit rotations applied before measurement so that a Pauli X or Y is measured as Z.

Read the explanation →
Measurement-based quantum computation

A model in which an entangled resource state is prepared in advance and the computation proceeds by adaptive single-qubit measurements.

Read the explanation →
Mid-circuit measurement

A measurement performed before the end of a computation, whose outcome can control later operations.

Read the explanation →
Minimum finding

The Dürr–Høyer algorithm, which finds the minimum of N values with O(√N) queries by repeated threshold searches.

Read the explanation →
Minimum gap

The smallest separation between the ground and first excited energies along an adiabatic path; runtime scales roughly as its inverse square.

Read the explanation →
Mixer

The non-commuting layer e^{−iβΣX_j} in QAOA that turns cost-dependent phases into changes of probability.

Read the explanation →
Mixing time

The number of steps a random walk needs for its distribution to come close to the stationary distribution; of order 1/δ for spectral gap δ.

Read the explanation →
Model error

The difference between a physical system and the Hamiltonian used to describe it, independent of the simulation algorithm.

Read the explanation →
Modular addition

Addition that wraps around at a fixed modulus, such as (a + b) mod 2ⁿ. The wrap-around keeps the map reversible on a fixed number of bits.

Read the explanation →
Modular exponentiation

The operation |k⟩|y⟩ ↦ |k⟩|a^k y mod L⟩, implemented by controlled multiplications by precomputed constants a^{2^j} mod L.

Read the explanation →
Monte Carlo estimation

Estimating an expected value by averaging random samples; precision ε costs order 1/ε² samples classically.

Read the explanation →
No fast-forwarding

The theorem that general Hamiltonians cannot be simulated for time t with a number of operations sublinear in t.

Read the explanation →
Non-unitary matrix

A matrix that changes the length of some vectors. It cannot be applied deterministically by a quantum circuit, only as a block of a larger unitary.

Read the explanation →
Oblivious amplitude amplification

Amplification of a block encoding of a scaled unitary using reflections on the ancillas only, so that it works for unknown input states.

Read the explanation →
Observable estimation

Estimating ⟨ψ|O|ψ⟩ from repeated measurements; operator-norm evolution error ε changes it by at most 2‖O‖ε.

Read the explanation →
One-bit teleportation

The two-qubit circuit (controlled-Z, then measurement at angle α) that moves a state to an auxiliary qubit while applying HP(−α) up to a Pauli X.

Read the explanation →
Operator norm

The largest factor by which an operator stretches a normalized vector: ‖A‖ = max ‖Aψ‖ over unit ψ. It bounds the worst-case effect of an error operator.

Read the explanation →
Optimal simulation

Hamiltonian simulation using O(αt + log(1/ε)) block-encoding calls, matching lower bounds.

Read the explanation →
Oracle

An operation that gives access to a hidden function or input, specified by its action on basis states, such as U_f|x⟩|y⟩ = |x⟩|y ⊕ f(x)⟩. Its internal construction is not part of the query count.

Read the explanation →
Order

The smallest r > 0 with a^r ≡ 1 (mod L), defined when gcd(a, L) = 1.

Read the explanation →
Order finding

Finding the order r of a modulo L. Phase estimation of modular multiplication on the state |1⟩ samples s/r for random s.

Read the explanation →
Orthogonal states

States with zero inner product. They can be distinguished with certainty by measuring in a basis that contains them.

Read the explanation →
Overshoot

The decrease in success probability when amplification continues past the optimal number of iterations.

Read the explanation →
Parameter-shift rule

dE/dθ = [E(θ + π/2) − E(θ − π/2)]/2 for a parameter entering through a single Pauli rotation.

Read the explanation →
Parameterized circuit

A fixed gate sequence with adjustable rotation angles, producing a family of trial states.

Read the explanation →
Parity circuit

A CNOT ladder that computes the parity of several qubits into one, used to apply a phase depending on that parity and then uncomputed.

Read the explanation →
Parity constraint

With d signal calls, the implemented polynomial has the parity of d.

Read the explanation →
Pauli correction

A Pauli gate applied, depending on a measurement outcome, to remove a known byproduct and make the result deterministic.

Read the explanation →
Pauli exponential

The unitary e^{−iθP} for a Pauli string P, implemented by basis changes, a CNOT parity ladder, and one Z rotation.

Read the explanation →
Pauli frame

A classical record of Pauli byproducts that have not been physically corrected, used to reinterpret later measurement outcomes.

Read the explanation →
Pauli string

A tensor product of single-qubit operators I, X, Y, Z. Pauli strings form a basis for Hermitian matrices on n qubits.

Read the explanation →
Pebbling

A game modelling which intermediate values a reversible computation stores: a stage may be computed or uncomputed only while its predecessor is stored.

Read the explanation →
Period

The smallest shift r under which a pattern or function repeats: f(x + r) = f(x).

Read the explanation →
Phase error

The difference between an intended and an implemented phase. An error δ in every phase changes any normalized state by at most δ.

Read the explanation →
Phase estimation

The algorithm that estimates an eigenphase φ of U by applying controlled powers U^{2^j} to an eigenstate and an inverse Fourier transform to the controls.

Read the explanation →
Phase factors

The rotation angles φ₀, …, φ_d in a quantum signal processing sequence, which determine the implemented polynomial.

Read the explanation →
Phase gap

The smallest nonzero eigenphase of a quantum walk operator; for Szegedy walks it is at least 2√δ.

Read the explanation →
Phase gate

The single-qubit gate P(θ) = diag(1, e^{iθ}). Special cases are Z = P(π), S = P(π/2), and T = P(π/4).

Read the explanation →
Phase kickback

The effect by which an operation acting on a target in an eigenstate multiplies the controlling branch by the eigenvalue, moving information from the target into a relative phase.

Read the explanation →
Phase oracle

The operation |x⟩ ↦ (−1)^{f(x)}|x⟩, which records a Boolean function in signs. One query to U_f with the target in |−⟩ implements it.

Read the explanation →
Phase resolution

The grid spacing 1/2^m of phase estimation with m control qubits. The nearest grid point is obtained with probability at least 4/π².

Read the explanation →
Phase-gradient trick

Producing the phase e^{2πiv/M} by adding v modulo M into a reusable Fourier state, which kicks the phase back onto the controlling register.

Read the explanation →
Polynomial approximation

Finding a low-degree bounded polynomial close to a target function on a region; its degree is the query cost of the transformation.

Read the explanation →
Postselection

Keeping a run only when a measurement gives a chosen outcome. Its cost is the inverse success probability, or its square root with amplification.

Read the explanation →
Preparation circuit

A known unitary A with A|0ⁿ⟩ = |ψ⟩. Unlike a supplied copy of |ψ⟩, it can be inverted and controlled.

Read the explanation →
PREPARE

The circuit that loads coefficient weights √(a_j/α) into an ancilla register in the LCU construction.

Read the explanation →
Product formula

An approximation of e^{−i(A+B)t} by products of e^{−iAδ} and e^{−iBδ} over short steps δ; also called Trotterization.

Read the explanation →
Product of block encodings

Sequential application of two block encodings with separate ancillas, encoding AB/(αβ).

Read the explanation →
Product representation

The factorization of F_N|x⟩ into single-qubit states, one per output bit, each with a phase set by a binary fraction of x.

Read the explanation →
Promise

A restriction on the allowed inputs that an algorithm may assume without checking. On inputs that violate the promise, the problem places no requirement on the output.

Read the explanation →
Promise problem

A problem whose allowed inputs are restricted by a promise; behavior on other inputs is unconstrained.

Read the explanation →
QAOA

The quantum approximate optimization algorithm, alternating cost-phase layers e^{−iγC} with mixer layers e^{−iβB} and optimizing the angles.

Read the explanation →
QRAM

The unitary F_N|x⟩ = N^{−1/2} Σ_y e^{2πixy/N}|y⟩. For N = 2ⁿ it has a circuit of O(n²) gates.

Quantum singular value transformation

The framework that applies a polynomial to the singular values of a block-encoded matrix by alternating the encoding, its inverse, and projector-controlled phases.

Qubitization

Turning a Hermitian block encoding of H/α into a walk W whose eigenphases are ±arccos(λ_j/α), one two-dimensional plane per eigenvalue.

Query

One application of an oracle, whatever state it acts on, including a superposition of inputs.

Query complexity

The number of oracle queries an algorithm uses, ignoring all other operations. Lower bounds in this model hold for every algorithm with the stated access.

Query lower bound

A proof that every algorithm in a given access model needs at least a certain number of queries, such as Ω(√N) for unstructured search.

A process that moves from a vertex to a random neighbour at each step, described by a transition matrix P.

Reflection

Repeat-until-success

A circuit that applies the desired operation on one outcome and an undoable operation on another, repeated until success; exact, with a random number of attempts.

Resource estimate

A count of qubits, gates, depth, and time for a concrete instance, under stated assumptions about the gate set and error correction.

Reversible arithmetic

Arithmetic implemented as a permutation of basis states, such as modular addition, so that it can act on superpositions.

Robust phase estimation

An estimation schedule of powers and repetitions designed to bound the error even when individual outcomes are noisy.

Root of unity

A complex number ω with ω^N = 1. The N-th roots e^{2πik/N} are equally spaced on the unit circle, and their k-th powers sum to zero unless N divides k.

The inverse QFT with each qubit measured as soon as it is final and the remaining controlled rotations replaced by classically controlled single-qubit rotations.

The polynomial-time quantum algorithm for factoring (and discrete logarithms) that reduces factoring to order finding and solves order finding by phase estimation.

Shot allocation

Dividing measurements among Hamiltonian terms, optimally in proportion to |h_j|σ_j, giving variance at most λ²/R.

The statistical uncertainty in an expectation value estimated from a finite number of measurements, falling as 1/√R.

Signal operator

The one-qubit unitary W(x) = e^{iθX} with x = cos θ, whose top-left entry is the signal x.

Simon’s problem

Given a two-to-one function with f(x) = f(y) exactly when y = x ⊕ s, find s. Quantum algorithms need O(n) queries; bounded-error classical algorithms need Ω(2^{n/2}).

Singular value

A stretch factor σ_j in A|w_j⟩ = σ_j|u_j⟩, with orthonormal input and output directions. The largest equals ‖A‖.

Sparse access

Oracles that return the positions and values of the nonzero entries in each row of a sparse matrix.

Spectral decomposition

Writing a Hermitian H as Σ λ_j |v_j⟩⟨v_j| with real eigenvalues and orthonormal eigenvectors, so that functions of H act eigenvalue by eigenvalue.

Read the explanation →
Spectral filter

A bounded polynomial approximating a step function on the spectrum, used to project onto eigenvalues in a chosen range.

Spectral gap

δ = 1 − |λ₂| for a Markov chain, where λ₂ is its second-largest eigenvalue in magnitude; the classical mixing time is of order 1/δ.

Estimation error of order 1/√N from N independent repetitions, the same scaling as classical sampling.

State injection

Applying a non-Clifford gate by consuming a magic state with Clifford operations, measurement, and a conditional correction.

Stationary distribution

A probability distribution π left unchanged by one step of a Markov chain, πP = π; uniform for a symmetric chain.

Optimization using noisy estimates of the objective or gradient.

Subgroup

A subset of a group that is itself a group under the same operation, such as {0ⁿ, s} under XOR.

The factor α in a block encoding of A/α. It is at least ‖A‖, and success probabilities scale as 1/α².

Success criterion

The condition a run must satisfy to count as correct, such as exact correctness on every input or correctness with probability at least 2/3.

The probability p = sin²θ that measuring the prepared state gives a marked outcome.

Recursively constructed product formulas of any even order 2k, with error O(t^{2k+1}/r^{2k}).

The step e^{−iδA/2}e^{−iδB}e^{−iδA/2}, whose error over r steps is O(t³/r²).

The quantum walk W = R_B R_A built from two reflections determined by a Markov chain’s transition probabilities.

The single-qubit gate diag(1, e^{iπ/4}). In many fault-tolerant schemes it is far more expensive than Clifford gates, so T count is a key cost measure.

Any part of the state whose value differs between computational branches. Branches with orthogonal records cannot interfere, whether or not the record is measured.
