Coherent Computation

How can a classical calculation become a reusable coherent subroutine?

Chapter direction

Starting point: Quantum Computing: reversible embeddings, controlled gates, and uncomputation.

Anchor example: A reversible predicate evaluation whose workspace must be cleared.

This lesson includes explanations, worked examples, and problems with solutions. Advanced results whose proofs are outside the chapter are identified explicitly.

  2. 2.2 Workspace Management

2.1 Reversible Evaluation

Suppose a search procedure needs to recognize three-bit strings satisfying \(f(a,b,c)=(a\land b)\oplus c\). An ordinary program can compute the intermediate bit \(g=a\land b\), combine it with \(c\), and discard \(g\). In a quantum algorithm, that discarded bit may distinguish branches that must later interfere. We need a callable subroutine with an explicit promise about what remains after it finishes.

2.1.1 Input and output contracts

For an \(n\)-bit input \(x\) and an \(m\)-bit function value, the clean reversible contract is

\[\ket{x}\ket{y}\ket{0^w}\longmapsto\ket{x}\ket{y\oplus f(x)}\ket{0^w}.\]

Here \(y\) is the output target, \(w\) is the number of scratch qubits, and XOR acts bit by bit. The target may start in any state; the scratch register must start in zero. This condition must hold coherently, with the stated phases, for every basis input. Once it does, linearity determines its action on every superposition.

Keeping \(x\) avoids a simple obstruction. If two distinct inputs have the same function value, the proposed map \(\ket{x}\mapsto\ket{f(x)}\) would merge distinct basis states and would not be reversible. Preserving \(x\) and adding into \(y\) avoids merging: applying the clean oracle twice restores \(y\).

For the three-bit predicate, a compact implementation uses a Toffoli with controls \(a,b\) and target \(y\), followed by a CNOT from \(c\) to \(y\). These toggle \(y\) by \(ab\) and then by \(c\), producing \(y\oplus ab\oplus c\). This particular predicate needs no scratch space. We will deliberately implement it with temporary storage next, because larger calculations cannot always avoid that storage so easily.

2.1.2 Arithmetic on superpositions

A classical circuit built from reversible gates acts on every basis component with the same gate sequence. Consider incrementing a two-bit register \(\ket{b_1b_0}\), where \(b_1\) is the high bit. Apply CNOT from \(b_0\) to \(b_1\), then X on \(b_0\). The first gate flips the high bit exactly when the original low bit creates a carry; the second flips the low bit. The result is addition of one modulo four:

\[00\mapsto01,\quad01\mapsto10,\quad10\mapsto11,\quad11\mapsto00.\]

Thus \((\ket{00}+i\ket{11})/\sqrt2\) becomes \((\ket{01}+i\ket{00})/\sqrt2\). No measurement or classical branching is needed. Reversing the gate order gives the inverse, subtraction of one modulo four.

The word “modulo” specifies the overflow behavior. For an \(n\)-bit incrementer, process target bits from highest to lowest, flipping bit \(j\) if all lower original bits are one, and finally flip bit zero. Descending order preserves the lower bits until their controls have been used. This describes a family of reversible circuits, but multi-controlled gates still need a decomposition into the available elementary gates. Counting each large controlled gate as a single physical operation would hide part of the cost.

Problem. Reverse the two gates of the two-bit incrementer without changing either gate. Is the result still addition of one?

Worked solution

No. Starting with 00, X on the low bit gives 01 and the subsequent CNOT gives 11. The whole map is subtraction of one modulo four, the inverse permutation. Reversible gates can be individually self-inverse while their ordered product is not.

2.2 Workspace Management

2.2.1 Compute, use, and uncompute

Allocate two initially zero scratch bits \(g,t\). Define a computation \(C\) by three gates: Toffoli from \(a,b\) into \(g\), CNOT from \(g\) into \(t\), and CNOT from \(c\) into \(t\). Afterward \(g=ab\) and \(t=ab\oplus c=f(a,b,c)\). Use one more CNOT to add \(t\) into the external target \(y\). Then apply the three gates of \(C\) in reverse order.

For a fixed input \(x=(a,b,c)\), the register states in order \((x,g,t,y)\) are

\[\begin{aligned}\ket{x,0,0,y}&\xrightarrow{C}\ket{x,ab,f(x),y}\\&\xrightarrow{\mathrm{CNOT}_{t\to y}}\ket{x,ab,f(x),y\oplus f(x)}\\&\xrightarrow{C^{-1}}\ket{x,0,0,y\oplus f(x)}.\end{aligned}\]

The external target is not involved in the inverse, so the answer survives. The intermediate bits disappear because the retained input still contains enough information to reverse their computation. Resetting them blindly would not implement this operation.

For a concrete superposition, take \((\ket{000}+\ket{110})/\sqrt2\), with all three other registers initially zero. The two inputs have function values zero and one. Computation and copying produce

\[\frac{\ket{000}\ket0\ket0\ket0+\ket{110}\ket1\ket1\ket1}{\sqrt2}.\]

Uncomputation changes this to

\[\frac{\ket{000}\ket0\ket0\ket0+\ket{110}\ket0\ket0\ket1}{\sqrt2}.\]

Both scratch bits now factor out as zeros. The output target still distinguishes the inputs, as the contract intends. Clearing scratch space does not mean erasing the requested output.

For a phase oracle, initialize the external target in \(\ket-\). The middle CNOT then contributes \((-1)^{f(x)}\), while its target stays \(\ket-\). Uncomputation removes the intermediate records, giving

\[\sum_x\alpha_x\ket{x}\ket{00}\ket-\longmapsto\sum_x\alpha_x(-1)^{f(x)}\ket{x}\ket{00}\ket-.\]

On the concrete pair, the input becomes \((\ket{000}-\ket{110})/\sqrt2\). Now the relative sign can influence later interference without a scratch record distinguishing the branches.

The reversible strategy of retaining an output and then undoing temporary computation originates in Bennett’s Logical Reversibility of Computation (1973). The coherent version here follows by applying the same reversible circuit to superposed inputs.

Problem. Does the copying CNOT violate the impossibility of cloning an unknown quantum state?

Worked solution

On a basis value it performs \(\ket b\ket0\mapsto\ket b\ket b\). On \(\alpha\ket0+\beta\ket1\), it produces \(\alpha\ket{00}+\beta\ket{11}\), not \((\alpha\ket0+\beta\ket1)^{\otimes2}\). The target is a coherent record of a basis value, not an independent copy of an arbitrary state. In our construction the record is used before the original workspace is uncomputed.

2.2.2 Time and space tradeoffs

The drawn circuit uses six qubits, two Toffolis, and five CNOTs. Its simpler direct implementation uses four qubits, one Toffoli, and one CNOT. Both implement the same predicate contract. The longer version is useful as a construction method; it is not optimal for this predicate. Toffoli counts must themselves be translated if the chosen elementary gate set does not include Toffoli.

More generally, suppose a reversible computation \(C\) costs \(T\) gates, preserves its input, and computes an \(m\)-bit answer together with temporary data. Copying the answer into an external XOR target costs \(m\) CNOTs. Running \(C^{-1}\) costs another \(T\), giving \(2T+m\) gates for this clean construction, with the same scratch storage as \(C\) and the additional external target. This is a construction bound, not a lower bound.

Suppose instead there are two stages: first compute a temporary value \(u\), then use \(u\) to compute a final value \(v\). One choice is to retain \(u\) until everything is finished. Another is to clear \(u\) after creating \(v\), reuse its space, and reconstruct \(u\) later if reversing the second stage requires it. The latter saves storage during the intervening work but repeats gates. Dependencies determine when a value may be cleared; “free every temporary immediately” is not a coherent algorithm.

There is a second constraint. Between \(C\) and \(C^{-1}\), the use step must preserve the registers needed to reverse \(C\). Reading a computed bit as a control satisfies this condition. Arbitrarily overwriting the input or computed value generally does not.

Problem. Compute \(g=x\) with CNOT from \(x\) to a zero scratch bit, flip \(x\), then apply the same CNOT to “uncompute” \(g\). What remains?

Worked solution

The first step gives \((x,g)=(x,x)\). After the flip the pair is \((x\oplus1,x)\). The final CNOT leaves \(g=x\oplus(x\oplus1)=1\), not zero. The original computation’s input was changed, so its inverse was no longer applied to the required state.

2.3 Algorithmic Access

2.3.1 Preparation and inverse access

A reusable quantum subroutine needs more than a name and a desired output. A preparation circuit \(A\) specifies a reversible operation with \(A\ket{0^n}=\ket\psi\). If its gates are known and their inverses can be implemented, reversing their order and inverting each constructs \(A^\dagger\). It maps \(\ket\psi\) back to zero. A supplied copy of \(\ket\psi\) does not specify such a circuit.

This distinction matters in amplification. Define \(S_0=2\ket0\bra0-I\), where zero denotes the all-zero register. It leaves that basis state unchanged and negates every orthogonal basis state. Then

\[A S_0 A^\dagger=2\ket\psi\bra\psi-I.\]

To see the equality, apply the product to \(\ket\psi\): the inverse preparation maps it to zero, \(S_0\) leaves it there, and \(A\) restores it. Any state orthogonal to \(\ket\psi\) is mapped by \(A^\dagger\) to a state orthogonal to zero and is negated. This constructs a reflection using one preparation, one inverse preparation, and a zero-state phase operation. Chapter 5 will use the reflection to increase success probability.

Controlled access needs its own justification. Given a specified gate sequence, one can in principle control each gate, including any phase that becomes relative between the control branches. Merely being handed an unknown black box does not specify how to do this. We will therefore distinguish access to \(U\), \(U^\dagger\), and controlled-\(U\) in later algorithms.

2.3.2 Gate costs and output requirements

A clean output contract prevents hidden garbage; it does not guarantee a cheap computation. Charge every oracle evaluation used to compute and uncompute, the gates used to prepare an input distribution, the scratch qubits, and any repetitions needed for readout. A formula like \(2T+m\) counts gates only after specifying what counts as one gate.

Likewise, producing \(\sum_x\alpha_x\ket{x}\ket{f(x)}\) does not supply a classical table of all \(f(x)\). Measuring it yields a sample with input probability \(|\alpha_x|^2\). Such a state is useful if the next coherent operation can extract a property from it; its usefulness is not the same as printing every component.

Problem. In the six-wire circuit, omit the inverse computation, use target \(\ket-\), and prepare the input \((\ket{000}+\ket{110})/\sqrt2\). Why can discarding the scratch bits not reproduce a clean phase oracle?

Worked solution

Before cleanup the state is \((\ket{000}\ket{00}-\ket{110}\ket{11})\ket-/\sqrt2\). A later input-only operation cannot make amplitudes with distinct scratch states cancel. Ignoring those states gives the same input statistics as an equal mixture of the two basis inputs, rather than the coherent signed superposition. For an explicit test, apply CNOT from the first input bit to the second, then a Hadamard on the first. The clean signed superposition becomes \(\ket{100}\) deterministically. With the distinguishing scratch record retained or discarded, the first-bit result is instead a fair coin.

We now have a concrete method for evaluating a function coherently and restoring its temporary storage. When the retained effect is a sign, the computation becomes a phase encoding. The next chapter uses that encoding to recover a hidden string and makes precise how a small interference example extends to arbitrary input length.
