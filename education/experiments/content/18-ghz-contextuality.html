18.1 The question and the apparatus

Prepare three qubits in |GHZ⟩=(|000⟩+|111⟩)/√2 and let each station choose X or Y. Rather than estimate a smooth correlation curve, focus on products of three outcomes. Quantum theory predicts certain products for selected triples of settings. Those certainties conflict with a single assignment of all six local values.

A second construction, the Peres–Mermin square, uses compatible observables arranged into rows and columns. Each observable appears in two contexts. Its purpose is to test the assumption that its assigned value is independent of which compatible companions are measured. Spatial separation and measurement compatibility are different physical conditions.

The explorer switches between the GHZ product ledger and the square. Step through the rows of the argument. This is an animated logical calculation, not a simulated loophole-free experiment. Each displayed product must be tied to the specified quantum state or operator identity.

18.2 Build a prediction

For the chosen GHZ state, the predictions are XXX=+1, XYY=−1, YXY=−1, and YYX=−1. Suppose all local X and Y results have preassigned ±1 values independent of the other stations' choices. Multiply the last three equalities: each Y value appears twice and cancels, leaving XXX=−1, contradicting the first prediction.

For the square use rows (XI, IX, XX), (IY, YI, YY), and (XY, YX, ZZ), with tensor products implied. Each row contains commuting observables and has product +I. The first two columns also have product +I, while the last column has product −I. These are operator identities, independent of the state.

A context-independent assignment respecting these product relations is impossible: multiplying all six row and column constraints gives +1 from each value appearing twice, but −1 from the prescribed products. The inference uses compatibility and functional consistency. It does not merely say that all unperformed questions are meaningless.

18.3 What the evidence can establish

Ideal certainty proofs become statistical tests when there is noise. For GHZ, the Mermin combination M=⟨XXX⟩−⟨XYY⟩−⟨YXY⟩−⟨YYX⟩ is four ideally, while deterministic local assignments have |M|≤2. A visibility model scales the ideal correlations, giving a violation only above the corresponding threshold.

Contextuality experiments must check compatibility and disturbance. Measuring purportedly compatible observables with different apparatus implementations can introduce a context dependence unrelated to the intended theorem. The operational version of a noncontextuality assumption should be stated before interpreting a violation.

These examples sharpen the distinction between a mathematical contradiction in an assignment scheme and a contradiction in quantum predictions. Quantum theory consistently computes each compatible measurement context. The conflict comes from demanding one joint classical value table satisfying every constraint.

Explore the experiment

Switch between GHZ and the Peres–Mermin square. Step through each constraint and multiply the signs by hand. Identify which values occur twice and which product carries the negative sign.

A worked example

If every ideal GHZ correlation is reduced by visibility v, when does the Mermin expression exceed two?

M=4v, so a violation requires v>1/2 in this specific white-noise-style scaling model. At v=1/2 it reaches the bound; experimental uncertainty still matters.

Try it yourself

Problem 18.1

Why do the Y values disappear in the GHZ multiplication?

Hint

Each takes a value ±1.

Worked solution

Every local Y value appears twice, and (±1)²=1.

Problem 18.2

Does the Peres–Mermin square require a special entangled input state?

Hint

Inspect whether the constraints are state expectations or operator identities.

Worked solution

The product identities hold for every state in the two-qubit space. Implementing compatible measurements remains essential.

Problem 18.3

Why is checking disturbance important in a contextuality test?

Hint

Compare the same observable in different contexts.

Worked solution

If its implementation or preceding operations change it, the measured contexts may not represent the same observable assumed in the argument.

What to carry forward

A no-go argument identifies incompatible assumptions. Real tests also need the compatibility, calibration, and statistical conditions behind the ideal algebra.
