3.1 Registers and Gates

Prepare a Bell pair and measure it. Only equal bits should appear, but that symmetric example can conceal an ordering mistake. We will add an asymmetric test before trusting the program.

3.1.1 Quantum and classical registers

Qubits carry quantum state; classical bits receive measurement records. QuantumCircuit(2) creates two quantum wires, indexed zero and one. Appending H on zero and CX(0,1) means the first is the control and the second the target. A two-qubit state here is written |q1 q0〉; the leftmost displayed ket bit is not the first Python index.

3.1.2 Gate order and circuit composition

Instructions are appended in chronological order. In a matrix product, the last applied gate appears on the left. Circuit composition appends another circuit with an explicit wire mapping. A circuit box may stand for many elementary gates; decomposition reveals its contents, while transpilation additionally adapts them to a gate set and connectivity.

Problem 3.1. Would counts containing only 00 and 11 prove entanglement?

Worked solution

No. A classical mixture of those states has the same computational-basis distribution. An XX measurement can distinguish that mixture from the ideal Bell state.

3.2 Measurement

3.2.1 Mapping qubits to classical bits

Measurement maps a selected quantum wire to a selected classical bit. measure_all() adds a register and measures every qubit, whereas measure(qubit, clbit) lets you choose the mapping. Count strings describe the classical storage, so changing that mapping changes how the result should be decoded even when the physical state is unchanged.

3.2.2 Bit strings and tensor-product ordering

Qiskit’s integer convention makes qubit zero the least significant bit. Applying X only to qubit zero gives |01〉 and state-vector index one. The label ZI acts on qubit one, while IZ acts on qubit zero. Reversing a drawing for visual convenience does not automatically reverse these mathematical conventions. The asymmetric check in the companion catches confusion that Bell-state counts cannot expose.

Problem 3.2. What state results from X on qubit one alone?

Worked solution

It is |10〉, with state-vector index two. This is the opposite single-bit position from X on qubit zero.

3.3 Circuit Inspection

3.3.1 Drawing and decomposing circuits

A text circuit drawing is available without plotting dependencies. Read its wires from left to right in time, but read a returned bit string according to its classical register ordering. Inspect gate counts and decompositions when a familiar-looking box hides arithmetic or multi-controlled gates. Visual compactness is not a resource bound.

3.3.2 Comparing code with predicted evolution

The Bell state is \((\ket{00}+\ket{11})/\sqrt2\). Ideal measurements therefore never return 01 or 10. Counts fluctuate between 00 and 11. The companion checks support, then uses X on only qubit zero to verify index order. Testing a second measurement basis would additionally distinguish a coherent Bell pair from a classical mixture.

The complete companion below can be downloaded as chapter_03.py. Run it from a terminal using the course environment. Assertions check the stated behavior; printed counts are samples, not universal expected output.

"""Runnable companion for Quantum Programming, Chapter 3."""
from qiskit import QuantumCircuit
from qiskit.primitives import StatevectorSampler
from qiskit.quantum_info import Statevector

bell = QuantumCircuit(2)
bell.h(0)
bell.cx(0, 1)
bell.measure_all()
counts = StatevectorSampler(seed=8).run([bell], shots=1024).result()[0].data.meas.get_counts()
assert set(counts) <= {"00", "11"}
# An asymmetric check is essential: a Bell state hides reversed bit order.
asymmetric = QuantumCircuit(2)
asymmetric.x(0)
assert Statevector.from_instruction(asymmetric).probabilities_dict() == {"01": 1.0}
print(bell.draw(output="text"))
print(counts)

Problem 3.3. Why include a text drawing in a runnable example?

Worked solution

It makes the appended gate order and wire targets inspectable. The numerical test still supplies the stronger check of the circuit’s action.

With the indexing fixed, we can compare circuits directly with their mathematical states and operators.

Sources and further study: IBM, bit ordering.

1. Quick check §

A three-qubit circuit applies X only to qubit 2. Predict its bit-string label and its statevector index before running it.

Hint 1

Qubit 0 is the rightmost (least significant) bit.

Hint 2

Label \(q_2q_1q_0\).

Worked solution

The label is 100 and the index is \(4\): qubit 2 is the most significant of three bits. probabilities_dict returns {'100': 1.0}. Reading labels left to right as qubits 0, 1, 2 would wrongly predict 001.

from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

circuit = QuantumCircuit(3)
circuit.x(2)
probabilities = Statevector.from_instruction(circuit).probabilities_dict()
assert abs(probabilities["100"] - 1) < 1e-12

2. Quick check §

Qubit 0 is flipped to 1, and qubit 1 is left at 0. The circuit then measures qubit 0 into classical bit 1 and qubit 1 into classical bit 0. What bit string appears in the counts?

Hint 1

Count strings are written with classical bit 0 on the right.

Hint 2

Classical bit 1 holds qubit 0’s value.

Worked solution

Classical bit 1 receives \(1\) and classical bit 0 receives \(0\), and count strings list classical bits from highest to lowest, so every shot gives 10. The physical state is the same \(\ket{q_1q_0}=\ket{01}\) as without the swapped mapping; only the storage changed. Decoding counts requires knowing the measurement map.

from qiskit import QuantumCircuit
from qiskit.primitives import StatevectorSampler

circuit = QuantumCircuit(2, 2)
circuit.x(0)
circuit.measure(0, 1)
circuit.measure(1, 0)
counts = StatevectorSampler(seed=1).run([circuit], shots=10).result()[0].data.c.get_counts()
assert counts == {"10": 10}

3. Quick check §

For the state prepared by X on qubit 0 of two qubits, predict the expectation values of the Pauli labels ZI and IZ.

Hint 1

The rightmost character acts on qubit 0.

Hint 2

\(\langle Z\rangle=+1\) on \(\ket0\) and \(-1\) on \(\ket1\).

Worked solution

ZI acts with \(Z\) on qubit 1, which is \(\ket0\): expectation \(+1\). IZ acts on qubit 0, which is \(\ket1\): expectation \(-1\). Swapping the two predictions is the typical symptom of reading Pauli labels in the wrong order.

import numpy as np
from qiskit.quantum_info import Statevector, SparsePauliOp

state = Statevector.from_label("01")
assert np.isclose(state.expectation_value(SparsePauliOp("ZI")), 1)
assert np.isclose(state.expectation_value(SparsePauliOp("IZ")), -1)

4. Worked problem §

A Bell-pair subcircuit (H on its qubit 0, CX from 0 to 1) should be placed on qubits 2 and 0 of a three-qubit circuit. A student writes the code below and finds that big has no instructions. (a) Why? (b) Fix it. (c) Predict the resulting state’s labels.

from qiskit import QuantumCircuit

sub = QuantumCircuit(2)
sub.h(0)
sub.cx(0, 1)
big = QuantumCircuit(3)
big.compose(sub, qubits=[2, 0])
print(big.size())
Hint 1

compose returns a new circuit unless told otherwise.

Hint 2

qubits=[2, 0] maps subcircuit qubit 0 to qubit 2 and qubit 1 to qubit 0.

Worked solution

(a) compose returns a new circuit and leaves big unchanged unless inplace=True is given; the returned circuit was discarded. (b) Assign the result (or pass inplace=True). (c) The mapping puts H on qubit 2 and a CX from qubit 2 to qubit 0, entangling those two while qubit 1 stays \(\ket0\): the labels are 000 and 101, each with probability \(\frac12\).

from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

sub = QuantumCircuit(2)
sub.h(0)
sub.cx(0, 1)
big = QuantumCircuit(3).compose(sub, qubits=[2, 0])
probabilities = Statevector.from_instruction(big).probabilities_dict()
assert abs(probabilities["000"] - 0.5) < 1e-12 and abs(probabilities["101"] - 0.5) < 1e-12

5. Worked problem §

A Toffoli gate is drawn as one box. Decompose it once and count the resulting instructions. What does the count suggest about judging circuit cost from a drawing?

Hint 1

Use circuit.decompose() and count_ops().

Hint 2

Count the CNOTs and the \(T\)-type gates.

Worked solution

One level of decomposition gives \(6\) CNOTs, \(4\) \(T\) gates, \(3\) \(T^\dagger\) gates, and \(2\) Hadamards: fifteen elementary instructions for one drawn box. On fault-tolerant hardware the seven \(T\)-type gates dominate the cost. A compact drawing says nothing about resources; counts must be taken after decomposition, ideally after transpiling to the target gate set.

from qiskit import QuantumCircuit

toffoli = QuantumCircuit(3)
toffoli.ccx(0, 1, 2)
counts = dict(toffoli.decompose().count_ops())
assert counts == {"cx": 6, "t": 4, "tdg": 3, "h": 2}

6. Worked problem §

Counts of only 00 and 11 do not distinguish a Bell state from a classical mixture of \(\ket{00}\) and \(\ket{11}\). Write a check that does: apply H to both qubits before measuring, and compute the exact outcome probabilities for both preparations, using DensityMatrix for the mixture.

Hint 1

For the Bell state, \((H\otimes H)\ket{\Phi^+}=\ket{\Phi^+}\).

Hint 2

DensityMatrix.evolve applies a circuit to a mixed state.

Worked solution

After \(H\otimes H\), the Bell state still gives only 00 and 11, each with probability \(\frac12\), while the mixture gives all four outcomes with probability \(\frac14\). Exact probabilities make the test deterministic; in an experiment, the same comparison is made with sampled counts and a tolerance. Checking a second basis is what certifies coherence.

import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector, DensityMatrix

bell = QuantumCircuit(2)
bell.h(0)
bell.cx(0, 1)
bell.h([0, 1])
bell_probs = Statevector.from_instruction(bell).probabilities_dict()
assert np.isclose(bell_probs["00"], 0.5) and np.isclose(bell_probs["11"], 0.5)

rotate = QuantumCircuit(2)
rotate.h([0, 1])
mixture = 0.5 * DensityMatrix.from_label("00") + 0.5 * DensityMatrix.from_label("11")
mix_probs = mixture.evolve(rotate).probabilities_dict()
assert all(np.isclose(mix_probs[label], 0.25) for label in ["00", "01", "10", "11"])

7. Worked problem §

Prepare a five-qubit GHZ state \((\ket{00000}+\ket{11111})/\sqrt2\) in two ways: a chain of CNOTs \(0\to1\to2\to3\to4\), and a tree in which qubit 0 controls 1 and 2, then qubit 1 controls 3 while qubit 0 controls 4. Compare their depths and verify that the states agree.

Hint 1

Gates on disjoint qubits can share a layer.

Hint 2

Compare circuit.depth() and Statevector equivalence.

Worked solution

The chain has depth \(5\) (H plus four sequential CNOTs); the tree has depth \(4\), because the CNOTs \(0\to2\) and \(1\to3\) run in the same layer. Both prepare the same state. For \(n\) qubits a tree needs depth about \(1+\lceil\log_2n\rceil\), against \(n\) for a chain, so the same mathematical state can be much shallower, an important difference when qubits decohere while waiting.

from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

chain = QuantumCircuit(5)
chain.h(0)
for k in range(4):
    chain.cx(k, k + 1)
tree = QuantumCircuit(5)
tree.h(0)
tree.cx(0, 1)
tree.cx(0, 2)
tree.cx(1, 3)
tree.cx(0, 4)
assert chain.depth() == 5 and tree.depth() == 4
assert Statevector.from_instruction(chain).equiv(Statevector.from_instruction(tree))

8. Misconception §

A student reads count strings from left to right in the same order as the wires in the text drawing, top to bottom, and concludes that 01 means “qubit 0 is 0 and qubit 1 is 1.” Show with a one-gate example that this is backwards.

Hint 1

The top wire in the drawing is qubit 0.

Hint 2

Apply X to qubit 0 and look at the label.

Worked solution

Apply X to qubit 0 only: the label is 01. The rightmost character is qubit 0, which is \(1\); the leftmost is qubit 1, which is \(0\). The drawing lists qubit 0 at the top, but the bit string lists it last, following the integer convention in which qubit 0 is the least significant bit. Every analysis that maps strings back to qubits must use this rule, or reverse the order explicitly.

from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

circuit = QuantumCircuit(2)
circuit.x(0)
assert Statevector.from_instruction(circuit).probabilities_dict() == {"01": 1.0}

9. Extension §

Some textbooks write the first qubit leftmost. Use Statevector.reverse_qargs() to convert the state of X on qubit 0 into that convention, and explain when such a conversion is appropriate and when it hides a bug.

Hint 1

reverse_qargs reverses the order of subsystems.

Hint 2

Convert once, at a clearly marked boundary.

Worked solution

In Qiskit’s convention the state is labelled 01; after reverse_qargs() it is labelled 10, matching a convention in which qubit 0 is written first. Converting is appropriate at a single, documented boundary, for example when comparing with a formula from a paper. Scattering conversions through a program, or reversing to make a failing test pass without understanding why, can mask a genuine wiring or measurement-map error.

from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

circuit = QuantumCircuit(2)
circuit.x(0)
state = Statevector.from_instruction(circuit)
assert state.probabilities_dict() == {"01": 1.0}
assert state.reverse_qargs().probabilities_dict() == {"10": 1.0}

10. Extension §

A circuit has two classical registers: a (one bit) measuring qubit 0, and b (two bits) measuring qubits 1 and 2. Qubit 1 is flipped. Predict the counts stored for each register and the combined string returned by join_data(). Why is it safer to read registers by name?

Hint 1

Each register is reported separately, with its own bit order.

Hint 2

In the joined string, the register added later appears on the left.

Worked solution

Register a reports 0 (qubit 0 is \(\ket0\)). Register b reports 01: its bit 0 holds qubit 1 (\(1\)) and its bit 1 holds qubit 2 (\(0\)). join_data() concatenates the registers, here as 010, with b on the left because it was added after a. Reading registers by name avoids depending on concatenation order, which changes if the circuit is built differently.

from qiskit import QuantumCircuit, QuantumRegister, ClassicalRegister
from qiskit.primitives import StatevectorSampler

q = QuantumRegister(3)
a = ClassicalRegister(1, "a")
b = ClassicalRegister(2, "b")
circuit = QuantumCircuit(q, a, b)
circuit.x(1)
circuit.measure(0, a[0])
circuit.measure([1, 2], b)
result = StatevectorSampler(seed=1).run([circuit], shots=5).result()[0]
assert result.data.a.get_counts() == {"0": 5}
assert result.data.b.get_counts() == {"01": 5}
assert result.join_data().get_counts() == {"010": 5}
