Starting point: Earlier programming chapters; relevant constructions from Quantum Computing and Quantum Algorithms.

Anchor example: Implement teleportation with measurement-dependent corrections.

This lesson includes explanations, worked examples, and problems with solutions. Advanced results whose proofs are outside the chapter are identified explicitly.

12.1 Mid-Circuit Operations

Teleportation is a demanding program test because every measurement branch must recover the same input state. Averaging only the easiest branch would hide a broken correction rule.

12.1.1 Measurement and reset

A mid-circuit measurement writes a classical bit while other quantum wires remain available. Reset prepares a wire in zero but can destroy its previous correlations. These are physical operations, not Python variable assignments. The reference StatevectorSampler is intended for suitable final-measurement workloads; the companion uses Aer for measurement-conditioned circuit execution.

12.1.2 Classical conditions and feedback

The with circuit.if_test((bit,1)) context appends an operation conditioned on a classical record. A host-language if cannot inspect the result of an unexecuted circuit. The condition refers to a classical bit or register, so use the exact object and encoding intended by the measurement map.

Problem 12.1. Why apply Z controlled by c0 rather than c1?

Worked solution

The H measurement on the original input determines the phase correction. The Bell-half measurement determines the bit-flip correction. Swapping these records fails on general input states.

12.2 Conditional Programs

12.2.1 Teleportation

The example places the input on q0, Alice’s Bell half on q1, and Bob’s on q2. After CX(0,1) and H(0), Alice measures q0 into c0 and q1 into c1. Bob applies X when c1 is one and then Z when c0 is one. These corrections invert the branch operator X^c1 Z^c0 up to an irrelevant branch phase.

12.2.2 Iterative procedures

For a known test input prepared by Ry(0.7) then Rz(0.4), apply its inverse on Bob after correction. Measuring Bob should then give zero in every branch. This verifies a state with nontrivial amplitudes and relative phase. Repeat with other preparations or an entangled reference for stronger channel validation; one test state is not complete process tomography.

Problem 12.2. Does Bob receive the state before Alice communicates her outcomes?

Worked solution

Without the records his state is averaged over the four Pauli branches. The corrections require those classical bits, so the protocol does not signal instantly.

12.3 Execution Constraints

12.3.1 Simulator and backend capabilities

A simulator accepting if_test does not prove a selected device supports the same dynamic circuit. Check backend capabilities, supported conditions, reset behavior, and timing constraints before submission. The companion runs locally and does not imply hardware availability. A controller’s limited classical expressions may require rewriting a high-level condition.

12.3.2 Latency, branches, and correctness

Feedback can save qubits or coherent depth, but adds measurement and classical latency. In the counts below, bit strings are c2 c1 c0; c2 is the final verification result and must be zero. The lower two bits vary because Alice’s Bell measurement is random. We assert correctness of every observed branch, not only the aggregate fraction of convenient outcomes.

The complete companion below can be downloaded as chapter_12.py. Run it from a terminal using the course environment. Assertions check the stated behavior; printed counts are samples, not universal expected output.

"""Runnable companion for Quantum Programming, Chapter 12."""
from qiskit_aer import AerSimulator
from qiskit import QuantumCircuit, transpile

# q0=input, q1=Alice's half, q2=Bob's half; c0,c1 are correction records.
qc = QuantumCircuit(3, 3)
qc.ry(0.7, 0); qc.rz(0.4, 0)
qc.h(1); qc.cx(1, 2)
qc.cx(0, 1); qc.h(0)
qc.measure(0, 0); qc.measure(1, 1)
with qc.if_test((qc.clbits[1], 1)):
    qc.x(2)
with qc.if_test((qc.clbits[0], 1)):
    qc.z(2)
# Inverse of the known test preparation verifies the recovered state.
qc.rz(-0.4, 2); qc.ry(-0.7, 2)
qc.measure(2, 2)
sim = AerSimulator(seed_simulator=23, max_parallel_threads=1)
counts = sim.run(transpile(qc, sim), shots=1024).result().get_counts()
assert all(key[0] == "0" for key in counts)
print("c2 c1 c0:", counts)

Problem 12.3. Why test a nontrivial phase as well as real amplitudes?

Worked solution

A missing Z correction may be invisible on a basis state. A phase-sensitive input exposes that error.

Correct dynamic logic can still fail under noise. The next chapter separates noise models from sampling and approximation.
