15.1 Hamiltonian Simulation

Advanced circuit boxes often hide two separate issues: how accurately they implement a target transformation, and how often a selected auxiliary outcome occurs. We will expose both with small matrices.

15.1.1 Product-formula circuits

For H=X+Z and time one, alternate Rz(2/r) then Rx(2/r), repeated r times. Since Rz(θ)=exp(−iθZ/2), this realizes (exp(−iX/r)exp(−iZ/r))^r. Compare its operator with exp(−i(X+Z)), computed classically only for this small verification instance. The gate order is chosen deliberately to match the formula.

15.1.2 Time and approximation error

The first-order norm bound is at most 1/r for this example. The companion checks r=10,20,40 against that bound. It reports approximation error separately from sampling and hardware noise. Increasing r reduces the formula error but adds gates, so on hardware the best r can be finite rather than as large as possible.

Problem 15.1. Why is the rotation angle 2/r rather than 1/r?

Worked solution

Qiskit’s Pauli rotation convention has a factor one half in the exponential. Using 1/r would simulate half the intended term strength.

15.2 Operator Embeddings

15.2.1 Ancillas and normalization

A block encoding of A/α places that transformation in the zero-ancilla block of a unitary. The scale α and ancilla count are part of the interface. Successful projection produces A|ψ〉/α before normalization. A matrix entry check verifies the encoding, while a state-specific probability check tells how expensive selection will be.

15.2.2 Linear combinations of unitaries

For A=(I+X)/2, use an auxiliary H, controlled-X, then H. In the companion, auxiliary q1 is the high bit, so the selected block is the top-left two-by-two block. Reversing the ancilla and system indices changes which matrix slice is correct. Randomly choosing I or X would not implement this coherent sum.

Problem 15.2. What is the success probability of the LCU example on system zero?

Worked solution

The selected vector is (|0〉+|1〉)/2, with squared norm one half. The normalized conditional state is plus.

15.3 Polynomial Transformations

15.3.1 Phase sequences

Signal processing alternates an encoded signal with phase rotations. Fix the sign convention, ordering, selected auxiliary block, and admissible polynomial before importing a phase list. For the scalar signal W(x)=xI+i√(1−x²)X, two calls give response 2x²−1. Repeating a block encoding does not generally square its selected block, because unselected amplitudes can return.

15.3.2 Verification and compilation costs

Validate a candidate polynomial at sample points and at its promised interval boundaries, then test the matrix action on small encoded examples. Sampling is not a proof of a uniform approximation bound, which must come from the construction. Charge encoding calls, normalization, success amplification, phase synthesis, and compilation. The companion verifies product formulas and the basic LCU block used by those more advanced constructions.

The complete companion below can be downloaded as chapter_15.py. Run it from a terminal using the course environment. Assertions check the stated behavior; printed counts are samples, not universal expected output.

"""Runnable companion for Quantum Programming, Chapter 15."""
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Operator
from scipy.linalg import expm

X = np.array([[0, 1], [1, 0]])
Z = np.diag([1, -1])
errors = []
for steps in (10, 20, 40):
    qc = QuantumCircuit(1)
    for _ in range(steps):
        qc.rz(2/steps, 0)
        qc.rx(2/steps, 0)
    error = np.linalg.norm(Operator(qc).data - expm(-1j*(X+Z)), 2)
    assert error <= 1/steps + 1e-12
    errors.append(error)
# An LCU encoding of (I+X)/2: ancilla q1, system q0.
lcu = QuantumCircuit(2)
lcu.h(1); lcu.cx(1, 0); lcu.h(1)
assert np.allclose(Operator(lcu).data[:2, :2], (np.eye(2)+X)/2)
print("Product-formula errors:", errors)

# Verify the low-degree signal response independently of a synthesis package.
for x in np.linspace(-1, 1, 21):
    W = x*np.eye(2) + 1j*np.sqrt(max(0, 1-x*x))*X
    assert np.allclose(W.conj().T @ W, np.eye(2))
    assert np.isclose((W @ W)[0, 0], 2*x*x-1)

Problem 15.3. Why cannot a degree count alone specify total cost?

Worked solution

Each signal call may contain a large encoding circuit, and success amplification or gate synthesis adds work. The access implementation matters.
