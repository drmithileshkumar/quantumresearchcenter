5.1 Circuit Interfaces

A useful circuit fragment should behave predictably when embedded in a larger computation. Its interface must specify wire order, parameters, and workspace, just as a classical function specifies its inputs and outputs.

5.1.1 Python circuit factories

A circuit factory is a Python function returning a newly constructed circuit. The rotation factory below makes one Ry gate with a supplied angle. Fresh objects prevent one experiment’s edits from silently changing another. Returning a circuit also lets the caller decide where it is composed and when it is executed.

5.1.2 Register contracts and composition

The interface of a predicate may be “input wires first, target next, zeroed scratch last; preserve inputs and clear scratch.” Document such contracts beside the factory. compose can map the component’s wires onto selected wires of a larger circuit. A valid mathematical component on the wrong wire mapping is still a program bug.

Problem 5.1. Why return a fresh circuit instead of a shared global one?

Worked solution

Appending gates mutates circuit objects. A shared object can accumulate instructions across calls and make experiments depend on call history.

5.2 Reusable Operations

5.2.1 Custom gates and controlled gates

to_gate() packages a unitary circuit into a reusable gate, and control() constructs a controlled version when supported. Control is a mathematical construction whose decomposition can be costly. It is not equivalent to using a Python if statement. A global phase of the base operation becomes a relative phase when controlled and must be preserved.

5.2.2 Inverses and parameter binding

Parameter("theta") creates a symbolic parameter. assign_parameters binds it to a numerical value without replacing the entire circuit construction. inverse() reverses a reversible circuit; a circuit containing measurement generally has no unitary inverse. The companion composes a bound rotation with its inverse and compares the result with the identity matrix.

Problem 5.2. Does U followed by U† test the intended specification?

Worked solution

It checks reversibility and the implementation of the inverse, but a wrong U can also pass. Compare with independently predicted outputs or matrices.

5.3 Workspace Contracts

5.3.1 Ancilla allocation

Ancillas are extra quantum wires, not temporary Python variables. Allocate them explicitly and state their required initial state. A borrowed qubit in an unknown state is a different resource from a clean zero ancilla. Simply stopping references to a wire does not physically erase its correlation with the data.

5.3.2 Uncomputation and cleanup checks

Check workspace restoration on coherent inputs, not just individual values. After a clean subroutine, the workspace must factor into its specified state, with the correct relative phases on the useful registers. A probability-zero error in scratch measurement is useful but does not alone certify the target action. The next oracle chapter gives a full coherent sign check.

The complete companion below can be downloaded as chapter_05.py. Run it from a terminal using the course environment. Assertions check the stated behavior; printed counts are samples, not universal expected output.

"""Runnable companion for Quantum Programming, Chapter 5."""
import numpy as np
from qiskit import QuantumCircuit
from qiskit.circuit import Parameter
from qiskit.quantum_info import Operator

angle = Parameter("theta")
def rotation(theta):
    qc = QuantumCircuit(1, name="rotation")
    qc.ry(theta, 0)
    return qc

component = rotation(angle)
bound = component.assign_parameters({angle: 0.7})
identity = bound.compose(bound.inverse())
assert np.allclose(Operator(identity).data, np.eye(2))
controlled = bound.to_gate().control(1)
qc = QuantumCircuit(2)
qc.append(controlled, [0, 1])
print(qc.draw(output="text"))

Problem 5.3. Can a symbolic circuit be sampled before all necessary parameters are bound?

Worked solution

Only if parameter values are supplied through a supported execution interface. Otherwise its numerical evolution is unspecified and execution should reject it.

Reusable parameterized circuits become numerical experiments through sampling and estimation primitives.
