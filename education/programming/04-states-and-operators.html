4.1 State Representations

A simulator can show the state hidden inside a circuit. Used carefully, this is a debugging instrument: it lets us compare the program with the predicted mathematical action before introducing sampling or hardware noise.

4.1.1 State vectors and density matrices

A state vector lists complex amplitudes in a fixed basis. A density matrix also describes uncertainty and subsystems: for a pure vector ψ it is ψψ†, while a mixture averages these outer products. Statevector.from_instruction evolves an initially zero register through a suitable circuit. DensityMatrix provides the more general representation. Neither is a promise that a hardware run can reveal all those numbers.

4.1.2 Composite systems and subsystem order

For a Bell pair, tracing out qubit one leaves the other in I/2. partial_trace takes the subsystem indices to discard, not the indices to keep. Its result is not the plus state even though both have fair Z measurements. The plus state has off-diagonal entries 1/2; I/2 does not. The distinction appears in an X-basis test.

Problem 4.1. What does partial_trace(state,[1]) keep for two qubits?

Worked solution

It discards subsystem one and keeps subsystem zero. Confusing the two can pass unnoticed on symmetric states.

4.2 Operators and Observables

4.2.1 Unitary operators

Operator(circuit) constructs the circuit’s matrix when the circuit has a suitable unitary description. A unitary U satisfies U†U=I, and the companion checks this numerically. Matrices grow as 4^n complex entries, so this is a small-system verification technique. An exact matrix calculation is not a scalable simulation strategy for arbitrary large circuits.

4.2.2 Pauli observables and expectation values

A Pauli observable has outcomes ±1. For the Bell state, XX and ZZ have expectation one, while ZI has expectation zero. SparsePauliOp stores sums of Pauli strings and coefficients without necessarily constructing a dense matrix. In a multi-qubit string, the rightmost character acts on qubit zero. The simulator computes an expectation directly; an experiment estimates it from repeated measurements.

Problem 4.2. Does a zero expectation of Z imply a maximally mixed state?

Worked solution

No. Plus, minus, and many other states have zero Z expectation. Additional observables are needed to determine the state.

4.3 Simulation

4.3.1 Exact evolution and sampled results

An exact expectation and a sampled mean answer different questions. The former checks ideal mathematical action; the latter models finite measurement records. A density-matrix noise simulation adds another layer. Keep all three results separately so a discrepancy can be traced to code, sampling, or the noise model rather than attributed vaguely to “quantum randomness.”

4.3.2 Simulator access versus physical measurement

The companion verifies Bell correlations, the reduced state, and unitarity. Its tolerances address floating-point arithmetic. Extend it by changing H to an Ry rotation and predicting the reduced probabilities cos²(θ/2), sin²(θ/2) before running. Off-diagonal terms remain absent locally after the entangling CNOT, even though the global state is pure.

The complete companion below can be downloaded as chapter_04.py. Run it from a terminal using the course environment. Assertions check the stated behavior; printed counts are samples, not universal expected output.

"""Runnable companion for Quantum Programming, Chapter 4."""
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector, DensityMatrix, Operator, SparsePauliOp, partial_trace

qc = QuantumCircuit(2)
qc.h(0)
qc.cx(0, 1)
state = Statevector.from_instruction(qc)
local = partial_trace(DensityMatrix(state), [1])
assert np.allclose(local.data, np.eye(2) / 2)
assert np.isclose(state.expectation_value(SparsePauliOp("XX")), 1)
assert np.isclose(state.expectation_value(SparsePauliOp("ZI")), 0)
assert np.allclose(Operator(qc).data.conj().T @ Operator(qc).data, np.eye(4))
print("Local state:", local.data)

Problem 4.3. Why avoid dense matrices in the large-instance benchmark?

Worked solution

Their classical construction may dominate the experiment exponentially. Use them as small-instance correctness checks, and report scalable resource counts separately.

1. Quick check §

Two qubits are prepared with H on qubit 0 only. Predict partial_trace(state, [1]) and partial_trace(state, [0]).

Hint 1

The second argument lists the subsystems to discard.

Hint 2

The state is \(\ket0_1\otimes\ket+_0\).

Worked solution

partial_trace(state, [1]) discards qubit 1 and keeps qubit 0, giving \(\ket+\bra+\), the matrix with all entries \(\frac12\). partial_trace(state, [0]) keeps qubit 1, giving \(\ket0\bra0\). For a product state each reduced state is pure; for the Bell state both would be \(I/2\).

import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector, partial_trace

circuit = QuantumCircuit(2)
circuit.h(0)
state = Statevector.from_instruction(circuit)
assert np.allclose(partial_trace(state, [1]).data, np.full((2, 2), 0.5))
assert np.allclose(partial_trace(state, [0]).data, np.diag([1, 0]))

2. Quick check §

Predict the Bell-state expectation values of ZZ, XX, YY, and XZ before computing them.

Hint 1

\(\ket{\Phi^+}\) is a \(+1\) eigenstate of \(ZZ\) and \(XX\).

Hint 2

\(YY=-(XX)(ZZ)\) for these two-qubit Paulis.

Worked solution

\(\langle ZZ\rangle=1\), \(\langle XX\rangle=1\), \(\langle YY\rangle=-1\), and \(\langle XZ\rangle=0\). The value of YY follows from \(Y\otimes Y=-(X\otimes X)(Z\otimes Z)\), and both factors are \(+1\) on the Bell state. Expectation values of several Paulis are a compact fingerprint of a state that can be checked exactly in simulation and estimated in experiment.

import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector, SparsePauliOp

bell = QuantumCircuit(2)
bell.h(0)
bell.cx(0, 1)
state = Statevector.from_instruction(bell)
expected = {"ZZ": 1, "XX": 1, "YY": -1, "XZ": 0}
for label, value in expected.items():
    assert np.isclose(state.expectation_value(SparsePauliOp(label)), value)

3. Quick check §

A dense operator on \(n\) qubits has \(4^n\) complex entries of \(16\) bytes each. Estimate its memory for \(n=10\) and \(n=20\). What does this imply for verifying circuits with Operator?

Hint 1

\(4^{10}\approx10^6\).

Hint 2

\(4^{20}\approx10^{12}\).

Worked solution

\(n=10\): about \(1.05\times10^6\) entries, \(17\) MB. \(n=20\): about \(1.1\times10^{12}\) entries, \(18\) TB. Operator is an excellent check for small subcircuits, a dozen qubits or so, but not a general simulation strategy; larger tests need statevectors, structured simulators, or properties checked on samples.

4. Worked problem §

Replace H by ry(\(\pi/3\)) in the chapter’s companion, followed by the same CNOT. Predict the reduced state of qubit 0 and the expectations of ZZ and XX, then verify them.

Hint 1

The state is \(\cos\frac\pi6\ket{00}+\sin\frac\pi6\ket{11}\).

Hint 2

\(\langle XX\rangle=2\cos\frac\theta2\sin\frac\theta2=\sin\theta\).

Worked solution

The state is \(\cos\frac\pi6\ket{00}+\sin\frac\pi6\ket{11}\). Qubit 0’s reduced state is \(\mathrm{diag}(0.75,0.25)\) with no off-diagonal terms. \(\langle ZZ\rangle=1\), since both terms have equal bits, and \(\langle XX\rangle=\sin\frac\pi3\approx0.866\). The reduced state alone looks like a classical mixture; the \(XX\) correlation reveals the coherent superposition.

import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector, SparsePauliOp, partial_trace

circuit = QuantumCircuit(2)
circuit.ry(np.pi / 3, 0)
circuit.cx(0, 1)
state = Statevector.from_instruction(circuit)
assert np.allclose(partial_trace(state, [1]).data, np.diag([0.75, 0.25]))
assert np.isclose(state.expectation_value(SparsePauliOp("ZZ")), 1)
assert np.isclose(state.expectation_value(SparsePauliOp("XX")), np.sin(np.pi / 3))

5. Worked problem §

Compute the purity \(\mathrm{tr}\rho^2\) of the Bell state and of its one-qubit reduced state using DensityMatrix.purity(). Interpret the two numbers.

Hint 1

A pure state has purity \(1\).

Hint 2

\(I/2\) has purity \(\frac12\).

Worked solution

The two-qubit Bell state has purity \(1\): it is pure. Its reduced state \(I/2\) has purity \(\frac12\), the minimum for a qubit. Purity is a convenient numerical check: a globally pure state whose parts are mixed must be entangled, and the purity of the parts measures how strongly.

import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector, DensityMatrix, partial_trace

bell = QuantumCircuit(2)
bell.h(0)
bell.cx(0, 1)
state = Statevector.from_instruction(bell)
assert np.isclose(DensityMatrix(state).purity(), 1)
assert np.isclose(partial_trace(state, [1]).purity(), 0.5)

6. Worked problem §

Define \(H=0.5\,ZZ-0.3\,XI\) as a SparsePauliOp. Predict its expectation value in the Bell state and in \(\ket{++}\), and verify.

Hint 1

\(XI\) acts with \(X\) on qubit 1.

Hint 2

In \(\ket{++}\), \(\langle ZZ\rangle=0\) and \(\langle XI\rangle=1\).

Worked solution

Bell state: \(\langle ZZ\rangle=1\) and \(\langle XI\rangle=0\), so \(\langle H\rangle=0.5\). For \(\ket{++}\): \(\langle ZZ\rangle=0\) and \(\langle XI\rangle=1\), so \(\langle H\rangle=-0.3\). Linear combinations of Pauli strings are evaluated term by term, which is also how an experiment estimates them, one measurement setting per group of compatible terms.

import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector, SparsePauliOp

hamiltonian = SparsePauliOp(["ZZ", "XI"], [0.5, -0.3])
bell = QuantumCircuit(2)
bell.h(0)
bell.cx(0, 1)
assert np.isclose(Statevector.from_instruction(bell).expectation_value(hamiltonian), 0.5)
assert np.isclose(Statevector.from_label("++").expectation_value(hamiltonian), -0.3)

7. Worked problem §

Verify the identity “Hadamards on the target turn CX into CZ” with Operator equivalence. Then explain why Operator.equiv, rather than exact matrix equality, is the right comparison.

Hint 1

Put H on qubit 1 before and after cx(0, 1).

Hint 2

equiv ignores a global phase and allows floating-point tolerance.

Worked solution

The circuit H on qubit 1, CX from 0 to 1, H on qubit 1 has the same operator as CZ, and Operator.equiv confirms it. equiv tests equality up to a global phase within a numerical tolerance, which is what “the same gate” means physically. Exact equality would fail on harmless phase conventions or rounding, while a relative phase error would still be caught.

from qiskit import QuantumCircuit
from qiskit.quantum_info import Operator

left = QuantumCircuit(2)
left.h(1)
left.cx(0, 1)
left.h(1)
right = QuantumCircuit(2)
right.cz(0, 1)
assert Operator(left).equiv(Operator(right))

8. Misconception §

A student calls Operator on a circuit that contains a measurement, expecting “the matrix of the circuit.” What happens, and what should they do to inspect the unitary part?

from qiskit import QuantumCircuit
from qiskit.quantum_info import Operator

circuit = QuantumCircuit(1, 1)
circuit.h(0)
circuit.measure(0, 0)
Operator(circuit)
Hint 1

A measurement is not a unitary operation.

Hint 2

remove_final_measurements(inplace=False) strips terminal measurements.

Worked solution

Qiskit raises a QiskitError, “Cannot apply operation with classical bits: measure.” A measurement has no unitary matrix. To inspect the unitary part, remove the final measurements (remove_final_measurements(inplace=False)) and build the Operator of what remains; mid-circuit measurements need a channel or instrument description, not a unitary.

9. Extension §

Estimate \(\langle ZZ\rangle\) and \(\langle XX\rangle\) for the ry(\(\pi/3\)) state from sampled counts, as an experiment would: measure directly for ZZ, and apply H to both qubits before measuring for XX. Compare with the exact values \(1\) and \(0.866\), and explain the size of the discrepancy.

Hint 1

\(\langle ZZ\rangle=(n_{00}+n_{11}-n_{01}-n_{10})/N\).

Hint 2

The statistical error is about \(\sqrt{(1-\langle P\rangle^2)/N}\).

Worked solution

With \(8192\) shots, the ZZ estimate is exactly \(1\) (only 00 and 11 occur) and the XX estimate is near \(0.866\), within about \(\sqrt{(1-0.75)/8192}\approx0.006\). The XX measurement requires a different circuit: one setting per non-commuting observable. Exact expectations check the program; sampled estimates model what an experiment reports, with an uncertainty that must be carried along.

import numpy as np
from qiskit import QuantumCircuit
from qiskit.primitives import StatevectorSampler

def parity(counts, shots):
    return (counts.get("00", 0) + counts.get("11", 0) - counts.get("01", 0) - counts.get("10", 0)) / shots

prep = QuantumCircuit(2)
prep.ry(np.pi / 3, 0)
prep.cx(0, 1)
z_basis = prep.copy()
z_basis.measure_all()
x_basis = prep.copy()
x_basis.h([0, 1])
x_basis.measure_all()
shots = 8192
results = StatevectorSampler(seed=5).run([z_basis, x_basis], shots=shots).result()
zz = parity(results[0].data.meas.get_counts(), shots)
xx = parity(results[1].data.meas.get_counts(), shots)
assert np.isclose(zz, 1) and abs(xx - np.sin(np.pi / 3)) < 0.03

10. Extension §

A statevector of \(n\) qubits needs \(2^n\) amplitudes of \(16\) bytes. (a) Estimate the memory for \(n=30\) and \(n=100\). (b) Run a \(100\)-qubit GHZ circuit with Aer’s stabilizer method and check the outcomes. (c) Why is this possible, and what is its limit?

Hint 1

\(2^{30}\times16\approx17\) GB.

Hint 2

Clifford circuits (H, S, CNOT, Paulis) can be simulated efficiently.

Worked solution

(a) \(n=30\): about \(17\) GB; \(n=100\): about \(2\times10^{31}\) bytes, impossible. (b) The stabilizer simulator runs the \(100\)-qubit GHZ circuit in a fraction of a second, and every outcome is all zeros or all ones. (c) Clifford circuits keep the state in a form described by polynomially many bits (a stabilizer tableau), so they can be simulated efficiently. Adding non-Clifford gates such as \(T\) or arbitrary rotations removes this shortcut; a simulator’s capacity depends on the circuit’s structure, not only its width.

from qiskit import QuantumCircuit
from qiskit_aer import AerSimulator

n = 100
ghz = QuantumCircuit(n)
ghz.h(0)
for k in range(n - 1):
    ghz.cx(k, k + 1)
ghz.measure_all()
counts = AerSimulator(method="stabilizer").run(ghz, shots=100, seed_simulator=1).result().get_counts()
assert set(counts) <= {"0" * n, "1" * n}
