Oracles and Arithmetic

How do we implement an oracle rather than assume it exists?

Chapter direction

Starting point: Earlier programming chapters; relevant constructions from Quantum Computing and Quantum Algorithms.

Anchor example: Construct and verify a reversible predicate and its phase-oracle form.

This lesson includes explanations, worked examples, and problems with solutions. Advanced results whose proofs are outside the chapter are identified explicitly.

  1. 7.1 Reversible Predicates
  2. 7.2 Arithmetic Circuits
  3. 7.3 Phase Oracles

7.1 Reversible Predicates

The oracle f(a,b,c)=ab XOR c is small enough to verify exhaustively and rich enough to expose the distinction between a Boolean truth table and a coherent circuit.

7.1.1 Boolean evaluation

Assign a,b,c to qubits zero, one, and two, and the answer target to qubit three. A Toffoli controlled by zero and one toggles the target by ab; CNOT from two toggles it by c. Inputs are retained and the target is XORed with f. No scratch is needed for this predicate. In a larger predicate, the compute–copy–uncompute construction supplies cleanup.

7.1.2 Answer registers and retained inputs

The full contract applies for target zero and target one. Testing only a zero target can miss an implementation that initializes or overwrites the answer irreversibly. The companion checks all sixteen basis columns against the required permutation. Basis columns with their complex phases determine the whole linear operation; basis probabilities alone do not.

Problem 7.1. What happens to an answer target initially one when f=1?

Worked solution

It becomes zero. The answer operation is XOR, not assignment.

7.2 Arithmetic Circuits

7.2.1 Addition and comparison

A two-bit incrementer applies CX from the low bit to the high bit, then X on the low bit, producing addition modulo four. A comparator can compute whether a−b borrows, retain the flag, and reverse the arithmetic. Explicitly choose modular or overflow-preserving behavior. The bit width is part of the function; it cannot be inferred from an unbounded mathematical integer.

7.2.2 Precision and workspace requirements

Fixed-point arithmetic stores a scaled integer, so changing width changes both range and precision. Extra carries, comparison flags, and temporary products require wires and cleanup. Counting only the final phase or output gate hides most of the oracle implementation. For a finite table, state preparation or memory access also needs a specified circuit.

Problem 7.2. Why test a target minus state?

Worked solution

It turns function values into relative phases and exposes phase or cleanup errors that may be invisible on measured basis inputs.

7.3 Phase Oracles

7.3.1 Compute, phase, and uncompute

Preparing the answer target in minus converts the bit oracle to a sign oracle. Every input amplitude gains (−1)^f, while the target remains minus. The companion prepares all eight inputs uniformly and compares every final complex amplitude with this prediction. This catches unwanted phases and retained records that a histogram test could miss.

7.3.2 Superposition tests and resource counts

The resource count for this implementation is one Toffoli and one CNOT, plus preparation and readout if used. A Toffoli is not native on every backend, so report both this logical count and its compiled decomposition. The circuit’s simple contract makes it usable as an independent component in search, phase encoding, or a larger arithmetic calculation.

The complete companion below can be downloaded as chapter_07.py. Run it from a terminal using the course environment. Assertions check the stated behavior; printed counts are samples, not universal expected output.

"""Runnable companion for Quantum Programming, Chapter 7."""
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Operator, Statevector

# f(a,b,c) = ab XOR c; q0=a, q1=b, q2=c, q3=target.
qc = QuantumCircuit(4)
qc.ccx(0, 1, 3)
qc.cx(2, 3)
matrix = Operator(qc).data
for index in range(16):
    a, b, c = index & 1, (index >> 1) & 1, (index >> 2) & 1
    expected = index ^ (((a & b) ^ c) << 3)
    assert np.allclose(matrix[:, index], np.eye(16)[:, expected])
# Target minus makes the same oracle a phase oracle.
prep = QuantumCircuit(4)
prep.h([0, 1, 2])
prep.x(3)
prep.h(3)
state = Statevector.from_instruction(prep.compose(qc))
expected = []
for index in range(16):
    a, b, c, target = [(index >> k) & 1 for k in range(4)]
    expected.append((-1)**((a & b) ^ c ^ target) / 4)
assert np.allclose(state.data, expected)
print("All basis columns and coherent signs verified")

Problem 7.3. Is a four-bit adder an implementation of arbitrary-precision integer addition?

Worked solution

No. Its range and overflow behavior are fixed. A scalable implementation specifies a family parameterized by width and gives its resource growth.
