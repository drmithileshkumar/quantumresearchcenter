8.1 Fourier Methods

Implement two familiar transformations and compare their matrices or output probabilities with independent formulas. Small examples are useful for debugging, but the construction must keep its conventions explicit.

8.1.1 Constructing the Fourier circuit

Our two-qubit Fourier transform uses the positive exponential exp(2πixy/4)/2. The code applies H to qubit one, a controlled π/2 phase, H to qubit zero, and a swap. The matrix assertion compares every entry with the mathematical transform. Omitting the swap changes output bit order; taking the inverse changes the exponent sign.

8.1.2 Controlled powers and phase estimation

Phase estimation prepares a control register, applies controlled powers of a chosen unitary, then inverse QFT. A power implemented by repeating U costs that many U uses. When testing, choose an eigenstate with an exactly representable phase before testing approximate phases or superpositions. Decode the control bits using the register mapping, not the visual wire order alone.

Problem 8.1. Why compare QFT matrices instead of only transforming zero?

Worked solution

Both forward and inverse Fourier transforms map zero to the same uniform state. A zero-input test misses the sign convention.

8.2 Amplitude Manipulation

8.2.1 Preparation and reflections

For four items with only 11 marked, begin uniformly and apply CZ to negate the marked amplitude. A prepared-state reflection follows. The reflection sequence used in the companion differs by a global sign from one common convention; the success probability is unaffected. This phase convention would matter if the whole iteration were later coherently controlled.

8.2.2 Search and amplification

One Grover iteration gives unit success for one marked item out of four. The companion checks probability at index three. For larger instances, choose iterations from the initial success probability or use a justified unknown-success schedule. More iterations can reduce success, so a loop that runs “until enough gates” is not an algorithm.

Problem 8.2. What happens after a second Grover iteration in the four-item example?

Worked solution

The success returns to one quarter. The rotation has passed the good direction.

8.3 Quantum Walks

8.3.1 Position and coin registers

A coined walk uses a coin register and a position register. Implement a coin rotation followed by reversible conditional increment and decrement modulo the graph size. Keep the coin: discarding its direction information after each step changes the evolution. A non-power-of-two position space also needs a policy for unused basis states so the full circuit remains unitary.

8.3.2 Implementation and classical baselines

A meaningful benchmark compares the same access and output tasks. Verify small matrices, then measure compiled gates, depth, qubits, oracle calls, and readout costs as size grows. A classical simulator runtime is a property of the simulation method, not evidence that the quantum algorithm is slow or fast on quantum hardware. The two examples below establish correctness checks, not a performance advantage.

The complete companion below can be downloaded as chapter_08.py. Run it from a terminal using the course environment. Assertions check the stated behavior; printed counts are samples, not universal expected output.

"""Runnable companion for Quantum Programming, Chapter 8."""
import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Operator, Statevector

# Positive-sign QFT on integer labels |q1 q0>.
qft = QuantumCircuit(2)
qft.h(1)
qft.cp(np.pi / 2, 0, 1)
qft.h(0)
qft.swap(0, 1)
expected = np.array([[np.exp(2j*np.pi*x*y/4)/2 for x in range(4)] for y in range(4)])
assert np.allclose(Operator(qft).data, expected)
# One Grover step for marked state |11> in four items.
search = QuantumCircuit(2)
search.h([0, 1])
search.cz(0, 1)
search.h([0, 1]); search.x([0, 1]); search.cz(0, 1)
search.x([0, 1]); search.h([0, 1])
assert np.isclose(Statevector.from_instruction(search).probabilities()[3], 1)
print(qft.draw(output="text"))

Problem 8.3. Can the position register alone generally implement a reversible coined shift?

Worked solution

The direction label is needed to distinguish the routes. Removing it without another reversible encoding can merge states and invalidate the proposed unitary.

Questions and worked problems

These exercises draw on the whole chapter. Attempt each question before opening a hint, explain your reasoning, then compare it with the worked solution.

1. Quick check §

Verify that the inverse of the chapter’s positive-sign QFT matches \(e^{-2\pi ixy/4}/2\). Why is the sign convention worth an explicit test?

Hint 1

Build the expected matrix with the negative exponent.

Hint 2

Phase estimation uses the inverse transform.

Worked solution

qft.inverse() matches the matrix with \(e^{-2\pi ixy/4}/2\). Libraries and papers differ on which sign is “the” QFT, and phase estimation needs the inverse of whichever transform produced its phase ramp. A wrong sign returns \(-\phi\) (mod \(1\)) instead of \(\phi\), an error that a test on \(\ket0\) alone would miss, because both transforms send \(\ket0\) to the uniform state.

import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Operator

qft = QuantumCircuit(2)
qft.h(1)
qft.cp(np.pi / 2, 0, 1)
qft.h(0)
qft.swap(0, 1)
inverse = np.array([[np.exp(-2j * np.pi * x * y / 4) / 2 for x in range(4)] for y in range(4)])
assert np.allclose(Operator(qft.inverse()).data, inverse)

2. Quick check §

Modify the chapter’s four-item search to mark \(01\) (qubit 0 equal to \(1\), qubit 1 equal to \(0\)) instead of \(11\). Which gates change, and what probability does the marked index reach after one iteration?

Hint 1

X gates turn the marked pattern into \(11\) for the CZ.

Hint 2

Wrap the oracle’s CZ with X on qubit 1.

Worked solution

Only the oracle changes: apply X to qubit 1, then CZ, then X to qubit 1, so the sign falls on \(\ket{01}\). The diffusion step is unchanged. After one iteration, index \(1\) has probability \(1\). Separating the oracle from the diffusion makes this change local and testable.

import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

search = QuantumCircuit(2)
search.h([0, 1])
search.x(1)
search.cz(0, 1)
search.x(1)
search.h([0, 1]); search.x([0, 1]); search.cz(0, 1)
search.x([0, 1]); search.h([0, 1])
assert np.isclose(Statevector.from_instruction(search).probabilities()[1], 1)

3. Quick check §

Remove the final swap from the two-qubit QFT. Show that the result equals the full QFT followed by an extra swap. Is the swap-free circuit wrong?

Hint 1

SWAP is its own inverse.

Hint 2

Compare operators of ns + swap with qft.

Worked solution

The swap-free circuit followed by a swap equals the full QFT, so the swap-free version computes the same transform with its output qubits in reversed order. It is not wrong if the reversal is accounted for, for example by relabeling outputs or by absorbing it into later wiring; many implementations omit the swaps to save gates. It is wrong only if downstream code assumes the standard order.

import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Operator

full = QuantumCircuit(2)
full.h(1)
full.cp(np.pi / 2, 0, 1)
full.h(0)
full.swap(0, 1)
no_swap = QuantumCircuit(2)
no_swap.h(1)
no_swap.cp(np.pi / 2, 0, 1)
no_swap.h(0)
swap = QuantumCircuit(2)
swap.swap(0, 1)
assert Operator(no_swap.compose(swap)).equiv(Operator(full))

4. Worked problem §

Implement two-bit phase estimation for \(U=P(\pi/2)\), whose eigenstate \(\ket1\) has phase \(\phi=1/4\). Controls are qubits 0 (power \(1\)) and 1 (power \(2\)); the target is qubit 2 in \(\ket1\). Apply the controlled powers as controlled phases and then the inverse of the chapter’s QFT on the controls. Predict and verify the control readout.

Hint 1

\(U^2=P(\pi)\).

Hint 2

The control register ends in \(\ket j\) with \(j=4\phi=1\).

Worked solution

Controlled-\(U\) is cp(\(\pi/2\)) from qubit 0 and controlled-\(U^2\) is cp(\(\pi\)) from qubit 1. They write \(e^{2\pi ik/4}\) onto control basis state \(\ket k\), and the inverse QFT returns \(\ket{j}\) with \(j=1\). The full label is 101 (target 1, controls 01), with probability \(1\), so \(\phi=j/4=1/4\). Testing with an exactly representable phase first isolates convention errors from rounding effects.

import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

qft = QuantumCircuit(2)
qft.h(1)
qft.cp(np.pi / 2, 0, 1)
qft.h(0)
qft.swap(0, 1)
estimate = QuantumCircuit(3)
estimate.x(2)
estimate.h([0, 1])
estimate.cp(np.pi / 2, 0, 2)
estimate.cp(np.pi, 1, 2)
estimate.compose(qft.inverse(), qubits=[0, 1], inplace=True)
assert np.isclose(Statevector.from_instruction(estimate).probabilities_dict()["101"], 1)

5. Worked problem §

Repeat phase estimation with three control qubits for a phase that is not exactly representable, \(\phi=1/3\). (a) Which outcome is most likely, and with what probability? (b) What estimate of \(\phi\) does it give? (c) How would you test this case, given that the outcome is random?

Hint 1

\(8\phi\approx2.67\), so expect \(j=3\) most often.

Hint 2

Compare the distribution with \(|a_j|^2=\sin^2(\pi M\Delta)/(M^2\sin^2\pi\Delta)\).

Worked solution

(a) The control readout \(j=3\) has probability about \(0.69\), with \(j=2\) next at about \(0.17\). (b) \(j=3\) gives \(\phi\approx3/8=0.375\), the nearest grid value to \(1/3\). (c) Compare the exact output distribution from Statevector with the analytic formula for every \(j\), rather than asserting a single outcome; in sampled runs, test that the frequency of \(j=3\) lies within a tolerance of \(0.69\).

import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

def inverse_qft(n):
    circuit = QuantumCircuit(n)
    for j in range(n // 2):
        circuit.swap(j, n - 1 - j)
    for j in range(n):
        for k in range(j):
            circuit.cp(-np.pi / 2 ** (j - k), k, j)
        circuit.h(j)
    return circuit

phi, m = 1 / 3, 3
circuit = QuantumCircuit(m + 1)
circuit.x(m)
circuit.h(range(m))
for j in range(m):
    circuit.cp(2 * np.pi * phi * 2 ** j, j, m)
circuit.compose(inverse_qft(m), qubits=range(m), inplace=True)
probabilities = Statevector.from_instruction(circuit).probabilities_dict(qargs=list(range(m)))
M = 2 ** m
for j in range(M):
    delta = phi - j / M
    analytic = np.sin(np.pi * M * delta) ** 2 / (M ** 2 * np.sin(np.pi * delta) ** 2)
    assert np.isclose(probabilities.get(format(j, "03b"), 0), analytic)
assert max(probabilities, key=probabilities.get) == "011"

6. Worked problem §

Implement a coined walk on a four-cycle: qubit 0 is the coin, qubits 1 and 2 hold the position (low bit on qubit 1). Each step applies H to the coin, increments the position if the coin is \(1\), and decrements it if the coin is \(0\). Starting from coin \(0\) at position \(0\), predict the position distribution after three steps and verify it.

Hint 1

A controlled two-bit incrementer is ccx(coin, p0, p1) followed by cx(coin, p0).

Hint 2

Decrement is the inverse of increment, controlled on coin \(0\) (wrap the controls with X).

Worked solution

After three steps the walker is at position \(3\) with certainty: interference cancels every route to position \(1\). The controlled increment is ccx(0, 1, 2), cx(0, 1); the decrement controlled on coin \(0\) is X on the coin, then cx(0, 1), ccx(0, 1, 2), then X on the coin. A classical random walk would be at position \(1\) or \(3\) with probability \(\frac12\) each; the coin register must be kept, not measured, for the interference to occur.

import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

def step(circuit):
    circuit.h(0)
    circuit.ccx(0, 1, 2)   # increment when coin is 1
    circuit.cx(0, 1)
    circuit.x(0)           # decrement when coin is 0
    circuit.cx(0, 1)
    circuit.ccx(0, 1, 2)
    circuit.x(0)

walk = QuantumCircuit(3)
for _ in range(3):
    step(walk)
positions = Statevector.from_instruction(walk).probabilities_dict(qargs=[1, 2])
assert np.isclose(positions["11"], 1)

7. Worked problem §

Implement Grover search for one marked item, \(111\), among eight. Use H, Toffoli, H on qubit 2 as the controlled-controlled-Z oracle, and the standard diffusion. Compute the success probability after \(0,1,2,3\) iterations and compare with \(\sin^2((2k+1)\theta)\), \(\sin\theta=1/\sqrt8\).

Hint 1

The best number of iterations is \(2\).

Hint 2

Diffusion: H on all, X on all, controlled-controlled-Z, X on all, H on all.

Worked solution

The success probabilities are \(0.125\), \(0.781\), \(0.945\), and \(0.330\) for \(k=0,1,2,3\), exactly \(\sin^2((2k+1)\theta)\). The third iteration overshoots. The test compares each value with the formula, which checks both the oracle and the diffusion, and documents why the iteration count is a parameter derived from \(N\), not a loop that runs until some budget is exhausted.

import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Statevector

def ccz(circuit):
    circuit.h(2)
    circuit.ccx(0, 1, 2)
    circuit.h(2)

def grover(iterations):
    circuit = QuantumCircuit(3)
    circuit.h([0, 1, 2])
    for _ in range(iterations):
        ccz(circuit)
        circuit.h([0, 1, 2]); circuit.x([0, 1, 2])
        ccz(circuit)
        circuit.x([0, 1, 2]); circuit.h([0, 1, 2])
    return Statevector.from_instruction(circuit).probabilities()[7]

theta = np.arcsin(1 / np.sqrt(8))
for k in range(4):
    assert np.isclose(grover(k), np.sin((2 * k + 1) * theta) ** 2)

8. Misconception §

A student tests a QFT implementation only on the input \(\ket{00}\), checks that the output is the uniform superposition, and declares it correct. Construct a wrong circuit that passes this test, and state a test that would catch it.

Hint 1

Any circuit that applies H to each qubit sends \(\ket{00}\) to the uniform state.

Hint 2

Compare full operators, or test several inputs with phases.

Worked solution

\(H\otimes H\) alone sends \(\ket{00}\) to the uniform superposition, exactly like the QFT, and so does the inverse QFT. All three differ on other inputs; for example the QFT and \(H\otimes H\) give different phases on \(\ket{01}\). A correct test compares the full operator with the defining matrix (as the chapter does), or checks every basis input including relative phases. A single input exercises only one column of the matrix.

import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Operator, Statevector

hh = QuantumCircuit(2)
hh.h([0, 1])
assert Statevector.from_instruction(hh).equiv(Statevector([0.5, 0.5, 0.5, 0.5]))
qft_matrix = np.array([[np.exp(2j * np.pi * x * y / 4) / 2 for x in range(4)] for y in range(4)])
assert not np.allclose(Operator(hh).data, qft_matrix)

9. Extension §

Build a four-qubit positive-sign QFT and an approximate version that omits the smallest controlled phase, cp(\(\pi/8\)). (a) Compute the operator-norm distance between them. (b) Compare it with the bound \(|e^{i\pi/8}-1|\). (c) How does this scale to large registers?

Hint 1

A controlled phase differs from the identity by \(e^{i\theta}-1\) on one basis state.

Hint 2

Use numpy’s matrix 2-norm of the difference.

Worked solution

(a) The distance is about \(0.390\). (b) That equals \(|e^{i\pi/8}-1|\approx0.390\): removing one controlled phase changes the circuit by exactly that gate’s deviation from the identity, because unitaries before and after it preserve norms. (c) Dropping every rotation smaller than \(2\pi/2^b\) gives total error below about \(2\pi n/2^b\) with only \(O(n\log n)\) gates, the approximate QFT of Quantum Algorithms; omitting larger angles, as here, gives a large error.

import numpy as np
from qiskit import QuantumCircuit
from qiskit.quantum_info import Operator

def inverse_qft(n):
    circuit = QuantumCircuit(n)
    for j in range(n // 2):
        circuit.swap(j, n - 1 - j)
    for j in range(n):
        for k in range(j):
            circuit.cp(-np.pi / 2 ** (j - k), k, j)
        circuit.h(j)
    return circuit

exact = inverse_qft(4).inverse()
approximate = QuantumCircuit(4)
for instruction in exact.data:
    if instruction.operation.name == "cp" and np.isclose(abs(float(instruction.operation.params[0])), np.pi / 8):
        continue
    approximate.append(instruction)
distance = np.linalg.norm(Operator(exact).data - Operator(approximate).data, 2)
assert np.isclose(distance, abs(np.exp(1j * np.pi / 8) - 1))

10. Extension §

In phase estimation with \(m\) control qubits, controlled-\(U^{2^j}\) built by repetition needs \(2^j\) uses of controlled-\(U\). (a) Count the total uses for \(m=3\) and \(m=10\). (b) For \(U=P(\lambda)\), what shortcut implements \(U^{2^j}\) at the cost of one gate? (c) Why does a benchmark of phase estimation need to state which of these was used?

Hint 1

Total \(2^m-1\).

Hint 2

\(P(\lambda)^k=P(k\lambda)\).

Worked solution

(a) \(m=3\): \(7\) uses; \(m=10\): \(1023\). (b) \(P(\lambda)^{2^j}=P(2^j\lambda)\), a single controlled phase, which is why the worked problems used cp(\(2^j\lambda\)) directly. (c) With repetition, the circuit grows exponentially in the number of bits of precision; with a shortcut, linearly. Modular multiplication in Shor’s algorithm has such a shortcut, while general Hamiltonian evolution does not. A runtime or gate count is meaningless without saying which construction was used.
