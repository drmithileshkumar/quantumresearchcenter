2.1 Python and Environments

A first program should have a result we can predict without the computer. Starting from zero, H makes equal amplitudes; measurement should give a fair coin. We will separate that prediction from random fluctuations in a finite run.

2.1.1 Python through circuit examples

In circuit = QuantumCircuit(1), assignment binds a Python name to a one-qubit circuit. A method call such as circuit.h(0) appends an instruction on qubit index zero. Parentheses supply arguments; indentation groups statements in functions and loops. A dictionary such as counts maps a measured bit string to the number of times it occurred. The program below uses these features only where the experiment needs them.

2.1.2 Packages, versions, and isolated environments

Create an isolated environment rather than mixing course dependencies with unrelated projects. From the repository root, run the commands below. The requirements file pins the versions tested for this edition; the full environment lock records transitive packages. Use the accompanying TESTING.md for the tested Python version and platform notes.

Problem 2.1. Why should a fair coin not be tested by demanding exactly 2048 ones?

Worked solution

Even an ideal fair source fluctuates. Exact equality would reject many correct executions. Test a distribution with a justified tolerance and test the unitary separately.

2.2 The Qiskit Ecosystem

2.2.1 SDK, Aer, and Runtime

The Qiskit SDK supplies circuit construction, quantum-information objects, transpilation, and reference primitives. Aer is a separate simulation package with noise models and additional simulation methods. IBM Runtime supplies remote execution services and associated primitives. Local examples need no cloud token; importing a remote client is not the same as submitting a job.

2.2.2 Notebooks and executable scripts

A script executes from top to bottom in a fresh process. A notebook can retain variables from earlier cells, making a seemingly reproducible result depend on hidden execution order. Restart and run all cells when using notebooks, and keep the tested experiment in a script. Record versions, seeds, parameters, and shots; a seed fixes a particular pseudorandom experiment only within its implementation context.

Problem 2.2. What does changing the seed change?

Worked solution

It changes the pseudorandom shot sequence, not the ideal quantum probability. A changed probability indicates a different circuit, model, or execution setting.

2.3 A First Program

2.3.1 Build, run, and inspect

The example creates H|0〉, adds measurement with measure_all(), and passes the resulting circuit to StatevectorSampler. The primitive returns a job; result()[0] selects its first workload result. The automatically created classical register is named meas, so data.meas.get_counts() returns its counts. The simulator internally computes amplitudes, but the requested result is a sampled classical record.

2.3.2 Predictions and reproducible results

For R=4096 fair-coin shots, the expected count of one is 2048 and the standard deviation of its frequency is \(1/(2\sqrt R)=1/128\). The assertion allows a much wider interval than that fluctuation. It checks a plausible distribution and total shot count, not an exact random sequence. A fixed seed helps regression testing, but a single passing sample is not a proof that H is correct.

The complete companion below can be downloaded as chapter_02.py. Run it from a terminal using the course environment. Assertions check the stated behavior; printed counts are samples, not universal expected output.

"""Runnable companion for Quantum Programming, Chapter 2."""
import sys
from importlib.metadata import version
from qiskit import QuantumCircuit
from qiskit.primitives import StatevectorSampler

circuit = QuantumCircuit(1)
circuit.h(0)
circuit.measure_all()
counts = StatevectorSampler(seed=7).run([circuit], shots=4096).result()[0].data.meas.get_counts()
assert sum(counts.values()) == 4096
assert abs(counts.get("1", 0) / 4096 - 0.5) < 0.05
print("Python", sys.version.split()[0], "Qiskit", version("qiskit"))
print(counts)

Problem 2.3. Where are amplitudes measured in this example?

Worked solution

They are not physically measured. The reference simulator computes them classically to generate samples. Hardware can provide measurement outcomes, not its complete internal state vector.
